Talk 109 · University of Naples Federico II

Fabio Giampaolo: Learning Paradigms for Neural Networks: The Locally Backpropagated Forward-Forward Algorithm

This lecture explores an alternative neural-network training paradigm that combines local backpropagation with Hinton's forward-forward idea.

YouTube source · Talk page

Core Problem

Backpropagation is effective but can be awkward when models include non-differentiable components, distributed heterogeneous devices, or physics-related modules that do not fit a clean end-to-end differentiable graph.

First-Principles Model

Standard backpropagation optimizes a global objective by sending gradients backward through the whole network. The forward-forward algorithm instead trains layers using local goodness criteria for positive and negative examples. The locally backpropagated forward-forward strategy tries to keep useful gradient-based optimization inside local modules while reducing dependence on a single global backward pass.

Key Claims

  • Backpropagation remains the dominant neural-network training method.
  • Certain real-world and physics-related settings expose weaknesses of global end-to-end backpropagation.
  • Non-differentiable components can break standard gradient flow.
  • Distributed learning over heterogeneous devices motivates more local training strategies.
  • The locally backpropagated forward-forward algorithm merges backpropagation with forward-forward training.
  • The aim is to broaden where deep-learning strategies can be applied.

Important Terms

Backpropagation

The standard algorithm for computing gradients through a neural network using the chain rule.

Forward-Forward Algorithm

A training paradigm associated with Geoffrey Hinton that uses forward passes and local goodness measures instead of global backpropagation.

Local Learning

Training where modules or layers use local objectives rather than relying only on a global loss.

Non-Differentiable Component

A model part whose output cannot be smoothly differentiated with respect to its input or parameters.

Heterogeneous Devices

Computing systems composed of different device types or capabilities.

Connections Across The Series

  • This talk connects learning algorithms, distributed training, and scientific ML architectures.
  • It complements physics-informed talks where differentiability assumptions can fail.
  • It also links to broader discussions of algorithmic progress beyond transformer architecture: training rules themselves matter.

Practical Caution

Alternative training paradigms must be judged by optimization stability, scaling behavior, and task performance, not only by biological or distributed-computing appeal.

Takeaway

The first-principles lesson is that local objectives can make learning more modular, but they must still solve the credit-assignment problem well enough to compete with backpropagation.
