Talk 109 · University of Naples Federico II

Fabio Giampaolo: Learning Paradigms for Neural Networks: The Locally Backpropagated Forward-Forward Algorithm

This lecture explores an alternative training method for neural networks that combines local gradient updates with Geoffrey Hinton's forward-forward idea, which trains layers using local quality measures instead of a global backward pass.

YouTube source · Talk page

Core Problem

Backpropagation works well but can fail when models include parts that don't have smooth gradients (non-differentiable components), run on different kinds of hardware spread across a network, or contain physics simulations that don't fit into a single end-to-end calculation of gradients.

First-Principles Model

Standard backpropagation optimizes one global goal by sending error signals backward through the whole network. The forward-forward algorithm instead trains each layer using local quality scores that measure how well the layer separates correct answers from incorrect ones. The locally backpropagated forward-forward strategy keeps gradient-based learning inside local sections of the network while reducing the need for a single global backward signal that travels all the way through.

Key Claims

  • Backpropagation remains the most widely used neural-network training method.
  • Some real-world and physics-based settings reveal where global end-to-end backpropagation breaks down.
  • Parts that don't have smooth gradients can stop standard error signals from flowing backward.
  • Training spread across different computer types pushes us toward local training strategies that don't need a single global signal.
  • The locally backpropagated forward-forward algorithm merges backpropagation with forward-forward training.
  • The goal is to expand where deep-learning methods can work.

Important Terms

Backpropagation

The standard method for computing how to change each part of a neural network using calculus chain rule, by sending error signals backward through layers.

Forward-Forward Algorithm

A training method developed by Geoffrey Hinton that uses only forward passes and local quality measures—comparing how the network responds to correct versus incorrect examples—instead of computing backward gradients.

Local Learning

Training where individual layers or modules use their own local goals instead of relying only on a single global error signal sent from the final output.

Non-Differentiable Component

A part of the model where the output does not change smoothly with its input or parameters, which breaks the continuous gradient chain that backpropagation needs.

Heterogeneous Devices

A group of different computer processors or systems with different speeds, memory, or computing styles working together.

Connections Across The Series

  • This talk connects how we design learning algorithms, how to train neural networks across many machines, and how to build machine-learning models for science and physics.
  • It builds on physics-informed talks where assuming smooth gradients doesn't hold, showing what to do when the math breaks those assumptions.
  • It also fits into wider conversations about what makes learning work beyond just transformer architecture—the actual training rules themselves determine progress.

Practical Caution

Alternative training methods must be judged by how stable they are when training, how well they scale to larger networks, and actual task performance—not just by whether they sound more like how brains work or fit better on distributed computers.

Takeaway

The first-principles lesson is that local training goals can make learning more separate and modular, but they still need to solve the credit-assignment problem (how each part of the network learns which of its changes help or hurt the final answer) well enough to match backpropagation.
