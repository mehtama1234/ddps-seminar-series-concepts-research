Talk 71 · University of Pittsburgh

Hassan Babaee: CUR Matrix Decomposition For Scalable Reduced-Order Modeling

This lecture uses CUR matrix decomposition to make reduced-order models with time-evolving bases scalable for nonlinear PDEs while cutting down the complexity of putting the method into code.

YouTube source · Talk page

Core Problem

Dynamical low-rank approximation with time-evolving bases can solve high-dimensional PDEs by tracking a low-rank representation that changes, but for generic nonlinear PDEs the cost savings disappear. For nonlinearities (terms where input changes produce non-proportional changes in output) that aren't polynomials, computing the reduced equations can cost as much as solving the original full-size model, and putting the method into code is difficult.

First-Principles Model

DLRA represents a solution that starts high-dimensional and evolves by keeping low-rank factors that change over time. Those factors get updated by minimizing how far the model's prediction misses the actual PDE answer. CUR decomposition picks the most informative rows and columns to approximate large matrices using just a few entries, allowing smart selection of how to evaluate nonlinear terms. This lets time-evolving-basis reduced models handle generic nonlinear PDEs at their promised reduced cost.

Key Claims

  • DLRA pulls out correlations from high-dimensional PDE solutions.
  • Time-evolving bases are built from minimizing prediction error rather than extracted from data computed beforehand.
  • DLRA stays efficient for linear or quadratic PDEs, but generic nonlinearities force full-size costs.
  • Nonlinearities that aren't polynomials create especially difficult challenges for time-evolving-basis equations.
  • Smart sparse selection based on CUR decomposition makes time-evolving-basis reduced models scale for nonlinear PDEs.
  • The method reduces how much code rewriting is needed to apply time-evolving-basis reduced models to new PDEs.

Important Terms

CUR Matrix Decomposition

A way to approximate a large matrix by picking a few columns, a few rows, and computing a small connecting matrix from their overlap.

Dynamical Low-Rank Approximation

A method for handling evolving high-dimensional systems by keeping track of time-changing low-rank factors.

Time-Dependent Basis

A shrunk set of directions that evolves during a simulation instead of staying fixed after being learned from precomputed data.

Sparse Interpolation

A way to approximate nonlinear terms by computing them only at carefully picked informative points or entries.

Non-Polynomial Nonlinearity

A nonlinear term that cannot be written as a polynomial, which typically makes computing reduced versions much harder.

Connections Across The Series

  • This lecture continues the reduced-model lineage with a scalable computational method for nonlinear PDEs.
  • It connects to learning-based reduced models and adaptive reduced models as another path to making reduced simulation work in practice.
  • It also links to active sampling and data-selection methods like CUR: pick the rows and columns that do the real computational work.

Practical Caution

Smart sparse selection must keep low-rank error under control. If the picked rows or columns skip important nonlinear behavior, the reduced model runs fast but gives wrong answers.

Takeaway

The core lesson is that fast reduced models need both low-rank structure and cheap nonlinear evaluation. CUR provides the selective sampling that keeps nonlinear reduced models actually reduced.
