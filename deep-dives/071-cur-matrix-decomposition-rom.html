Talk 71 · University of Pittsburgh

Hassan Babaee: CUR Matrix Decomposition For Scalable Reduced-Order Modeling

This lecture uses CUR matrix decomposition to make time-dependent-basis reduced-order models scalable for nonlinear PDEs while reducing intrusiveness.

YouTube source · Talk page

Core Problem

Dynamical low-rank approximation with time-dependent bases can solve high-dimensional PDEs by evolving a low-rank representation, but generic nonlinear PDEs can destroy the cost advantage. For non-polynomial nonlinearities, evaluating the reduced equations can cost as much as solving the full-order model, and implementation can be highly intrusive.

First-Principles Model

DLRA represents a high-dimensional evolving solution with time-dependent low-rank factors. Those factors are updated by minimizing the PDE residual. CUR decomposition selects informative rows and columns to approximate large matrices sparsely, enabling adaptive interpolation of nonlinear terms. This lets time-dependent-basis ROMs approximate generic nonlinear PDEs at their nominal reduced cost.

Key Claims

  • DLRA extracts multidimensional correlations from high-dimensional PDE solutions.
  • Time-dependent bases evolve from residual minimization rather than being extracted from precomputed data.
  • DLRA can be efficient for linear or quadratic PDEs, but generic nonlinearities create full-order costs.
  • Non-polynomial nonlinearities are especially challenging for time-dependent-basis evolution equations.
  • Adaptive sparse interpolation based on CUR decomposition enables scalable TDB-based ROMs for nonlinear PDEs.
  • The method reduces the intrusiveness required to apply time-dependent-basis ROMs to new PDEs.

Important Terms

CUR Matrix Decomposition

A matrix approximation using selected columns, selected rows, and a small linking matrix.

Dynamical Low-Rank Approximation

Approximating an evolving high-dimensional system by time-evolving low-rank factors.

Time-Dependent Basis

A reduced basis that changes over time rather than being fixed after offline training.

Sparse Interpolation

Approximating nonlinear terms by evaluating them at selected informative entries or locations.

Non-Polynomial Nonlinearity

A nonlinear term not expressible as a simple polynomial, often complicating reduced evaluation.

Connections Across The Series

  • This lecture continues the ROM lineage with a scalable algebraic method for nonlinear PDEs.
  • It connects to DL-ROMs and adaptive ROMs as another way to make reduced simulation practical.
  • It also links to active sampling and CUR-style data selection: choose the rows/columns that carry the computation.

Practical Caution

Sparse interpolation must control low-rank approximation error. If selected rows or columns miss important nonlinear structure, the reduced model can be fast but inaccurate.

Takeaway

The first-principles lesson is that scalable ROMs need both low-rank structure and cheap nonlinear evaluation. CUR supplies the selective sampling needed to keep nonlinear reduced models reduced.
