Talk 44 · Caltech

Kaushik Bhattacharya: Multi-Scale Modeling And Neural Operators

This lecture explains neural operators as function-to-function approximators that can carry fine-scale material physics into efficient coarse-scale multiscale models.

YouTube source · Talk page

Core Problem

Material behavior emerges from interacting physics across electronic, atomistic, defect, domain, and continuum scales. Directly resolving every fine-scale detail inside engineering-scale simulations is often impossible, while crude homogenization can lose the details that control performance.

First-Principles Model

Multiscale modeling decomposes the problem into an ordered hierarchy of scales. The coarse scale provides boundary conditions or loading to the fine scale, and the fine scale returns effective responses. A neural operator learns this map between function spaces rather than between finite-dimensional vectors. If trained as a controlled approximation to the fine-scale operator, it can be embedded at the coarse scale with high fidelity and lower cost.

Key Claims

  • Materials involve coupled physics across many length and time scales.
  • Multiscale modeling uses a divide-and-conquer hierarchy in which coarser scales control and filter finer-scale details.
  • The practical bottleneck is repeatedly solving expensive fine-scale problems inside coarse-scale computations.
  • Neural operators approximate maps from one function space to another, which matches the mathematical structure of many physical solution operators.
  • Operator learning is different from ordinary supervised learning on fixed-size vectors because the input and output are functions.
  • Neural operators can preserve small-scale detail while making coarse-scale implementation computationally efficient.

Important Terms

Multiscale Modeling

A modeling strategy that links physical descriptions across different spatial or temporal scales.

Neural Operator

A neural model that learns a map between function spaces, such as from a coefficient field to a solution field.

Function Space

A set whose elements are functions, making the learning problem infinite-dimensional before discretization.

Coarse Scale

The larger-scale representation used for engineering simulation or system-level prediction.

Fine Scale

The smaller-scale physics, such as atomistic or microstructural behavior, that informs effective large-scale response.

Connections Across The Series

  • This lecture is central to the playlist's neural-operator thread and complements talks on FNOs, DeepONets, and ROMs.
  • It connects operator learning to classical multiscale mechanics rather than treating it as a generic black-box surrogate.
  • It also links to uncertainty and reliability because coarse-scale predictions inherit approximation errors from learned fine-scale closures.

Practical Caution

A neural operator is only useful if it approximates the right operator over the right distribution of functions. Good interpolation on one discretization does not guarantee multiscale validity under new microstructures, loads, or boundary conditions.

Takeaway

The first-principles lesson is that operator learning becomes powerful when the learned object matches the physics object: a map between fields, scales, and boundary-conditioned responses.
