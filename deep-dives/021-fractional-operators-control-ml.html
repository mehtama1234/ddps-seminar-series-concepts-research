Talk 21 · George Mason University

Harbir Antil: Applications Of Fractional Operators From Optimal Control To Machine Learning

This lecture introduces fractional operators (mathematical tools that work with non-integer orders of derivatives) as nonlocal models for imaging, geophysics, optimal control, data science, and deep neural networks.

YouTube source · Talk page

Core Problem

Many physical and data systems show nonlocal behavior—long-range correlations, memory effects, or anomalous diffusion (spreading that doesn't follow standard random-walk rules)—that classical integer-order differential operators cannot capture naturally. Using only local derivatives can miss how heterogeneous materials, images, or reacting flows influence each other across distances.

First-Principles Model

A fractional operator extends the standard idea of differentiation to non-integer orders. Instead of measuring change only at one point, the operator can encode interactions reaching across distance or back through time. The fractional Laplacian is one example: it spreads or diffuses information in a way that reflects how systems interact over distance. Fractional exponents can also become parameters you estimate from data or random variables that capture uncertainty.

Key Claims

  • Fractional calculus handles anomalous diffusion and systems where effects reach back in time or across distance.
  • In some cases, fractional operators can replace complicated nonlinear image-smoothing models with simpler linear fractional differential equations.
  • Controlling systems with fractional differential equations raises new mathematical and computational questions.
  • Unknown fractional exponents can be treated as tunable parameters or as random variables when uncertainty matters.
  • Fractional operators can be built into deep neural network layers.
  • Chemical reacting flows show abrupt time-scale changes where fractional neural models may help.

Important Terms

Fractional Operator

A mathematical operation with a non-integer order, typically encoding how influence spreads across distance or persists over time.

Fractional Laplacian

A nonlocal (affects things far away) generalization of the Laplace operator; used to model diffusion and change in ways that reflect real-world spreading or long-range interaction.

Anomalous Diffusion

Spreading of particles or information that deviates from standard diffusion; particles wander farther or slower than expected from classical theory.

Hereditary Property

Dependence on prior states or history; the system's current behavior carries imprints of its past.

Fractional DNN

A neural network layer or module designed using ideas from fractional operators to capture nonlocal or time-dependent patterns.

Connections Across The Series

  • This talk expands the conversation about operator learning by focusing on operators that capture nonlocal physics.
  • It ties to optimal control and uncertainty quantification because fractional exponents and nonlocal dynamics can become uncertain parameters that affect control decisions.
  • It also relates to graph networks: both are ways to represent how things influence each other beyond a fixed small neighborhood on a grid.

Practical Caution

Fractional models can fit data well but introduce choices: which fractional order to use, how to handle boundaries, and how to compute the operator all shape the results. Use fractional operators when the physics genuinely shows nonlocal behavior, not as a generic dial to turn up complexity.

Takeaway

The core insight is that not all dynamics happen only locally. Fractional operators give machine learning and science a way to describe nonlocality, memory, and anomalous transport.
