Talk 66 · North Carolina State University

Ralph Smith: Parameter Subset Selection And Active Subspaces

This lecture explains how parameter subset selection and active subspace methods isolate influential directions in high-parameter engineering and biological models for calibration, surrogate modeling, and uncertainty propagation.

YouTube source · Talk page

Core Problem

Engineering and biological models often have many parameters, but measured responses may not uniquely identify them. High-fidelity simulations are also too expensive for brute-force Bayesian calibration or uncertainty propagation. The practical problem is deciding which parameters or combinations actually matter.

First-Principles Model

A high-dimensional parameter space can contain low-dimensional influential structure. Parameter subset selection tries to identify individual parameters that are estimable or important; active subspaces identify low-dimensional linear combinations of parameters that drive output variation. Once those directions are found, one can build surrogates, calibrate Bayesian models, and propagate uncertainty in a reduced effective space.

Key Claims

  • Many engineering and biological model parameters are nonidentifiable from measured responses.
  • High-fidelity simulation cost can preclude direct Bayesian calibration and uncertainty propagation.
  • Global sensitivity analysis can rank influential inputs, but has limitations.
  • Parameter subset selection offers an alternative way to isolate influential parameters.
  • Active subspace techniques identify important directions in parameter space, not just individual parameters.
  • Bayesian calibration on active subspaces can quantify uncertainties in physical parameters.

Important Terms

Nonidentifiability

A condition where model parameters are not uniquely determined by the available measurements.

Global Sensitivity Analysis

A family of methods for quantifying how uncertainty in inputs affects uncertainty in outputs.

Parameter Subset Selection

Choosing a smaller set of parameters that are most influential or identifiable.

Active Subspace

A low-dimensional subspace of parameter combinations that explains most output variation.

Bayesian Calibration

Estimating parameter distributions by combining prior knowledge, model predictions, and observed data.

Connections Across The Series

  • This lecture connects UQ, inverse problems, and surrogate modeling through dimensional reduction in parameter space.
  • It complements ROM talks by reducing input dimensions rather than state dimensions.
  • It also provides a practical route for digital twins: calibrate only the parameters the data can actually inform.

Practical Caution

Parameter ranking can be misleading if parameters interact nonlinearly or if the response metric changes. Active subspaces should be validated for the specific quantity of interest and data regime.

Takeaway

The first-principles lesson is that not every parameter deserves equal attention. Effective calibration starts by finding the directions the data and outputs can actually see.
