Talk 66 · North Carolina State University

Ralph Smith: Parameter Subset Selection And Active Subspaces

This lecture explains how to find which parameters and combinations of parameters matter most in high-dimensional engineering and biological models, making it possible to calibrate them, build fast approximations, and estimate uncertainty.

YouTube source · Talk page

Core Problem

Engineering and biological models often have dozens or hundreds of parameters, but the measurements you can actually make don't give you enough information to pin down all of them. Running high-fidelity simulations millions of times to explore what happens is too expensive. The real problem: Which parameters or combinations of parameters actually change the outputs you care about?

First-Principles Model

A parameter space with many dimensions can hide a much smaller structure that actually drives the outputs. Parameter subset selection finds individual parameters you can reliably measure or estimate from data. Active subspaces (low-dimensional directions, or combinations, of parameters) capture how most of the output changes happen along just a few directions. Once you identify these directions, you can build fast approximations, tune Bayesian calibration to focus on what matters, and compute how uncertainties flow through the model in a much smaller space.

Key Claims

  • Most engineering and biological model parameters cannot be uniquely pinned down from the measurements available.
  • The cost of running high-fidelity simulations many times makes direct Bayesian calibration and full uncertainty propagation impractical.
  • Global sensitivity analysis can rank which inputs have the strongest effect, but has limits.
  • Parameter subset selection provides a direct way to pick out which parameters are most influential.
  • Active subspace techniques find important directions in parameter space (combinations and patterns), not just single parameters.
  • Bayesian calibration done on active subspaces can estimate the uncertainty in physical parameters.

Important Terms

Nonidentifiability

When the data available cannot pin down model parameters to a unique answer, because different parameter choices give nearly the same output.

Global Sensitivity Analysis

A set of methods that measure how uncertainty in the inputs causes uncertainty in the outputs.

Parameter Subset Selection

Choosing a smaller group of parameters that are most changeable from data or have the most effect on outputs.

Active Subspace

A low-dimensional space of parameter combinations that accounts for most of the variation in outputs.

Bayesian Calibration

Estimating what values and ranges parameters must have by combining prior assumptions, model predictions, and observed measurements.

Connections Across The Series

  • This lecture ties together uncertainty quantification, inverse problems (finding parameters from measurements), and surrogate modeling by reducing the number of parameters to track.
  • It complements reduced-order model talks by shrinking the number of inputs instead of the number of states.
  • It also gives a practical path for digital twins: figure out which parameters the data can actually teach you about, then calibrate only those.

Practical Caution

Ranking parameters by importance can mislead you if they interact in nonlinear ways or if the metric you care about shifts with different data. Active subspaces must be checked carefully for the exact quantity of interest and the regime of data you're working with.

Takeaway

The core insight is that not all parameters are equally important. Good calibration starts by finding which directions the data and the model outputs can actually reveal.
