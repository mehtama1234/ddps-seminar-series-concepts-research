Talk 24 · University of Texas at Austin

Tan Bui-Thanh: Model-Constrained Deep Learning For Inference, Control And UQ

This lecture presents model-constrained deep learning as a way to embed scientific forward models inside inference, control, and uncertainty quantification workflows.

YouTube source · Talk page

Core Problem

Inverse problems and control tasks cannot rely on unconstrained prediction alone. Measurements may be sparse, noisy, high-dimensional, and indirect, while the unknown parameter space can be high-dimensional. Bayesian or optimization-based inference may require many expensive forward PDE solves.

First-Principles Model

A forward model maps parameters or shapes to observations by solving a PDE. An inverse problem tries to recover parameters from observations. In Bayesian inversion, the solution is a posterior distribution over parameters. Model-constrained deep learning places the mathematical model inside the neural or variational approximation so learning respects the physics while reducing the cost of exploring the posterior or control space.

Key Claims

  • Scientific ML combines scientific computing, which uses law-derived models, with machine learning, which learns data-driven models.
  • Forward problems solve PDEs from known parameters; inverse problems reconstruct hidden causes from limited measurements.
  • High-dimensional parameters and high-dimensional data create severe computational challenges.
  • Bayesian inverse problems are expensive because posterior exploration repeatedly calls the forward model.
  • Variational approaches can approximate the posterior with a parameterized distribution.
  • The key idea is to put the underlying mathematical model inside the variational or deep-learning architecture.

Important Terms

Model-Constrained Deep Learning

A learning approach where predictions or latent variables are constrained by a governing scientific model.

Forward Problem

Computing observations or states from known parameters by solving the physical model.

Inverse Problem

Inferring hidden parameters, shapes, or sources from observations.

Posterior Distribution

A probability distribution over unknowns after combining prior assumptions with observed data.

Variational Inference

Approximating a difficult posterior distribution with a tractable parameterized distribution.

Connections Across The Series

  • This talk is a direct bridge between differentiable simulation, implicit layers, and uncertainty-aware scientific ML.
  • It connects to hybrid twins because real twins need inference and UQ, not only forward prediction.
  • It also connects to control because decision quality depends on model-constrained inference of the current state and uncertainty.

Practical Caution

A model-constrained neural method is only as reliable as both pieces: the forward model must represent the relevant physics, and the variational or neural approximation must capture the posterior uncertainty well enough for the downstream decision.

Takeaway

The first-principles lesson is that inference and control need learning systems that respect the forward physics while making uncertainty computation tractable.
