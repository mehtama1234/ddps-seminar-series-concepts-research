Talk 113 · Georgia Tech

Elizabeth Qian: Multi-Fidelity Linear Regression for Scientific Machine Learning from Scarce Data

This lecture shows how combining cheap approximate data with rare expensive data makes scientific machine learning more reliable when you don't have much high-quality information.

YouTube source · Talk page

Core Problem

Scientific surrogate models (math stand-ins that run fast instead of slow physics simulations) often need high-quality simulation data, but collecting that data costs money and time. When you train a model on a small amount of high-quality data, it memorizes the details of what you happened to measure instead of learning the underlying pattern, making predictions unreliable on new problems.

First-Principles Model

Multi-fidelity learning accepts a tradeoff: expensive simulations give accurate answers but you can afford very few, while cheap approximations are easier to get but biased (consistently off in some direction). The method stacks them: use lots of cheap data to shrink the wild swings in prediction, then use the rare expensive data to fix the direction bias. For linear models (where you're fitting a straight line through your data), this gives a clear, understandable way to see how mixing data sources at different quality levels helps when you have very little good data.

Key Claims

  • When you only have a small amount of high-quality training data, the model learns noise instead of the true pattern.
  • Lower-quality data can help even when it's not fully correct.
  • The proposed method uses multi-fidelity linear regression as a starting point for understanding the bigger picture.
  • Real scientific problems naturally give you data at different quality levels and different costs.
  • The main goal is to make predictions trustworthy when expensive high-quality data runs out.
  • The method recasts small-data learning as a problem of balancing prediction swings versus prediction direction, with costs factored in.

Important Terms

Multi-Fidelity Learning

Training from data sources that differ in how much they cost and how accurate they are.

High-Fidelity Data

Accurate results, usually from full physics simulation or real experiment, but expensive to collect.

Low-Fidelity Data

Cheaper results from simplified models, coarser versions of simulations, or educated guesses.

Linear Regression

A model that represents what you're predicting as a straight-line function of the measured input values.

Scarce Data

A situation where you have far fewer reliable training examples than the uncertainty in your model, leaving it prone to learning noise.

Connections Across The Series

  • This talk ties together uncertainty counting (how sure am I?), smart data selection (which new test should I run?), stand-in models that run fast, and science from very little data.
  • It adds to neural operator and reduced model talks by showing that what data costs and how good they are both shape what you can learn.
  • It also speaks to how to build good training sets when running a simulation is expensive.

Practical Caution

Cheap data cuts down prediction wildness but brings in its own slant. Whether multi-fidelity learning actually helps depends on whether the relationship between cheap and expensive data stays the same across the range of situations you want to predict.

Takeaway

The core lesson is that small-data learning gets stronger when the model pulls information from readily available cheaper sources without losing track of which data you can actually trust.
