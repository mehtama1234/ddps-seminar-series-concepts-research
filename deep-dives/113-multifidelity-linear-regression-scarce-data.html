Talk 113 · Georgia Tech

Elizabeth Qian: Multi-Fidelity Linear Regression for Scientific Machine Learning from Scarce Data

This whole series is about getting computers to predict how physical things behave by learning from examples instead of hand-written math. When you have only a tiny amount of trustworthy data, this talk shows how to add cheaper, cruder guesses to the mix: the computer learns from the cheap wrong guesses to narrow down its wild swings, then uses the rare expensive data to fix the direction it's off in.

YouTube source · Talk page

Core Problem

To predict how a wing cuts through air or heat spreads through metal, scientists build stand-in programs that run fast (instead of watching it really happen or running slow step-by-step math). These stand-ins need lots of examples to learn from. Collecting those examples costs real money and time. When you train a model on just a few examples, it memorizes each one instead of spotting the true pattern underneath. Imagine a student who only sees three word problems and tries to guess the rule: if it gets lucky, great, but usually it invents a weird pattern that only fits those three. That breaks when the student tries a new problem.

First-Principles Model

Multi-fidelity learning accepts a real tradeoff: the best simulations give you accurate answers, but you can afford to run only a handful; cheap, rough approximations are fast to generate, but they're biased (always off in some direction). Stack them this way: flood your model with lots of cheap, rough data so it stops making wild guesses all over the place, then use the few precious expensive runs to correct the direction the cheap data pulled it. For linear models (where you fit a line through your points), you can see exactly how these two sources combine when you hardly have any good data at all.

Key Claims

  • When the model sees only a few real examples, it starts memorizing those examples instead of learning the true rule underneath.
  • Lower-quality data can be useful even when it's consistently wrong.
  • Linear regression with multiple data sources gives a clear way to understand this larger idea.
  • Real science problems always have data at different quality levels and different costs naturally built in.
  • The goal is to make predictions work when you run out of expensive, trustworthy data.
  • This method recasts the small-data puzzle as balancing two things: how much the predictions wobble side to side, versus how much they tilt in one direction, weighed by what each type of data costs.

Important Terms

Multi-Fidelity Learning

Training a model using data sources that differ in cost and accuracy — some cheap but wrong, others expensive but right — to get better predictions when data is scarce.

High-Fidelity Data

Accurate results from running a full realistic simulation or a real experiment; costs money and time to collect.

Low-Fidelity Data

Cheaper, quicker results from using a coarse, simplified model or rough educated guess instead of the real thing.

Linear Regression

A simple model that assumes what you're predicting is a straight line plotted against the input measurements.

Scarce Data

Having so few reliable training examples that the model's guess bounces all over the place; it can't tell real patterns from random noise in what it saw.

Connections Across The Series

  • This talk weaves together measuring confidence (how sure is the prediction?), picking which experiment to run next smartly, building fast stand-in models, and squeezing learning from barely any data.
  • It extends earlier talks on neural operators and model reduction by showing that the cost and accuracy of data sources both matter for what a model can learn.
  • It speaks to how to pick good training examples when running a full simulation is expensive.

Practical Caution

The cheap data shrinks the wild swings but brings its own steady tilt. Whether mixing different data sources actually helps depends on one thing: is the relationship between cheap guesses and expensive truth the same everywhere you want to make predictions? If the cheap model works one way in some regions and different in others, stacking them can backfire.

Takeaway

When training data is scarce, the model learns more by pulling hints from cheap, easy sources while staying honest about which data actually deserve trust.
