Talk 16 · Carnegie Mellon University

Priya Donti: Incorporating Power System Physics Into Deep Learning Via Implicit Layers

This whole series is about getting computers to predict how physical things behave by learning from data instead of only hand-written math. One approach is to add physics rules directly into a learning program's structure. This talk shows how to build a learning program with special layers that solve real-world power-grid decision problems step-by-step as the program runs, so the program's predictions automatically obey what a real power system must do.

YouTube source · Talk page

Core Problem

Learning programs can predict numbers with high accuracy, but those numbers often break rules that power grids must follow. A real electricity grid has hard requirements: supply must equal demand, power lines can only carry so much current, equipment must stay stable, and physical limits cannot be crossed. A prediction is only useful if it solves the actual optimization problem that grid operators run to make decisions.

First-Principles Model

Usually a layer in a learning program is a direct calculation: multiply inputs by numbers, add them up, apply a squashing function. But a layer can also be defined differently: as the answer to a hidden problem—an optimization task (pick the best choice given constraints), a rule for how things change over time (how voltage adjusts when power flows), a balance point (a state where forces stop shifting), or a control rule (what action should the system take). If that hidden problem can be solved in a differentiable way (meaning we can compute how to nudge the program's dials based on the solution), the entire program learns end-to-end while preserving the real domain structure.

Key Claims

  • Special network layers can encode complex operations like optimization problems, rules for how things change, and other structured tasks.
  • Power-grid physics and hard requirements can be built into learning programs rather than checked only after predictions are made.
  • The main power-grid optimization problem (choosing generation and power flow with all limits enforced) can be embedded inside a network by working through a sequence of optimization steps or by differentiating through its optimality conditions.
  • Programs trained to optimize actual system outcomes perform better on what operators care about, not just raw prediction error.
  • Special layers give the program prior knowledge by reflecting how the domain actually works.
  • They also enforce rules that cannot be broken and support stable control in real physical systems.

Important Terms

Implicit Layer

A part of a learning program that is defined by solving an equation, optimization problem, or system of rules rather than by doing a direct calculation.

Optimal Power Flow

An optimization problem that decides how much power each generator produces and how it moves through lines while respecting all physical limits and network rules.

KKT Conditions

Mathematical rules that describe when a constrained optimization has found its best solution, and how to compute the impact of small changes to that solution.

Decision-Driven Learning

Training a prediction program by measuring how good the choices that result from the predictions are, not just the distance between the prediction and the actual number.

Hard Constraint

A requirement that must be true exactly, enforced by the rules themselves, not just encouraged by adding extra penalty points to the score.

Connections Across The Series

  • This talk extends physics-informed learning beyond penalty scores that measure how badly rules are broken to optimization layers and requirements that must be met during actual operation.
  • It connects to inverse problems and control because the program learns by measuring success in the decision or control problem it serves, not by prediction accuracy alone.
  • It also complements differentiable simulation: both treat a structured physical computation as a step inside the learning process.

Practical Caution

Low prediction error alone is not enough for grids. The learned program must be tested by checking whether it produces decisions that are feasible (physically possible), stable (safe to operate without damage or failure), and useful under the actual rules and constraints of the power system.

Takeaway

The core lesson is that a learning program for real infrastructure should include the operational decision—what the system is required to do—baked into its structure, not just predict numbers that come before the actual problem.
