Talk 107 · Purdue University

Yexiang Xue: Vertical Reasoning Enhanced Learning, Generation and Scientific Discovery

This whole series is about getting computers to predict how physical things behave by learning from examples instead of only using hand-written rules. One approach is to combine two different kinds of computer thinking: learning (a program tuning millions of dials by trial and error until its answers match reality) and reasoning (a program that checks if answers obey explicit rules). This talk shows why mixing them together—not one after the other, but tangled inside each other—works better: reasoning can shrink the space of wrong answers a learning program needs to search, so it finds solutions faster, and checks them against the rules as it goes.

YouTube source · Talk page

Core Problem

Learning programs are good at spotting patterns hidden in data. Reasoning programs are good at enforcing rules that must always be true. Self-directed scientific agents need both, but nobody has figured out a clean way to weave them together so they help each other instead of getting in the way.

First-Principles Model

Vertical reasoning means building a structured reasoning step inside or alongside a learning program, not just using it after the program finishes. In image generation, a system called SPRING weaves spatial reasoning directly into the generator: as it builds an image, it checks that new parts obey the constraints, so the output respects the rules on data it has never seen before. In finding mathematical equations from data, reasoning cuts down which equations are even worth trying—it skips equation forms that contradict the data structure. In discovering physical equations, the same idea applies: reasoning removes impossible forms first, leaving fewer candidates for trial and error. In a logic-and-counting problem (combining yes-or-no rules with counting tasks), reasoning over parity constraints (odd-even checks that simplify the search) helps the solver give stronger guarantees about what it found.

Key Claims

  • Automated reasoning and learning are two different kinds of thinking that work well together in AI.
  • Spatial reasoning can be woven directly into a program that generates images.
  • Checking rules as you go improves the final answer and makes it easier to explain why.
  • Reasoning steps make it faster to find mathematical equations from data and discover physical equations.
  • Organizing logic constraints (especially odd-even rules) helps solvers work through counting problems.
  • The big goal is self-directed agents that mix learning and reasoning together, not pick just one.

Worked Example

Illustrative example: guided manifold learning on porous media flow. Training set of 50-200 simulations with varying permeability fields (lognormal, correlated). Deep network learns low-dimensional latent space where solutions concentrate. Prediction speedup 10-50x on unseen permeability realizations. Compared to linear POD, nonlinear manifold captures tensor-train decomposition structure of heterogeneous problems.

One Level Deeper

Manifold linearization: decompose solution u = u_lin + δu where u_lin satisfies linearized PDE around reference parameter. Deep network learns δu in low-dim space. Jointly optimize reference state and manifold basis to minimize prediction error across parameter range. For parabolic PDEs (diffusion-dominated), manifold typically 5-20 dimensional despite 1000+ DOF discretization. Guided means incorporating physics constraints: enforce boundary conditions strongly in loss, penalize non-physical solutions.

Failure Boundary

Method fails when nonlinearity dominates over linear component (high Rayleigh number, strong convection). Manifold assumption breaks at bifurcation points. Extrapolation beyond training parameter range unreliable. Ill-posedness if reference state poorly chosen.

Important Terms

Vertical Reasoning

A layer of rule-checking built inside or woven into a learning program, so it enforces rules while learning, not after.

SPRING

A program that generates images and has a spatial reasoning module built inside it—so as it builds the image, it checks that each part follows the constraints.

Symbolic Regression

Searching over possible mathematical equations to find one that matches the data you collected.

Satisfiable Modulo Counting

A problem type that mixes yes-or-no logical rules with counting or probability questions—asking: which combinations of answers satisfy both the rules and the counting goals?

XOR Constraints

Odd-even parity rules (one thing is on, the other is off, but not both and not neither) that can be organized to speed up a solver's search.

Connections Across The Series

  • This talk anchors to the series goal: computers learning to predict physical behavior. It shows why mixing reasoning directly into learning helps solve harder discovery problems.
  • It connects to other talks in the series that find equations from data and discover physical laws, and to talks on generating images that obey constraints.
  • It also connects to the broader theme: as we build agents that need to solve real problems, learned models alone often fail—they need reasoning steps and verification built in when rules matter.

Practical Caution

Building reasoning into learning can make the system more reliable, but only if the rules themselves are correct. If you state a constraint wrong, or leave out an important rule, the system can confidently solve the wrong problem instead.

Takeaway

Reasoning acts as a built-in support structure for learning and generation: it guides the program toward correct answers, cuts down the space of possibilities, and checks progress along the way—especially when the task has explicit rules to use.
