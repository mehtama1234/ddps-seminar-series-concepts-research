Talk 46 · Texas A&M University

Ming Zhong: Machine Learning Of Self Organization From Observation

This lecture develops a data-driven framework for learning interaction laws in self-organizing collective systems directly from observed trajectories.

YouTube source · Talk page

Core Problem

Self-organization appears in systems such as flocking, crowds, crystals, superconductivity, and social behavior. The macroscopic pattern may be visible, but the microscopic interaction rule among agents is unknown. The challenge is to infer physically meaningful dynamical laws from observations rather than only forecast trajectories.

First-Principles Model

A collective system can be modeled as interacting agents whose velocities or accelerations depend on pairwise distances, states, and agent types through interaction kernels. Given trajectory data from multiple initial conditions, the learning problem is to estimate those kernels so the resulting dynamical system reproduces observed behavior and predicts new collective motion. Theory studies convergence as data from initial conditions increases.

Key Claims

  • Self-organization can be studied through observed trajectories of interacting agents.
  • The goal is to derive interpretable dynamical systems and interaction rules, not only black-box predictions.
  • Learning interaction kernels can validate and improve existing models of collective behavior.
  • Convergence analysis depends on data from multiple initial conditions and on how trajectory data are discretized.
  • The framework extends from homogeneous agents to heterogeneous systems such as predator-prey interactions.
  • Steady-state observations can also contain information about interaction kernels, though the inverse problem requires regularization.

Important Terms

Self-Organization

Collective behavior where large-scale order emerges from local interactions among components or agents.

Interaction Kernel

A function describing how one agent influences another as a function of distance, state, or type.

Homogeneous Agents

Agents governed by the same interaction laws.

Heterogeneous Agents

Agents of different types with different interaction rules, such as predators and prey.

Trajectory Data

Time-indexed observations of agent states used to infer the governing interaction laws.

Connections Across The Series

  • This lecture connects to equation discovery and symbolic modeling because it learns governing laws from data.
  • It also links to nonlocal kernels and graph-based physics: collective behavior depends on relational interactions.
  • It complements forecasting talks by emphasizing interpretable dynamics over pure trajectory extrapolation.

Practical Caution

Inferring interaction laws from observation is an inverse problem. Good trajectory fit does not guarantee a unique or physically correct kernel, especially with limited initial conditions or steady-state-only data.

Takeaway

The first-principles lesson is that collective patterns are compressed evidence about interaction laws. Scientific ML should recover the laws, not just replay the pattern.
