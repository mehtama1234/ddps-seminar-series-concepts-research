Talk 32 · Max Planck Institute for Dynamics of Complex Technical Systems

Peter Benner: Identification Of Nonlinear Dynamical Systems From Noisy Measurements

This lecture studies how to identify nonlinear differential equations from noisy and sparse measurements by blending SINDy-style sparse discovery with numerical time-integration ideas.

YouTube source · Talk page

Core Problem

System identification tries to recover dynamical equations from observed trajectories. For nonlinear systems, sparse observations and measurement noise make the problem difficult because numerical derivatives become unreliable, dictionary choices matter, and spurious terms can be selected.

First-Principles Model

A dynamical system defines time derivatives as a function of the current state. Sparse identification assumes that this function can be represented by only a few active terms from a candidate dictionary. Instead of differentiating noisy data directly, numerical integration formulas such as Runge-Kutta can connect states across time steps and make the identification problem more robust.

Key Claims

  • Discovering dynamical models from measurements is essential for analysis, optimization, and control.
  • SINDy popularized sparse identification of nonlinear dynamics from data.
  • Noise and sparse sampling remain central obstacles for nonlinear system identification.
  • The talk focuses on a Runge-Kutta SINDy variant that uses time integration structure.
  • Choosing the dictionary automatically remains an important open issue.
  • For wave or transport phenomena, the integration scheme should respect the dynamics being identified.

Important Terms

System Identification

Inferring a mathematical dynamical model from observed input-output or trajectory data.

SINDy

Sparse Identification of Nonlinear Dynamics, which selects active terms from a dictionary of candidate nonlinear functions.

Dictionary

The candidate library of functions from which the right-hand side of the dynamical system is selected.

Runge-Kutta Scheme

A time-integration method that approximates state evolution using weighted stage derivatives.

Noisy Measurements

Observed data contaminated by measurement error, which can corrupt derivative estimates and term selection.

Connections Across The Series

  • This talk extends the Brunton interpretability lecture by focusing on the numerical-analysis details of equation discovery.
  • It connects to Koopman and Green's function talks because all three seek dynamical structure from data.
  • It also connects to control because an identified model is often needed before optimization or feedback design.

Practical Caution

Sparse discovery can return elegant equations that are artifacts of noise or a poor dictionary. The dictionary, integration scheme, and noise model are part of the scientific assumption set.

Takeaway

The first-principles lesson is that equation discovery is not only regression. It is regression constrained by dynamics, time integration, noise, and candidate physics.
