Talk 70 · University of Wisconsin-Madison / Argonne National Laboratory

Victor Zavala: Bayesian Optimization With ML Models, Physics, And High-Throughput Experiments

This lecture presents Bayesian optimization methods that combine physics reference models, learned residuals, scalable uncertainty estimates, and high-throughput experimental design.

YouTube source · Talk page

Core Problem

Bayesian optimization is attractive when experiments or simulations are expensive, but standard GP-based BO can struggle with large-scale models, physical prior knowledge, and high-throughput experimental settings where many experiments can run in parallel. The problem is how to exploit physics and throughput without losing uncertainty-guided search.

First-Principles Model

BO selects the next experiment by optimizing an acquisition function built from a surrogate and uncertainty estimate. If physics provides a reference model, the unknown performance can be decomposed into reference prediction plus residual. Learning the residual with a GP focuses data on what physics misses. The reference model can also partition the design space for parallel search and support scalable acquisition functions for larger parametric models.

Key Claims

  • Bayesian optimization can exploit large-scale ML models, physical knowledge, and high-throughput experiments.
  • A performance function can be decomposed into a physics-based reference model and a learned residual model.
  • Learning the residual with a Gaussian process can accelerate search.
  • Reference models can partition the design space for parallel experimental search.
  • High-throughput experiments require BO methods that can select batches, not only one point at a time.
  • Scalable acquisition functions can extend BO to large parametric models with basic uncertainty quantification.

Important Terms

Bayesian Optimization

A sample-efficient optimization method using probabilistic surrogates and acquisition functions.

Reference Model

A prior model, often physics-based or low-fidelity, that captures coarse structure of the performance function.

Residual Model

A learned correction for what the reference model fails to predict.

Gaussian Process

A probabilistic surrogate model that defines a distribution over functions.

Acquisition Function

A criterion used by BO to choose the next experiment or simulation point.

Connections Across The Series

  • It also complements physics-ML hybrid modeling by treating physics as a prior rather than a replacement for learning.
  • It provides an optimization-side counterpart to uncertainty-aware surrogate modeling.

Practical Caution

A poor reference model can bias the search. Physics-informed BO should monitor residual behavior and uncertainty rather than assuming the reference model is reliable everywhere.

Takeaway

The first-principles lesson is that BO is controlled experimentation under uncertainty. Physics helps most when it guides search while leaving room to learn its residual errors.
