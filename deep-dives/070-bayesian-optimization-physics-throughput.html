Talk 70 · University of Wisconsin-Madison / Argonne National Laboratory

Victor Zavala: Bayesian Optimization With ML Models, Physics, And High-Throughput Experiments

This lecture presents Bayesian optimization methods—a way to search for good answers when experiments are expensive—that combine physics models, learned corrections to those models, uncertainty estimates you can scale up, and designs for running many experiments at once.

YouTube source · Talk page

Core Problem

Bayesian optimization is useful when experiments or simulations cost time or money. But standard methods based on Gaussian processes struggle when your model is large, when you have physics knowledge to use, or when you can run many experiments in parallel. The challenge is how to use physics and parallelism while still keeping your search guided by uncertainty—how confident you are in your predictions.

First-Principles Model

Bayesian optimization picks the next experiment by optimizing an acquisition function: a formula that scores each possible choice using a surrogate (a fast substitute model) and uncertainty estimates. If physics gives you a reference model (a rough first guess based on known laws), you can split performance into two parts: what the physics model predicts plus the residual (what's left over). Training a Gaussian process—a statistical model that assigns probabilities to different functions—on just the residual focuses your limited experiments on catching what physics misses. The reference model also lets you divide up the design space so parallel searches don't waste effort, and it helps build acquisition functions that work on large models.

Key Claims

  • Bayesian optimization can use large-scale ML models, physical knowledge, and experiments run in batches together.
  • You can split what happens into two parts: a physics-based reference model plus a learned correction model.
  • Training a Gaussian process on just the correction speeds up your search.
  • Reference models can split up the design space so you run parallel experiments without duplication.
  • Running many experiments at once requires Bayesian optimization methods that choose groups of points, not one at a time.
  • Scalable acquisition functions can extend Bayesian optimization to large parametric models using simple uncertainty counts.

Important Terms

Bayesian Optimization

A search method that uses statistical models to make quick guesses about good choices and only runs the experiments most likely to teach you something new.

Reference Model

A starting model, often built from physics or simple science, that captures the basic shape of how performance changes.

Residual Model

A learned model that captures the errors or corrections the reference model misses.

Gaussian Process

A statistical tool that assigns probabilities to different possible functions, letting you estimate both what will happen and how sure you are about it.

Acquisition Function

A scoring formula that Bayesian optimization uses to decide which experiment or simulation to try next.

Practical Caution

A weak physics model can send your search in the wrong direction. When using physics-informed Bayesian optimization, watch how well the residual behaves and how sure your uncertainty estimates are, rather than trusting the reference model everywhere.

Takeaway

The core idea is that Bayesian optimization is smart experimentation when you're unsure. Physics works best when it points your search in the right direction while still letting you learn what it gets wrong.
