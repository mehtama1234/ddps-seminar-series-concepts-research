Talk 101 · University of Hong Kong

Z. Zhang: DeepParticle: Learning Invariant Measure by a Deep Neural Network Minimizing Wasserstein Distance

This lecture shows DeepParticle, a method that learns parameterized invariant measures (long-time probability distributions) for high-dimensional particle systems governed by partial differential equations (PDEs).

YouTube source · Talk page

Core Problem

High-dimensional PDEs with sharp fronts, steep gradients, or concentrated regions are hard for mesh-based methods. Particle-based methods that simulate interactions directly can handle these features better but become slow for long-time computations. The challenge: predict the behavior at expensive physical conditions without actually running the full particle simulation there.

First-Principles Model

For Fisher-KPP fronts in flows without divergence, PDE theory reduces the speed calculation to finding the largest eigenvalue of an advection-diffusion operator (a number that controls how fast disturbances spread). The Feynman-Kac formula connects certain PDE quantities to paths of random particles, enabling a resampling-based particle algorithm whose distribution converges to a long-time invariant measure. DeepParticle learns a family of these invariant measures using a neural network whose inputs encode the Peclet number (the ratio of how fast particles move to how much they diffuse). The network is trained with a Wasserstein loss (how much effort to move probability mass from the network's output to the true distribution), using only moderate Peclet values where computation is cheap. This trains the network to predict the invariant measures at harder, more expensive high-Peclet regimes.

Key Claims

  • DeepParticle combines deep learning, optimal transport, and interacting particle computation.
  • The method focuses on Fisher-KPP front speeds in incompressible flows.
  • Front-speed calculations reduce to finding the principal eigenvalue of an advection-diffusion operator.
  • The Feynman-Kac formula provides a stochastic interpretation that particle algorithms can use.
  • The learned object is a parameterized family of invariant measures.
  • The method extends to learning stochastic particle dynamics like Keller-Segel chemotaxis aggregation.

Important Terms

DeepParticle

A method combining neural networks, optimal transport, and interacting particles to learn invariant measures for expensive physical regimes.

Invariant Measure

A probability distribution that stays the same as a dynamical or stochastic process evolves over long times.

Feynman-Kac Formula

A mathematical relationship that expresses certain PDE quantities as expected values computed along random-particle paths.

Interacting Particle Method

A simulation using many particles whose dynamics affect each other or are resampled to represent a probability distribution.

Wasserstein Distance

An optimal-transport distance that measures the minimum total distance all particles must move to transform one probability distribution into another.

Connections Across The Series

  • This lecture connects stochastic dynamics, PDE analysis, optimal transport, and deep learning.
  • It differs from talks on operator learning by targeting invariant distributions instead of only learning input-output mappings of PDE solutions.
  • It also relates to rare-event simulation and multiscale methods because the technique targets expensive parameter regimes that would be costly to compute directly.

Practical Caution

Learning invariant measures at moderate parameters does not guarantee accuracy at extreme parameters. Extrapolation to higher Peclet numbers must be checked against physics or more detailed simulations.

Takeaway

The first-principles insight is that some high-dimensional PDE questions become learnable by targeting the long-time distributional property that controls the answer.
