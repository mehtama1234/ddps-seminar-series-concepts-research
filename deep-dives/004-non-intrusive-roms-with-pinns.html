Talk 4 · EPFL

Jan Hesthaven: Non-Intrusive ROMs Using Physics-Informed Neural Networks

This lecture shows how neural networks can replace mathematical projections in reduced-order modeling when you cannot look inside the full simulator and must learn from its input-output data alone.

YouTube source · Talk page

Core Problem

Projection-based ROMs work well if you can access the governing equations, but many real solvers are old, proprietary, classified, or commercial and only available as closed programs. For nonlinear problems, even ROMs built with full access can slow down because evaluating the projected nonlinear equations still requires returning to the full state dimension.

First-Principles Model

A ROM trades generality for speed by learning a compact map from parameters to solution coefficients. If the full operator is open, projection-based math gives you equations for those coefficients directly. If the operator is closed, a neural network can learn the parameter-to-coefficient map from repeated runs of the simulator, and adding physics-informed loss terms can improve how closely the predictions obey the underlying physics.

Key Claims

  • Reduced-order modeling speeds up repeated parameterized PDE solves by representing solutions using a small set of basis vectors.
  • Nonlinear problems create a bottleneck because the projected nonlinear equations still depend on the full-dimensional state.
  • Non-intrusive ROMs are necessary when you have only the input and output of the solver, not its internal structure.
  • A neural network can map parameters directly to the expansion coefficients in the reduced basis.
  • If a good reduced basis exists, the parameter-to-coefficient map should usually be smooth enough for a small neural network to learn.
  • Physics-informed neural networks can supplement classical ROM construction, solving specific bottlenecks rather than replacing numerical solvers entirely.

Important Terms

Intrusive ROM

A reduced-order model that needs access to the solver's equations or internal structure.

Non-Intrusive ROM

A reduced-order model built from input-output data without modifying or examining the full solver.

Expansion Coefficients

The low-dimensional numbers multiplying each reduced basis vector to rebuild an approximate solution.

Projection Bottleneck

The cost or access barrier that arises when reduced equations still require full-dimensional operator calculations.

Overfitting In ROM Nets

A failure where the neural parameter-to-coefficient map is too complex for the number of simulator runs used to train it.

Connections Across The Series

  • This lecture lays out the practical ROM workflow that later talks build on: collecting snapshots from the full simulator offline, constructing a reduced basis from them, then using a fast predictor online.
  • It places PINNs in a concrete engineering role: fixing specific bottlenecks in ROM construction rather than replacing full numerical solvers.
  • It connects to design workflows because ROMs become most valuable when you must run many parameterized simulations in sequence.

Practical Caution

A neural ROM only works if the reduced basis captures the essential shape of solutions and if the learned coefficient map works on new parameter values outside the training set. Making the neural network deeper or wider without proportionally more simulator data can cause overfitting, making predictions worse on untested parameters.

Takeaway

The lecture's central lesson is practical: use neural networks where classical ROM methods hit a wall, particularly when the solver is only available as a closed program or when nonlinear coefficient maps are expensive.
