Talk 10 · Technical University of Munich

Nils Thuerey: Differentiable Physics Simulations For Deep Learning

This lecture argues for tightly coupling simulators and deep learning by making the simulator differentiable, so gradients from physical dynamics can guide learning, inverse problems, and control.

YouTube source · Talk page

Core Problem

Using simulators only as data generators creates a weak connection between physics and learning. Many applications need the model to know how changing an input, parameter, or control would change the simulated outcome. That requires gradients through the simulator.

First-Principles Model

A simulator maps initial states, parameters, or controls to future physical states. If we can differentiate that map, we can optimize causes from effects: reduce numerical error, infer controls, improve designs, and train networks inside the physical loop. The simulator becomes part of the computational graph rather than an external data source.

Key Claims

  • Physical models and numerical methods are valuable and should be kept where possible, while learning handles errors, observations, and uncertain components.
  • Forward simulation predicts what happens; inverse problems ask what inputs or controls would produce a desired outcome.
  • Supervised learning from simulator data is useful but loosely coupled to physics.
  • Putting physics only into a loss is tighter, but differentiable simulation gives a still tighter simulator-learning integration.
  • The key object is a gradient of the simulation with respect to the state or input.
  • Differentiable solvers can support solver-in-the-loop learning, control, and correction of numerical errors.

Important Terms

Differentiable Simulator

A simulator that provides gradients of outputs with respect to inputs, states, controls, or parameters.

Solver-In-The-Loop

A learning setup where a numerical solver is part of the training loop and contributes gradient information.

Adjoint

A method for efficiently propagating sensitivities backward through a simulation or optimization problem.

Inverse Problem

A problem where observed or desired outcomes are used to infer hidden causes, parameters, or controls.

Numerical Error Correction

Learning a correction that reduces errors introduced by coarse grids, low-order methods, or approximate solvers.

Connections Across The Series

  • This is the differentiable-simulation anchor for the playlist and complements PINNs by putting the solver inside learning rather than only adding residual penalties.
  • It connects to control, inverse design, fluid simulation, and later foundation-model-for-science discussions.
  • It also gives a bridge between classical adjoint methods and modern automatic differentiation.

Practical Caution

Differentiability is useful only if the gradients are meaningful and computationally feasible. Large multiphysics codes, long rollouts, discontinuities, and unstable adjoints can still make the approach hard.

Takeaway

The first-principles lesson is that gradients turn simulation from a black-box data source into an optimization object. That is why differentiable physics is central to inverse problems, control, and scientific ML.
