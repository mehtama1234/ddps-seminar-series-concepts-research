Talk 10 · Technical University of Munich

Nils Thuerey: Differentiable Physics Simulations For Deep Learning

This lecture shows how to connect simulators and deep learning by making the simulator compute gradients, so that signals from physical laws can guide learning, answer inverse problems, and improve control.

YouTube source · Talk page

Core Problem

Using simulators only to generate training data misses a chance. Many real applications need to know: if I change an input, a parameter, or a control signal, how would the physical outcome change? To answer that question, you need gradients that flow back through the simulator.

First-Principles Model

A simulator takes initial conditions, parameters, or control actions and predicts future physical states. If the simulator computes gradients, you can turn the problem around: start from a desired outcome and work backward to find what causes would produce it. This lets you reduce numerical error, infer what controls produced an observation, improve designs, and train neural networks inside the physics simulation loop. The simulator stops being just a data generator and becomes part of the optimization path itself.

Key Claims

  • Physical models and numerical methods have real value and should be preserved when possible, with learning handling measurement noise, observation gaps, and unknown effects.
  • Forward simulation shows you what will happen; inverse problems ask what initial conditions or actions would lead to a desired outcome.
  • Learning from simulator-generated data is helpful but loosely connected to the physics.
  • Adding physics only to the loss function creates a tighter connection, but differentiable simulation creates the tightest coupling between simulator and learning.
  • What matters most is the gradient of the simulation result with respect to the starting conditions or the action taken.
  • Solvers that compute gradients can be used inside the training loop for learning, control, and fixing errors in approximate numerical methods.

Important Terms

Differentiable Simulator

A simulator that computes and returns gradients showing how its outputs would change if inputs, states, control signals, or parameters changed.

Solver-In-The-Loop

A learning system where a numerical solver runs as part of training and provides gradient information to guide the learning.

Adjoint

A method for efficiently calculating how a small change at the end of a simulation would have needed to change earlier steps to produce that outcome.

Inverse Problem

A problem where you start with observed or desired outcomes and work backward to find the hidden causes, parameters, or actions that led to them.

Numerical Error Correction

Learning a small adjustment that cancels out errors introduced by using coarse computational grids, simple mathematical methods, or approximate solvers.

Connections Across The Series

  • This is the differentiable-simulation foundation for the playlist and extends PINNs by moving the solver into the learning process rather than only adding penalty terms.
  • It connects to control, inverse design, fluid simulation, and upcoming talks on machine learning for science.
  • It also bridges classical adjoint methods from scientific computing to modern automatic differentiation tools.

Practical Caution

Gradients are useful only if they accurately reflect what really happens and if computing them stays fast enough. Large codes that combine many physics domains, long prediction horizons, sudden discontinuities, and unstable math can still make this approach impractical despite the theory.

Takeaway

The core insight is that gradients turn simulation from an opaque data source into something you can optimize through. That is why differentiable physics matters for inverse problems, control, and machine learning applied to science.
