Talk 15 · ENSAM Institute of Technology / ESI Group

Francisco Chinesta: Empowering Hybrid Twins From Physics-Informed Artificial Intelligence

This series is about teaching computers to predict how things behave in the physical world by learning from examples instead of using only hand-built math. One approach is to start with the math that engineers already know (the physics model), then add a learning program that figures out what the physics model misses — the real-world messy bits that the simple math cannot capture — so the computer gets closer to what actually happens.

YouTube source · Talk page

Core Problem

Physics models are approximations. They describe the big rules — how heat flows, how stress builds in material, how a machine wears — but real systems behave differently because of things the model did not account for: uneven loading over time, hidden material changes, or effects too detailed to write down. Engineers need digital twins that combine the known physics with a separate piece that learns the gap between what the math predicts and what the actual machine does. A pure physics model leaves the gap uncorrected. A pure data-learning program can be unreliable and may not respect the physical rules that the system must follow.

First-Principles Model

The core idea is a simple picture: what actually happens equals the known physics plus the unseen gap. A hybrid twin keeps two parts working together. Part one is the original physics model — the trusted equations engineers built over years. Part two is a learning program trained on measurements to predict just the difference: prediction from physics minus what we actually measured. When you add these two parts together, the twin matches reality better. Now the twin can do two jobs: diagnosis (figuring out what is wrong or different right now by comparing physics + learned gap to the real measurement) and prognosis (predicting what will happen next by running both models forward).

Key Claims

  • Industry is shifting from selling a product once to guaranteeing how it performs during actual real-world use.
  • A physics model always misses something, so treating the mismatch between prediction and measurement as a real phenomenon to model directly makes sense.
  • The best digital twins combine trusted physics equations with a learned model that predicts the gap.
  • When a learning program predicts the gap, it should still obey physical laws, including the rules about energy and mass that govern the system.
  • Once the twin matches reality, it can help you figure out what is wrong now (diagnosis) and what will happen next (prognosis).
  • Model reduction, curve fitting, and data learning are related techniques for building accurate approximations when you combine physics and data this way.

Worked Example

A composite material crash simulation with 5+ million finite elements and 20 parameters (thickness, material properties, design geometry) normally requires days or weeks per run. Using proper generalized decomposition (PGD) with sparse sampling, the method generates a parametric solution with approximately 20 simulation runs—one per parameter. A Hyundai car crash example demonstrates real-time parameter exploration: sliders control structural thicknesses and show impact on peak stress and energy absorption instantly. A resin infusion (RTM) process exhibits filling time that scales inversely with permeability; inverse analysis identifies the actual permeability from observations in seconds by interrogating the parametric solution, matching experimental flow front position to within measurement uncertainty.

For a tensile test with stochastic material parameters (k, ε₀, n following distributions), the method computes not just one traction curve but a 95% confidence corridor—the range within which results fall with 95% probability. The fracture point probability corridor is obtained by adding variance to parameter distributions while keeping the base parametric model fixed.

One Level Deeper

The hybrid paradigm decomposes reality as: Real system = Physics-based model + Deviation (ignorance). Model order reduction via PGD treats parameters as extra coordinates; a solution u(x,t,μ₁,...,μₘ) is approximated by separable form: Σᵢ Xᵢ(x)·Tᵢ(t)·Pᵢ₁(μ₁)·...·Pᵢₘ(μₘ). This tensor decomposition avoids the curse of dimensionality by solving low-dimensional univariate problems. Sparse regularization (elastic net or Lasso) selects which basis functions contribute, avoiding overfitting in low-data regimes where sampling ≈ number of parameters.

When model predictions diverge from measurements, the deviation is learned as a separate data-driven model (neural network, polynomial regression, or kernel method) preserving physics: new models are trained to satisfy conservation laws (energy), entropy production, and symmetries via Hamiltonian + dissipation structure. The final prediction combines high-fidelity fast physics with corrective deviation model: prediction = parametric PDE solution + learned_gap_model.

Failure Boundary

The method assumes the high-fidelity model captures the dominant physics correctly and deviations are small perturbations. If the model is fundamentally wrong (missing coupling, incorrect PDE form), no regression can fix it—deviation learning only works for unmodeled-but-small effects. Sparse sampling (≈ p samples for p parameters) relies on the assumption that a rich basis exists and sparsity will select the right terms; if the true solution has dense dependence on all parameters, underfitting occurs. Parametric solutions are only accurate within the sample range; extrapolation beyond observed parameter values is unreliable. For highly nonlinear or bifurcating systems (where small parameter changes cause large qualitative shifts), interpolation on manifolds can fail if the dimension of the manifold is underestimated or if transitions are sharp rather than smooth.

Important Terms

Hybrid Twin

A digital copy of a real machine or system that combines two prediction engines running side by side: a model built from known physics equations, and a separate program trained on data that learns to correct or fill in what the physics misses.

Model Gap

The difference between what the physics equations predict and what happens in the real system, measured by comparing predictions to actual sensor data.

Diagnosis

Using measurements from right now to figure out what the current state of the system is, or to spot something unusual or broken.

Prognosis

Using the twin to predict what the system will do in the future, or to estimate when it might fail.

Thermodynamic Consistency

A rule that any learned model must follow: it cannot violate the basic laws about energy, heat, and mass that must hold true in any real system.

Connections Across The Series

  • This is the clearest direction in DDPS for hybrid physics-and-learning systems: learn only the missing piece instead of trying to learn everything from raw data alone.
  • It connects to fast reduced-order models because these lean physics models often become the core backbone of a real-time twin that needs to run quickly.
  • It also connects to uncertainty and control because diagnosis and prognosis require the twin to stay correct as the real system changes and new measurements arrive.

Practical Caution

A digital twin is not just a screen showing numbers or a single learning program trained on old data. If the twin does not split physics from learned corrections, you cannot tell when the model is guessing far beyond the range of examples it saw. That breaks trust. You need to know when the learned part is being asked to predict something it has never seen before.

Takeaway

The central idea is this: hybrid twins are gap models wrapped around physics. Keep the physics you know. Learn what you do not. Train the twin on real measurements so it can correct itself and match the real system.
