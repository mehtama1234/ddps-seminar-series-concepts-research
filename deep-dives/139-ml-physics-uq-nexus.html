Talk 139 · Johns Hopkins University

Michael Shields: The Nexus of Machine Learning, Physics-Based Modeling, and Uncertainty Quantification

This lecture explains how to measure and account for uncertainty in machine-learning models that simulate physics and make scientific predictions.

YouTube source · Talk page

Core Problem

Physics-based models have uncertainties in inputs, parameters, and how we model the world itself. When we add machine learning, we introduce more uncertainty from data, training choices, and whether the learned model works on new problems. Scientific predictions that matter need both machine learning and uncertainty measurement—not treating uncertainty as a last-minute afterthought.

First-Principles Model

Uncertainty falls into two types: epistemic (what we could know if we had more information) and aleatory (randomness built into nature itself). In scientific machine learning, there are two directions. First: UQ for ML asks how sure we can be about a machine-learning model's predictions. Second: ML for UQ means using machine learning to speed up or improve how we calculate uncertainty through a system, build simpler models that replace expensive ones, figure out which inputs matter most, and solve inverse problems (working backward from measurements to find unknown causes). The lecture frames these roles as increasingly vital for broad scientific models that other researchers can trust.

Key Claims

  • Uncertainty measurement and machine learning are increasingly needed in physics-based models that run on computers.
  • Physics-based models are filled with epistemic and aleatory uncertainties.
  • Adding machine learning to a physics model creates additional uncertainties beyond what the original physics had.
  • Uncertainty measurement has become central to physics-based modeling.
  • The talk separates uncertainty measurement of ML models from using ML to improve uncertainty measurement itself.
  • Scientific models that can be widely applied require methods that measure and account for uncertainty.

Important Terms

Uncertainty Quantification

Measuring and calculating uncertainty in model inputs, parameters, model structure, and what the model predicts.

Epistemic Uncertainty

Uncertainty from not knowing something that could be learned with more data or better measurements.

Aleatory Uncertainty

Uncertainty that comes from randomness or natural variation in the world.

UQ for ML

Measuring how uncertain a machine-learning model is in its predictions.

ML for UQ

Using machine learning to speed up or improve the process of measuring uncertainty in physical systems.

Connections Across The Series

  • This talk connects ideas about trustworthy AI, Bayesian methods for neural models, multi-fidelity learning (combining simulations with different levels of detail), and scientific foundation models.
  • It strengthens all other DDPS lectures by making uncertainty a main output alongside predictions.
  • It also ties to evaluation discussions: reliability means knowing when a model might be wrong and by how much.

Practical Caution

Uncertainty measurements can give false confidence. They should be tested against known cases, checked on data the model hasn't seen before, and examined for how sensitive they are to assumptions about the model's form.

Takeaway

The first-principles lesson is that scientific machine learning is incomplete unless it measures how uncertain its predictions are and explains why.
