Talk 122 · University of Amsterdam

Max Welling: Machine Learning for Molecules and Materials

This lecture surveys how machine learning is changing molecular and materials science through learned energy models, density-functional calculations, and math-based scientific applications.

YouTube source · Talk page

Core Problem

Natural-science problems like molecular simulation and materials discovery need accurate models of how atoms and molecules interact across different scales. Traditional physics equations are expensive to solve, while generic machine learning often ignores symmetries (patterns that repeat), conservation laws (quantities that never change), and the physical structure that should guide how the model works.

First-Principles Model

Machine learning for molecules and materials builds in physical constraints—symmetries and conservation laws—to learn energy landscapes, atomic forces, how electrons behave, and continuum models that predict what happens at large scales. Learned force fields quickly approximate what expensive quantum or atomic-scale calculations would give. Density-functional theory (a physics method using electron density instead of full wave equations) and partial-differential-equation models are places where machine learning components can speed up scientific prediction while keeping the mathematical structure intact.

Key Claims

  • Machine learning has become a major application area in the natural sciences, not just text and images.
  • Machine learning has made significant contributions to molecular and materials modeling.
  • Learned force fields are a central example of how machine learning can copy scientific models.
  • Density-functional theory and partial-differential-equation modeling are important areas where machine learning helps science.
  • Mathematics, physics, and neuroscience continue to inspire better machine learning algorithms.
  • Machine learning applied to science may help address large challenges like climate change.

Important Terms

ML Force Field

A learned model that predicts how much energy a molecule has and what forces push atoms around, enabling fast simulation without expensive quantum calculations.

Density Functional Theory

A physics method for modeling systems with many particles by tracking electron density instead of solving full wave equations.

Molecular Simulation

Computer calculation of how molecules move and interact with each other.

Materials Discovery

Finding new materials with desired properties by combining computation, experiments, and machine learning.

Physical Inductive Bias

A choice in how the model is built, derived from physical principles like symmetry or conservation, that steers the model toward physically sensible answers.

Connections Across The Series

  • This talk connects foundation models for science, geometric deep learning (machine learning that respects shapes and symmetries), physics-aware architectures, and materials discovery.
  • It complements lectures on molecules, partial-differential equations, and neural operators by placing them as part of a broader shift where machine learning enters science.
  • It also links to the data-progress theme because high-quality scientific data and simulation results shape how well the model works.

Practical Caution

Scientific machine learning models for molecules and materials must respect symmetries and physical constraints. High accuracy on benchmark tests is not enough if the model breaks on chemistries or material conditions it hasn't seen during training.

Takeaway

The core lesson is that science machine learning works best when learned approximations are guided by the geometry and laws of the physical system.
