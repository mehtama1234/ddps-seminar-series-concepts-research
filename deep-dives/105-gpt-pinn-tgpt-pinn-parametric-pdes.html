Talk 105 · UMass Dartmouth

Yanlai Chen: GPT-PINN and TGPT-PINN

This whole series is about getting computers to predict physical behavior by learning from examples instead of only hand-written math. One popular way is to let a learning program (a huge bank of dials the computer tunes by trial and error until its answers look right) also be told the laws of physics as it learns. But when you want to solve physics equations that change as one value—like thickness or temperature—shifts, training the whole learning program over and over is too slow. This talk shows how to reuse a trained learning program from one value and bolt it together with other versions at different values, feeding the result into a tiny network that learns how the answer shifts as the value changes—giving you accurate answers fast.

YouTube source · Talk page

Core Problem

Physics equations that change as parameters shift (like thickness, angle, or pressure) are everywhere in engineering. Right now, the slow way is to train a learning program from scratch each time the parameter changes. We waste time and also waste computing power because the same size network might be overkill for one setting and too small for another. We need a way to train once and reuse that work for many different parameter values.

First-Principles Model

Start with a learning program trained on one physics equation at one parameter value—it has millions of dials tuned to make its predictions match the physics. The new idea: take these trained programs from selected parameter values and treat each one as a single unit (the way a simple rule or a sensor is a unit). Stack them together and feed the results into a second, much tinier learning program. This tiny program only needs to learn how the answer shifts as the parameter changes, not rediscover the physics from scratch. That's the first version. The second version adds a mixing layer before each trained unit, allowing the tiny program to stretch or squeeze the trained outputs into new patterns—like translating between different languages—so it can reuse them even more flexibly.

Key Claims

  • Training a learning program for each new parameter value is too slow when you have many values to solve.
  • You can treat already-trained learning programs as building blocks inside a much smaller network.
  • The outer network can be shrunk to just one hidden layer with far fewer dials than the original.
  • You can add exactly as many dials as you need by building the layer one dial at a time.
  • This approach gives accurate answers across all parameter values with far less computation.
  • Adding a mixing layer before the trained blocks lets the outer network reuse them in even more flexible ways.

Important Terms

PINN

A learning program trained to predict physics by having two goals: match real observations and also obey the physics equation (the penalty for breaking the equation is added to the training score).

GPT-PINN

A method that takes already-trained learning programs from a few parameter values and feeds their outputs into a smaller learning program that learns how the answer shifts across all parameters.

TGPT-PINN

The version with a mixing layer added—the smaller program can stretch and squeeze the trained outputs before using them, letting it adapt them to new situations.

Parametric PDE

A physics equation whose answer changes as you change one or more values (like how the temperature pattern in a heated rod changes as the rod gets thicker or the heat input rises).

Meta-Network

A learning program that sits on top of other learning programs and learns how to combine or switch between them, treating them as tools rather than training from scratch.

Connections Across The Series

  • This work sits at the crossroads of three ideas: training learning programs to respect physics rules, compressing big learning programs into smaller ones that still work, and learning how to reuse trained programs across many situations.
  • Earlier talks showed neural operators—ways to train one learning program that works for all parameter values at once. This talk does something related but different: it stacks pre-trained programs together instead.
  • The repeated pattern in this whole seminar is: how do we avoid re-training and re-computing the same physics over and over? This talk answers it by showing how trained work can become reusable parts.

Practical Caution

The trained programs you reuse are only useful if you picked parameter values that actually cover the kinds of answers that appear. Pick wrong values, and the tiny program might confidently give answers that are completely off. It's like training someone to recognize animals by only showing them cats and dogs, then asking them about a llama.

Takeaway

Physics equations with changing parameters get faster and cheaper to solve when you reuse trained learning programs (like building blocks) in a smaller network rather than training from zero each time.
