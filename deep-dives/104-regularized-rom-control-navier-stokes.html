Talk 104 · Universita Cattolica del Sacro Cuore

Francesco Ballarin: Regularized Reduced Order Models for Control of Navier-Stokes Equations

This lecture shows how adding smoothing terms and stabilization makes reduced-order models more reliable for steering incompressible fluid flows described by Navier-Stokes equations.

YouTube source · Talk page

Core Problem

When fluid simulations on a coarse grid miss fine detail, they produce wiggles and false oscillations. Reduced-order models (ROMs—simplified versions that run fast) make this worse because they throw away so much information. Add control to the picture: now the ROM must both simulate the flow accurately and steer it where you want it to go.

First-Principles Model

Full-order simulations add dampening and filtering to stop the wiggles. A ROM compresses the flow field down to a few key patterns, but that compression can remove the natural dampening, making the reduced equations unstable. The talk compares two fixes: evolve-filter-relax, where you run one time step, filter out spurious high-frequency junk, then pull the result back toward the stable manifold (the set of states the system naturally prefers); and approximate deconvolution, where you filter and then try to guess what the missing high-frequency parts were. Both strategies then get plugged into feedback control (where you measure the flow state and use it to adjust your actuators).

Key Claims

  • Smoothing is standard practice for full-size fluid simulations, yet few researchers study how to stabilize ROMs.
  • Flows where transport overwhelms diffusion, especially on marginal grids, are fragile to missing scales.
  • A ROM for control must stay accurate when you're feeding back the measured state, not just when you run it open-loop (no feedback).
  • Evolve-filter-relax smoothing can be used inside a reduced-order feedback controller.
  • Approximate-deconvolution smoothing offers a different way to recover the effects of filtered-out scales.
  • A good ROM balances speed, stability, and control accuracy.

Important Terms

Navier-Stokes Equations

The laws that describe how incompressible or compressible fluids move, accounting for momentum and pressure.

Convection-Dominated Flow

A flow regime where material gets carried along faster than it spreads out, creating sharp edges and making numbers blow up on coarse grids.

Evolve-Filter-Relax ROM

A reduced model that takes one time step, removes high-frequency nonsense with a filter, then nudges the result back to a stable zone.

Approximate Deconvolution

A technique that guesses what information was discarded by a filter, to restore accuracy lost during smoothing.

Feedback Control

A method where you measure the current state of the system and use that measurement to decide what command to send, so the system steers toward your target.

Connections Across The Series

  • This lecture brings together ROMs, flow control, numerical smoothing, and closure methods (ways to account for unresolved scales).
  • It fills a gap next to talks on operator inference and projection-based methods by asking what happens when small scales destabilize a reduced controller.
  • It also touches digital twins: if you want a fast surrogate of a controlled flow system to run in real time, that surrogate must stay stable when you're steering it.

Practical Caution

A smoothed ROM can stop wobbling but give you the wrong answer. For control, the smoothing must protect the dynamics you actually need to control, not just hide all the wiggles.

Takeaway

Reduced-flow control needs stabilization designed for the shrunk-down equations, not just copying smoothing rules from the full simulation.
