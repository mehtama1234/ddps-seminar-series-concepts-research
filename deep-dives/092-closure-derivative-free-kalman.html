Talk 92 · University of Wisconsin-Madison

Jinlong Wu: Data-Driven Closure Modeling Using Derivative-Free Kalman Methods

This lecture uses derivative-free Kalman methods to learn deterministic and stochastic closure models for complex dynamical systems from limited and indirect data.

YouTube source · Talk page

Core Problem

Turbulence, cloud dynamics, and other multiscale systems cannot resolve all degrees of freedom. Closure models are necessary, but traditional closures have limited representation power and empirical calibration. Learning closures is harder when data are indirect, limited, or noisy.

First-Principles Model

A closure maps resolved variables to the unresolved effects that influence their evolution. Kalman inversion methods treat unknown closure parameters as latent states and update them using ensemble-based data assimilation, without requiring explicit derivatives of the closure objective. This makes it possible to learn closures from indirect observations and to extend from deterministic closures to sparse and stochastic closure forms.

Key Claims

  • Closure problems are critical for complex dynamical systems where resolving all degrees of freedom is infeasible.
  • Existing closure models remain unsatisfactory partly because of limited representation power and empirical calibration.
  • Derivative-free Kalman methods can learn closure models from indirect and limited data.
  • The approach supports deterministic closure learning.
  • Sparse identification of dynamical systems can also be handled in this framework.
  • Derivative-free Kalman inversion can learn stochastic closures from indirect data.

Important Terms

Closure Model

A model for unresolved physical effects on resolved variables.

Derivative-Free Kalman Method

An ensemble-based update method for parameter learning that avoids explicit gradient computation.

Indirect Data

Observations that do not directly measure the closure quantity being learned.

Sparse Identification

Learning governing equations or closures by selecting a small number of active terms.

Stochastic Closure

A closure model that represents unresolved effects probabilistically.

Connections Across The Series

  • This lecture continues the closure thread from LES, ROMs, and structure-preserving closure talks.
  • It connects to data assimilation because Kalman-style updates infer parameters from observations.
  • It also links to SINDy and sparse system identification as tools for interpretable learned closures.

Practical Caution

Derivative-free methods avoid gradients but not identifiability problems. If indirect data are too weak, multiple closure models may explain the observations equally well.

Takeaway

The first-principles lesson is that closure learning is inference from partial evidence. Kalman methods provide a gradient-free route when direct closure data are unavailable.
