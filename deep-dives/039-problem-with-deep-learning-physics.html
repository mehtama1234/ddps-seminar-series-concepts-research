Talk 39 · Princeton University

Miles Cranmer: The Problem With Deep Learning For Physics And How To Fix It

This lecture argues that deep neural networks that hide their inner workings can create scientific debt in physics and proposes interpretable alternatives such as inductive biases and symbolic regression.

YouTube source · Talk page

Core Problem

Deep learning can solve high-dimensional prediction problems, but if the learned solution is opaque, science may gain performance without understanding. That creates scientific debt: future researchers must explain what the model learned and whether it reflects real physical mechanism.

First-Principles Model

Physics already has a language for explaining things: mathematics. Instead of using neural networks only as hidden-solution predictors, you can build physical structure into the network itself, such as Lagrangian neural networks (where the network learns an energy-like quantity and applies physics equations to compute motion), or distill trained networks into symbolic equations using symbolic regression (a method that searches for formulas fitting data). The goal is to turn learned patterns into testable scientific statements you can inspect.

Key Claims

  • Using deep learning without guidance can delay the need to understand the physical problem.
  • Standard interpretation methods from computer vision do not work well for physics because physics has symbolic mathematical structure.
  • Inductive bias restricts the space of functions a model can learn toward physically realistic forms.
  • Lagrangian neural networks learn a physical quantity (like energy) inside an existing mechanics framework.
  • Graph networks match particle-like physical systems well because natural systems are relational rather than only gridded.
  • Symbolic regression can approximate internal neural-network components with analytic equations.

Important Terms

Scientific Debt

The accumulated explanatory burden created when a model predicts well without producing scientific understanding.

Inductive Bias

A prior restriction on what functions a model can learn, often used to encode physical structure.

Symbolic Regression

A search method for finding analytic equations that fit data or approximate a learned model.

Lagrangian Neural Network

A neural model that learns an energy-like function and derives dynamics through mechanics equations.

Equation Distillation

Extracting simpler symbolic formulas from a trained neural network or its learned components.

Connections Across The Series

  • This talk stands in opposition to hidden-solution surrogate modeling throughout the series.
  • It connects to SINDy, Green's functions, and nonlocal kernels because all emphasize learning inspectable mechanisms.
  • It also ties back to physics-guided forecasting: inductive bias is not optional decoration, it is what makes models scientifically usable.

Practical Caution

A physically inspired neural network can still fail if the prior is too weak or the variables cannot be determined from the data. Interpretability methods should produce testable equations or mechanisms, not just prettier graphs.

Takeaway

The first-principles lesson is that scientific machine learning should pay back its explanatory debt. Use neural networks to discover mechanisms, not merely to hide them.
