Talk 39 · Princeton University

Miles Cranmer: The Problem With Deep Learning For Physics And How To Fix It

This lecture argues that black-box deep learning can create scientific debt in physics and proposes interpretable alternatives such as inductive biases and symbolic regression.

YouTube source · Talk page

Core Problem

Deep learning can solve high-dimensional prediction problems, but if the learned solution is opaque, science may gain performance without understanding. That creates scientific debt: future researchers must explain what the model learned and whether it reflects real mechanism.

First-Principles Model

Physics already has an interpretability language: mathematics. Instead of using neural networks only as black-box predictors, one can build physical inductive biases into the architecture, such as Lagrangian neural networks, or distill trained networks into symbolic equations using symbolic regression. The aim is to turn learned patterns into inspectable scientific statements.

Key Claims

  • Using deep learning blindly can postpone the need to understand the physical problem.
  • Standard interpretation methods from computer vision are not ideal for physics because physics has symbolic mathematical structure.
  • Inductive bias restricts the space of functions a model can learn toward physically meaningful forms.
  • Lagrangian neural networks learn a physical quantity inside an existing mechanics framework.
  • Graph networks are well suited to particle-like physical systems because natural systems are relational rather than only gridded.
  • Symbolic regression can approximate internal neural-network components with analytic equations.

Important Terms

Scientific Debt

The accumulated explanatory burden created when a model predicts well without producing scientific understanding.

Inductive Bias

A prior restriction on what functions a model can learn, often used to encode physical structure.

Symbolic Regression

A search method for analytic equations that fit data or approximate a learned model.

Lagrangian Neural Network

A neural model that learns a Lagrangian or energy-like function and derives dynamics through mechanics equations.

Equation Distillation

Extracting simpler symbolic formulas from a trained neural network or its learned components.

Connections Across The Series

  • This talk is a philosophical and technical counterweight to black-box surrogate modeling throughout the series.
  • It connects to SINDy, Green's functions, and nonlocal kernels because all emphasize learning interpretable mechanisms.
  • It also ties back to physics-guided forecasting: inductive bias is not optional decoration, it is what makes models scientifically usable.

Practical Caution

A physically inspired neural network can still be degenerate if the prior is too weak or the variables are not identifiable. Interpretability methods should produce testable equations or mechanisms, not just nicer visualizations.

Takeaway

The first-principles lesson is that scientific ML should repay its explanatory debt. Use neural networks to discover mechanisms, not merely to hide them.
