Talk 39 · Princeton University

Miles Cranmer: The Problem With Deep Learning For Physics And How To Fix It

This whole series is about getting computers to predict how physical things behave by learning from examples instead of only hand-written math. A popular way is to feed a learning program (a huge bank of dials the computer tunes by trial and error) the laws of physics as it trains. This talk asks: when you use this approach to solve a physics problem, do you end up with an answer that works well but stays hidden inside the network — and if so, does that help science or hurt it?

YouTube source · Talk page

Core Problem

A learning program can predict what happens in high-dimensional, complicated situations — like how a fluid flows around an object with many shapes and forces — better and faster than writing out all the math by hand. But if the answer is completely hidden inside millions of tuned dials, science gets stuck. Future researchers don't know what physical rule the program learned, whether that rule is actually true in the real world, or whether the program just found a sneaky shortcut that works for the data it saw but breaks on new situations. This accumulated debt — knowing it works but not why — is what blocks science from moving forward.

First-Principles Model

Physics has a language built in: mathematical rules. Instead of hiding the answer inside a neural network, you can build physical structure into how the network itself works. One way: a Lagrangian neural network is a program that learns a single number (like energy) and then applies the known laws of physics to predict how things move from that energy value. Another way: after training a network, you can search for simple math formulas that match what the network learned, using a process called symbolic regression — this turns the network's hidden decision into an equation you can read and test. The goal is to turn the patterns the program found into statements a scientist can inspect and check.

Key Claims

  • A learning program without guidance can delay the hard work of truly understanding the physical problem.
  • Methods that worked well for explaining images don't work well for physics, because physics has built-in mathematical structure that images don't.
  • Placing constraints on what a model can learn steers it toward solutions that act like real physics.
  • Lagrangian neural networks learn a physical quantity (energy-like) by baking in the existing laws of motion.
  • Networks built as graphs (nodes connected like particles) match natural systems well, because real systems are built on relationships between parts.
  • You can take what a trained network learned and approximate it with simple math formulas that humans can read.

Important Terms

Scientific Debt

The gap between knowing a model works and actually understanding why it works — the unpaid cost that blocks science.

Inductive Bias

A constraint you build into a model beforehand that restricts what answers it's allowed to learn, steering it toward physically sensible patterns.

Symbolic Regression

A computer search that tries to build simple, readable math formulas that fit the data or approximate a trained network.

Lagrangian Neural Network

A network designed to learn a single physical quantity (energy) and then apply motion equations to predict what happens next.

Equation Distillation

Pulling simple math formulas out of a trained network so you can see and test them instead of leaving them hidden.

Connections Across The Series

  • This talk goes against the idea of using learning programs purely as fast replacements for physics simulations — a theme running through the whole series.
  • It connects to talks on SINDy (a method to extract equations from data), Green's functions (a classical physics tool), and kernel methods, because all of them prioritize learning rules you can inspect and verify.
  • It ties back to physics-guided forecasting: you can't treat constraints as a nice extra — they're what makes a model useful to actual science.

Practical Caution

Even when you build physics into a network, it can still fail if your built-in constraints are too weak or if the data doesn't contain enough information to pin down the quantity you're trying to learn. If you create a method to see what's inside the network, it should produce equations you can actually test, not just diagrams that look nicer than before.

Takeaway

Scientific machine learning has a debt: it must repay the cost of not understanding. Use learning programs to uncover the mechanisms at play — not to hide them behind numbers.
