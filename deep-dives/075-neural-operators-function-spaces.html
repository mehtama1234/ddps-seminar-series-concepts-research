Talk 75 · Caltech / NVIDIA

Anima Anandkumar: Neural Operators On Function Spaces

This lecture explains neural operators as function-space learners for PDEs and multiscale scientific systems, emphasizing zero-shot generalization and large speedups over numerical solvers.

YouTube source · Talk page

Core Problem

Scientific systems such as weather, climate, deep earth, materials, and quantum-to-planetary-scale processes are governed by mappings between fields, not fixed-size vectors. Standard neural networks tied to one discretization struggle to generalize across resolutions, domains, and boundary conditions.

First-Principles Model

A PDE solver maps input functions, such as coefficients, initial conditions, or forcing fields, to output functions, such as solution fields. A neural operator learns this operator directly on function spaces. Because the learned object is a discretization-independent map, it can be evaluated on new meshes and can capture multiscale field-to-field structure more naturally than ordinary finite-dimensional networks.

Key Claims

  • Neural operators are designed for solving PDEs by learning mappings between function spaces.
  • Function-space learning is especially suitable for multiscale scientific applications.
  • Applications include weather and climate modeling, deep earth modeling, and other scientific simulations.
  • Principled neural-operator approaches can enable zero-shot generalization beyond the training domain.
  • Neural operators can produce 4-5 orders of magnitude speedups over numerical weather models and other simulations.
  • Their advantage is not just using neural networks, but learning the right mathematical object: an operator.

Important Terms

Neural Operator

A neural architecture that learns mappings between functions rather than fixed-dimensional vectors.

Function Space

A mathematical space whose elements are functions, such as fields over a spatial domain.

Zero-Shot Generalization

Generalizing to new regimes or domains without additional training examples from that regime.

Multiscale Process

A process whose behavior depends on interactions across many spatial or temporal scales.

Operator Learning

Learning the map from inputs to solution functions for a family of problems.

Connections Across The Series

  • It connects to ROMs because both seek reusable fast maps, but operators target function-to-function generalization.

Practical Caution

Zero-shot generalization must be tested against real distribution shifts, not assumed from architecture alone. Operator learning can still fail outside the training physics or boundary-condition family.

Takeaway

The first-principles lesson is that PDE learning should target solution operators, not isolated solution vectors. The architecture should match the mathematical object.
