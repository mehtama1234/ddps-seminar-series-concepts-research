Talk 108 · Stanford University

Gianluca Iaccarino: AutoEncoders for Aerodynamic Predictions

This lecture uses autoencoders to learn low-dimensional latent representations for predicting aerodynamic flow over wing geometries.

YouTube source · Talk page

Core Problem

Aerodynamic prediction over many wing geometries requires fast generation of unseen flow cases, but flow fields are high-dimensional and nonlinear. Linear compression can miss separated-flow structure, while black-box nonlinear compression raises trust and uncertainty questions.

First-Principles Model

An autoencoder maps a high-dimensional flow field into a low-dimensional latent code and then decodes that code back to a flow field. If the dataset is carefully constructed, the latent variables can align with meaningful aerodynamic inputs and performance quantities. The lecture compares nonlinear autoencoder compression against Gaussian process regression and linear compression, while investigating uncertainty from architecture, hyperparameters, and training-data amount.

Key Claims

  • Autoencoders can provide nonlinear compression for aerodynamic flow data.
  • The latent representation can support prediction for new wing geometries.
  • Careful dataset construction can make latent variables interpretable in terms of aerodynamic performance.
  • The method is tested for both attached and separated flow conditions.
  • Internal or model-form uncertainties arise from architecture choices, hyperparameters, and training-data size.
  • Comparisons with Gaussian processes and linear compression clarify when nonlinear latent models add value.

Important Terms

Autoencoder

A neural network trained to compress data into a latent representation and reconstruct it.

Latent Variable

A learned low-dimensional coordinate representing important variation in the original data.

Separated Flow

A flow regime where the boundary layer detaches from the surface, creating complex wake behavior.

Model-Form Uncertainty

Uncertainty caused by choices in the model architecture or assumptions, not just data noise.

Nonlinear Compression

Dimensionality reduction that uses nonlinear mappings rather than linear subspaces.

Connections Across The Series

  • This talk connects autoencoders, ROMs, latent spaces, and uncertainty-aware aerodynamic prediction.
  • It complements nonlinear manifold ROM talks by focusing on interpretability of latent coordinates.
  • It also links to design workflows, where new geometries must be evaluated quickly.

Practical Caution

A smooth latent space can look interpretable while hiding extrapolation. Trust requires checking architecture sensitivity, data coverage, and performance on unseen flow regimes.

Takeaway

The first-principles lesson is that useful aerodynamic ML compresses flow fields into latent variables that are predictive, interpretable, and uncertainty-aware.
