Talk 48 · Princeton University / Johns Hopkins University

Yannis Kevrekidis: No Equations, No Variables, No Parameters, No Space And No Time

This whole series is about getting computers to predict how physical things behave by learning from data and examples instead of only hand-written math. This talk asks: do you always need to know the step-by-step rules written down as equations, or can you sometimes find useful shorthand descriptions of a complex system directly from observations, without writing any equations at all?

YouTube source · Talk page

Core Problem

The normal way to study a complex system goes like this: watch what happens, choose some numbers to track (called variables: for instance, temperature at three spots), write down rules that say how those numbers change over time, pick the numbers that go into the rules (called parameters: things like how heat spreads through metal), and then work through the math to predict what happens. But for many real systems, this gets stuck. Nobody agrees on which numbers are really important to track, or they're hidden deep inside millions of pieces of data. The tiny, detailed simulation (like tracking every atom's motion) might run perfectly, but nobody can write down a simple closed-form rule (equations) that says how the system behaves at the big-picture level. The right shorthand description might live in such a twisted, high-dimensional space that you can't spot it by guessing.

First-Principles Model

Here is the flip: forget about starting with equations. Start with the goal: do you want to predict the future, trace how the system stays stable or jumps to a different mode as something shifts, or control it? Then ask: can I build the actual computational operators I need directly from data, or by running the detailed simulation in short bursts? Several tools can do this without equations. Manifold learning is the idea that real complex systems often live on a simpler, curved surface hidden inside high-dimensional data (like how many different movies can be described by a small set of hidden genres, even though each movie has thousands of pixels). Autoencoders are neural networks - programs with millions of little dials tuned by trial and error until their answers match the data - that squeeze data into a much smaller, compressed representation (like summarizing a long movie plot into a few key story beats), then unsqueeze it back out. Diffusion maps build simple coordinates by watching how fast disturbances spread across the data (the same logic that tells you how far gas has diffused through a room: far means time has passed). Neural ODEs are networks that describe how variables change moment by moment (using a rule: at each step, the next state depends on the current state according to a formula the network has learned). Operator learning teaches a network to map entire functions or states directly to other states (like learning that if the temperature distribution looks like X, it will look like Y a moment later), skipping the need for intermediate equations. Together, these can recover the low-dimensional shorthand and the evolution rules from raw data.

Key Claims

  • Modern neural networks have older roots in the study of how to identify nonlinear systems (real-world systems where a change in one part can cause wildly different effects depending on context).
  • A computational approach to modeling can hit the same analysis goals - prediction, detecting when behavior jumps to a different mode, control - by working with data or short bursts of detailed simulation instead of assuming you have a closed-form equation at the top level.
  • The right numbers to track in a system can be discovered by learning from data, rather than guessed by intuition or tradition.
  • Low-dimensional curved surfaces, where real complex systems live, can be revealed by studying the patterns in high-dimensional observation data.
  • Diffusion maps (a method that uses spreading patterns in data to extract simple coordinates) show one way to learn coordinates that work as useful high-level summaries.
  • The phrase 'no equations, variables, parameters, space, or time' means: the representation you need for your task can be learned rather than assumed or guessed ahead of time.

Worked Example

A micro-scale plankton model with birth, death, random walk, and ocean currents generates stochastic agent trajectories. Without writing the governing equation, coarse-projective integration solves the macroscopic pair-correlation function P(r) by lifting: construct particles matching target P(r), run microscopic simulator for Δt_micro, measure derivative dP/dt at macro scale, then step macro variables by Δt_macro >> Δt_micro using Euler with estimated derivative. Result: macro-scale solution evolves smoothly as observed PDE, 100–1000× speedup compared to direct micro-simulation while maintaining accuracy in statistics and bifurcation structure.

One Level Deeper

Coarse-projective integration requires (1) lifting: given macro state (moment/correlation function), construct ensemble of micro-realizations consistent with it; (2) micro-burst: short-time forward integration to accumulate micro-statistics; (3) restriction: project evolved micro-ensemble back to macro observable and estimate its time derivative via finite difference. The key insight is that macro dynamics are robust to microscopic details—many micro-realizations drive similar macro evolution. Mathematically, the macro system is a hidden Markov process; estimating dP/dt from noisy micro-data requires ensemble averaging. Optional tagging (e.g., stochastic particles with slow/fast splitting) can improve efficiency.

Failure Boundary

Equation-free fails when micro-realizations don't converge to macro observables—incompatibility between lifting and restriction operators causes artificial drift. If the macroscopic observable is poor (e.g., first moment only for a multi-modal distribution), lifting is underdetermined and multiple micro-ensembles map to same macro state, introducing error. Multi-scale separation breaks down: if macro and micro timescales overlap, no clear time-scale hierarchy exists to justify large Δt_macro. For partial-differential equations with spatial coupling, lifting microscopic particles on a coarse grid requires ad-hoc boundary conditions that may not match the true PDE. Method requires strong intuition about which observables matter—wrong choice leads to information loss and prediction failure.

Important Terms

Equation-Free Modeling

A computational approach where you perform high-level analysis and prediction using data or short runs of detailed simulation, instead of finding and writing down the closed-form equations for the whole system.

Macro Observable

A single number or small group of numbers that summarize what the system is doing at the large scale (like temperature averaged across a room, or the main direction a flock is moving).

Manifold Learning

Methods that discover that a complex system's behavior actually lives on a simpler, curved surface - like how a flat sheet of paper, even when crumpled, is still fundamentally two-dimensional - hidden inside high-dimensional data.

Diffusion Maps

A method that learns simple coordinates from data by measuring how fast patterns spread and change (diffusion), the same logic physicists use to measure how gases or heat move through space.

Coarse Time-Stepper

A computational shortcut that advances the high-level description forward in time: translate the abstract description to the detailed level, run the detailed simulation for a short time, translate back to the abstract level.

Connections Across The Series

  • This lecture connects directly to talks on learning effective dynamics (how to predict a system's behavior when you only care about the large-scale motion, not every tiny detail) and data-driven methods for dynamics.
  • It also relates to work on reduced-order models (simplified versions of complex systems that still capture the important behavior) and learning operators (teaching networks to map entire system states to future states), because both search for lower-dimensional or operator-based descriptions of dynamics.
  • Broadly, it reframes scientific machine learning: before you hunt for equations or build a simulator, first figure out what numbers or coordinates even make the problem solvable.

Practical Caution

Learning the shorthand from data only works if your data actually cover the important curved surfaces and operating conditions. A low-dimensional structure that fits your training data perfectly can fail completely when you encounter new situations, rare jumps the training data missed, or parameters your data never saw.

Takeaway

Equations are one tool to write down dynamics, not the only tool. The real goal is to find the shorthand descriptions and operators that make prediction and analysis possible. Sometimes data or quick simulations can give you those shortcuts without writing a single equation.
