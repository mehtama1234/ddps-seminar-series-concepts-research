Talk 48 · Princeton University / Johns Hopkins University

Yannis Kevrekidis: No Equations, No Variables, No Parameters, No Space And No Time

This lecture argues that modern data-driven modeling can sometimes skip explicit equations, variables, parameters, space, and time by finding useful high-level observables and computational representations straight from observations.

YouTube source · Talk page

Core Problem

Classical modeling starts with observations, then defines variables, writes equations, picks parameters, and analyzes. Complex systems often block this path because the right high-level variables stay hidden, the microscopic simulator may exist without closed equations, and the effective geometry or time scale may be buried inside high-dimensional data.

First-Principles Model

The first-principles move is to separate the scientific goal from the traditional symbolic box. If your goal is prediction, continuation, bifurcation analysis (how system behavior changes as a parameter shifts), or control, you can sometimes build the needed computational operators directly from data or short bursts of simulation. Manifold learning (finding low-dimensional curved structure inside high-dimensional data), diffusion maps, autoencoders (neural networks that compress data into smaller representations), recurrent nets, neural ODEs (neural networks that describe change over time), and operator learning can identify low-dimensional coordinates, high-level observables, or evolution rules without first writing a closed-form high-level equation.

Key Claims

  • Many modern neural architectures have older roots in nonlinear dynamical-system identification.
  • Equation-free modeling keeps the analysis goal but swaps explicit high-level equations for computational experiments on data or microscopic simulators.
  • The right variables can be learned from data rather than chosen by intuition alone.
  • Manifold learning can reveal low-dimensional curved structure inside high-dimensional observations.
  • Diffusion maps are one way to learn coordinates on data manifolds that serve as high-level observables.
  • The phrase no equations, variables, parameters, space, or time points to learning the representation needed for the task rather than assuming it in advance.

Important Terms

Equation-Free Modeling

A computational method that performs high-level analysis using data or microscopic simulators without closed-form high-level equations.

Macro Observable

A reduced variable that summarizes the large-scale state of a complex system.

Manifold Learning

Methods that discover low-dimensional curved structure inside high-dimensional data.

Diffusion Maps

A manifold-learning method that uses diffusion geometry on data to construct useful low-dimensional coordinates.

Coarse Time-Stepper

A computational operator that advances high-level variables by lifting them to microscopic states, simulating briefly, and restricting back.

Connections Across The Series

  • This talk links directly to Petros Koumoutsakos' effective dynamics lecture and later data-driven dynamics talks.
  • It also connects to ROMs (reduced-order models, simplified versions of complex systems) and neural operators because both search for lower-dimensional or operator-level descriptions.
  • It reframes scientific ML as representation discovery: first learn what variables or coordinates make the problem solvable.

Practical Caution

Learning coordinates from data works only if the data cover the relevant curved structures. A beautiful low-dimensional embedding can break when you encounter new operating conditions, rare transitions, or parameters you didn't see during training.

Takeaway

The first-principles lesson is that equations are one way to represent dynamics, not the only way. The deeper goal is to find the coordinates and operators that make prediction and analysis possible.
