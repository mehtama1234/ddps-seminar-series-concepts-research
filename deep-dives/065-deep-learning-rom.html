Talk 65 · Politecnico di Milano

Andrea Manzoni: Deep Learning For Reduced Order Modeling

This lecture explains how deep neural networks can improve reduced-order modeling by learning non-intrusive ROMs and neural operators to approximate parametrized PDEs quickly.

YouTube source · Talk page

Core Problem

Classical ROMs speed up parametrized PDE solves for real-time simulation, uncertainty quantification, control, monitoring, and digital twins. But nonlinear time-dependent problems often stay expensive because reducing the dynamics, compressing terms carefully, and accessing the original solver code can be hard to build or deploy in practice.

First-Principles Model

A ROM approximates high-resolution solutions in a low-dimensional representation. Deep learning can replace or add to several ROM parts: encoders map full-resolution snapshots to latent coordinates, decoders reconstruct high-resolution fields, neural maps evolve or parameterize reduced states, and POD-enhanced variants mix classical linear bases with neural nonlinear approximation. The goal is fast simulation without requiring full access to modify the solver.

Key Claims

  • ROM techniques such as reduced basis methods are essential for efficient approximation of parametrized differential equations.
  • ROMs enable real-time simulation and repeated scenario evaluation for uncertainty quantification, control, monitoring, data assimilation, and digital twins.
  • Deep neural networks can build ROMs from full-resolution model snapshots in a fully non-intrusive way.
  • Deep-learning ROMs use neural networks as core building blocks for parametrized PDE approximation.
  • POD-enhanced deep-learning ROMs combine classical projection structure with neural nonlinear maps.
  • Deep learning can also approximate nonlinear ROM operators and improve selective compression of reduced terms.

Important Terms

Reduced-Order Model

A lower-dimensional approximation of a high-resolution model used to speed up simulation.

Full-Order Model Snapshot

A stored high-resolution solution sample used as training or basis data for a ROM.

DL-ROM

A deep-learning-based reduced-order model that uses neural networks to learn reduced coordinates, reconstruction, or dynamics.

POD-DL-ROM

A ROM that combines Proper Orthogonal Decomposition (a classical method to find the simplest basis vectors) with deep neural networks.

Non-Intrusive ROM

A reduced model built without modifying or deeply accessing the code of the original high-resolution solver.

Connections Across The Series

  • This lecture continues the ROM thread and bridges classical reduced basis and POD methods with neural surrogates.
  • It connects to industrial digital twins because real-time parametrized simulation is a core twin capability.
  • It also links to CUR decomposition, adaptive ROMs, and neural operators as different answers to the same compression-and-speed problem.

Practical Caution

A neural ROM trained on snapshots inherits the limits of what those snapshots cover. Non-intrusive convenience does not remove the need for error checks when the model runs on new parameters, geometries, or transient regimes it hasn't seen before.

Takeaway

The first-principles lesson is that deep learning helps ROMs when it learns the nonlinear maps that classical linear reduction cannot represent cheaply.
