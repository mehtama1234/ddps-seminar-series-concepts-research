Talk 96 · University of Twente

Mengwu Guo: Probabilistic Methods for Data-Driven Reduced-Order Modeling

This lecture explains how probabilistic reduced-order modeling can make data-driven digital twins fast while also quantifying uncertainty.

YouTube source · Talk page

Core Problem

Digital twins and multi-query simulations need models that run much faster than full-order solvers. A deterministic surrogate can be fast but overconfident, especially when the online input leaves the region covered by offline simulations.

First-Principles Model

A reduced-order model shrinks a high-dimensional physical system into a lower-dimensional representation. Probabilistic ROMs add uncertainty to this shrinking and prediction process. Gaussian process regression treats the full-order solver as an offline tool and builds a simulation-free online surrogate. Deep kernel learning uses neural networks inside manifold Gaussian processes to discover low-dimensional latent dynamics from noisy high-dimensional images. Bayesian operator inference estimates reduced operators from data while keeping the projected reduced-state equation form and adding regularization and uncertainty estimates.

Key Claims

  • Probabilistic ROMs are useful when fast simulation must also report computational credibility.
  • Gaussian process reduced-order surrogate modeling uses full-order solvers offline for data generation and avoids simulation online.
  • Deep kernel learning can combine neural representation learning with Gaussian process uncertainty.
  • Bayesian reduced-order operator inference is a method that estimates reduced operators without requiring full-order solver internals, and its estimates come with uncertainty bounds.
  • Bayesian inference naturally embeds penalty-based regularization and uncertainty quantification.
  • The three methods span different levels of access to physics structure, from treating the solver as unknown, to partially visible, to fully known.

Important Terms

Probabilistic ROM

A reduced-order model that represents uncertainty in predictions, operators, latent states, or model error.

Gaussian Process Regression

A probabilistic regression method that gives both a mean prediction and predictive uncertainty.

Deep Kernel Learning

A hybrid method that uses neural networks to learn features or latent coordinates used by a kernel model.

Bayesian Operator Inference

A method for estimating reduced dynamical operators from data using Bayesian priors and posterior uncertainty.

Tikhonov Regularization

A penalty-based regularization method that stabilizes ill-posed inverse or regression problems.

Connections Across The Series

  • This talk connects ROMs, surrogate modeling, uncertainty quantification, and digital twins.
  • It complements operator inference and neural operator lectures by asking how much physics structure the learner should retain.
  • It also links to active learning and experimental design because posterior uncertainty can guide where new simulations are most valuable.

Practical Caution

A posterior distribution is only as credible as the model class, priors, and training coverage. A simulation-free online surrogate can produce incorrect predictions when the input falls outside the region where training data existed.

Takeaway

The first-principles lesson is that a useful ROM for deployment should be fast, structurally grounded when possible, and honest about uncertainty.
