Talk 54 · Stanford University

Tailin Wu: Learning To Accelerate Large-Scale Physical Simulations

This lecture presents learned simulators for large-scale fluid and plasma systems, using graph networks, U-Nets, and multi-step training to predict long-term evolution and capture behavior at many different scales.

YouTube source · Talk page

Core Problem

Large-scale fluid and plasma simulations can involve millions of cells and take days or weeks to run. Machine learning models trained to copy these simulations promise to run faster, but they must handle uneven geometry, local and global dynamics, behavior at different scales coupled together, and errors that grow as you run them forward in time.

First-Principles Model

A physical simulator updates a field state over time. A learned simulator approximates that update map. For subsurface flow, local water-oil dynamics can be represented by graph neural networks over mesh cells, while pressure has more global structure better captured by U-Net-like field models. Training on multi-step losses exposes the model to its own prediction errors, improving long-term stability compared with training on just the next single step.

Key Claims

  • Classical numerical solvers for fluids and plasmas require days of computation for large systems.
  • Machine learning models trained to copy these simulations can make them faster but must overcome long-term evolution and behavior-at-different-scales challenges.
  • Hybrid simulators combine graph networks for local dynamics with 3D U-Nets for global pressure dynamics.
  • Graph neural networks handle irregular or mesh-based local interactions where information flows along connections.
  • Training on multiple future steps improves accuracy over long runs compared with training on only the next step.
  • The method scales to very large systems, handling millions of cells in the subsurface example.

Important Terms

Learned Simulator

A machine learning model trained to copy how a physical simulator updates a system forward in time.

Graph Neural Network

A neural network that sends information along graph edges, designed for mesh or particle systems where connections matter.

U-Net

An encoder-decoder convolutional architecture that reads a field as input and writes a field as output.

Multi-Step Loss

A training goal that penalizes prediction errors over several time steps ahead, not just the next one.

Long-Term Rollout

Running a learned simulator forward by applying its update rule repeatedly to predict many future time steps.

Connections Across The Series

  • This lecture continues the learned-surrogate idea with a concrete graph-based simulator for large systems.
  • It connects to Petros Koumoutsakos' work by combining different neural architectures where the physics suggests each one fits.
  • It also connects to neural operators and reduced-order models because the learned model approximates an evolution operator.

Practical Caution

A learned simulator that predicts the next step accurately may accumulate large errors when run forward many steps. Long-term stability must be tested directly, especially when the surrogate (learned copy) is used for control or inverse design.

Takeaway

Learned simulation is repeated operator application. Stability over many steps is what really matters, not next-step prediction alone.
