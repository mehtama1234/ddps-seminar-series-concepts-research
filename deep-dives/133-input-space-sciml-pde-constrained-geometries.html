Talk 133 · Georgia Tech

Raphael Pestourie: Input-Space Scientific Machine Learning for PDE-Constrained Optimization of Geometries

This lecture proposes input-space scientific ML, where learned models accelerate PDE-driven design by modeling solver inputs rather than relearning the PDE solution.

YouTube source · Talk page

Core Problem

Many SciML methods learn the PDE solution directly, forcing the model to relearn physical laws already encoded in the numerical solver. For geometry optimization, this can be inefficient because the design variable is the input geometry and the solver already knows the governing PDE.

First-Principles Model

Input-space SciML leaves the physics to the numerical solver and learns transformations or surrogate structure in the solver input space. Physics-Enhanced Deep Surrogates accelerate simulation of PDE-driven properties, while HiLAB supports efficient exploration of high-dimensional geometry design spaces for PDE-constrained optimization. The method is demonstrated on benchmark PDEs and nanophotonic metasurface design.

Key Claims

  • Scientific ML can enhance both simulation and optimization of PDE-governed properties.
  • Learning the PDE solution can waste effort by relearning laws already encoded in solvers.
  • Input-space SciML models the input space of a PDE solver.
  • The numerical solver remains responsible for the physics.
  • PEDS accelerates simulation of PDE-driven properties.
  • HiLAB supports efficient optimization over high-dimensional geometry spaces.

Important Terms

Input-Space SciML

Scientific ML that models or transforms solver inputs while leaving the PDE solve to numerical physics.

PDE-Constrained Optimization

Optimization where feasible designs are evaluated through PDE-governed physics.

Physics-Enhanced Deep Surrogate

A surrogate model that accelerates simulation while retaining a physics solver in the loop.

Geometry Optimization

Design optimization where the variable is a physical shape or geometry.

Metasurface

An engineered surface with subwavelength structures controlling electromagnetic behavior.

Connections Across The Series

  • This talk connects PDE-constrained design, differentiable solvers, inverse design, and scientific ML.
  • It complements neural PDE surrogate lectures by arguing that the solver can remain the physics engine.
  • It also links to materials and nanophotonics design where geometry is the core input.

Practical Caution

Input-space ML can be efficient, but the solver still determines physical fidelity. If the solver model is incomplete, input-space learning will optimize against incomplete physics.

Takeaway

The first-principles lesson is that for design problems, learning the input-to-solver interface can be more effective than learning the whole PDE solution.
