Talk 50 · University of Houston

Daniel Floryan: Charting Dynamics From Data

This whole series is about getting computers to predict how physical things move and change by learning from real data instead of hand-written math. This talk shows how to find the true number of dimensions (the simplest way to describe what's actually happening) by using overlapping local maps and learning the motion rules on each map separately.

YouTube source · Talk page

Core Problem

Many real systems are so complicated that writing down their motion rules from first principles is impossible or takes too long. But when you plot their behavior over time, the path the system traces often lives on a much simpler surface hidden inside the high-dimensional recorded data. The challenge is finding local coordinate systems that fit this hidden surface and the motion rules that work there, so you can build a simplified model that still captures how the system actually evolves.

First-Principles Model

Imagine a crumpled or curved surface (like a sheet of paper folded in 3D space). You can describe any point on it using overlapping local coordinate systems, where each system covers just one flat patch. From time-series data, you group trajectories into overlapping neighborhoods, learn a local coordinate system on each neighborhood, figure out how things move within each local system, and then stitch all the pieces together into one continuous dynamical model. The result is a simplified description that uses only as many coordinates as the system truly needs, rather than as many as you happened to record.

Key Claims

  • Learning models from data is most useful when the real motion rules are unknown or when there are so many rules written down that computing them is too slow.
  • Systems in nature typically move along lower-dimensional surfaces, even when you record hundreds or thousands of measurements.
  • Overlapping local coordinate systems can cover any curved surface, no matter how twisted.
  • Time-series data can be split into overlapping groups that each get their own local coordinate system.
  • Learning how the system moves within each local coordinate system creates simplified models that use only the number of dimensions you really need.
  • Local coordinate systems let you tell the difference between the true shape of the system and artifacts that come from your measurement choices, and both of these improve predictions.

Worked Example

Circle example: 40 equally-spaced points, 2D ambient data reduced to 1D intrinsic manifold with 3 overlapping patches. Error nearly perfect after training. Torus periodic orbit: 3 patches, 1D reduction from 3D ambient space, high fidelity over 10 periods. Quasi-periodic torus (incommensurate): 6 patches from 3D to 2D representation with minor phase-speed offset but excellent reconstruction. Reaction-diffusion spiral wave: 20,000+ dimensional system reduced to 1D model with minimal reconstruction error between high-res and learned dynamics. Kuramoto-Sivashinsky system: periodic case maps to 1D model with high fidelity; disparate time scales (factor of 100) captured from single time unit of training data; intermittent dynamics with non-periodic bursts: 6-patch atlas yielding 3D dynamical model, qualitatively correct but quantitative quiescence duration off (attributed to logarithmic divergence inherent to saddle points).

One Level Deeper

Atlas of overlapping patches (coordinate domains) with local coordinate maps (invertible neural networks / autoencoders) flattening curved manifolds to Euclidean spaces. K-means clustering with overlap procedure creates boundary/internal point distinction. Under-completed autoencoders encode/decode local dimensionality reduction (forward and inverse mappings). Neural networks approximate dynamics in reduced coordinates: either ODEs (dx/dt via neural net) or discrete time-delta flow maps. Strong Whitney embedding theorem (bound 2n for worst case) shows theoretical limit without charts. Dissipation mechanism drives trajectories to inertial manifolds. State space decomposition into regions of distinct behavior; local models compose via chart transitions.

Failure Boundary

Manifold learning methods without charts fail to recover intrinsic dimension (non-injective mappings cause information loss). Cannot globally flatten topologically non-trivial manifolds (e.g., torus always collapses when flattened as single chart). Sample complexity depends on intrinsic (not ambient) dimension but unknown a priori—must empirically determine number of patches. Hyperparameter selection (patch count, local dimension per patch) requires trial/iteration. Noise robustness: transitions between patches amplify disagreement where manifold intersections occur under noisy data. Limited to systems with clear dissipative structure enabling inertial manifolds; chaotic systems with logarithmic divergence capture gross structure but fail on quantitative timescale details. Global methods (single autoencoder without patching) achieve only order-of-magnitude worse reconstruction even at 2n dimensions per Whitney bound.

Important Terms

Manifold

A space that may twist and curve when you look at it from far away, but in any small local region looks like ordinary flat space.

Atlas

A collection of overlapping local coordinate systems that together cover an entire curved surface, the way pages of an atlas cover Earth.

Chart

One local coordinate system that describes one small flat patch of a curved surface.

Intrinsic Dimension

The true minimum number of coordinates you need to keep track of to specify exactly where the system is, without any redundancy.

Time-Series Data

A record of measurements taken one after another over time that shows how a system's state changes moment by moment.

Connections Across The Series

  • This approach expands on earlier work discovering hidden structure in data by providing a concrete geometric method that uses local maps.
  • It shares the same goal as reduced-order models: finding small-dimensional descriptions of how systems evolve in time.
  • It ties together the study of curved surfaces, nonlinear motion, and building models that you can use to control what happens next.

Practical Caution

The local coordinate systems only work well if your data samples the entire hidden surface and covers the transitions between neighborhoods. If the data leave gaps or skip over where one neighborhood transitions to the next, the learned coordinate systems can create artificial jumps and give wrong predictions for how the system evolves.

Takeaway

When you simplify a dynamical system by finding its true dimensions, you're not just squashing numbers — you have to make sure that the way things move still makes sense in the new simpler coordinates. Picking the right local coordinates is how you separate the real shape of the system from the clutter that came from how you happened to measure it.
