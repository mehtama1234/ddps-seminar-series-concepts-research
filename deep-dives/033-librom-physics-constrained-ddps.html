Talk 33 · Lawrence Livermore National Laboratory

Youngsoo Choi: libROM For Physics-Constrained Data-Driven Physical Simulations

This lecture introduces libROM as a practical software library for physics-constrained data-driven reduced-order modeling across LLNL physical simulation workflows.

YouTube source · Talk page

Core Problem

Data-driven physical simulation needs working software, not just published papers. Models trained only on data can be easy to build but may ignore the underlying physics laws, while models built from first principles and constrained by data can be accurate and reliable but need infrastructure to handle bases, hyper-reduction, linking components together, and checking sensitivity.

First-Principles Model

A projection ROM squeezes full-order state data into reduced bases, evolves low-dimensional coordinates, and rebuilds the full state. For nonlinear systems, hyper-reduction samples residual or nonlinear terms so the cost to run online does not grow with the full model size. libROM bundles these ingredients so users can build physics-constrained reduced models and repeat examples.

Key Claims

  • Physical simulations have always relied on data, from measurements to calibrated laws.
  • Models trained only on data ignore first principles, while models constrained by physics combine both data and the governing equations.
  • libROM supports POD (principal orthogonal decomposition, a method to find the most important patterns in data) through static, incremental, randomized, and space-time SVD methods.
  • Hyper-reduction is required to make nonlinear ROM fast enough to run.
  • The library includes working examples such as Poisson, nonlinear diffusion, and Lagrangian hydrodynamics.
  • Time-windowing and nonlinear manifold ROMs handle long-time simulations where flow pushes material around strongly.

Important Terms

libROM

An LLNL software library for reduced-order modeling that builds smaller, faster versions of physics simulations by combining data and first-principles constraints.

Physics-Constrained ROM

A reduced model that uses both data and the governing equations or first-principles residuals to stay accurate.

Incremental SVD

An algorithm that updates the most important patterns as new data arrive without rebuilding the entire basis from scratch.

DEIM

Discrete Empirical Interpolation Method, a hyper-reduction technique that samples only the most important nonlinear terms instead of computing all of them.

Component-Wise ROM

A reduced model built from smaller reduced pieces that are linked together into a coupled system.

Connections Across The Series

  • This talk turns many earlier ROM concepts into a working software stack.
  • It connects to nonlinear manifold ROM, hyper-reduction, and component ROM talks by showing them as reusable software capabilities you can actually use.
  • It also supports the full study-system goal because libROM is where concepts become workflows you can redo and validate.

Practical Caution

A library makes ROM workflows simpler, but it does not remove the need for modeling judgment. Users still need to choose suitable bases, sampling points, physics constraints, and testing strategies for the target simulation.

Takeaway

The first-principles lesson is that scalable scientific machine learning needs software tools. libROM is the engineering layer that turns ROM theory into workflows you can repeat and trust.
