Talk 33 · Lawrence Livermore National Laboratory

Youngsoo Choi: libROM For Physics-Constrained Data-Driven Physical Simulations

This lecture introduces libROM as a practical software library for physics-constrained data-driven reduced-order modeling across LLNL physical simulation workflows.

YouTube source · Talk page

Core Problem

Data-driven physical simulation needs software, not just papers. Black-box latent models can be easy to train but may ignore first principles, while physics-constrained ROMs can be accurate and robust but require infrastructure for bases, hyper-reduction, component coupling, and sensitivity analysis.

First-Principles Model

A projection ROM compresses full-order state data into reduced bases, evolves low-dimensional coordinates, and reconstructs the full state. For nonlinear systems, hyper-reduction samples residual or nonlinear terms so online cost does not scale with the full model. libROM packages these ingredients so users can build physics-constrained reduced models and reproduce examples.

Key Claims

  • Physical simulations themselves have always relied on data, from observations to calibrated laws.
  • Black-box ROMs use data alone, while physics-constrained ROMs combine first principles with data.
  • libROM supports POD through static, incremental, randomized, and space-time SVD methods.
  • Hyper-reduction is required for nonlinear ROM efficiency.
  • The library includes examples such as Poisson, nonlinear diffusion, and Lagrangian hydrodynamics.
  • Time-windowing and nonlinear manifold ROMs address long-time advection-dominated simulations.

Important Terms

libROM

An LLNL library for reduced-order modeling and physics-constrained data-driven physical simulations.

Physics-Constrained ROM

A reduced model that uses both data and the governing equations or first-principles residuals.

Incremental SVD

An algorithm for updating singular-vector bases as new data arrive without recomputing everything from scratch.

DEIM

Discrete Empirical Interpolation Method, a hyper-reduction technique for sampling nonlinear terms.

Component-Wise ROM

A reduced model built from smaller reduced components that are assembled into a coupled system.

Connections Across The Series

  • This talk converts many earlier ROM concepts into an implementation stack.
  • It connects to nonlinear manifold ROM, hyper-reduction, and component ROM talks by showing them as reusable software capabilities.
  • It also supports the full study-system goal because libROM is where concepts become reproducible workflows.

Practical Caution

A library makes ROM workflows easier, but it does not remove modeling judgment. Users still need to choose appropriate bases, sampling points, physics constraints, and validation regimes for the target simulation.

Takeaway

The first-principles lesson is that scalable scientific ML needs tooling. libROM is the engineering layer that turns ROM theory into repeatable simulation workflows.
