Talk 19 · DeepMind

Alvaro Sanchez-Gonzalez And Tobias Pfaff: Learning Physical Simulation With Graph Networks

This lecture explains graph networks as learned simulators that represent particles, meshes, and deformable systems as graphs and advance them through message passing.

YouTube source · Talk page

Core Problem

Learned simulators can be fast, but many neural architectures generalize poorly outside the training distribution. Physical simulations also come in many discretizations: particles, triangular meshes, tetrahedral meshes, and adaptive cloth meshes. A useful architecture should handle variable structure and generalize to larger or different systems.

First-Principles Model

A physical state can be encoded as a graph: nodes represent particles or mesh vertices, edges represent neighborhood interactions, and features store physical quantities. A graph network performs message passing so local interactions update edge and node representations. An encode-process-decode model then predicts the next simulation state, and repeated next-step prediction creates a rollout.

Key Claims

  • Graph networks can model particle, mesh, and deformable simulations with the same broad architecture.
  • The model learns next-step prediction and then rolls out over time.
  • Message passing mirrors the local pairwise or neighborhood interactions common in physics.
  • Permutation equivariance makes predictions independent of arbitrary node and edge ordering.
  • Using relative local structure helps extrapolate to larger domains and different positions.
  • Graph structure can generalize better than fixed-grid CNN-style representations for irregular simulation domains.

Important Terms

Graph Network

A neural architecture operating on nodes, edges, and graph-level features.

Message Passing

A computation where edge and node features are updated by exchanging information across graph neighborhoods.

Encode-Process-Decode

A graph-network pipeline that encodes a physical state, repeatedly processes messages, and decodes an updated state.

Rollout

Repeatedly applying a one-step simulator to predict a trajectory over many time steps.

Permutation Equivariance

The property that reordering graph nodes or edges does not change the physical meaning of the prediction.

Connections Across The Series

  • This talk adds a representation alternative to grids and bases: graph structure can track physical adjacency directly.
  • It connects to operator learning because both learn reusable physical maps, but graph networks emphasize local interaction structure.
  • It also connects to long-rollout robustness concerns in fluid and turbulence talks because one-step errors compound over rollout.

Practical Caution

A graph simulator must be evaluated on rollout stability and out-of-distribution geometries, not just one-step error. Local message passing helps generalization, but it does not guarantee physical conservation or stability by itself.

Takeaway

The first-principles lesson is that physical simulation is often local and relational. Graph networks exploit that by learning interactions on the structure the simulator already uses.
