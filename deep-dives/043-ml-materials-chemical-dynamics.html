Talk 43 · Los Alamos National Laboratory

Sergei Tretiak: Machine Learning For Materials And Chemical Dynamics

This lecture surveys machine learning as a surrogate for materials and chemical dynamics, emphasizing active data generation and the need to overcome locality limits in molecular models.

YouTube source · Talk page

Core Problem

High-fidelity quantum and molecular simulations are expensive, but materials discovery needs many evaluations across structures, configurations, and dynamical regimes. Machine learning can approximate structure-property relationships, yet it fails if training data miss important configurations or if the model's locality assumptions ignore long-range charge, polarization, dispersion, or excited-state effects.

First-Principles Model

A molecular ML model maps atomic structure to energies, forces, or properties. Local models gain favorable scaling by decomposing predictions into neighborhoods, but real chemistry can contain nonlocal interactions. Active learning closes the data loop: run the model, detect uncertain configurations, compute new reference data, retrain, and repeat. Nonlocal architectures add interaction layers, self-consistent cycles, or charge-equilibration mechanisms so the surrogate respects broader physical coupling.

Key Claims

  • Machine learning provides surrogate models trained on reference chemical or materials data.
  • Training data quality is a central determinant of model accuracy because the model can only learn the configurations it sees.
  • Active learning automatically expands the dataset where model uncertainty is large.
  • Locality assumptions make atomistic ML scalable but can miss charge transfer, polarization, electrostatics, dispersion, and excited-state effects.
  • Nonlocal effects can be addressed with interaction layers, self-consistent cycles, and charge-equilibration schemes.
  • Chemical dynamics requires not just static property prediction but stable behavior across evolving configurations.

Important Terms

Machine-Learned Potential

A surrogate model that predicts molecular energies and forces from atomic configurations.

Active Learning

A data acquisition loop that adds new reference calculations where the current model is uncertain.

Locality Approximation

The assumption that an atom's contribution can be predicted mostly from its nearby environment.

Nonlocal Interaction

A physical effect where distant atoms or global charge structure influence local behavior.

Charge Equilibration

A mechanism that estimates charge redistribution across a molecular system to capture long-range electrostatic effects.

Connections Across The Series

  • This lecture connects to data-centric scientific ML: the active learning loop is as important as the network architecture.
  • It also links to multiscale modeling because local atomic rules must produce reliable material-scale behavior.
  • It reinforces the series theme that physical inductive bias is often required when extrapolation is dangerous.

Practical Caution

A model that is accurate on a benchmark set can still fail in simulation if dynamics carries it into configurations outside the training distribution or into regimes dominated by nonlocal physics.

Takeaway

The first-principles lesson is that molecular ML is a controlled approximation of quantum or atomistic physics. Its reliability depends on where data are gathered and which physical couplings the architecture can represent.
