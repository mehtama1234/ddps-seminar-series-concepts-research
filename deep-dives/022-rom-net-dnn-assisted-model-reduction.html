Talk 22 · MINES ParisTech

David Ryckelynck: Model Order Reduction Assisted By Deep Neural Networks

This whole series is about getting computers to predict how physical things behave by learning from data, instead of (or alongside) slow hand-written math. One popular approach uses simplified models that run fast by working in a smaller number of dimensions—but picking the right simplified model for different input data is hard. This talk is about a method that uses a learning program (a bank of dials tuned by trial and error) to automatically pick the right simplified model for each input, like an image showing where damage is happening.

YouTube source · Talk page

Core Problem

When you simulate something real—how a structure breaks under stress, how air flows around a wing—the answer depends heavily on input data that can look messy and complicated, like an image or a medical scan. You could build one global simplified model that works in a lower number of dimensions, but it might not work well across all the different inputs, or it might be hard to understand why it works. On the other hand, if you use a learning program as a complete replacement for the simulation, you lose speed and the clear structure that comes from the classical mathematical approach (a simplified simulation that solves in fewer dimensions).

First-Principles Model

ROM-net combines learning with simplified-model selection. You start by building a dictionary: group your simulation data by how similar it is, and for each group, compute a reduced basis—a small list of directions that capture the main pattern in that group. A learning program (with millions of dials) takes the input data, such as an image showing damage, and decides which group it belongs to, which tells it which simplified model to use or how to blend models together. The result is a piecewise-linear reduced model: made up of separate flat regions (linear pieces) stitched together, where each piece solves much faster than the full simulation. This approach also works with a further speedup trick that cuts not just the dimensions but the number of calculations needed.

Key Claims

  • This method extends simplified-model selection to cases where inputs are high-dimensional and image-like.
  • Building a collection of local simplified models can be understood as creating a lower-dimensional space made of separate flat pieces joined together.
  • Grouping data before building simplified models allows each group to have its own tuned simplified basis.
  • Collections of local simplified models are easier to understand and work with compared to learning programs that compress data to a single code and uncompress it.
  • Further calculation reduction becomes straightforward when the simplified space is made of separate flat pieces.
  • The method works with simulation data you already have, while keeping the clear structure that comes from classical mathematical models.

Worked Example

ROM-net trained on thermomechanical turbine blade problem: high-fidelity finite element model has 200,000 degrees of freedom; reduced order model achieves 60x speedup with 5% error in predicting plastic strain. Clustering uses 6 clusters, each with 2-mode reduced basis, achieving dissimilarity (Grassmann distance) well-separated from single-global-basis (red curve) approach. CNN classifier achieves 74% accuracy in mapping temperature field images to clusters. Offline training cost amortized across many online parameter queries.

Elastoplastic problem initially requires 100 loading cycles taking 300 days with full FEM. ROM-net acceleration makes parametric uncertainty quantification tractable. Local reduced bases computed per cluster via SVD on simulation subsets, cluster labels learned by CNN from thermal field images, then projection into local ROM space and Galerkin assembly replace expensive residual evaluations.

One Level Deeper

ROM-net couples three distinct operations: (1) Offline clustering in Grassmann manifold using ideal reduced basis per simulation and k-medoid algorithm to partition data by angles between subspaces. (2) CNN classifier trained to map input parameter μ (thermal field as image) to cluster label, with loss = supervised classification error. (3) For each cluster k, local reduced basis V_k obtained by SVD; solution projection: minimize ||r(q)|| where q = V_k z_k and r is FEM residual restricted to cluster's basis.

Dimensionality reduction replaces high-dim latent space (true solution manifold) with piecewise-linear approximation (k clusters × local basis). Galerkin projection: V_k^T r(V_k z) = 0 solved at each parameter query. Hyper-reduction via reduced integration domain (energy sampling) or DEIM further reduces residual assembly cost. Grassmann distance d_G(V_i, V_j) = angles between column spaces, computed as SVD of V_i^T V_j; small distance ⇒ good local basis overlap.

Failure Boundary

With insufficient data points in database, oscillations appear in constitutive response due to sparse coverage of latent space (line 687-701). Single global reduced basis (no clustering) shows higher dissimilarity (red curve line 792-810) than clustered approach, increasing approximation error where single basis fits poorly. CNN mislabeling (74% accuracy line 827) can direct wrong cluster; however, near-cluster misclassifications cause small errors since neighboring bases are geometrically close (line 838-844).

Temporally expensive: when k << n (6 modes vs 200k DOFs), complexity scales as k^3 due to dense reduced system (vs sparse FEM), limiting mode count. Memory scales linearly with k clusters × basis size, requiring storage per cluster (line 1156-1165). Method assumes smooth latent manifold with well-defined cluster boundaries; abrupt parameter-dependent transitions in physics may violate piecewise-linear approximation.

Important Terms

ROM-net

A method that uses a learning program to connect input data to the right simplified model (a simulation that runs much faster by working in fewer dimensions).

Dictionary-Based ROM

A collection of simplified models from which the right one is picked or blended for a given input.

Sparse Dictionary Learning

Learning simplified representations using only a small number of local lower-dimensional models or pieces.

Piecewise Linear Latent Space

A lower-dimensional representation made of several local flat regions (linear subspaces) joined together, rather than one single flat region.

Image-Type Parameter

A high-dimensional input, such as a scan or damage map, used to tell the simulation what to predict.

Connections Across The Series

  • This talk sits between methods that build simplified models from data alone (without changing the original simulator), automatically finding good learning-program designs, and simplified models that handle curved shapes instead of flat ones: it uses learning programs to route among structured simplified models.
  • It connects to digital twins because images or sensor readings can pick the right simplified behavior.
  • It reinforces a recurring theme in this seminar series: learning programs work best when they help classical simplification methods instead of replacing them.

Practical Caution

The number of groups and how well they're built matter a lot. Too few groups and you'll miss important variations in the input; too many and you'll need more memory and more time to train the learning program. The learning program that picks which model to use also needs to be tested carefully to make sure it still works right when the input changes in ways it hasn't seen before.

Takeaway

Neural networks can pick the right simplified model for each input, while keeping the speed and structure that come from simplified-model selection and further calculation reduction.
