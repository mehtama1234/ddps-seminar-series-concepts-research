Talk 132 · Sapienza University of Rome

Alessandro Alla: Data-Driven Algorithms for Online Identification and Control of Partial Differential Equations

This lecture presents online algorithms that identify unknown PDE parameters while controlling the system.

YouTube source · Talk page

Core Problem

PDE control often assumes known parameters and complete information, but real systems may have unknown coefficients, unknown initial conditions, sparse boundary data, or partial observability. The controller must act while learning the model.

First-Principles Model

The first scenario assumes the PDE is observable given a control input and initial condition. Starting from an initial parameter estimate, the controller is computed with the State-Dependent Riccati Equation, then the observed trajectory updates parameters via Bayesian linear regression until stopping. The second scenario uses physics-informed neural networks to handle incomplete information such as unknown initial conditions, sparse boundary data, and unknown PDE coefficients.

Key Claims

  • The goal is online identification and control of PDEs with unknown parameters.
  • One scenario assumes observability under a control input and initial condition.
  • SDRE provides a control law from the current parameter estimate.
  • Observed trajectories are used to iteratively update parameter configuration.
  • Bayesian linear regression provides a data-driven parameter update mechanism.
  • PINNs are used when information is incomplete.

Important Terms

Online Identification

Estimating model parameters during operation as data arrive.

PDE Control

Designing inputs to control systems governed by partial differential equations.

State-Dependent Riccati Equation

A control method that generalizes Riccati-based design to nonlinear or state-dependent systems.

Bayesian Linear Regression

Linear regression with probabilistic parameter uncertainty and updating.

Physics-Informed Neural Network

A neural network trained with physics residuals or constraints.

Connections Across The Series

  • This talk connects control, online learning, Bayesian updating, and PINNs.
  • It complements flow-control and ROM-control lectures by making model uncertainty part of the controller loop.
  • It also links to adaptive digital twins because the model is updated as the system evolves.

Practical Caution

Online identification can destabilize control if parameter updates are noisy or delayed. The learning loop needs safeguards, stopping criteria, and uncertainty-aware control decisions.

Takeaway

The first-principles lesson is that controlling a PDE with unknown parameters requires learning and control to run as one closed loop.
