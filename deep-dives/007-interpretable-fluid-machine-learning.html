Talk 7 · University of Washington

Steven Brunton: Interpretable And Generalizable Machine Learning For Fluid Mechanics

This lecture argues that fluid ML should prefer simple, interpretable, physically meaningful models that work well on new problems not seen during training.

YouTube source · Talk page

Core Problem

Fluid mechanics produces high-dimensional data and expensive simulations, but just predicting outputs is not enough. A model can match the flow it has seen before while failing when conditions change—new controls, different shapes, changed parameters—if it has not captured the sparse (few important) physical structure hiding inside the flow.

First-Principles Model

Many fluid systems show a lot of data in how we measure them but simplify into just a few key directions, and their governing dynamics often use only a sparse subset of possible terms. Interpretable ML tries to find those directions, identify which terms matter, find correction terms for missing physics, or spot where approximate models need adjustment rather than building a hidden system that just maps inputs to outputs.

Key Claims

  • Machine learning for engineering can be viewed as optimization and regression over rich data.
  • Generalization requires more than fitting trajectories; models should capture simple structure where it exists.
  • The principle of simplicity motivates sparse models: as simple as possible, but no simpler.
  • Sparse Identification of Nonlinear Dynamics (SINDy) learns governing equations from measured states and how they change over time.
  • Choosing the right coordinates (ways to measure and describe the flow) can turn a high-dimensional fluid problem into a low-dimensional model.
  • ML can also focus on discrepancy modeling: learning the mismatch between an imperfect physical model and observed dynamics.

Important Terms

Parsimony

The modeling principle that a useful explanation should use the simplest structure sufficient to describe the phenomenon.

SINDy

Sparse Identification of Nonlinear Dynamics, a method that selects a small number of active terms from a library of candidate dynamics.

Sparse Regression

Regression that encourages most candidate coefficients to be zero, leaving only the important terms.

Coordinate Discovery

Finding variables in which complicated high-dimensional dynamics become simpler.

Discrepancy Modeling

Learning the mismatch term between an approximate physical model and the true observed system.

Connections Across The Series

  • This is the conceptual link between reduced-order models (simpler versions that keep key behavior), operator inference (learning how operations change the system), and scientific ML: learn structure, not just outputs.
  • It connects to later surrogate and closure talks because closures are often discrepancy models for physics that happens below our measurement resolution.
  • It also gives a benchmark for interpretability: can the learned object be inspected as equations, modes (directions of motion), balances (how forces relate), or correction terms?

Practical Caution

A neural model that forecasts fluid snapshots may still be scientifically weak if it does not show what variables, balances (how different forces add up), or missing-physics terms are driving the flow. Generalization should be tested by trying new regimes, not just checking whether it works on data in between the training examples.

Takeaway

The lecture's first-principles message is that interpretability is not decoration. In fluids, when you can actually see and write down the structure, that is often exactly what lets the model work on new problems.
