Talk 69 · Johns Hopkins University

Soledad Villar: The Passive Symmetries Of Machine Learning

This whole series is about getting computers to predict physical behavior by learning from examples. One big obstacle: when we write down data, we make arbitrary choices—which directions to call x and y, which units to measure in, how to number things. This talk is about why learning programs that ignore these choices and give the same answer no matter how we write things down end up predicting better on new situations they've never seen.

YouTube source · Talk page

Core Problem

Whenever we measure and record data, we make choices that have nothing to do with reality: we pick a coordinate system (which way is x? which is y?), we pick units (meters or feet?), we label nodes in a diagram with numbers or names. The learning program doesn't know these choices are meaningless. If it shifts its answers when we rotate the coordinate system or switch units, it's learning noise from how we happened to write things down, not the actual structure of what's happening in the world.

First-Principles Model

A passive symmetry is what stays the same about reality when we change how we write it down. If you rotate your coordinate axes, swap units from meters to feet, relabel nodes in a graph, or pick a different measurement direction, the real thing doesn't change—only its description does. A smart learning program should treat these as the same input and give the same output for them. One way to build this into the program: set it up so that when you transform the input in a predictable way, the output transforms in a matching way (this is called group equivariance—a matching pair of transformations, one on the way in and one on the way out, that fit together like gears).

Key Claims

  • The same real situation can be written down many different ways, and each way creates an exact symmetry—the model should recognize all versions as identical.
  • Passive symmetries come from coordinate rotations, unit conversions, relabeling (like numbering nodes differently in a graph), and gauge choices (alternative mathematical conventions that describe the same physics).
  • These are not hidden features of nature—they are explicit consequences of our choices in writing things down. Yet they control whether a learning program generalizes well.
  • You can build these symmetries directly into the structure of a neural network (the program with millions of adjustable dials) using group equivariance.
  • Models that respect these symmetries predict better on situations they have never seen before.
  • This work bridges machine learning practice to deep ideas from physics and causality.

Worked Example

Double pendulum with springs under gravity: O(3) equivariance (rotations in XY plane) plus Hamiltonian energy conservation. Learned as equivariant neural ODE dx/dt = F_θ(|pairwise inner products|), where scalar invariant functions (sums of relative distances) parameterize position updates. Adding rotation symmetry: error → 8.2%. Adding Hamiltonian constraint (learn H, integrate with canonical equations): error → 6.5%. Adding time translation (energy conservation via Hamiltonian integrator): error → 4.1%. Vanilla unconstrained network: error → 15%. On point cloud with n particles in R^d, invariant energy learned as E(x) = ∑_i<j f(||x_i - x_j||²) (rotation-invariant by construction); equivalent force = ∑_j≠i g_ij(distances) · (x_i - x_j) where g_ij are learned coefficient functions.

Graph neural network task (node classification on 100-node graph): message passing ensures permutation equivariance by definition (aggregates from neighbors only, independent of adjacency matrix ordering). Classical network fitted ~85% accuracy; permutation-invariant GNN fitted ~91% on same graph size.

One Level Deeper

Active symmetries (conservation laws via Noether): energy conservation ↔ time translation; momentum conservation ↔ spatial translation; angular momentum ↔ rotation. Passive symmetries (representation choices): change of coordinates (rotation matrix R), change of units (scaling factors). First fundamental theorem of invariant theory: rotation-invariant function of point cloud {x_i} can be written as f(pairwise inner products {x_i·x_j}). Equivariant function (output transforms with input): ∀g∈G, ∀θ: F(g·x;θ) = g·F(x;θ). Implement via irreducible representations (group representation theory decomposes tensor products into irreducible blocks; equivalent maps preserve block structure) or invariant theory (multiply scalar invariants by input vectors). Hamiltonian neural network: parameterize H(q,p), compute ∂H/∂p → q̇, -∂H/∂q → ṗ automatically preserves Poisson bracket {·,·} structure.

Failure Boundary

Over-specification: imposing all known symmetries when some are violated weakly (e.g., slight dissipation) introduces bias. Graph isomorphism barrier: message passing networks cannot distinguish non-isomorphic graphs if they're locally identical; need higher-order invariants or subgraph kernels. Sparse data: enforcing strong symmetry constraints shrinks hypothesis class; if true solution is barely equivariant or uninvariant, generalization error increases despite smaller model class. Dimensional analysis failure: Buckingham π theorem requires all relevant physical variables to be present; missing variables break dimensional consistency. Stiffness: symplectic/Hamiltonian integrators require smaller time steps than explicit methods, increasing computational cost despite theoretical advantages.

Important Terms

Passive Symmetry

A sameness that appears when you change how you describe something but the thing itself stays the same—like describing the same chair with different coordinate systems.

Coordinate Freedom

The fact that you can describe any object using infinitely many different coordinate systems (different choices of which direction is x, y, z) without changing what the object actually is.

Gauge Symmetry

Different mathematical write-ups that represent one and the same physical state, like different choices for the zero-point of voltage in an electrical circuit.

Units Covariance

When you switch measurement units (say from inches to centimeters), all quantities scale together in a consistent, predictable way—the real relationships don't change.

Group Equivariance

A property where the model transforms its output in a matching way when its input is transformed—for example, if you rotate the input image, the output also rotates by the same amount.

Connections Across The Series

  • This lecture connects to equivariant neural networks and graph models that learn while respecting symmetries throughout this seminar series.
  • It explains why symmetries matter in actual practice: learning programs need to ignore arbitrary notation choices so they zero in on the real world, not artifacts of how we happened to write things down.
  • It directly improves generalization (predicting well on new data): models that dismiss meaningless notation choices learn structure that transfers to situations they have never encountered.

Practical Caution

Not every sameness should be forced into a model. A model should ignore arbitrary choices like coordinate systems or measurement units, but it must recognize real differences when they exist. For example: water really does flow downhill, and a model that treats 'uphill' the same as 'downhill' would be fatally wrong.

Takeaway

If a learning program gives the same answer regardless of arbitrary choices in notation and measurement, it's focusing on the real structure instead of accidents of how we wrote things down. That's what makes it work better on new situations.
