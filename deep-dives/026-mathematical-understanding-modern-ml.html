Talk 26 · Brown University

Yeonjong Shin: A Mathematical Understanding Of Modern Machine Learning

This whole series is about getting computers to predict physical behavior by learning from examples instead of only hand-written math. This talk focuses on the math behind machine learning: when we teach a computer to solve science problems using learned rules and physics, we can break down exactly where mistakes come from—some come from the model's shape, some from not having enough data, some from learning only what was in your examples, and some from the training process getting stuck. This talk is about understanding each type of mistake so we know when these methods work and when they fail.

YouTube source · Talk page

Core Problem

Machine learning often works through trial and error on real problems, but when we use it for science—to solve equations, predict material behavior, or simulate physical systems—we need to know when it actually gets the right answer and when it fails without warning. A popular approach is to build a learning program (a set of dials tuned by trial and error) that is also given the laws of physics while it trains. These methods look promising in experiments, yet without math we cannot tell if they truly solve the equations correctly, whether they will work on new situations, or whether the trial-and-error tuning will actually discover a good solution.

First-Principles Model

Every learning method makes mistakes in different ways. Approximation error: the model class (the range of shapes the learning program can take) might not be wide enough to capture reality, no matter how good the training. Estimation error: you only see a finite batch of examples, not infinite samples, so your view of reality is incomplete. Generalization error: the gap between what the model learned on your examples and how it behaves on new, unseen situations. Optimization error: the trial-and-error tuning stops at some answer but not the best possible answer the model class could reach. When we combine learning with physics, we need to track all four errors together and ask how they change as we get more data, train longer, and pick better models.

Key Claims

  • Machine learning's success comes from the model design, the training method, the data available, and the computing power to run it.
  • Scientific machine learning adds a new constraint: the learned model must also obey the laws of physics.
  • Physics-informed learning methods show strong results but need mathematical proof about when they work and proof that training will find a good solution.
  • Generalization error and optimization error are distinct problems and must not be mixed up.
  • The talk develops mathematical theory for physics-informed learning using techniques from regularization and classical rules for differential equations.
  • Understanding the math can lead to new and better algorithms for training these learning programs.

Important Terms

Approximation Error

The gap between what the best possible model in your chosen set of shapes can express and the actual target you are trying to learn. If your set of shapes is too narrow, approximation error will be large no matter what.

Estimation Error

Mistakes that arise because you learn from a limited number of examples, not an infinite amount of data. More data shrinks this error.

Generalization Error

The gap between how well your learned model performs on the data you trained it with and how well it performs on new data the program has never seen before.

Optimization Error

The difference between the answer your training algorithm actually finds and the best possible answer that exists within your chosen model class. A slow or stuck training process causes this.

PINN Consistency

A mathematical property that says: if we gather enough data and train long enough under the right conditions, the solution found by a physics-informed learning method will approach the true solution of the physical equations.

Connections Across The Series

  • This talk provides the mathematical proof for when physics-informed learning should work in theory, complementing an earlier talk about why these methods fail in practice.
  • It connects to robustness and uncertainty because dependable scientific machine learning requires us to separate and measure each type of error, not just check overall accuracy on examples.
  • It helps explain later talks about advanced methods (like learning operators that map between functions) by distinguishing between a model's ability to express solutions and its ability to train successfully.

Practical Caution

A mathematical proof about the ideal best solution does not mean a real training algorithm will find it. When using physics-informed learning methods, we need both the math showing the ideal solution exists and practical checks during training to spot when the search is getting stuck or going the wrong direction.

Takeaway

The first step in reliable scientific machine learning is tracking the error budget. Approximation failure, data failure, generalization failure, and optimization failure are four separate types of trouble, and each needs its own remedy.
