Talk 25 · UC San Diego

Rui Wang: Physics-Guided Deep Learning For Dynamics Forecasting

This whole series is about getting computers to predict how physical things behave by learning from examples instead of only hand-written math. One approach is to inject known physics rules directly into a learning program: ideas like how fluids can't compress, how things look the same under rotation, and tricks from engineers' step-by-step calculators. This talk is about why mixing physics and deep learning produces better forecasts when systems evolve in space and time, and which diagnostics you need to trust the model.

YouTube source · Talk page

Core Problem

Predicting how physical systems evolve over time is hard. A system like fluid flow happens at many scales at once—big swirls carry small eddies inside them. A learning program trained only on examples might capture the big patterns but miss smaller ones. It might also break the rules that should always hold, like incompressibility (the idea that fluid can't vanish). Tiny errors early on balloon into huge mistakes later, so a model that looks good for a few steps ahead might fail after many steps.

First-Principles Model

A dynamics forecasting model is a program that takes a picture or description of how things look now and predicts how they'll look next. Physics-guided learning teaches it better by baking in physics ideas: using numerical recipes from classical engineering (like how to step a system forward in small increments), enforcing symmetries (if you rotate the input, the output rotates the same way), adding penalties when fluid rules are broken (like when divergence is nonzero when it should be zero), and making sure the program learns both large and small features separately instead of blurring them together.

Key Claims

  • Combining deep learning with known physics rules makes forecasts stay physically realistic for longer.
  • Neural networks can be redesigned to include numerical methods and symmetries, not just fitted to data.
  • For fluids that can't compress, enforcing zero divergence (as a penalty during learning) keeps predictions grounded in physics.
  • Symmetries like rotation and translation help the model generalize to new situations it hasn't seen before.
  • Training purely on pixel errors can hide the fact that a model gets the big patterns right but botches small scales.
  • Even with physics guidance, forecasting fails when test conditions drift too far from training—a problem without a complete solution yet.

Worked Example

A physics-guided TurblenceNet (TFNet) for Rayleigh-Bénard convection jointly learns velocity components and filters them using trainable spatial and temporal filters inspired by large-eddy simulation. On 2D synthetic data at high Reynolds numbers, the model achieves divergence errors near zero across all prediction horizons (compared to baseline models with diverging divergence), and energy spectrum errors remain closer to ground truth. The model, when applied autoregressively, remains stable 300+ frames into the future, whereas standard deep learning baselines begin to diverge earlier.

For symmetry-incorporated models handling three-dimensional transformations (rotation, uniform motion, scaling), equivalence constraints allow the model to automatically generalize to unseen rotations (e.g., 90-degree rotations) and scaling factors (e.g., 3x scale change) without retraining. On real ocean dynamics, the symmetry-informed model maintains predictive consistency across these transformations, whereas non-equivariant baselines fail to generalize.

One Level Deeper

TFNet uses a three-level decomposition via spatial and temporal filters: velocity u is split into large-scale u*, fluctuation u', then u* is further split into temporal average u_bar and fluctuation u_tilde. Each component (u_bar, u_tilde, u') is encoded separately, then a shared decoder learns interactions. The divergence constraint L_div = ||∇·u||^2 penalizes compressibility, enforcing the continuity equation. Energy spectrum loss ensures the model captures multi-scale Kolmogorov structure.

For symmetry, group correlation replaces standard convolution: h(x,y) = ∫ ψ(ρ(g)x - y) φ(y) dy where g ∈ G. Scaling equivalence applies kernels at multiple scales λ in {1/3, 1, 3}; rotation equivalence uses regular representations of cyclic groups (C4) where each rotation maps to a permutation matrix. Uniform motion covariance is achieved by centering: shift input to zero mean, apply convolution, shift output back—this is a learned inductive bias that respects conservation laws.

Failure Boundary

At very high Reynolds numbers (Re >> 1), even with multi-scale decomposition, small-scale dynamics become harder to predict accurately. Distribution shift is a fundamental challenge: the model trained on one Rayleigh number or buoyancy value degrades on others unless explicitly trained via meta-learning. Symmetry enforcement comes at computational cost (multiple scale/rotation kernels per layer); scaling breaks down if the assumed transformations don't match the physics (e.g., non-uniform scaling). Long rollouts accumulate error despite the constraints; the model cannot recover from phase drift in chaotic regimes.

Important Terms

Dynamics Forecasting

Predicting how a physical system will look or behave at future moments, given snapshots from now or the past.

Physics-Guided Deep Learning

Using a program with millions of adjustable dials (tuned by trial and error until its answers look right) while also telling it physical facts—like 'this fluid can't change density' or 'rotating the input must rotate the output the same way'—so it learns answers that respect both data and physics.

Equivariance

When you apply a transformation to the input (like rotating or sliding it), the output is transformed in exactly the corresponding way—a property that keeps the model's answers physically sensible under changes in perspective or position.

Divergence Loss

A score for how much a predicted fluid field disobeys the rule that incompressible fluids can't have fluid disappearing or appearing at a point; the program tries to push this score down during learning.

Distribution Shift

When test conditions differ from training conditions—for example, a model trained on slow flow is asked to predict fast flow—accuracy typically drops because the model learned only what it saw, not the underlying rules.

Connections Across The Series

  • This talk sits alongside research on building simulators as differentiable programs (you can compute gradients through them) and learning reduced-order models (stripped-down versions that capture the essential physics but run faster) by insisting on long-horizon physical consistency.
  • It takes the next step beyond PINNs, which fit equations; this approach uses physics to sculpt both how the neural network is built and what losses steer learning, for forward forecasting rather than solving given equations.
  • It reinforces a recurring theme in this series: a model can interpolate well within its training regime but completely fail when conditions shift—a hard problem still being solved.

Practical Caution

Don't judge a forecasting model only by how pixel-by-pixel errors stack up over a few steps. Instead, check the physics by hand: Is the divergence staying small for incompressible flow? Are the frequencies (the wiggles at different scales) staying realistic? Are conserved quantities (things that should never change) actually staying constant? Does it still work when you train on fluid flowing one way and test it flowing sideways or faster?

Takeaway

Forecasting future states is not just sliding frames forward in time. The model must preserve the rules and symmetries that make future states physically believable. Learning from examples is powerful only when those examples are combined with the structures we already know must be true.
