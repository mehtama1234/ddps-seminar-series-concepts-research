Christopher Rackauckas: Generalizing SciML And Differentiable Simulation Beyond Continuous Models

This lecture argues that scientific machine learning and differentiable simulation should go beyond ordinary differential equations (equations describing how things change smoothly over time) and partial differential equations to include jump processes (sudden discrete events), stochastic simulations (random outcomes), agent-based models (many actors following rules), particle filters (methods for tracking uncertainty), and differentiable Bayesian computation (computing probabilities while recording how to improve them).

YouTube source · Talk page

Core Problem

Much scientific machine learning has focused on continuous models—ordinary and partial differential equations where change happens smoothly. But real scientific simulation also includes discontinuities (sudden changes), stochastic events (random outcomes), agents (independent actors), particle filters (sequential probability tracking), MCMC (Markov chain methods for exploring probability distributions), and hybrid forms mixing discrete and continuous parts. Differentiating through these systems (computing how to adjust them to match data) introduces mathematical, numerical stability, and practical coding challenges that differ from the adjoint methods (reverse-mode calculation) used for smooth differential equations.

First-Principles Model

Differentiable simulation means building a simulator you can train—adjusting unknown functions or numbers inside it to match observed data. If a scientific model has unknown pieces, you can swap them for neural networks or other trainable pieces, as long as you can compute gradients (the calculus that shows how to adjust the unknown pieces to improve fit). Extending this beyond smooth models means computing gradients through randomness, events that happen at specific moments, discrete choices, chaotic behavior, and algorithms that do inference (estimate hidden states from data).

Key Claims

  • Scientific machine learning has successfully incorporated ordinary and partial differential equations into deep learning through differentiable simulation.
  • Scientific simulation also includes jump diffusions (processes combining random drift with sudden events), agent-based models, and other non-continuous forms.
  • Differentiable simulation can be generalized to chaotic simulations (sensitive to initial conditions) and stochastic simulations (involving randomness).
  • Particle filters and agent-based models require specific differentiation approaches not available for smooth equations.
  • Bayesian inverse problems (inferring unknown parameters from data) can require differentiating MCMC methods themselves.
  • As differentiable programming spreads to new domains, numerical stability and implementation issues become central concerns.

Important Terms

Differentiable Simulation

A simulation built so you can compute gradients through it—the calculus showing how to adjust unknown parameters to improve fit to data.

Jump Diffusion

A stochastic process that combines smooth random drift (diffusion) with sudden discrete events (jumps).

Agent-Based Model

A simulation of many interacting actors, each following their own local rules, producing collective behavior.

Particle Filter

A sequential method for estimating hidden states in random systems by maintaining many sample trajectories and reweighting them as new data arrives.

Differentiable MCMC

Treating Markov chain Monte Carlo algorithms or their results in a way that allows gradients to flow through them for learning.

Connections Across The Series

  • This lecture extends the automatic differentiation and differentiable programming thread from earlier sessions.
  • It connects to FP-IRL (inverse reinforcement learning from data), stochastic generative models, and Bayesian inverse problems because all require computing gradients through non-standard simulation loops.
  • It also offers a software perspective on making scientific machine learning general and practical rather than limited to differential equations only.

Practical Caution

A gradient through a stochastic or discrete simulator can give biased results, become numerically unstable, or depend on implementation choices. You must match your differentiation method to the mathematical object you're actually trying to optimize.

Takeaway

The foundational insight is that scientific machine learning must differentiate through scientific computation in all its forms, not only smooth differential equation solvers.
