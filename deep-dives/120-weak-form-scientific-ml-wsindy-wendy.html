Talk 120 · University of Colorado Boulder

David Bortz: The Weak Form Is Stronger Than You Think

This whole series is about computers learning to predict how physical systems behave from examples. One challenge: when data is messy and noisy, trying to guess the rules by taking point-by-point derivatives fails badly. This talk shows a different approach — instead of measuring derivatives directly at each spot, you multiply the equation by helper functions and integrate, which lets you shift the noise problem to a much smoother calculation.

YouTube source · Talk page

Core Problem

Early methods for discovering equations from data tried to find the rules by measuring how much the data changes at each individual point. That requires computing derivatives — rates of change — but real data is always contaminated by measurement errors and sensor noise. When you compute derivatives from noisy data, you magnify those errors, so the discovered equations and estimated parameters become wrong.

First-Principles Model

The weak form is a different way of writing equations. Instead of asking 'what are the derivatives at each point?', you ask 'does this equation hold on average across a region when weighted by any test function I choose?' You pick helper functions (called test functions), multiply them by the equation, and integrate across space. Integration by parts moves the burden of taking derivatives from the noisy raw data to these smoother helper functions, making the whole calculation much more stable. WSINDy (Weak-form Sparse Identification of Nonlinear Dynamics) uses this to automatically discover equations, while WENDy applies the same idea to estimate the numbers that define a system and measure how sure we can be about them.

Key Claims

  • Finding the equations that govern a system matters because it creates models humans can read, check, and explain — not just opaque number-crunching.
  • Methods that try to match the equation at every single point of noisy data fail badly.
  • Weak-form methods address the real-world obstacles: noise, the scattered choices in how to discretize space, estimating unknown parameters, and refining wrong guesses.
  • WSINDy lets you discover equations using the weak form.
  • WENDy lets you estimate parameters using the weak form.
  • Using this approach can make results much more reliable, more accurate, and faster to compute.

Worked Example

Korotenga-Sivashinsky equation (4th-order PDE with nonlinearity) with 20% noise: parameter estimation achieves <1% error in <1 second on laptop via weak form, vs. wild spread (1%-100%+ error, 1 second to hundreds of seconds) using standard output-error methods in MATLAB. Lawrence chaotic system with 10% noise: <1% error in milliseconds. Burgers equation at 100% noise: 96% of experiments correctly identify terms (sparse library selection), parameter error <2.5%. Koshinsky equation: 96% accuracy identifying 3 key terms, 30% parameter error at max noise. Fourth derivative of data correctly recovered through weak form even with 50% noise (red vs. blue curves essentially overlapping).

One Level Deeper

Weak form ansatz: replace PDE u_t + f(u, u_x, u_xx, ...) = 0 with integral against test function φ (compactly supported, zero at endpoints). Integration by parts shifts derivatives from noisy data u to smooth test function φ, forming weak derivatives. Sparse regression on library matrix G (columns = basis functions u, u_x, u_xx, etc. evaluated at data; rows = equations via test functions), solve GW = B where W are parameters to identify. Piecewise polynomial test functions with power p give discretization error O(ΔT^(p+1)) via trapezoidal rule superconvergence on periodic extensions. Residual decomposition: bias from wrong parameters + noise corruption + numerical discretization error; optimal test function radius balances numerics vs. noise.

Failure Boundary

Scaling sensitivity: KDV with 50% noise exhibits condition number ~10^26 in G matrix without rescaling (6 orders of magnitude in time/space values); rescaling drops to 10^6, enabling double-precision computation. Too large polynomial library (e.g., u^10) causes numerical rank deficiency. Model form error: extra terms in library biased but still correctly identified under asymptotic consistency theorem (for linear+bilinear models, will recover truth with enough data). Cannot learn nonlocal integral operators reliably; depends on data diversity supporting the nonlocality. Chaotic multiscale systems require careful test function design; Shaninsky chaos challenges standard weak form but still manageable at <100% noise.

Important Terms

Weak Form

A way of writing an equation using integration instead of derivatives at individual points. You multiply the equation by a helper function (which you choose), integrate across a region, and ask whether that integral is zero. It is mathematically the same as the original equation but much more tolerant of noise.

Strong Form

The standard way of writing an equation by taking derivatives directly at each point, without any integration. It is exact but sensitive to noise in the data.

WSINDy

Weak-form Sparse Identification of Nonlinear Dynamics — a method that discovers the equations describing a system by using weak forms instead of pointwise derivatives, making it work much better on noisy data.

WENDy

A weak-form method that estimates the unknown numbers (parameters) in dynamical equations and also computes uncertainty bands around those estimates.

Equation Learning

The process of automatically finding the governing equations (the rules explaining how a system evolves) by analyzing measurement data from that system.

Connections Across The Series

  • This talk connects symbolic regression (converting data into human-readable equations), sparse model discovery (identifying which terms actually matter), inverse problems (using measurements to figure out what caused them), and scientific machine learning that handles noise.
  • It complements talks on PINNs (Physics-Informed Neural Networks) and differentiable solvers by offering a different mathematical angle — variational and integral formulations — on the same underlying equations.
  • It also grounds the ideas in real experimental data, where noise and measurement error are unavoidable facts of life.

Practical Caution

Weak forms reduce how much noise hurts your answer, but they are not automatic. You have to pick which helper functions to use, decide how big your integration regions should be, and choose what library of candidate terms to search through. Each of these choices changes which equations the method discovers.

Takeaway

Integrating an equation against helper functions transforms a problem poisoned by noisy derivatives into a more stable, reliable problem. Understanding this switch is the core of why weak-form methods work better.
