Talk 47 · TU Delft

Alice Cicirello: Interpretable, Explainable And Non-Intrusive Uncertainty Propagation

This lecture shows how to find the range of possible outputs from an expensive computer model when inputs might vary, using machine learning to pick which model runs matter most, while keeping the process understandable to engineers.

YouTube source · Talk page

Core Problem

Engineering choices need to know whether a system will work under changing conditions, but running realistic physics models can take hours or days. Finding the full range of outputs usually means running the model thousands of times or changing how the solver works, which may not be practical for real-world simulations.

First-Principles Model

Uncertainty propagation means tracking how variations in inputs become variations in outputs as they flow through a computational model. If you treat the simulator as a black box (you run it but don't change its code), you need to pick a few runs wisely. Machine-learning optimization can search for which input combinations give the highest and lowest outputs, and then explain why those extremes happen by building a simple mathematical model (called a surrogate) that approximates the expensive one.

Key Claims

  • Uncertainty quantification helps engineering decisions by computing how variations in inputs ripple into variations in performance.
  • For models that take a long time to run, the main challenge is picking as few model runs as possible.
  • Non-intrusive methods don't modify the simulator's code or simplify the underlying physics.
  • Interpretability means a human can trace through how a result was calculated.
  • Explainability means presenting results in a form engineers can actually use and reason about.
  • Machine-learning optimization can search for output extremes (highest and lowest values) instead of densely testing the entire input space.

Important Terms

Uncertainty Propagation

Tracking how ranges or variations in model inputs flow through to ranges or variations in outputs.

Non-Intrusive Method

A method that treats the simulator as a black box—you run it but don't change or rewrite its code.

Interval Uncertainty

Uncertainty expressed as ranges ("between 10 and 20") rather than full probability distributions.

Bayesian Optimization

A method that uses a simple statistical model to predict which runs will be most informative, then picks those runs instead of trying everything.

Performance Bound

A limit (upper or lower) on how well a system performs when inputs can vary within their ranges.

Connections Across The Series

  • This talk addresses the series' uncertainty theme by showing how to handle variability in real engineering problems.
  • It connects to active learning—both use strategies to pick which experiments or model runs matter most when testing is expensive.
  • It builds on interpretability talks by showing that explaining uncertainty results is essential for engineers to trust and use them.

Practical Caution

If your sampling strategy misses certain input regions or your surrogate doesn't capture the full behavior, you might miss the true extremes. Treat output bounds as reliable only after checking that your search strategy and surrogate actually covered the important parts of the input space.

Takeaway

The core idea is that uncertainty quantification is a problem with limited computing budget. You must pick your runs smartly to find the bounds you care about, then show engineers clearly why those bounds are what they are.
