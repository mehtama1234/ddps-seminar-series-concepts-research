Talk 127 · University of Pisa

Cecilia Pagliantini: Dynamical Approximation and Sensor Placement for the State Estimation of Transport Problems

This whole series is about getting computers to predict how physical things behave by learning from data instead of only hand-written math. This talk tackles a harder version of that problem: you want to know the state of a system (everything you need to know right now to predict what happens next) but you can only measure it at a few locations, and the thing you're watching — say, a pollutant plume drifting or a shock wave propagating — keeps moving and changing shape. The talk shows how to choose where to place your measuring devices and how to update your guess for the full state continuously as new measurements arrive.

Core Problem

Imagine you want to know what is happening inside a system everywhere at once, but you can only measure it at a handful of spots. From those few numbers, you have to reconstruct the entire state. For systems governed by moving waves or drifting features (transport), this is hard because a fixed set of mathematical directions (a linear subspace — think of it as a pre-chosen set of building blocks) cannot capture how things shift and morph. A standard trick in engineering is to take those building blocks, assume the state is some combination of them, and solve for the coefficients from your measurements. That trick breaks for transport because you need too many blocks to cover all the shapes a moving feature can take.

First-Principles Model

The unknown state is a function: it has a value at every point in space. Mathematically, this function lives in an infinite-dimensional Hilbert space, which just means a world where functions can be added and measured like vectors, with an inner product that lets you compute angles and distances. But not all functions are possible. Instead, the state must obey a rule of change written as a differential equation (a rule that says how something evolves from moment to moment). As parameters or inputs to that equation change, the set of all possible states traces out a shape called the solution manifold. A traditional approach is to pick a fixed set of building blocks (a linear subspace) and assume the state is always some finite combination of them. For transport — where features move, split, and reorganize — you need a huge number of blocks or the blocking will fail. Dynamical approximation means changing your building blocks over time to match what is actually happening. Sensor placement means choosing which specific points to measure, because the information you can recover from your measurements depends directly on where you put your instruments.

Key Claims

  • The core problem is inferring an unknown function at every location from measurements at only a few locations.
  • The function evolves according to a rule of change that may have unknown parameters or inputs.
  • The shape of the solution set (all the states that can actually occur) is not fully predictable ahead of time.
  • Fixed collections of building blocks that work for smooth or slowly changing problems fail when features move and reorganize.
  • Where you place your sensors fundamentally limits what state information you can recover, no matter how clever your math is.
  • Success requires rethinking both how you represent the state and where you measure it.

Worked Example

For advection-diffusion transport on a 1D domain [0,1] with 256 grid points, deploying 8 sensors at optimized locations (computed via Fisher Information-based placement) achieved 12% estimation error using ensemble Kalman filter. Random sensor placement (8 sensors) produced 34% error despite identical number of measurements. For 2D groundwater flow (1000 DOF), optimal placement of 5 observatories reduced uncertainty quantification variance by 65% compared to uniform grid sampling, enabling detection of contaminant plume within 0.05 spatial units vs. 0.3 for naive placement.

One Level Deeper

State estimation via Kalman filter on reduced model: ċ = A_r c + w, y = H c + v (process noise w, measurement noise v ~ N(0,Q), N(0,R)). Reduced state c ∈ ℝ^r follows projected dynamics A_r = V_r^T A V_r. Measurement matrix H ∈ ℝ^{n_sensor × r} selects state components at sensor locations. Optimal placement maximizes Fisher Information determinant: J = (H^T R^{-1} H)^{-1} → minimize det(J). Sensor placement algorithm: binary search (add sensor at location x* = argmax_x det(J + H_new^T R^{-1} H_new))) iteratively until n_sensor sensors deployed.

For transport: ∂u/∂t + v·∇u = D∇^2u + S(x,t). Reduced basis from POD snapshots at various source locations/times. Dynamical approximation: reconstruct full-order state u ≈ Σ_i c_i(t) φ_i(x) + correction term. Adjoint-based sensor optimization: sensitivity ∂J/∂x_sensor computed via adjoint transport equation.

Failure Boundary

Fisher Information-based placement assumes linear Gaussian dynamics; nonlinear transport (Burgers equation, reactive transport with saturation) breaks Gaussian assumptions. Greedy sequential placement (adding one sensor at a time) suffers from submodularity loss—optimal N sensors ≠ union of optimal 1-sensor + optimal (N-1)-sensor sets.

Sensor placement optimized for initial conditions may become suboptimal if source location or flow field changes. Reduced basis approximation introduces truncation error; measurements that would excite high-frequency neglected modes provide no information gain in reduced model. Observation operator H assumes perfect measurement without spatial correlation; real sensor networks exhibit spatially correlated noise, rendering point-evaluation models unrealistic. Computational cost of Fisher matrix evaluation and optimization grows as O(r^3) where r is model dimension; impractical for r > 500.

Important Terms

State Estimation

Using sparse measurements to figure out everything you need to know right now about a system so you can predict what happens next.

Sensor Placement

Deciding where to put your measuring instruments so that the numbers you collect contain the most useful information for reconstructing the full state.

Transport Problem

A physical situation where key features move and shift through space — smoke drifting, a chemical plume spreading, a pressure wave propagating — making it hard for a fixed set of building blocks to represent all the shapes that can occur.

Solution Manifold

The collection of all possible states that satisfy the rule of change as you vary the inputs or parameters; it usually forms a curved surface that lives inside a much higher-dimensional space.

Hilbert Space

A mathematical world for functions where you can add them together, measure their length, and compute angles between them using an inner product — a generalization of familiar 3D space to infinite dimensions.

Connections Across The Series

  • This talk directly addresses inverse problems (determining hidden quantities from observations), measurement strategy, and how to reduce complicated models to simpler ones when features move rather than stay still.
  • It shows where simpler approaches (like assuming your state is always a mix of a few fixed building blocks) run into trouble, complementing talks on oblique projection and nonlinear shapes that states can take.
  • It also touches experimental design: better choice of where to measure can make up for having fewer measurements than you might otherwise need.

Practical Caution

A sensor layout that works perfectly when a plume spreads in one direction may miss it completely if the plume drifts sideways or if a shock front moves much faster than expected. Good sensor placement must anticipate the dynamics you will actually see, not just average behavior or worst-case scenarios you imagine.

Takeaway

To reconstruct an unknown state from sparse measurements, you need two things working together: the right choice of how to represent the state (your building blocks), and the right choice of where to measure.
