Talk 127 · University of Pisa

Cecilia Pagliantini: Dynamical Approximation and Sensor Placement for the State Estimation of Transport Problems

This lecture studies how to reconstruct transport-dominated states from limited measurements using time-varying approximations and strategic sensor placement.

YouTube source · Talk page

Core Problem

State estimation asks for an unknown function from finitely many measurements. For parametric transport problems, the solution set may shift or deform in ways that fixed linear subspaces cannot capture well, making standard projection-based model reduction break down.

First-Principles Model

The unknown state lives in an infinite-dimensional Hilbert space (a mathematical space for functions with well-defined inner products), but its possible values lie on a solution manifold (the surface of all solutions as parameters change) generated by a parametric differential equation. A common strategy approximates that manifold by a finite-dimensional linear subspace and estimates the state there. Transport dynamics break this strategy because shifts and moving fronts need many linear modes to represent accurately. Dynamical approximation (changing the representation over time) and sensor placement (choosing where to measure) address both the representation itself and where measurements should be taken.

Key Claims

  • The problem is reconstructing an unknown function from finite measurements.
  • The function is assumed to be generated by a parametric differential equation with unknown inputs.
  • The geometry of the solution set is not known in advance.
  • Linear model-reduction subspaces can fail for transport problems.
  • Sensor placement is central because measurements determine what state information is recoverable.
  • The talk combines approximation strategy with state-estimation design.

Important Terms

State Estimation

Inferring the current state (everything you need to know to predict what happens next) of a system from limited observations.

Sensor Placement

Choosing where to measure a system to get the most information for reconstruction or control.

Transport Problem

A system where features move through space, often making fixed linear subspaces inefficient for representing the solution.

Solution Manifold

The set of all possible solutions as parameters or inputs vary; a lower-dimensional surface within a higher-dimensional space.

Hilbert Space

An infinite-dimensional vector space with an inner product (a way to measure angles and distances), commonly used to represent functions.

Connections Across The Series

  • This talk connects inverse problems (inferring hidden quantities from observations), sensor placement, model reduction, and transport-dominated dynamics.
  • It complements oblique-projection and nonlinear-manifold ROM talks by showing where linear subspaces fail.
  • It also links to experimental design because better sensors can compensate for having fewer measurements.

Practical Caution

A sensor layout optimized for one transport regime may fail when fronts or coherent structures move differently. Sensor design must reflect the expected dynamics, not only average variability.

Takeaway

The first-principles lesson is that reconstruction quality depends on both how you represent the state and where you choose to measure.
