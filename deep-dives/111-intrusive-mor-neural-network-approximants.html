Talk 111 · Weierstrass Institute

Francesco Romor: Intrusive Model Order Reduction Using Neural Network Approximants

This lecture describes an intrusive and interpretable reduced model that uses neural networks to approximate the curved surface where solutions live while keeping the physical equations active during prediction.

YouTube source · Talk page

Core Problem

Linear projection-based reduced models fail when the solution manifold (the set of all possible answers as parameters change) has slowly decaying Kolmogorov n-width, which means you need many reduced modes to get accuracy. Neural networks can approximate curved manifolds well, but most neural-network reduced models become data-only surrogates that throw away the governing equations during prediction.

First-Principles Model

The method keeps the physical and numerical model running during the prediction phase while using neural networks to approximate the curved solution manifold. Autoencoders (neural networks that compress data by learning to squeeze and unsqueeze it through a narrow middle layer) compress linear approximations into fewer coordinates. Hyper-reduction techniques then lower the cost of evaluating the retained model terms, so the approach combines the power of nonlinear approximation with the interpretability of keeping the physics equations visible.

Key Claims

  • Slow Kolmogorov n-width decay limits how well linear reduced modes can approximate curved solution manifolds.
  • Neural networks can accurately approximate the curved surface where solutions live.
  • Most existing implementations abandon the equations and become data-only surrogates.
  • The proposed method stays intrusive by keeping the physical and numerical model running during prediction.
  • Autoencoders can squeeze the dimensionality of linear approximations into lower-dimensional coordinates.
  • Adaptive hyper-reduction is necessary to make the retained model computationally affordable.

Important Terms

Intrusive MOR

Model order reduction that requires direct access to the governing equations or numerical operators.

Kolmogorov n-Width

A measure of how well a curved solution surface can be approximated by an n-dimensional flat subspace.

Solution Manifold

The collection of all solutions that emerge as parameters or input values change.

Autoencoder

A neural network that learns to compress data by encoding it into a narrow middle layer and then decoding it back.

Hyper-Reduction

Techniques that reduce the computational cost of evaluating nonlinear or high-dimensional terms in a reduced model.

Connections Across The Series

  • This talk connects intrusive reduced models, autoencoders, curved solution surfaces, and scientific machine learning.
  • It contrasts with data-only neural surrogate talks by explaining why keeping the equations matters.
  • It also relates to manifold-learning discussions showing that flat subspaces are often not enough.

Practical Caution

Intrusive neural reduced models need direct access to and careful handling of the governing numerical model. They offer more visibility than data-only surrogates but become harder to deploy when you have only input-output simulator data and no access to the equations themselves.

Takeaway

The lesson is that nonlinear neural compression can work alongside intrusive physics rather than replacing the equations entirely.
