Talk 86 · University of Utah

Amir Arzani: A Flexible And Generalizable XAI Framework For Scientific Deep Learning

This whole series is about getting computers to predict physical behavior by learning from examples instead of only hand-written rules. One challenge: when you train a learning program (a huge bank of dials the computer tunes by trial and error until its answers look right) to predict something physical, it often refuses to explain why it made those choices, and it fails when given inputs unlike anything it saw during training. This talk shows a method to solve both problems: take a trained network and fit a much simpler set of mathematical rules (integral equations — formulas that sum effects together) to what it learned, then test those rules against real physics to make sure they actually work.

YouTube source · Talk page

Core Problem

Learning programs trained to predict physical behavior often suffer from two linked failures: first, they give no explanation for their choices, so you can't tell if they're actually capturing real physics or just getting lucky; second, they tend to fail badly when you ask them to predict something at a temperature, size, or condition they never saw during training. The root cause: real experiments and measurements rarely cover every possible condition a model might meet, so the learning program never learns what to do in those gaps.

First-Principles Model

The method starts by taking a trained learning program and asking it: what patterns did you pick up on? It pokes the network with inputs across the range it learned from, then takes all those outputs and fits a much simpler, readable model (built from integral equations — formulas where one quantity is defined as a sum of effects calculated across space or time using a kernel weight and other rules). The goal is to find the sparsest set (fewest terms, most important ones only) that still captures what the network learned. This simpler model acts like a translator: it can explain what the network discovered and also predict outside the training range, much like how operator learning (a method where you teach the computer one general rule that works across a whole family of problems) tries to capture general patterns rather than specific cases.

Key Claims

  • Making models readable and making them work on new inputs are deeply connected: both depend on the network truly learning real physics, not just memorizing training data.
  • When physics-based learning tasks cannot create exhaustive data covering all conditions, models trained on limited data will predict poorly on new conditions.
  • The proposed method works both during design (to guide which physical rules matter) and after training (to explain a finished model).
  • You can extract understanding from a trained network by testing it carefully across the input space it learned on.
  • A small set of carefully chosen mathematical rules can often replace a huge network while staying readable.
  • This approach trades some raw prediction speed for the ability to read the rules and trust them against real physics.

Important Terms

Explainable AI

Methods that let humans understand why a model made a particular prediction by showing the reasoning in a way humans can read and judge.

Out-Of-Distribution Inference

Using a model to predict when the input falls outside the range of examples it trained on — the situation where most models guess badly.

Post-Hoc Explanation

An explanation of what a model learned applied after the model has already been built and trained, rather than built into the training itself.

Integral Equation Library

A collection of different mathematical rules (each one sums effects across space or time using a kernel function and other operations) that can be mixed and matched to build a readable model.

Sparse Regression

A method that picks out only the most essential terms from a long list of candidates, throwing away the rest so the final model stays simple and readable.

Connections Across The Series

  • This lecture connects interpretability with operator learning (a method that teaches a single rule across a whole family of similar problems), Green's functions (mathematical solutions that show how effects spread and accumulate), and sparse regression techniques (picking the most important terms from many candidates).
  • It builds on Miles Cranmer's scientific-debt talk by offering a concrete path to write down equations that capture what a network actually learned.
  • It also addresses out-of-distribution reliability — why models trained on limited data fail on new conditions — a problem that repeats across surrogate models and digital twins (virtual copies of real systems used to test ideas safely).

Practical Caution

The simpler model you extract only captures what the original network learned — it does not automatically describe the true physics. Before you trust this extracted model, you must check it against real measurements and compare it to known physics rules that must always hold true, so you catch cases where the network merely got lucky on its training data.

Takeaway

Prediction of physical systems can be made readable by converting what a trained network learned into a sparse set of mathematical rules you can actually write down and understand. But that extracted model is only the network's guess — you must always verify it against real physics to confirm it is not just pattern-matching noise.
