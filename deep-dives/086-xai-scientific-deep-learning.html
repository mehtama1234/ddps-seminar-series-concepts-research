Talk 86 · University of Utah

Amir Arzani: A Flexible And Generalizable XAI Framework For Scientific Deep Learning

This lecture presents an interpretable XAI framework for scientific deep learning that probes trained networks, fits sparse integral-equation models, and improves out-of-distribution reasoning.

YouTube source · Talk page

Core Problem

Scientific deep learning often lacks interpretability and fails under out-of-distribution inputs because training data rarely cover the full feature landscape. Black-box models may predict well in distribution while offering little explanation or extrapolation guidance.

First-Principles Model

The framework treats a trained neural network as a source of learned local knowledge. First, probe the network inside the training feature landscape. Then fit an interpretable surrogate from a library of integral equations with kernels and nonlinearities, using sparse regression to select a compact model. This interpretable model can be used by design or post hoc, and resembles a simpler interpretable version of operator learning.

Key Claims

  • Interpretability and generalization are central challenges in scientific deep learning.
  • OOD inference errors grow because physics-based learning tasks often cannot generate exhaustive datasets.
  • The proposed XAI framework can be used by-design or post-hoc with black-box models.
  • The method probes a trained neural network within its trained input landscape.
  • A sparse library of integral equations is fitted to produce an interpretable model.
  • The approach relates to neural operators but trades some expressiveness for analytical interpretability.

Important Terms

Explainable AI

Methods that make model behavior understandable to humans.

Out-Of-Distribution Inference

Prediction on inputs outside the distribution represented in training data.

Post-Hoc Explanation

An explanation method applied after a black-box model has already been trained.

Integral Equation Library

A collection of candidate integral-equation forms used to fit interpretable operators.

Sparse Regression

A regression method that selects a small number of active terms from a larger candidate library.

Connections Across The Series

  • This lecture connects explainability with neural operators, Green's functions, and symbolic sparse regression.
  • It complements Miles Cranmer's scientific-debt talk by offering an equation-like interpretation route.
  • It also links to OOD reliability, a recurring issue in surrogate models and digital twins.

Practical Caution

An interpretable surrogate explains the probed network behavior, not necessarily the true physical system. The explanation should be tested against physical data and governing constraints.

Takeaway

The first-principles lesson is that scientific explanation can be learned as a sparse operator approximation of a black-box model, but it must still be physically validated.
