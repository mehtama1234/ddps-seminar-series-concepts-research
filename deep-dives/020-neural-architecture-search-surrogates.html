Talk 20 · Argonne National Laboratory

Romit Maulik: Neural Architecture Search For Surrogate Modeling

This lecture shows how to automate surrogate-model design by searching over neural-network architectures, and how to use collections of different architectures to measure uncertainty.

YouTube source · Talk page

Core Problem

Surrogate modeling usually requires hand-designed architectures (the overall shapes and sizes of neural networks), hyperparameters (settings that control how networks train), bottlenecks (narrow layers that compress information), symmetry assumptions (the idea that encoder and decoder halves must mirror each other), and sequence-model choices. That manual work can take up most of the project time, and it can hide better architectures that humans would not naturally try, especially for weather forecasts or autoencoders (networks that compress data down and then rebuild it) trained to find low-dimensional patterns.

First-Principles Model

A neural architecture can be drawn as a directed acyclic graph: a flowchart where each box is an operation (matrix multiply, add, skip connection, dropout, etc.) and arrows point forward with no loops. Neural architecture search defines the space of all possible graphs—varying the number of layers, widths, skip connections (shortcuts that feed information forward to later layers), dropout rates (which nodes randomly turn off during training), tensor operations, and hyperparameters. An optimizer like aging evolution treats each candidate architecture as if it were a genome, evaluates performance on validation data, and breeds better candidates over generations. Sampling many different points in this space also produces an ensemble (a collection of diverse trained networks) that can be used for uncertainty quantification (measuring how confident predictions are).

Key Claims

  • DeepHyper automates the search over neural-network architectures and hyperparameters across many different network types.
  • Architecture search can discover surrogate models that work well without being physically encoded into the network structure.
  • The search space can be drawn as a directed acyclic graph showing all possible operations the search can choose.
  • Aging evolution interprets each candidate architecture as a genome and optimizes how well it performs on held-out validation data.
  • Neural architecture search can question default assumptions, such as the idea that encoder and decoder halves of autoencoders must have matching structures.
  • Collections of different architectures can support uncertainty quantification by sampling different model designs.

Important Terms

Neural Architecture Search

Automated search over the structure and hyperparameters of neural networks, instead of designing them by hand.

Search Space

All possible architectures, operations, and hyperparameter settings that the algorithm is allowed to try.

Aging Evolution

An evolutionary algorithm that treats candidate architectures like living organisms: it keeps the best ones, mutates them slightly, and removes the weakest ones over many generations.

Architecture Ensemble

A group of different trained networks, each with its own architecture, combined together to improve predictions and measure how much the choice of architecture affects the answer.

Asymmetric Autoencoder

A network that compresses data in an encoder half and reconstructs it in a decoder half, where the decoder structure is not forced to match the encoder structure.

Connections Across The Series

  • This talk builds on ROM-net and nonlinear manifold ROM work: the choice of architecture is something the scientific workflow should optimize over, not assume.
  • It relates to uncertainty and robustness because using many different architectures shows how much prediction changes when the model structure changes.
  • It also relates to hyper-reduction (using only the most important dimensions) because efficient, smaller architectures can reduce the cost of running predictions in real applications.

Practical Caution

Neural architecture search does not eliminate the need to check against physics and domain knowledge. If the search objective rewards only validation error (how well the model fits held-out test data), the search can find models that appear accurate on that test data but behave erratically, grow too large, or produce physically implausible predictions when deployed in the real world.

Takeaway

The first-principles lesson is that model architecture is itself a design choice. Neural architecture search searches over that choice instead of relying only on default designs that humans picked.
