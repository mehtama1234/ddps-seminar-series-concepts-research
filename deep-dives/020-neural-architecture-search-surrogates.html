Talk 20 · Argonne National Laboratory

Romit Maulik: Neural Architecture Search For Surrogate Modeling

This lecture presents neural architecture search as a way to automate surrogate-model design and use architecture ensembles for uncertainty quantification.

YouTube source · Talk page

Core Problem

Surrogate modeling often depends on hand-designed architectures, hyperparameters, bottlenecks, symmetry assumptions, and sequence-model choices. That manual tuning can dominate the workflow, and it can hide better architectures that a human would not naturally try, especially for geophysical forecasts or autoencoder-based reduced models.

First-Principles Model

A neural architecture can be represented as a directed acyclic graph of operations. Neural architecture search defines a search space over layers, widths, skip connections, dropout, tensor operations, and hyperparameters. An optimizer such as aging evolution treats architectures like genomes, evaluates them on validation performance, and evolves better candidates. Sampling the search space can also produce ensembles for UQ.

Key Claims

  • DeepHyper automates neural architecture and hyperparameter search across many neural-network families.
  • Architecture search can discover non-intrusive surrogate models from data.
  • The search space can be represented as a directed acyclic graph of possible operations.
  • Aging evolution interprets candidate architectures as genomes and optimizes validation performance.
  • NAS can challenge default assumptions, such as symmetric autoencoder designs.
  • Architecture ensembles can support uncertainty quantification by sampling high-dimensional model-form choices.

Important Terms

Neural Architecture Search

Automated search over neural-network structures and hyperparameters.

Search Space

The set of possible architectures, operations, and hyperparameters the algorithm is allowed to explore.

Aging Evolution

An evolutionary NAS algorithm that keeps, mutates, and replaces candidate architectures over time.

Architecture Ensemble

A collection of different trained architectures used to improve prediction or quantify model uncertainty.

Asymmetric Autoencoder

An encoder-decoder model whose encoder and decoder structures are not forced to mirror each other.

Connections Across The Series

  • This talk is a tooling counterpart to ROM-net and nonlinear manifold ROMs: architecture design can be part of the scientific workflow.
  • It connects to uncertainty and robustness because ensembles over architectures expose model-form variability.
  • It also connects to hyper-reduction because sparse or efficient architectures can matter for online cost.

Practical Caution

NAS does not remove the need for physics-aware evaluation. If the objective rewards only validation error, the search can produce models that are accurate on held-out data but unstable, too large, or physically implausible in deployment.

Takeaway

The first-principles lesson is that model architecture is itself a design variable. NAS searches that variable instead of relying only on human defaults.
