Talk 49 · Peking University / Princeton University

Weinan E: Machine Learning And Multi-Scale Modeling

This lecture explains how machine learning helps multiscale modeling by learning mathematical functions that can capture complex behavior—the kind classical hand-built models cannot express by hand.

YouTube source · Talk page

Core Problem

Multiscale modeling aims to connect quantum, atomistic, coarse-grained, continuum, and turbulence-level descriptions into practical simulations that predict real-world properties. The idea is powerful, but a real challenge remains: the effective models and closure relations (equations that account for what smaller scales do) can be too complicated to write down or parameterize by hand.

First-Principles Model

Each scale has a model that works well in its own range. The multiscale task is to move information between scales: fine-detailed models supply effective laws, closures, potentials, or constitutive relations (how a material responds to forces) for coarser models. Machine learning expands what models can be expressed for these connections between scales, making room for learned potentials, coarse-grained dynamics, non-Newtonian constitutive models, and reduced PDE models.

Key Claims

  • Multiscale modeling connects physical models across scales to build accurate simulation tools.
  • Its practical success has been limited because the functions and models needed are too hard to write by hand.
  • Machine learning offers flexible ways to represent closures and effective models.
  • Applications include molecular dynamics, coarse-grained molecular dynamics, non-Newtonian fluid dynamics, and PDE model reduction.
  • The hierarchy of physical models spans quantum mechanics, density functional theory, molecular dynamics, coarse-grained models, continuum mechanics, and turbulence models.
  • The central promise is not replacing physics, but learning the pieces that connect physical descriptions across scales.

Important Terms

Multiscale Modeling

A process of linking models defined at different physical scales to predict large-scale quantities of interest.

Closure Model

An approximate relation that captures the effects of small-scale details that a coarser model cannot represent directly.

Coarse-Grained Molecular Dynamics

A molecular simulation that groups many small degrees of freedom into fewer, larger effective units.

Non-Newtonian Fluid

A fluid whose stress-strain relationship cannot be described by a constant viscosity, unlike simple Newtonian fluids.

Effective Model

A model at one scale that captures the essential effects of more detailed physics at smaller scales.

Connections Across The Series

  • This lecture pairs naturally with Kaushik Bhattacharya's work on neural operators for multiscale mechanics.
  • It also connects to materials machine learning because learned potentials are one concrete way to bridge between scales.
  • It reinforces a theme that returns throughout the seminar: machine learning is most useful when it fills a gap in what a physics-based tool can express.

Practical Caution

A learned closure can be accurate inside its training regime and still break conservation, stability, or transfer across scales if it is not built into the larger simulator in a consistent way.

Takeaway

The first-principles lesson is that multiscale machine learning is about learning the interfaces between different physical descriptions. The model is valuable when it lets a trusted simulation reason across scales.
