Talk 49 · Peking University / Princeton University

Weinan E: Machine Learning And Multi-Scale Modeling

This whole series asks whether computers can learn to predict how physical things behave instead of (or alongside) using hand-written math. One common approach is to feed a learning program both the data and the physics rules as it trains. This talk tackles a different angle: when you're trying to simulate something that has parts at many different size scales—atoms bouncing, then molecules jiggling, then materials warping, then structures shaking—how do you connect these views? Machine learning can learn the equations that stitch these scales together when the equations are too hard for a person to write down by hand.

YouTube source · Talk page

Core Problem

Real-world systems happen at many size scales at once: electrons and atoms (quantum scale), groups of molecules (atomistic scale), bunches of molecules acting together (coarse-grained scale), bulk materials (continuum scale), and swirling flows at large scales (turbulence scale). To predict real properties—how strong a material is, how a fluid flows, how heat spreads—you need these scales to talk to each other in your simulation. The hard part is writing down the 'connectors' between scales: the equations that describe how the smaller-scale details add up to affect the larger scales. These connectors are often too tangled and complex to write by hand.

First-Principles Model

Each scale has its own successful description. At the atomic scale, you use quantum rules. At the molecular scale, you track the jiggling of atoms. At the material scale, you write down how the material stretches and bends. The job is to move information between scales: smaller-scale details should tell you what effective rules apply at the next scale up. For instance, molecular jiggling should tell you what viscosity (how thick or goopy a fluid is) to use in a larger-scale fluid simulation. Machine learning lets you learn these connection equations—the potentials (energy descriptions), the rules for how a coarse material responds to forces, the reduced equations for large systems—when writing them by hand is too hard or too time-consuming.

Key Claims

  • Real systems require connecting models across many size scales to build simulators that actually predict what happens.
  • The bottleneck is writing the equations that link scales; those equations are often too complicated to work out by hand.
  • Machine learning can learn flexible versions of these linking equations from data.
  • Concrete uses include atomic simulations, models where many atoms act as one blob, thick fluids that don't behave simply, and shrinking large systems into smaller equations.
  • The chain goes: quantum rules, density descriptions of electrons, atomic jiggling, clumps of atoms, bulk materials, swirling large flows.
  • The real goal is not to throw out physics, but to learn the specific pieces that connect one physical picture to the next.

Worked Example

Illustrative: Multiscale molecular dynamics (MD) coupled to continuum PDE. MD region has 10³-10⁴ atoms; continuum domain is discretized on macroscopic grid. ML learns the closure: macroscopic strain/stress history → coarse-grained force field. Example: polymer chain under load learns effective potential from MD ensemble averaging.

One Level Deeper

Heterogeneous multiscale method (HMM) solves macro-PDE, queries microscale model at sampling points. Neural network closure g_θ(history; μ) replaces expensive microscale solve: F_macro = g_θ(u_coarse, ∇u_coarse; μ). Loss: minimize ||F_fom - g_θ(·;μ)||² over trajectories. Coarse-grained time-stepping: u_{n+1} = u_n + Δt × (linear + g_θ(u_n)).

Failure Boundary

Closure is parameter-μ dependent; transfer to new μ fails if training set doesn't span parameter range. Microscale stochasticity (thermal noise) requires ensemble averaging; small ensemble → biased closure. Causality violation if network output depends on future history.

Important Terms

Multiscale Modeling

Building a simulation by connecting together separate descriptions that work well at different size scales—tiny (atoms) to large (structures)—so they can all predict what happens.

Closure Model

A replacement rule that says what the tiny-scale details add up to when you don't track each tiny detail separately in a larger-scale simulation (like saying 'friction here is this much' instead of computing every tiny collision).

Coarse-Grained Molecular Dynamics

A simulation that treats a bunch of atoms as single blobby units instead of tracking each atom separately, making the calculation much faster.

Non-Newtonian Fluid

A liquid or gas whose thickness (how hard it is to pour or stir) changes depending on how hard you push on it, unlike water which stays the same thickness no matter how fast you stir it.

Effective Model

A simplified rule at one size scale that captures what all the messy physics at smaller scales actually adds up to, without having to compute each tiny piece.

Connections Across The Series

  • This talk connects to Kaushik Bhattacharya's work on teaching programs to become simulators (neural operators) that handle systems across multiple scales.
  • It ties directly to machine learning for materials, because learning energy descriptions (potentials) is a concrete way to jump from smaller-scale atoms to larger-scale material behavior.
  • It reinforces a repeating thread across these talks: machine learning works best when it fills in the gaps that physics-based simulations cannot fill on their own.

Practical Caution

A rule learned from data can look perfect within the data it trained on, yet still break physical laws (like energy or momentum must be conserved), become unstable in new situations, or fail when moved to a different scenario. This happens if the learned rule is not grafted into the full simulation in a way that keeps the physics consistent across all scales.

Takeaway

The core idea is that multiscale machine learning is about learning the glue that holds together descriptions at different physical scales. The real win comes when learned rules let you trust your full simulation to work at every scale.
