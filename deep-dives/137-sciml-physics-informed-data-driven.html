Talk 137 · Texas A&M University

Ulisses M. Braga-Neto: Scientific Machine Learning: From Physics-Informed to Data-Driven

This lecture reviews scientific machine learning as a range from physics-informed collocation methods (enforcing known equations at selected points) to data-driven operator learning (finding the mathematical map from input to solution without writing equations).

YouTube source · Talk page

Core Problem

SciML combines scientific computation and machine learning, but different methods use physics and data in very different ways. Practitioners need to understand the tradeoff between enforcing known differential equations and learning directly from solution data when equations are unknown, incomplete, or expensive to solve.

First-Principles Model

Physics-informed methods such as PINNs and physics-informed Gaussian processes enforce differential equations at collocation points (chosen spots in the domain where you check the equations hold). Data-driven operator learning instead learns the map associated with a parametric differential equation—the mathematical transformation that takes input data to solution—often without explicit knowledge of the equation itself. The idea is that the physics may be embedded in the data rather than written in the loss function. The lecture compares these regimes and discusses applications including plasma turbulence.

Key Claims

  • SciML joins scientific computation and machine learning by applying neural methods to simulation, discovery, and inverse problems.
  • PINNs and PIGPs became widely used by making physics-informed collocation straightforward.
  • Operator learning is a newer data-driven approach to SciML.
  • Operator learning often does not require explicit knowledge of the underlying differential equations.
  • The physics-informed and data-driven approaches have different strengths and weaknesses.
  • The Hasegawa-Wakatani model of plasma turbulence is one application setting.

Important Terms

Scientific Machine Learning

Machine learning methods applied to scientific computation, simulation, discovery, and inverse problems (finding what caused observed measurements).

PINN

A physics-informed neural network that enforces differential equation constraints (the equation residuals must be near zero) during training.

Physics-Informed Gaussian Process

A Gaussian process model incorporating differential equation constraints.

Operator Learning

Learning maps between functions, such as transformations that take PDE input conditions to their solution.

Collocation

Enforcing an equation or constraint at selected points in the domain.

Connections Across The Series

  • This lecture synthesizes many earlier talks: PINNs, neural operators, data-driven PDEs, and scientific surrogates.
  • It connects to the first-principles theme by clarifying where physics enters the model.
  • It also links to data-progress discussions because data-driven SciML moves physical structure into the dataset.

Practical Caution

The idea that 'physics is in the data' is only true if the data cover the relevant conditions and actually preserve the physics. Otherwise data-driven operator learning can make poor predictions when the situation falls outside the data.

Takeaway

The first-principles lesson is that SciML methods differ mainly in where they put physics: in the equations, in the architecture, or in the data.
