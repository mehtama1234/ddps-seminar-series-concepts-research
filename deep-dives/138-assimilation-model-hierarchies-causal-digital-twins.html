Talk 138 · University of Wisconsin-Madison

Nan Chen: Bridging Models and Data: Assimilation, Model Hierarchies, Causal Inference and Digital Twins

This lecture presents data assimilation as a bridge connecting model hierarchies, causal inference, and digital twins.

YouTube source · Talk page

Core Problem

Scientific systems often have data, idealized models, and complex operational models that each capture different pieces of reality. A useful digital twin must combine these sources, handle sparse observations, and answer attribution or predictability questions rather than only forecast forward.

First-Principles Model

Data assimilation updates model states and parameters using observations. The lecture extends this role in three directions. Reconfigured latent data assimilation maps models of different complexity into a shared latent space so idealized and operational models can interact. Assimilative causal inference uses Bayesian data assimilation to trace causes backward from observed effects. Digital twins use these assimilation and causal tools to evaluate what-if scenarios and extreme events.

Key Claims

  • Data assimilation is a crucial bridge between models and data.
  • Model hierarchies can combine idealized and operational models.
  • Latent data assimilation can reduce cost and connect separated model classes.
  • Assimilative causal inference traces causes backward from observed effects.
  • Attribution and predictability questions matter for climate tipping points and extreme events.
  • These tools support digital-twin construction.

Important Terms

Data Assimilation

Combining model predictions with observations to estimate system state or parameters.

Model Hierarchy

A collection of models with different fidelity, complexity, or scope.

Latent Data Assimilation

Assimilation performed in a learned or reduced latent representation.

Assimilative Causal Inference

A framework using Bayesian assimilation to infer causes from observed effects.

Digital Twin

A continuously updated computational representation of a physical system for prediction and decision support.

Connections Across The Series

  • This talk connects data assimilation, latent spaces, digital twins, model hierarchies, and causal inference.
  • It complements ocean, subsurface, weather, and uncertainty lectures by making assimilation a unifying workflow.
  • It also links to agentic reasoning because a digital twin supports counterfactual what-if analysis.

Practical Caution

A digital twin can look authoritative while inheriting bias from its model hierarchy and sparse observations. Assimilation must quantify uncertainty and model mismatch.

Takeaway

The first-principles lesson is that assimilation is not just filtering; it is an interface for combining models, data, causality, and decision support.
