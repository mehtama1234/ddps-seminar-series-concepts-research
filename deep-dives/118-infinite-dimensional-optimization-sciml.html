Talk 118 · University Hospital Freiburg

Marius Zeinhofer: Infinite Dimensional Optimization for Scientific Machine Learning

This lecture advocates designing scientific ML optimizers in function space first and discretizing them into neural-network parameter space afterward.

YouTube source · Talk page

Core Problem

Scientific ML often optimizes neural networks as finite parameter vectors even though the underlying problem lives in function space. This can obscure the geometry of the problem and make optimization algorithms harder to understand or scale.

First-Principles Model

The proposed paradigm is first optimize, then discretize. One chooses an infinite-dimensional algorithm appropriate for the function-space problem, then discretizes it in the tangent space of the neural-network ansatz. This perspective can derive existing scientific ML algorithms and adapt natural-gradient ideas, including Kronecker-factored approximations, for large-scale applications.

Key Claims

  • Scientific ML optimization problems can be understood from an infinite-dimensional perspective.
  • The talk advocates first optimize, then discretize.
  • Algorithms should be chosen at the function-space level before being represented by neural networks.
  • The discretization occurs in the tangent space of the neural-network ansatz.
  • Recent state-of-the-art scientific ML algorithms can be derived in this framework.
  • Kronecker-factored natural-gradient approximations can be transferred to scientific ML.

Important Terms

Infinite-Dimensional Optimization

Optimization over functions or fields rather than finite-dimensional vectors.

First Optimize, Then Discretize

A numerical-analysis principle where the continuous optimization problem is designed before discretization.

Function Space

A mathematical space whose elements are functions.

Natural Gradient

A gradient method that accounts for the geometry of the parameter or function space.

Kronecker-Factored Approximation

A scalable approximation of curvature or Fisher information using Kronecker product structure.

Connections Across The Series

  • This talk connects optimization theory, neural-network ansatz spaces, PINNs, and scientific ML training.
  • It complements differentiable-solver talks by focusing on optimizer geometry rather than solver embedding.
  • It also links to first-principles ML theory by treating neural training as discretized functional optimization.

Practical Caution

Function-space reasoning can clarify algorithms, but implementation still depends on the chosen neural ansatz and discretization. Bad discretization can erase the advantages of the continuous formulation.

Takeaway

The first-principles lesson is that scientific ML optimization should respect the function-space problem before committing to finite network parameters.
