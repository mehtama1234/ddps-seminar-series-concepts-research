Talk 118 · University Hospital Freiburg

Marius Zeinhofer: Infinite Dimensional Optimization for Scientific Machine Learning

This lecture shows how to design scientific ML optimizers by first choosing a method for the function-space problem, then converting that method into updates for neural-network parameters.

YouTube source · Talk page

Core Problem

Scientific ML typically treats neural networks as lists of numbers to optimize, but the real problem lives in the world of functions (curves you can draw on a graph). Working directly with numbers can hide what the problem actually looks like geometrically and make it harder to build algorithms that scale or make sense.

First-Principles Model

The proposal is: optimize first in function space, then discretize. You pick an algorithm suited to the function-space problem, then convert it into a concrete update rule for your neural-network numbers using the tangent space (local direction) of your chosen neural architecture. This approach can re-derive existing scientific ML algorithms and adapt natural-gradient ideas, including Kronecker-factored approximations, for use on large problems.

Key Claims

  • You can understand scientific ML optimization problems by thinking about them as infinite-dimensional (working with whole functions instead of just lists of numbers).
  • The talk shows that you should optimize in function space first, then convert to network parameters.
  • Algorithms should be built at the function-space level before you represent them using neural networks.
  • The conversion from functions to network numbers happens in the tangent space (the set of small, allowable changes) of your chosen neural architecture.
  • Well-known scientific ML algorithms can be re-derived using this function-space way of thinking.
  • You can transfer natural-gradient approximations that use Kronecker products to scientific ML optimization.

Important Terms

Infinite-Dimensional Optimization

Optimization over complete functions or fields, not just finite lists of numbers.

First Optimize, Then Discretize

A numerical-analysis approach where you design the continuous (smooth, infinite-precision) optimization problem before converting it into concrete computer steps.

Function Space

A collection of all possible functions (or curves) you could pick from; a mathematical playground where the elements are functions, not numbers.

Natural Gradient

A gradient method that changes your steps to respect the true shape and distances in your parameter or function space, not just moving in the steepest direction.

Kronecker-Factored Approximation

A way to approximate the curvature (how sharply the landscape bends) using a special product structure that keeps computation fast for large problems.

Connections Across The Series

  • This talk bridges optimization theory, neural-network ansatz spaces, PINNs (physics-informed neural networks), and how to train scientific ML models.
  • It complements talks about embedding differential solvers by instead focusing on the geometry of the optimizer itself rather than how the solver fits inside the neural network.
  • It also links to first-principles ML theory by treating neural-network training as a discretized version of functional optimization.

Practical Caution

Thinking in function space can make algorithms clearer, but actually running them still depends on which neural ansatz you pick and how you convert the math into code. A sloppy conversion can lose all the advantages you got from thinking in function space.

Takeaway

The core insight is that scientific ML optimization should think about the problem in function space first, before deciding on a particular neural network size and shape.
