Talk 74 · Brown University

Ameya Jagtap: Scientific Machine Learning Through The Lens Of PINNs

This series is about getting computers to predict how physical things behave by learning from examples instead of only hand-written math rules. One popular way is to give a learning program (a huge set of adjustable dials the computer tunes by trial and error until its answers look right) both the laws of physics AND real-world data as it learns. This talk asks: what makes that approach work well, where does it break down, and how do you fix it? The talk is named after the person and method it focuses on.

YouTube source · Talk page

Core Problem

Computers have two old ways to predict how the world works. One: write down all the math rules (how heat spreads, how air pushes over a wing). That takes experts with deep knowledge and runs very slow for complicated shapes or long time periods. Two: just show a learning program examples and let it guess the pattern. The catch: learning programs usually need tons of examples, and they don't know the physics, so they might predict something that violates the laws of nature. This talk is about a third way: teaching a learning program to match both real data AND the physics laws at the same time. But that third way has its own problems—it doesn't always work well, especially if you have a lot of data, a huge region to predict, or many time steps.

First-Principles Model

Here's how the main method works. You write down a rule that says how something changes from moment to moment or place to place (a temperature rule, an airflow rule). Instead of solving it the hard way with exact math, you use a learning program to guess the answer at every spot in space and time. Then you nudge the program's dials by trial and error in two directions at once: (1) to match the real-world measurements you collected, and (2) to obey the physics rule. The program counts how badly it breaks the physics rule at each point—that's called a residual, and zero means the rule holds perfectly. To make this work at bigger scales, researchers split the problem into pieces. One way: break the big region into smaller zones and train each to conserve energy or mass within itself. Another way: treat time going forward as a real direction (cause comes before effect) rather than trying to learn everything at once. This respects how physics actually works.

Key Claims

  • Scientific machine learning is a real alternative: instead of hiring experts to write down all the math and run slow simulations, you can teach a learning program using real-world data and the known physics laws together.
  • The main method solves two kinds of problems: predicting what happens next (forward problems), or figuring out hidden causes from what you observe (inverse problems), even when your measurements are noisy or incomplete.
  • The main method has real wins but also hard limits.
  • Splitting the problem into zones or using conservation laws makes the method work on bigger datasets and larger regions.
  • Splitting time into ordered steps makes the method work for problems that unfold over long periods.
  • Training the program to respect causality—predicting earlier times before later times—gives a unified way to solve time-dependent problems that actually works.

Worked Example

2D Helmholtz equation Δu + k²u = 0 with k=25 (high-frequency wave, wavelength ~0.25) on domain [0,1]². Using ROD (ROuter-based Adaptive activation) neural network with 5 layers, 30 neurons each, and sinusoidal basis functions superimposed on tanh base. After 5000 iterations with L-BFGS, achieves relative error 10^-3 for high-frequency wave patterns. For 1D viscous Burgers with initial sine wave, boundary zeros, 150 measurement points + 8000 residual points: standard tanh network converges to 10^-2 error; adaptive activation reduces error to 10^-4. Inverse problem on compressible flow: inferring gas constant γ from Schlieren data and pressure using only oblique shock measurements; random placement gives γ ≈ 1.2-1.5 vs true 1.4, clustered near shock yields γ = 1.40±0.01 (meV accuracy).

One Level Deeper

PINN loss: L = w_data ||u - u_obs||² + w_res ||r(u)||² where r = ∂u/∂t + N[u] (residual of PDE N), evaluated via automatic differentiation. Adaptive activation: φ_a(z) = β · φ((z + n)/β) where β is learned alongside network weights; θ initialization β=1 ensures standard activation, then β adapts during optimization. RodY network (Rowdy): φ(z) = Σₖ aₖ sin(kπz) superimposed on base function to overcome spectral bias (networks struggle with high-frequency components). For multiscale problems, Fourier neural units φ(z) = sin(ωz) with learned frequencies ω help capture oscillatory solutions. Gauss-Newton or L-BFGS second-order optimization essential for PINNs; gradient descent alone often stalls in local minima.

Failure Boundary

Pure data-fitting mode (no physics residual) requires 200-300 solutions for 2D Navier-Stokes, accuracy ~1% error; adding residual loss reduces needed data to few snapshots but accuracy plateaus at ~10^-2 unless network and training carefully tuned. Spectral bias: networks learn low-frequency modes readily but high-frequency (small-scale) features require exponentially more parameters; Helmholtz with k=25 needs sinusoidal activation, plain tanh fails entirely. Stiff time-dependent problems (advection-diffusion, reaction-diffusion) exhibit solution blow-up during training; memory terms (LSTM) needed for long-time prediction but add complexity. Inverse problems with insufficient data or high noise cause ill-posedness; regularization (weight decay) helps but can bias recovered parameters.

Important Terms

Physics-Informed Machine Learning

Teaching a learning program (one with adjustable dials) by showing it both real-world measurements and the physics laws it must obey, so its answers always respect the science.

Physics-Informed Neural Network

A learning program with millions of adjustable dials, trained to do two things at once: match real measurements, and obey a rule that says how something changes from moment to moment or place to place.

Conservative PINN

A version of the learning program that respects conservation laws—like total energy or total mass staying the same—by training each smaller zone to conserve on its own rather than trying to conserve globally.

Extended PINN

A version that breaks a large or oddly-shaped region into smaller pieces and trains each piece separately, so the learning works better than trying to learn the whole thing at once.

Causal Sweeping

A training strategy where the program learns to predict what happened at earlier times before predicting later times, matching how cause and effect actually work in physics.

  • This talk builds on earlier talks about the promise and failures of the basic method: what it can do, why it breaks, and how to repair it.
  • It connects to earlier talks about conserving energy or mass because both try to solve the problem that standard training methods sometimes fail.
  • It also links to talks about other ways to teach a learning program physics, like operator learning (learning how a rule transforms inputs to outputs) and other mathematical schemes.

Practical Caution

This method can work, but you have to be careful about how you train. If your problem spans a long time or a huge region, training the learning program without splitting it into pieces almost always fails. The program gets confused and can't find an answer that works everywhere. You also need to pick a training strategy that respects what the physics actually does, like training the program to predict time in order (early times first, then later times) instead of random order.

Takeaway

PINNs are not one algorithm—they're a collection of different strategies for teaching a learning program to match both data and physics. Scaling them up to real problems means breaking apart the physics (conservation laws), the space (smaller zones), the time (forward causality), and the learning process (how you nudge the dials) into smaller, simpler pieces that work together.
