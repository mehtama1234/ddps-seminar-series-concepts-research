Talk 77 · Purdue University

Ying Liang: Data-Assisted Algorithms For Inverse Random Source Scattering

This lecture shows how to combine boundary measurements with machine learning to find the statistical properties of random sources in inverse scattering problems, needing far fewer random trials than traditional methods.

YouTube source · Talk page

Core Problem

Inverse source scattering appears in antenna design, medical imaging, earthquake monitoring, and similar work. When the source varies randomly and the surrounding medium is not fully known, standard approaches need many trials and must know the medium's properties in detail to accurately find what the source's statistics are.

First-Principles Model

The physical problem starts with boundary measurements created by wave equations or scattering equations. Integral equations (mathematical statements where unknowns appear within integrals) give a first guess at the source. Machine learning then improves that guess by learning the mapping from these equation-based approximations to the true source statistics. The goal is not to replace physics but to use observed data to cut down the number of trials needed.

Key Claims

  • Inverse random source scattering is an inverse problem with many real-world uses.
  • Standard methods require many trials and need to know the medium's properties in detail.
  • Combining boundary measurement data with machine learning can find the statistical properties of a random source.
  • Machine learning can improve the first approximation from integral equation methods.
  • This method achieved better reconstruction using only one tenth the number of trials that standard approaches need.
  • Among the image translation models tested, pix2pix worked best when inclusions were far apart and their positions were accurately known.

Important Terms

Inverse Source Scattering

Finding the properties of a source by observing the waves it scattered.

Stochastic Inverse Problem

An inverse problem where the source, medium, or measurements involve randomness.

Boundary Measurement

Data collected at the edge of a region, used to figure out what is inside.

Integral Equation

A type of equation where unknowns appear inside integrals; commonly used to solve scattering problems.

Pix2Pix

A machine learning model that learns to translate one type of image to another, used here to map measurement data to source properties.

Connections Across The Series

  • This talk brings together inverse problems, uncertainty in data, and machine learning-aided reconstruction.
  • It shows how the ideas from inverse problems work in a specific scattering example that includes randomness.
  • It also relates to earthquake monitoring and medical imaging, where measurements at a boundary must reveal sources hidden inside.

Practical Caution

Image translation models help only when the data they trained on matches the actual physics and geometry of your inverse problem. Treat these models as data-assisted aids that improve initial results, not as proof that the answer is unique or certain.

Takeaway

The key lesson is that observed data can lower the cost of sampling in inverse problems involving randomness, if that data is anchored to the physics equations.
