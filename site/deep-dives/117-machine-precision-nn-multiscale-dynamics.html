Talk 117 · Stanford University

Ching-Yao Lai: Machine-Precision Neural Networks for Multiscale Dynamics

This whole series is about getting computers to predict physical behavior by learning from examples instead of only hand-written math. One method uses a program with millions of little dials (a neural network) that tunes those dials by trial and error until predictions get better. This talk is about a trick: instead of one giant network learning everything at once, use many smaller networks in sequence, where each one learns to fix the errors the previous one made. The goal is to push those errors down to the tiniest level a computer can measure.

YouTube source · Talk page

Core Problem

Neural networks can match nearly any function given enough dials to tune, but in practice their predictions stop improving at some error level that's still too high for scientific work. Multiscale dynamics (physical situations with important changes at many different speeds and sizes — like a spinning dust devil within a hurricane within a weather system) make this much worse: tiny leftover errors from one stage multiply and grow when you step forward in time across many time steps, ruining the final answer.

First-Principles Model

A sequence of networks attacks the prediction error step by step. The first network captures the main signal. The second network learns what the first one missed: the leftover difference between the first network's answer and the true answer (called the residual). The third network captures what the first two missed combined, and so on. By dividing the job this way, the method keeps shrinking the remaining error in each round—getting closer to the tiniest difference a computer can store in its numbers (called double-precision, about 15-16 significant decimal digits) in a finite number of steps.

Key Claims

  • Scientific problems often need far higher accuracy than standard neural networks give.
  • Simply making networks bigger or training longer does not always break through the error plateau where improvement stops.
  • Training many networks in sequence, each fixing the previous one's mistakes, works better than one giant network.
  • This method works for both pure prediction and for physics-informed networks (networks told the laws of physics as they learn).
  • Prediction errors can shrink down to the smallest floating-point accuracy a computer can represent.
  • This addresses why neural networks have historically failed to reach the precision scientists need for multiscale phenomena.

Important Terms

Machine Precision

The smallest difference a computer can store and measure in its number format; for the standard double-precision format, about 15-16 decimal places.

Residual Learning

Training a new network to predict the leftover error that a previous network did not capture — the difference between the previous network's answer and the true answer.

Multi-Stage Neural Network

A sequence of separate networks, each trained to fix the mistakes made by all the previous networks combined, rather than one network trying to learn everything at once.

Multiscale Dynamics

Physical systems where important behavior happens at many different sizes and speeds simultaneously — a spinning storm within a larger weather system, heat spreading fast locally then slowly overall — and these scales interact with each other.

Double Precision

The standard computer number format that stores floating-point values with about 15-16 significant decimal digits, the level of accuracy scientists usually need.

Connections Across The Series

  • This talk combines numerical accuracy, physics-informed learning (giving networks the laws of physics as hints), error correction, and high-precision scientific computing with machine learning.
  • It complements talks on machine learning for differential equations (rules that say how things change) by asking not just whether networks can predict, but how finely they can do it.
  • It also connects to long-time prediction problems, where small errors from each time step add up to huge mistakes over many steps forward in time.

Practical Caution

Achieving machine precision on test functions the network saw during training does not mean the method will work on real situations it never saw. There is a hard difference: precision (the exactness of the numbers) is separate from generalization (whether the method works on new problems) and separate from whether the answers match what physics actually does.

Takeaway

Prediction error can be attacked step by step: first network captures the main behavior, second network captures the leftovers, third captures what both missed, and so on, each layer driving the error smaller.
