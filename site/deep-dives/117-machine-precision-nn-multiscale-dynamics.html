Talk 117 · Stanford University

Ching-Yao Lai: Machine-Precision Neural Networks for Multiscale Dynamics

This lecture shows how multi-stage neural networks fit prediction errors one layer at a time to push scientific ML accuracy to the limits of what computers can store in numbers.

YouTube source · Talk page

Core Problem

Neural networks can theoretically fit any function, but in practice their predictions stop getting better at some error level above the precision needed for scientific computing. Multiscale dynamics (processes that matter at many different sizes and speeds) make this worse because tiny remaining errors compound across many scales and long time steps.

First-Principles Model

A multi-stage neural network views learning as step-by-step error correction. The first network captures the main signal; the second network captures what the first one missed (the residual, or leftover error); later networks repeat this. By breaking the total error into pieces handled by separate networks, the method drives prediction mistakes close to the smallest possible error for double-floating-point numbers (the precision standard computers use) in a finite number of steps.

Key Claims

  • Scientific problems often need much higher accuracy than standard neural networks normally provide.
  • Simply making networks bigger or training longer does not always break through the error plateau.
  • Multi-stage training teaches each new network to fix the mistakes of the previous one.
  • The method works for both pure curve-fitting and physics-informed neural networks.
  • Prediction errors can get close to the smallest floating-point accuracy a computer can represent.
  • This addresses a long-standing problem: neural networks have struggled to reach the precision scientists need for multiscale phenomena.

Important Terms

Machine Precision

The smallest difference a computer can distinguish in its internal number storage; for double-precision floating-point, about 15-16 decimal places.

Residual Learning

Training a new model to predict the error (the leftover difference) that a previous model did not capture.

Multi-Stage Neural Network

A sequence of separate neural networks, where each one is trained to correct the mistakes made by all the previous ones combined.

Multiscale Dynamics

Physical systems where important changes happen across vastly different spatial or time scales that all interact with each other.

Double Precision

A standard computer number format that stores floating-point values with about 15-16 significant decimal digits.

Connections Across The Series

  • This talk combines ideas from numerical accuracy, physics-informed neural networks, error correction, and high-precision scientific computing with machine learning.
  • It complements talks on machine learning for differential equations by asking not just whether networks can approximate, but how accurately they can do it.
  • It also connects to long-time prediction problems, where even small errors from each step add up to large mistakes over many time steps.

Practical Caution

Achieving machine precision on simple test functions does not mean the method will reliably predict in situations it never saw before. Precision (how exact the numbers are) should be kept separate from generalization (how well it works on new data) and whether the answers are physically correct.

Takeaway

The core insight is that neural approximation error can be attacked step by step: fit the function, then fit the remaining error, then repeat.
