Talk 117 · Stanford University

Ching-Yao Lai: Machine-Precision Neural Networks for Multiscale Dynamics

This lecture presents multi-stage neural networks that fit residuals successively to push scientific ML accuracy toward machine precision.

YouTube source · Talk page

Core Problem

Neural networks are universal approximators in theory, but in practice their prediction errors often plateau above the precision needed for scientific computing. Multiscale dynamics make this worse because small residual errors can matter across scales and long integrations.

First-Principles Model

A multi-stage neural network treats learning as successive residual correction. The first network fits the main signal; the next network fits the residual left behind; later stages repeat the process. By decomposing the error across stages, the method can drive regression and PINN errors close to double-precision machine limits in a finite number of iterations.

Key Claims

  • Scientific problems often require much higher precision than standard neural-network practice delivers.
  • Large network size and longer training do not always push errors below a plateau.
  • Multi-stage training uses new networks to fit residuals from previous stages.
  • The approach applies to both regression problems and physics-informed neural networks.
  • Prediction errors can nearly reach double-floating-point machine precision.
  • The method addresses longstanding accuracy limitations in neural approximation for multiscale dynamics.

Important Terms

Machine Precision

The smallest numerical accuracy scale supported by a floating-point representation.

Residual Learning

Learning the error left by a previous model rather than the full target from scratch.

Multi-Stage Neural Network

A sequence of networks trained stage by stage, with each stage fitting the previous residual.

Multiscale Dynamics

Dynamics involving interacting processes across very different spatial or temporal scales.

Double Precision

A floating-point format with about 15-16 decimal digits of precision.

Connections Across The Series

  • This talk connects numerical accuracy, PINNs, residual correction, and multiscale scientific ML.
  • It complements machine-learning-for-PDE talks by asking not just whether networks approximate, but how accurately.
  • It also links to long-time prediction, where small approximation errors can accumulate.

Practical Caution

Machine-precision training on benchmark functions does not automatically imply robust extrapolation. Precision should be separated from generalization and physical validity.

Takeaway

The first-principles lesson is that neural approximation error can be attacked recursively: fit the function, then fit the residuals that remain.
