Talk 16 · Carnegie Mellon University

Priya Donti: Incorporating Power System Physics Into Deep Learning Via Implicit Layers

This lecture explains implicit layers as a way to put power-system constraints, optimization problems, and control structure inside neural networks.

YouTube source · Talk page

Core Problem

Deep learning models can be accurate statistically while violating the hard physics and operational constraints of an electric grid. Power systems require supply-demand balance, network feasibility, stability, and constraint satisfaction, so predictions are only useful if they integrate with the optimization and control problems that operators must solve.

First-Principles Model

A neural network layer does not have to be an explicit formula. It can be the solution of an implicit problem: an optimization problem, differential equation, equilibrium, or control rule. If that implicit problem is differentiable through its optimality or KKT conditions, the layer can be trained end-to-end while enforcing domain structure.

Key Claims

  • Implicit layers can encode rich functions such as optimization problems, differential equations, and other structured computations.
  • Power-system physics and hard constraints can be incorporated into deep networks rather than handled only after prediction.
  • AC optimal power flow can be embedded by differentiating through a sequence of optimization steps or through KKT conditions.
  • Decision-driven models can optimize for downstream system performance rather than only forecast error.
  • Implicit layers can provide inductive bias by reflecting the physical relationships of the domain.
  • They can also enforce hard constraints and support robust control in physical systems.

Important Terms

Implicit Layer

A neural network layer defined by the solution of an equation, optimization problem, or dynamical system rather than by a direct feedforward formula.

Optimal Power Flow

An optimization problem that chooses power generation and flows while satisfying network and physical constraints.

KKT Conditions

Optimality conditions used to characterize and differentiate constrained optimization solutions.

Decision-Driven Learning

Training a predictive model according to the quality of the downstream decision it enables.

Hard Constraint

A requirement that must be satisfied exactly or provably, not merely encouraged by a soft penalty.

Connections Across The Series

  • This talk broadens physics-informed learning from PDE residuals to optimization layers and operational constraints.
  • It connects to inverse problems and control because the model is trained around the decision or control problem it serves.
  • It also complements differentiable simulation: both make a structured physical computation part of the learning graph.

Practical Caution

A low forecast error is not enough in grid applications. The learned model must be evaluated by whether it produces feasible, stable, and useful decisions under the actual power-system constraints.

Takeaway

The first-principles lesson is that a neural model for infrastructure should include the decision physics, not just predict quantities upstream of it.
