Talk 16 · Carnegie Mellon University

Priya Donti: Incorporating Power System Physics Into Deep Learning Via Implicit Layers

This lecture shows how to build neural networks where internal layers solve optimization problems and satisfy power-system rules, so the network itself enforces what a real power grid must do.

YouTube source · Talk page

Core Problem

Deep learning models can predict numbers accurately but still violate hard rules that power grids must follow. Electricity grids require supply and demand to match, power lines to handle their loads, equipment to stay stable, and physical limits to be respected. So a prediction only matters if it fits into the optimization and control problems that grid operators actually solve.

First-Principles Model

A neural network layer does not have to be a direct computation. Instead, it can be defined as the answer to a hidden problem: an optimization task, a differential equation (one that describes how things change over time), an equilibrium point (a balanced state), or a control rule. If that hidden problem can be differentiated through its optimal answer or its KKT conditions (mathematical rules that define when a solution is best), the entire network can learn end-to-end while keeping the domain structure intact.

Key Claims

  • Implicit layers can encode rich computations such as optimization problems, differential equations, and other structured tasks.
  • Power-system physics and hard rules can be built into deep networks rather than handled only as a step after prediction.
  • AC optimal power flow can be embedded inside a network by differentiating through a sequence of optimization steps or through KKT conditions.
  • Models trained around downstream system outcomes can optimize for what actually matters to operators, not just prediction error.
  • Implicit layers provide prior structure by reflecting the physical relationships of the domain.
  • They also enforce hard requirements and support stable control in physical systems.

Important Terms

Implicit Layer

A part of a neural network defined by solving an equation, optimization problem, or system of rules for change, rather than by direct computation.

Optimal Power Flow

An optimization problem that chooses how much power to generate and how it flows through lines while satisfying all physical and network limits.

KKT Conditions

Mathematical rules that state when a solution to a constrained optimization problem is best, and how to compute gradients through that solution.

Decision-Driven Learning

Training a prediction model by measuring how good the decision is that results from its predictions, not just the prediction error alone.

Hard Constraint

A requirement that must be satisfied exactly or provably, not just encouraged by a penalty added to the loss.

Connections Across The Series

  • This talk extends physics-informed learning beyond PDE (partial differential equation) residuals to optimization layers and operational constraints that must be met in real time.
  • It connects to inverse problems and control because the model is trained around the decision or control problem it serves, not around prediction alone.
  • It also complements differentiable simulation: both make a structured physical computation part of the learning graph.

Practical Caution

Low prediction error is not sufficient for grids. The learned model must be tested by whether it produces decisions that are feasible (possible to carry out), stable (safe to operate), and useful under the actual physical rules and constraints of the power system.

Takeaway

The core lesson is that a neural model for real infrastructure should include the decision physics—what the system must do—not just predict numbers that sit upstream of the actual problem.
