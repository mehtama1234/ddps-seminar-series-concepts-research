Talk 61 · Pacific Northwest National Laboratory

Jan Drgona: Differentiable Programming For Modeling And Control Of Dynamical Systems

This lecture combines model predictive control, differentiable physics models, scientific machine learning, and offline policy optimization into a single method for building and training control systems.

YouTube source · Talk page

Core Problem

Classical model predictive control can enforce constraints and physical laws but runs slowly on devices with limited compute. Reinforcement learning can train control policies but needs huge amounts of data and often struggles with hard constraints. Energy and industrial systems need control methods that work fast, learn from small amounts of data, respect physical and safety constraints, and run on embedded hardware.

First-Principles Model

Differentiable predictive control treats the control law (the rule for choosing actions) as a trainable computation built from differentiable physics models and constraint equations. It keeps the classical MPC idea: simulate future states, choose actions that minimize cost, enforce constraints. The difference is that it pre-computes the policy offline using differentiable programming, so real-time execution just runs the learned policy instead of solving an optimization problem during operation.

Key Claims

  • Differentiable programming gives a useful way to think about optimal control of systems that change over time.
  • Differentiable predictive control merges classical MPC with scientific machine learning methods.
  • The method uses custom differentiable physics models to train control policies before deployment.
  • Nonlinear constraints can be included directly during policy training.
  • Case studies show results in building temperature control and electrical grid scheduling.
  • Embedded demonstrations show the method can run fast and efficiently for control deployed as a service.

Important Terms

Differentiable Predictive Control

A method for training control policies where the controller learns using differentiable (smoothly-varying) models of how the system behaves and differentiable representations of constraints.

Model Predictive Control

A strategy where the control system repeatedly predicts future behavior over a short time window, finds the best actions under that prediction, and applies them.

Offline Policy Optimization

Training a control strategy in advance (using models or simulations) so it can run fast without solving new optimization problems during operation.

Nonlinear Constraint

A limit or rule (such as 'power output cannot exceed this value') expressed using curved or bent mathematical functions.

Control As A Service

A way to package and deploy control algorithms so they can be reused across multiple systems or embedded into other applications.

Connections Across The Series

  • This lecture connects differentiable programming directly to control, fitting within the DDPS seminar's focus on differentiable methods.
  • It complements reinforcement learning and flow-control talks by showing how to combine learned models with classical optimization principles.
  • It also relates to digital twins because real-world control systems need fast, accurate models tied to the physical systems they operate.

Practical Caution

Policies trained offline can fail if the physics model is inaccurate or constraints are implemented only as soft penalties instead of hard limits. Real deployment needs testing against unexpected conditions and built-in safety fallbacks.

Takeaway

The core insight is that differentiability makes control design a trainable problem, but the controller is only as reliable as the physics model underneath it, how strictly constraints are enforced, and the care taken during deployment.
