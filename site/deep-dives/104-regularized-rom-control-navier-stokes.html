Talk 104 · Universita Cattolica del Sacro Cuore

Francesco Ballarin: Regularized Reduced Order Models for Control of Navier-Stokes Equations

This whole series asks: can computers learn to predict how physical things behave instead of solving hand-written math rules? This talk tackles one piece: when you shrink a simulator to run fast (keeping only the biggest patterns), it can become wobbly and wrong. Adding smoothing to the shrunken model stops the wobble and makes it safe to steer with automatic feedback.

YouTube source · Talk page

Core Problem

Engineers use rules (called differential equations) to describe how fluids move and change. Simulating those rules on a computer grid, even a coarse one, can produce false jittering and noise. When you shrink the simulation down to just a handful of key patterns—called a reduced-order model, or ROM—to make it run fast, you throw away tons of detail, and the jittering gets worse. Now add steering: the shrunken model must both predict the flow accurately AND let you control it (e.g., turn a valve to change the flow direction). That's harder than just predicting with no control.

First-Principles Model

In a full-size simulation, engineers add filters to kill the jittering. A ROM works by keeping only a few main patterns and throwing the rest away. This compression can remove the natural smoothing that keeps the full simulation stable, making the shrunken equations blow up and wiggle badly. This talk compares two fixes. First: evolve-filter-relax. You run one time step forward, then use a filter to strip out the junk high-frequency wiggles, then gently pull the result back toward the zone where the system naturally stays calm (this zone is called the stable manifold—think of it as a valley the system wants to roll into). Second: approximate deconvolution. You filter out the junk, then guess what information you lost and try to add it back. Both fixes get plugged into feedback control: you measure where the flow actually is right now, then use that measurement to decide what steering command to send next.

Key Claims

  • Smoothing is standard in real fluid simulators, but almost nobody studies how to smooth the shrunken-down versions.
  • When flow gets carried along much faster than it spreads out (especially on a coarse grid), the system is fragile and can break if you miss the small-scale details.
  • A shrunken model for steering must stay accurate when you're feeding back real measurements, not just when you run it open-loop with no feedback.
  • Evolve-filter-relax smoothing can be used inside a shrunken-model steering controller.
  • Approximate-deconvolution smoothing is another way to recover the effects of patterns that got filtered out.
  • A good shrunken model balances speed, stability, and steering accuracy.

Important Terms

Navier-Stokes Equations

The rules that describe how liquids and gases move, accounting for what pushes them and how they resist flowing.

Convection-Dominated Flow

A flow where the fluid gets shoved along faster than it spreads out sideways, making sharp edges and making predictions blow up on coarse grids.

Evolve-Filter-Relax ROM

A shrunken model that takes one step forward in time, strips out the high-frequency junk with a filter, then nudges the result back to where the system behaves smoothly.

Approximate Deconvolution

A guess-and-restore trick: after you filter something, you try to guess what got lost and add a correction to get closer to the truth.

Feedback Control

You measure the current state, then use that number to decide what command to send, so the system steers toward your goal.

Connections Across The Series

  • This lecture weaves together shrunken models, flow steering, numerical smoothing, and closure methods (ways to handle the patterns you threw away).
  • It fills a gap next to earlier talks about inferring operators and building shrunken models by asking: what goes wrong when tiny patterns destabilize a shrunken-model controller?
  • It also relates to digital twins: if you want a fast stand-in of a steering system to run in real time, that stand-in must stay stable when you're actively steering it.

Practical Caution

Smoothing stops the wobble but can lie to you about what the flow is actually doing. For steering, the smoothing must protect the flow patterns you actually need to control, not just hide all the noise.

Takeaway

Shrunken simulators used for steering need their own custom smoothing, built for the shrunken equations—you can't just copy the smoothing rules from the full-size simulator.
