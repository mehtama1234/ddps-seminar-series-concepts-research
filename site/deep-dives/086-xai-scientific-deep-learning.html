Talk 86 · University of Utah

Amir Arzani: A Flexible And Generalizable XAI Framework For Scientific Deep Learning

This lecture presents an interpretable XAI method for scientific deep learning that probes trained networks, fits sparse integral-equation models, and improves how well models work on new data outside their training set.

YouTube source · Talk page

Core Problem

Scientific deep learning often lacks interpretability and fails when given inputs unlike those in the training data, because training data rarely cover the full range of features the model might encounter. Models that predict well on familiar data often give little explanation or guidance on how to extrapolate to new conditions.

First-Principles Model

The method treats a trained neural network as a source of learned local patterns. First, probe the network within the feature space it saw during training. Then fit an interpretable substitute model from a library of integral equations (equations that sum up effects using kernels and nonlinearities), using sparse regression to select a small, compact model. This interpretable model can be used when building a system or after training to explain what a network learned, and works like a simpler, more understandable version of operator learning (mapping inputs to outputs using learned rules).

Key Claims

  • Interpretability and generalization are central challenges in scientific deep learning.
  • Out-of-distribution inference errors grow because physics-based learning tasks often cannot generate exhaustive datasets.
  • The proposed XAI method can be used at design time or after training with trained networks.
  • The method probes a trained neural network within the input space it saw during training.
  • A sparse library of integral equations is fitted to produce an interpretable model.
  • The approach relates to neural operators but trades some prediction power for analytical interpretability.

Important Terms

Explainable AI

Methods that make model predictions understandable to humans so we can see why the model makes its choices.

Out-Of-Distribution Inference

Prediction on inputs that fall outside the range of the data the model trained on.

Post-Hoc Explanation

An explanation method applied after a trained model has already been built to show what it learned.

Integral Equation Library

A collection of candidate integral-equation forms used to build interpretable rules that map inputs to outputs.

Sparse Regression

A regression method that picks out only the most important terms from a large list of possible predictors.

Connections Across The Series

  • This lecture connects explainability with neural operators, Green's functions (solutions to differential equations that show how effects spread), and sparse regression methods that pick important terms.
  • It complements Miles Cranmer's scientific-debt talk by offering a path to write down equations that match what a network learned.
  • It also links to out-of-distribution reliability, a recurring issue in surrogate models and digital twins (virtual copies of real systems).

Practical Caution

An interpretable substitute explains what the probed network learned, not necessarily the true physical system itself. The explanation should be tested against real physical measurements and physical rules that must hold true.

Takeaway

The first-principles lesson is that scientific explanation can be learned as a sparse operator approximation of a trained network, but it must still be tested against actual physics.
