Talk 98 · Dartmouth College

Dimitrios Giannakis: Quantum Information and Data Science for Modeling Classical Dynamics

This whole series is about getting computers to predict how physical systems behave by learning from data instead of only hand-written rules. one useful set of tools comes from operator theory: ways to turn nonlinear motion into linear equations by tracking what we observe and how likely each state is. This talk asks: when we borrow ideas from quantum mechanics—where the order you multiply things matters—what new ways can we organize classical dynamics (motion governed by Newton's laws, fluid flow, heat spread) to make computation faster and more reliable?

YouTube source · Talk page

Core Problem

Koopman and transfer operators can turn nonlinear motion into linear equations by switching to different 'lenses.' A Koopman operator sees the system through the quantities you measure (called observables), while a transfer operator sees it through the probability density—how likely each state is. In classical mechanics, the order you multiply things never matters: A times B equals B times A. But the talk asks: what if we use quantum mechanics ideas, where order DOES matter? Do we gain new tools or clearer pictures of classical systems by allowing this mismatch?

First-Principles Model

A dynamical system (anything that changes over time: a swinging pendulum, a fluid, a star) evolves its states, and we can also track how what we measure changes and how the odds of each outcome shift. The Koopman operator describes how your observations transform as the system steps forward; the transfer operator describes how the probability density spreads and shifts. The talk rewrites both using multiplication operators and density operators—concepts from quantum mechanics—which means data fitting and model closure (filling in missing physics at small scales) can speak the same mathematical language. This unification lets us design computations that keep probability densities positive (as they must be in reality) and construct operators straight from measured data using kernel methods (a way to compare data points and build patterns without first naming what patterns to look for).

Key Claims

  • Koopman and transfer operators let you use linear-equation techniques on nonlinear systems.
  • Quantum mechanics ideas provide a way to generalize how you represent what you observe and probability densities when multiplication order matters.
  • Probability densities can be written as density operators—mathematical objects from quantum mechanics adapted to describe classical distributions.
  • Fitting data and closing gaps in physics models fit into the same operator-based language.
  • Keeping densities nonnegative is essential because probability and physical states must stay nonnegative.
  • Kernel methods build the required operators directly from measured data without assuming a fixed form.

Worked Example

For El Niño prediction, the Koopman operator was embedded in a quantum formalism: sea surface temperature observations of the Indo-Pacific Ocean were mapped to the Niño 3.4 index. Over a 20-year test window with lead times from 0 to about 500 days, quantum expectation values tracked the true index evolution, with forecast uncertainty (a probability density encoded in the spectral measure) growing as lead time increased.

A harmonic oscillator was run on an actual 3-qubit IBM quantum computer, where 3 qubits represent a 2^3 = 8-dimensional space. Simulated circuits showed reasonable fidelity, but real hardware noise prevented meaningful results beyond about 1 qubit. For quasi-periodic toroidal dynamics, an efficient circuit with depth quadratic in the number of qubits simulates an exponentially large observable space.

One Level Deeper

The Koopman operator K acts on observables by composition with the flow: (K f)(x) = f(Φ_t(x)), where Φ_t is the time-t flow map. Its adjoint, the transfer (Perron-Frobenius) operator, acts on probability measures. The embedding maps a classical probability density ν into a quantum density operator ρ = |√ν⟩⟨√ν|, so evolution of measures under the transfer operator becomes conjugation by a unitary: ρ_t = U_t ρ_0 U_t^†.

The infinite-dimensional Hilbert space is projected onto a 2^n-dimensional subspace for n qubits. For pure-point-spectrum (quasi-periodic) systems, the Koopman generator decomposes into a sum of commuting single-qubit Z rotations, H = Σ_i λ_i (I ⊗ ... ⊗ Z_i ⊗ ... ⊗ I), giving an efficient circuit. To read out a prediction, apply a quantum Fourier transform then measure in the computational basis, decoding the classical observable.

Failure Boundary

The quantum-algorithm speedup is limited to pure-point-spectrum systems (integrable, quasi-periodic); generic chaotic dynamics do not factorize into commuting single-qubit generators, so the efficient circuit construction breaks. Quantum hardware noise dominates beyond about 3 qubits (decoherence and gate errors), so simulations look promising while real experiments fail past ~1 qubit.

The Hilbert-space dimension 2^n grows exponentially in qubits, but the observable space is also exponential, so a practical advantage requires carefully structured problems. Asymptotic consistency (projection error going to zero as n grows) is theoretically clean but slow in practice. The positivity-preservation benefit only helps if the competing classical scheme uses orthogonal projections; it is not a unique advantage over already-stable numerical schemes.

Important Terms

Koopman Operator

A linear transformation that evolves what you measure (called observables) as a nonlinear system steps forward in time.

Transfer Operator

A linear transformation that evolves how likely each state is (probability density) as the system steps forward.

Density Operator

A mathematical object that represents the odds of different states; borrowed from quantum mechanics and used here to describe ordinary probability distributions.

Non-Commutative Algebra

A set of multiplication rules where order matters: A times B can give a different answer than B times A.

Positivity-Preserving Approximation

A numerical method that keeps probability values and state representations nonnegative so they remain physically valid.

Connections Across The Series

  • This lecture extends operator-based methods across Koopman analysis, model closure in fluid and climate simulations, and learning from data.
  • It connects physics-informed machine learning with information geometry and quantum-inspired tools from linear algebra.
  • It also links to weather and climate modeling through data assimilation and subgrid-scale closure—how to guess what happens at scales too small to measure.

Practical Caution

Calling classical systems 'quantum-inspired' is a mathematical choice, not a claim that the system acts like a quantum one. The real payoff is whether this representation preserves the math we need and makes solving the equations faster or more stable in practice.

Takeaway

Switching how you represent what you measure and how likely states are can make nonlinear motion look more organized and easier to solve with linear-equation tools.
