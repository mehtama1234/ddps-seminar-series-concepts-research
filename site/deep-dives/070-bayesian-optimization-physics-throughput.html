Talk 70 · University of Wisconsin-Madison / Argonne National Laboratory

Victor Zavala: Bayesian Optimization With ML Models, Physics, And High-Throughput Experiments

This series chases one goal: getting computers to predict physical behavior by learning from data instead of only using hand-written math. When you can run experiments but they cost time or money, one approach is to use a smart search method called Bayesian optimization. This talk shows how to combine three things: a starting physics model that captures basic behavior, a learned model that fixes what the physics model gets wrong, and the ability to run many experiments at once.

YouTube source · Talk page

Core Problem

Bayesian optimization is a way to search smartly when each experiment or simulation takes effort or money. You start with a fast substitute model (called a surrogate: a quick guess-maker trained on past experiments) and you track how sure you are about its guesses. Standard versions struggle when your model is huge, when you have physics knowledge sitting around unused, or when you have the ability to run many experiments in parallel at the same time. The real puzzle is how to use physics and parallelism together while still having your search guided by your uncertainty—how confident your surrogate is in each prediction.

First-Principles Model

Bayesian optimization picks the next experiment by scoring all possible choices with a formula called an acquisition function. This formula uses a surrogate (fast substitute model) and uncertainty estimates to score what you'll learn. If you have a physics model (a rough first guess built from known scientific laws), you can split what happens into two parts: what the physics model predicts plus the gap left over (called the residual—the leftover bits the physics model misses). Train a Gaussian process (a statistical tool that assigns likelihoods to different possible models, so you get both a guess and a confidence level) on just the residual part. This focuses your limited experiments on catching exactly what physics gets wrong. The physics model also lets you carve up the design space so parallel experiments don't repeat effort, and it helps build acquisition formulas that work on large models.

Key Claims

  • Bayesian optimization can combine large-scale learned models, physics knowledge, and batches of experiments all at once.
  • You can split what happens into two pieces: a physics-based starting model plus a learned model that captures what's missing.
  • Training a statistical model on just the missing parts speeds up your search.
  • A physics-based starting model can divide the design space so parallel experiments don't duplicate effort.
  • Running many experiments at once requires Bayesian optimization methods that score groups of choices, not one at a time.
  • Acquisition formulas can extend Bayesian optimization to large models by using simple counts of uncertainty instead of exact calculations.

Worked Example

For HVAC plant controller tuning, model predictive control depends on horizon parameter and constraint tuning. A single 1-year simulation runs 3 hours, making brute-force search infeasible. Using Bayesian optimization with low-fidelity reference model (simplified physics), the algorithm identified optimal control parameters within the flat region of cost landscape (millions of dollars/year range) in ~20 experiments, versus 60+ required by standard BO without reference model.

For microbial community optimization, recurrent neural networks trained on limited high-throughput experiments achieve only neighborhood-level accuracy (not globally accurate), yet enable parametric BO to find improved bacterial species compositions. Even with inaccurate predictions, the closed-loop framework converges to better concentrations and community configurations that standard random experimental design cannot achieve.

One Level Deeper

Bayesian optimization decomposes performance f(x) = g(x; reference physics) + r(x; residual learned from data). The Fisher Information Matrix H = Σ J_i^T J_i (where J_i = ∂f/∂θ|_{θ_opt}) captures parameter sensitivity; acquisition function maximizes μ(x) + λσ(x) to balance exploitation (expected performance) vs. exploration (uncertainty reduction). Parametric models use Laplace approximation: σ^2(x) = (J^T H^{-1} J) ∝ posterior variance at x. Non-parametric Gaussian Process models with kernel k(x,x') and hyperparameter Θ: mean prediction m(x), variance v(x) from covariance structure.

High-throughput partitioning via level sets: decompose design space into regions where reference model predicts high/low performance. Run parallel BO agents in each partition with shared central model for global optimization. Recurrent neural nets for dynamics: y_t = RNN(x_t, h_{t-1}; W,b) where hidden state h_t encodes system memory; loss minimizes ||y_pred - y_data||_2 over trajectories, not pointwise errors.

Failure Boundary

Gaussian Process models scale poorly with number of observations (O(N^3) complexity for covariance matrix inversion). Fisher Information approach requires computing second derivatives and inverting large Hessians—prohibitive for deep neural networks. Non-parametric BO is inherently sequential (one experiment per cycle), making high-throughput parallelization difficult; standard acquisition functions cannot easily propose multiple candidate experiments simultaneously.

Parametric BO with neural networks is sensitive to model architecture and training; inaccurate models can drive search into wrong regions if acquisition function doesn't adequately explore. Neighborhood-level accuracy suffices locally but fails globally—recurrent neural nets trained on microbial communities exhibit poor long-term trajectory prediction, so the method only works in closed-loop iterative cycles. Reference models with incorrect physics can mislead partitioning, causing BO to ignore promising regions. Noise in input data (not output) is difficult to handle; no straightforward way to incorporate input uncertainty into gaussian process framework.

Important Terms

Bayesian Optimization

A search method that builds a statistical model of past results to make quick guesses about which experiments will teach you the most, then runs those experiments rather than trying everything.

Reference Model

A starting model, often built from physics or known science, that captures the overall pattern of how outcomes change as you vary inputs.

Residual Model

A learned model that captures the errors or corrections the reference model misses—the leftover gap between what physics predicts and what really happens.

Gaussian Process

A statistical tool that builds a model by assigning probabilities to different possible patterns, letting you estimate what will happen and how confident you should be in that estimate.

Acquisition Function

A scoring formula that decides which experiment or simulation to run next by balancing what looks like it will work well against how much you still need to learn about that region.

Practical Caution

A weak or wrong physics model can steer your search down the wrong path. When using Bayesian optimization with physics built in, pay close attention to how well-behaved the residual is and how honest your confidence estimates are, rather than trusting the physics model everywhere.

Takeaway

The core idea is that Bayesian optimization is smart experimentation when you have uncertainty. Physics works best when it points your search in the right direction while still letting you learn where it falls short.
