Talk 18 · Brown University

George Karniadakis: Approximating Functions, Functionals, And Operators Using Deep Neural Networks

This lecture connects PINNs and DeepONets by showing how neural networks can approximate not only functions, but functionals and operators that map functions to functions.

YouTube source · Talk page

Core Problem

Many physical systems are not one fixed input-output map between finite vectors. They are families of PDE solves, inverse problems, or system responses where the input may itself be a function, such as an initial condition, forcing, geometry, coefficient field, or sensor history. Standard neural networks can approximate functions, but simulation requires learning solution operators and doing so with limited data.

First-Principles Model

A function maps points to values. A functional maps a function to a scalar. An operator maps a function to another function. DeepONet represents an operator by combining a branch network that encodes the input function, often through sensors, with a trunk network that encodes the output location. Physics-informed losses and conservation laws can regularize these models when data are sparse or noisy.

Key Claims

  • Scientific ML often needs to learn from small data by using physics as priors or regularization.
  • PINNs are especially powerful for inverse problems because measurements help guide the optimization.
  • Operator learning is broader than learning a single solution; it approximates mappings between function spaces.
  • DeepONet uses branch and trunk networks to learn operators with continuous inputs and outputs.
  • The representation of the input function through sensors or basis choices matters.
  • Neural operator ideas can support digital-twin-like models of large physical systems.

Important Terms

Functional

A map whose input is a function and whose output is usually a scalar.

Operator

A map from one function to another function, such as a PDE solution map.

DeepONet

A neural operator architecture with a branch network for the input function and a trunk network for output coordinates.

Sensor Representation

A finite set of sampled values used to represent an input function for training or inference.

Physics-Informed Regularization

Using governing equations or conservation laws to constrain a learned model when data are limited.

Connections Across The Series

  • This is the main operator-learning anchor for the early DDPS sequence and extends the PINN lectures from solving one PDE to learning a whole solution map.
  • It connects to graph simulation and ROM-net because all three ask how to represent physical states and maps compactly.
  • It also connects to hybrid twins because an operator model can serve as a fast learned component inside a larger twin.

Practical Caution

Operator learning still depends on the distribution of input functions and how they are represented. A DeepONet trained on one function family may not generalize to very different forcings, geometries, or sensor layouts.

Takeaway

The first-principles lesson is that scientific ML often needs to learn maps between spaces of functions, not just labels. Neural operators are built for that level of abstraction.
