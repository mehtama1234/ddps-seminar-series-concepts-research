Talk 129 · Johannes Kepler University

Johannes Brandstetter: The Next Wave of Scientific Breakthroughs Is in the Latent Space

This whole series is about getting computers to predict how physical things behave by learning from examples instead of writing all the math by hand. This talk explores where breakthroughs might come from next: by finding simpler, learned ways to write down the state of complicated systems—what scientists call latent spaces (think of it like learning to describe a storm with a handful of key numbers instead of millions of details)—that capture the right physics and make the hard problems easier to solve.

YouTube source · Talk page

Core Problem

Methods that work well for text have shown that learning from huge amounts of data can be powerful. But science and engineering deal with physical things that have rules: how heat flows, how stress builds in materials, how fluids move. These systems have specific structures you can't ignore—different types of quantities to track, shapes and geometry that matter, effects that stretch across long distances and times. The core question is: what is the next useful way to represent and work with information when building learning programs for the sciences?

First-Principles Model

A latent space is a simpler version of a physical situation that a learning program discovers and builds. Instead of keeping track of a million details, the program learns to describe a system with a smaller set of learned numbers. These numbers capture what actually matters for prediction and understanding. The talk draws together recent wins in weather forecasting, image understanding, learning physics rules from data, neural operators (learning programs that take in one type of data and output another type, like predicting velocity fields from pressure), systems with many interacting physics (like a material that heats up and changes shape and strength all at once), the motion of atoms, how liquids and gases flow, and energy from nuclear reactions. The claim is this: the next scientific breakthroughs will come from latent spaces that encode the right quantities and how they interact.

Key Claims

  • The methods that work at scale for language can and must be adapted so they work for science and engineering.
  • Predicting weather and modeling climate have recently shown real wins using learning programs.
  • Good latent spaces connect ideas from understanding images, learning physics rules from data, and neural operators.
  • The next frontiers are systems where many physical processes happen together (heat plus shape-change), atom motion, fluid flow, and fusion energy.
  • A learned latent space can help you build models, create new designs, and discover scientific truths.
  • The real test is whether the latent space actually holds the physical structure that matters for your problem.

Worked Example

A large ensemble of molecular dynamics (MD) simulations generates 10,000 snapshots of protein conformations (3000 atoms each, 9000 coordinates). Classical PCA reduces to 10 principal components capturing 90% variance. Variational autoencoder (VAE) learns 4D latent space where: 1 dimension tracks protein folding progression (unfolded→folded), 2 dimensions capture side-chain rotamer states, 1 noisy. VAE reconstruction error ~0.02 Å RMSE. In latent space, physics-informed interpolation: sample latent code z_interp = t·z_unfolded + (1-t)·z_folded, decode to structure—generates realistic intermediate conformations not in training set. This reveals hidden folding pathway.

Climate data: 300 TB of global climate simulations (temperature, humidity, pressure fields). Supervised VAE learns 12D latent representation where 3 dims encode ENSO phase, 3 encode Atlantic oscillation, 6 encode noise/variability. Practitioners can navigate latent space to construct synthetic climates consistent with observations—explore 'what-if' scenarios faster than rerunning full models.

One Level Deeper

Autoencoder: encoder E(x) projects high-dimensional data x ∈ ℝ^9000 to latent code z ∈ ℝ^d; decoder D(z) reconstructs x̂. VAE adds probabilistic structure: E outputs (μ, Σ), samples z ~ N(μ, Σ), minimizes reconstruction loss + KL divergence penalty on p(z). This forces latent space to be continuous (any z decodable to sensible structure) and factorized (dimensions are independent). Physics-informed: augment loss with PDE residual or constraint satisfaction in latent space (e.g., decoded structure must satisfy covalent bond lengths). Manifold assumption: true dimensionality of scientific datasets is much lower than ambient dimension (e.g., protein conformation space ~100D, not 9000D). Latent space becomes arena for downstream tasks: interpolation, classification, anomaly detection via distances in z.

Failure Boundary

VAE collapse: network learns identity mapping (ignores latent code z), uses only decoder capacity. Requires careful tuning of β·KL coefficient. Posterior collapse: variance learned is near-zero, latent code unused. Dimension choice unclear: how many latent dimensions? Too few loses information; too many reintroduces curse of dimensionality. Reconstruction fidelity gap: ~0.02 Å RMSE acceptable for qualitative dynamics, but insufficient for chemical property prediction (pKa requires <0.01 Å accuracy in proton position). Interpolation pathways may violate physics: decoded intermediate structures may have broken bonds or steric clashes even if endpoints are valid. Training data bias: if training set lacks rare events (protein misfolding, extreme climate), latent space will not represent them—manifold is only as good as data. Transfer learning failure: VAE trained on one protein sequence does not generalize to another (latent code meaning is sequence-specific). Computational cost: training large VAE (10,000 images) on GPUs requires careful batching; inference still slow if decoder is expensive neural network.

Important Terms

Latent Space

A learned, compressed description of a system where a learning program discovers which details matter and which can be left out, usually much simpler than listing everything directly.

Scientific Foundation Model

A learning program trained on a wide range of scientific data so it can handle many different kinds of science tasks or problems without starting from scratch.

Multi-Physics Modeling

Building a model or simulator where many physical laws happen at once and influence each other—for example, heating that also causes materials to bend and weaken.

Neural Operator

A learning program that takes one kind of data (like pressure at every point in space) and outputs another kind (like velocity at every point), learning the relationship by examples instead of solving equations.

Computational Fluid Dynamics

Using a computer to solve equations and predict how liquids or gases flow, including their speed, pressure, and how they swirl and interact with objects.

  • It builds on earlier talks about autoencoders (learning to compress data), neural operators (learning mappings between different kinds of data), and materials models trained on wide datasets—all about finding the right learned representation.

Practical Caution

A latent space compresses information but can hide the 'why'—what actually causes what to happen. For science, you need to check three things: Does the compressed version actually predict correctly on new, unseen situations? Can you use it to steer the system toward a goal? Does it help you find new understanding or laws you didn't know before? If it fails any of these, it is a clever data summary but not a scientific tool.

Takeaway

Scientific machine learning advances when you find the right way to represent the problem—the representation where the physics becomes simpler and clearer.
