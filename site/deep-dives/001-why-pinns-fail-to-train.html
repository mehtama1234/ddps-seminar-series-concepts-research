Talk 1 · University of Pennsylvania

Paris Perdikaris: When And Why PINNs Fail To Train

This lecture explains that physics-informed neural networks fail not because adding physics to training is wrong, but because the resulting math problem for the optimizer can become stiff, spectrally biased, and badly balanced—where one loss term overpowers others.

YouTube source · Talk page

Core Problem

PINNs turn a PDE problem into a composite neural-network training problem: fit data, boundary conditions, initial conditions, and PDE residuals at the same time. That sounds elegant, but the optimizer may not send each constraint enough gradient signal—the mathematical direction and strength telling the network which way to update. High-frequency components, multiple scales, and boundaries especially suffer because the gradients pointing toward satisfying each constraint can be weak or cancel out.

First-Principles Model

A PINN represents the unknown field with a differentiable neural network—one whose output can be taken apart mathematically to compute derivatives. Automatic differentiation evaluates these derivatives, the PDE residual becomes a loss term to minimize, and gradient descent updates the network. The real object being solved is therefore not just the PDE; it is a constrained optimization dynamics—a system where changes to the network weights chase down multiple simultaneous goals. If that dynamics is stiff (requiring tiny steps) or biased (favoring certain frequencies), the PDE can be simple while training still fails.

Key Claims

  • Physics can be inserted through network design choices (architecture-level inductive bias) or through loss terms (loss-level regularization); PINNs mostly use the second route.
  • PINNs are unusual regularizers because they penalize the function output and its derivatives, not just the network weights themselves.
  • Even simple linear elliptic problems can fail if the training dynamics cannot satisfy boundary conditions or high-frequency structure.
  • PINN gradient flow can become stiff, forcing impractically small learning rates if trained without special techniques.
  • Different loss terms can produce imbalanced gradients, so one constraint can dominate while another receives almost no update.
  • Neural tangent kernel analysis helps diagnose spectral bias: low-frequency components are learned faster than high-frequency components.

Important Terms

Physics-Informed Neural Network

A neural network trained to represent a solution to a differential equation while also penalizing violations of that equation and its boundary or initial conditions.

Composite Loss

A training goal made from several terms added together, such as data mismatch, boundary loss, initial-condition loss, and PDE residual loss.

Gradient Flow Stiffness

A training problem where the continuous-time optimization system contains widely separated time scales, forcing stable gradient descent to take tiny steps.

Gradient Imbalance

A failure where different loss terms produce very different gradient sizes, so some constraints are effectively ignored while others move the network.

Spectral Bias

The tendency of standard neural networks trained by gradient descent to learn smooth, low-frequency patterns before sharp, high-frequency patterns.

Connections Across The Series

  • This is the natural starting point for the playlist because it separates the PINN idea from whether PINNs can actually train well.
  • It connects to later talks on weak forms, adaptive weighting, operator learning, and architectures that preserve physical structure.
  • It builds a diagnostic habit: do not ask only whether the physics loss is correct; ask whether the optimizer can actually use it to improve the network.

Practical Caution

Do not treat a small PDE residual loss as proof that the learned field is physically reliable. The loss weights, collocation points (where the PDE is checked), network architecture, optimizer choice, and the frequencies present in the true solution can all change whether the method is actually solving the intended problem.

Takeaway

The first-principles lesson is that PINNs are optimization systems, not magic PDE solvers. Their success depends on whether the training dynamics can send the right physical constraints into the right parts of the network function.
