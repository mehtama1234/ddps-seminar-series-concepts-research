Talk 46 · Texas A&M University

Ming Zhong: Machine Learning Of Self Organization From Observation

This whole series is about getting computers to predict how physical things behave by learning from examples instead of hand-written math. In many systems—schools of fish, flocking birds, crystal growth, traffic flow—large patterns emerge from simple local interactions between neighbors, but we don't know exactly what those neighbor-to-neighbor rules are. This talk is about teaching a computer to reverse-engineer those hidden interaction rules just by watching the motion trajectories.

YouTube source · Talk page

Core Problem

Self-organization happens in systems such as flocking, crowds, crystals, superconductivity, and social behavior. The large-scale pattern emerges and is visible, but the microscopic interaction rule among individual agents—what each agent actually does based on its neighbors—is hidden. The challenge is to work backward: look at the observed motion, and figure out what local rules must have generated it. This is harder than just predicting motion forward, because many different rules could produce the same observed pattern.

First-Principles Model

A collective system is built from individual agents whose speeds or accelerations depend on distances to neighbors, what state each agent is in, and what type each agent is. These relationships are described by interaction kernels—functions that capture how one agent influences another (like: a fish copies its neighbors' direction more when they are close, less when they are far). Given trajectory data (records of where each agent moved over time) from many different starting setups, the learning problem is to estimate those kernels so that when you run a simulation using them, it reproduces what you actually observed. Theory studies how good the estimated kernels become as you collect trajectories from more and more different starting conditions.

Key Claims

  • Self-organization can be studied by watching how individual agents move and interact.
  • The goal is to discover clear, interpretable rules about how agents interact, not just predict future motion without knowing why.
  • Learning the interaction rules can test whether existing theories about collective behavior are correct.
  • How well you can recover the rules depends on having trajectories from many different starting conditions and on how you discretize—break up the trajectory data into measurable pieces.
  • The method works for systems where all agents follow the same rules and also for mixed systems like predators and prey that follow different rules.
  • Even when you only observe steady-state behavior (where nothing seems to be changing), there is information hidden in those observations about the interaction rules, though you need to add extra constraints to solve the inverse problem reliably.

Worked Example

Flocking model: N=50 agents, each with position x_i and velocity v_i, system evolves via ∂x_i/∂t = v_i, ∂v_i/∂t = Σⱼ≠ᵢ φ(r_ij) with pairwise interaction kernel φ. From snapshots of observed dynamics over T=10 time units (training interval), the algorithm recovers φ using 100 different initial conditions and roughly 1D regression rate convergence. Learned kernel φ̂ achieves ≈0.1 relative error compared to true φ. Prediction at T=20 (beyond training) shows dynamics remain accurate up to T=15, with phase and amplitude well-preserved. For predator-prey (1 predator, 20 prey), 4 different kernels learned (prey-prey, predator-prey, prey-predator, predator-predator); algorithm correctly identifies zero kernel for predator-predator (no self-interaction data).

Pairwise interaction system: ∂x_i/∂t = Σⱼ φ(r_ij) e_ij where r_ij = |x_i - x_j|, e_ij = (x_j - x_i)/r_ij. Failure Boundary

If solutions are non-mixing (particles cluster into separated groups), pairwise distances concentrate in narrow range and ρ(r) becomes singular; convergence collapses. For high-dimensional state vectors d >> 1, learning general kernels φ(x_i, x_j) becomes intractable (curse of dimensionality); only distance-dependent kernels learnable. Long-time prediction (T >> training time) fails when system transitions to novel regimes (e.g., from flocking to milling to polarization); kernel valid only in regimes observed during training. Presence of external noise or model mismatch (system not purely pairwise) causes biased kernel estimates and divergence during prediction.

Important Terms

Self-Organization

Large-scale patterns and order that form by themselves from many small interactions between neighbors, with no central boss directing the outcome.

Interaction Kernel

A function that encodes the rule for how one agent affects another—for example, how strong the influence is based on distance, or what state the neighbor is in.

Homogeneous Agents

Individual agents that all follow the same interaction rules.

Heterogeneous Agents

Agents of different types—such as predators and prey—where each type follows its own set of interaction rules.

Trajectory Data

A timestamped record of where each agent is and what state it is in, recorded over time, showing the actual motion that you observe and want to learn from.

Connections Across The Series

  • This lecture connects to discovering equations and learning symbolic rules because it extracts governing laws directly from data rather than from human-written theories.
  • It links to nonlocal kernels and graph-based physics because collective behavior depends on how agents relate to and influence each other over distances.
  • It complements talks about predicting the future by emphasizing understanding and explaining the rules rather than just forecasting what happens next.

Practical Caution

Inferring interaction laws from observed motion is an inverse problem—working backward from results to causes. Matching the observed motion does not guarantee you found the unique or physically correct rule, especially when you only have trajectories from a few starting conditions or when you only see steady-state behavior where nothing appears to change.

Takeaway

Collective patterns are compressed recordings of what the interaction rules must be. Scientific machine learning should recover the rules themselves—understanding why the pattern exists—not just repeat the pattern by memorizing it.
