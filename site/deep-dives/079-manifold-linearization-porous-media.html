Talk 79 · Texas A&M University

Eduardo Gildin: Guided Deep Learning Manifold Linearization Of Porous Media Flow

This whole series is about getting computers to predict how physical things behave by learning from examples instead of using only hand-written math rules. One big challenge: oil and water moving through underground rock is ruled by equations that twist and change in complex ways, and simulating them is very slow. This talk shows a method that learns to work in a simpler, transformed space where the problem acts almost like a straight-line (linear) system—so a digital twin (a fast computer copy of the reservoir used for monitoring and making decisions) can actually run at the speed needed to control oil fields in real time.

YouTube source · Talk page

Core Problem

Simulating how oil and water move through rock takes a lot of computer time because the rules governing flow are nonlinear (they twist and feed back on themselves), and the computer has to solve equations over and over, once at each tiny step forward in time. When an oil company wants to run a real-time control system—adjusting well settings, testing 'what-if' scenarios, or optimizing where to drill—it needs a much faster stand-in for the full simulator. But usually, there is no way to peek inside the simulator's equations or use its internal structure directly.

First-Principles Model

The core idea is to find a transformed space where the messy, tangled physics starts to act like simple linear growth (the kind you get from a straight line). A method called E2CO (which stands for Embed to Control and Observe) uses two things together: it shrinks the problem down to fewer dimensions using data (a method called model reduction), and it trains a neural network (a program with millions of little dials the computer tunes by trial and error) to match both how the reservoir state changes over time and how the system responds when you change inputs—all without needing to look at the simulator's internal equations. Another path uses an autoencoder (a neural net that squeezes data down to a compact form and then unsqueezes it back) to map the reservoir flow equations onto a simpler surface, where a Koopman operator (a rule that says how measured properties evolve in a transformed space where things look linear) can approximate the motion, cutting the expensive work of solving twisted equations over and over.

Key Claims

  • Running a digital twin in real time—for monitoring, drilling choices, and optimization—needs the simulation to be much faster than the full physics model.
  • Neural networks trained on simulator output can match properties related to conservation (the rule that material cannot vanish or appear from nowhere).
  • E2CO glues data-shrinking and neural networks together to match both how the state moves and how the system reacts to inputs, all without touching the simulator's code.
  • The non-intrusive method (one that works without needing the simulator's internal structure) can be wrapped around any existing simulator.
  • POD (a data-based way to compress by keeping the most important patterns and throwing away the rest) can be supercharged by adding extra hidden dimensions to create a bilinear system (one where the only twist comes from state and input mixing together).
  • Autoencoders can shrink reservoir flow equations onto a compact shape where a Koopman operator (a linear rule in a transformed space) describes how things evolve.

Important Terms

Porous Media Flow

How liquids like oil, gas, or water move through rock and soil that have tiny holes (pores) throughout.

Reservoir Digital Twin

A fast computer simulation of an oil or gas field used to watch what is happening, test decisions before trying them, and steer the system from a control room.

E2CO

Embed to Control and Observe—a method that shrinks a big problem to fewer moving parts and trains a neural network to copy both how the state evolves and how the system answers when you push inputs, without needing to see inside the simulator.

Koopman Operator

A rule that describes how things you can measure (like pressure or flow rate) change over time when you view them in a specially chosen transformed space where the motion looks linear (like a straight line).

Manifold Linearization

Learning a twisted lower-dimensional surface where the complicated, tangled motion of fluids through rock starts to behave like simple linear growth.

Connections Across The Series

  • This lecture connects ideas from Koopman theory (how linear rules can describe twisted systems in a transformed view), autoencoders as shrinkers for physics, and the use of digital twins in real industry.
  • It also extends talks on learned simulators by showing how to add a fast model alongside an existing simulator without breaking into its code.
  • It reinforces the seminar's theme that the representation you choose matters: the best one is where you can predict and control with the least computer work.

Practical Caution

A learned linear stand-in only works well within the conditions the training data covered. In a real control system running on an actual oil field, you have to watch carefully: if the operating conditions drift outside what the model saw during training, or if the real field starts behaving differently than the digital copy, the fast approximation will fail and you need to fall back to checking against the true simulator or field data.

Takeaway

A working digital twin needs a way to represent the problem so that controlling it stays cheap to compute. Learning a transformed space where the physics looks more like linear rules (manifold linearization) is one practical way to turn the slow, twisted physics of oil and water flow into something you can actually run in real time.
