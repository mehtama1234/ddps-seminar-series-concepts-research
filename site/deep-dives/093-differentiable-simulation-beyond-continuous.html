Talk 93 · JuliaHub / Pumas AI / MIT Julia Lab

Christopher Rackauckas: Generalizing SciML And Differentiable Simulation Beyond Continuous Models

This whole series is about getting computers to predict how physical things behave by learning from data instead of only using hand-written math. This talk asks: what if we go beyond smooth-change rules and teach computers to simulate sudden jumps, randomness, many independent actors, and ways to estimate hidden states? The key idea is that learning programs should be able to tune themselves inside any kind of simulator—not just the smooth-change kinds—by computing which dials to nudge and by how much.

YouTube source · Talk page

Core Problem

Most machine learning work on science has focused on smooth-change rules (rules saying how things change moment to moment or place to place, where the changes happen gradually). Real scientific simulation, though, also has sudden changes (like a ball bouncing or a switch flipping), random outcomes (like quantum dice rolls or weather fluctuations), actors following rules (people or particles acting independently), ways to guess hidden states from messy observations, and mixed systems combining random and smooth parts. When you try to compute which dials to nudge in these kinds of simulators to match real data, the math gets much messier than for smooth rules—different tricks are needed.

First-Principles Model

Differentiable simulation means building a simulator that can learn: you swap unknown parts inside it with learning programs (or other adjustable dials) and compute gradients—the directions to nudge those dials to make the simulation match observed data better. For simulators with smooth rules, this is manageable. For simulators with randomness, sudden jumps, discrete choices, or behaviors sensitive to tiny changes in starting conditions, computing these nudge-directions gets harder and trickier. You have to track how changes flow through randomness, events that happen at specific instants, discrete switches, and algorithms that guess hidden states.

Key Claims

  • Machine learning for science has successfully used smooth-change rules (ordinary and partial differential equations) inside learning programs through differentiable simulation.
  • Real scientific simulation also includes sudden-jump processes (mixing random drift with discrete events), many independent actors following rules, and other non-smooth forms.
  • Differentiable simulation can extend to simulators that are chaotic (tiny changes in starting conditions cause huge differences) and stochastic (involving randomness).
  • Methods for guessing hidden states from data and independent-actor models need special ways to compute nudge-directions that do not work for smooth equations.
  • Inverse problems (figuring out unknown numbers from observations) sometimes need to compute nudge-directions even through the algorithms that explore probability distributions.
  • As this idea spreads to new domains, numerical stability and how code is written become central problems.

Worked Example

Illustrative example: guided manifold learning on porous media flow. Training set of 50-200 simulations with varying permeability fields (lognormal, correlated). Deep network learns low-dimensional latent space where solutions concentrate. Prediction speedup 10-50x on unseen permeability realizations. Compared to linear POD, nonlinear manifold captures tensor-train decomposition structure of heterogeneous problems.

One Level Deeper

Manifold linearization: decompose solution u = u_lin + δu where u_lin satisfies linearized PDE around reference parameter. Deep network learns δu in low-dim space. Jointly optimize reference state and manifold basis to minimize prediction error across parameter range. For parabolic PDEs (diffusion-dominated), manifold typically 5-20 dimensional despite 1000+ DOF discretization. Guided means incorporating physics constraints: enforce boundary conditions strongly in loss, penalize non-physical solutions.

Failure Boundary

Method fails when nonlinearity dominates over linear component (high Rayleigh number, strong convection). Manifold assumption breaks at bifurcation points. Extrapolation beyond training parameter range unreliable. Ill-posedness if reference state poorly chosen.

Important Terms

Differentiable Simulation

A simulator built so you can compute how to adjust any unknown dials inside it to make its predictions match observed data better—by calculating nudge-directions (gradients) through the whole chain of calculations.

Jump Diffusion

A process that mixes random drift (smooth, random wandering) with sudden discrete jumps (discrete events happening at specific times).

Agent-Based Model

A simulator of many independent actors, each following their own local rules, creating collective behavior that emerges from all their interactions.

Particle Filter

A method for guessing hidden states in a random system: maintain many sample paths and update which ones look right as new observations arrive.

Differentiable MCMC

Treating algorithms that explore probability distributions in a way that allows nudge-directions to flow backward through them for learning.

Connections Across The Series

  • This lecture extends the automatic-nudge-direction (automatic differentiation) and learning-through-code (differentiable programming) ideas from earlier talks.
  • It connects to learning from rewards (inverse reinforcement learning), random generative simulators, and inverse problems because all need computing nudge-directions through unusual kinds of loops.
  • It also gives a practical view: making machine learning for science work generally, not only for smooth-change rules.

Practical Caution

Computing nudge-directions through a simulator with randomness or sudden jumps can give wrong answers, blow up numerically (numbers become huge or collapse), or depend on how you build the code. You must pick a method to compute nudge-directions that actually matches what you are trying to improve.

Takeaway

The foundational insight is that machine learning for science must compute nudge-directions through any kind of scientific simulator, not only smooth-change solvers.
