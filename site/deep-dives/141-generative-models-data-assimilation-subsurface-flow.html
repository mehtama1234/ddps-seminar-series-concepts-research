Talk 141 · Carnegie Mellon University

Su Jiang: Generative Models for Data Assimilation in Subsurface Flow

This lecture shows how generative models (systems trained to create realistic samples from learned patterns) can describe and sample high-dimensional subsurface states for data assimilation.

YouTube source · Talk page

Core Problem

Subsurface-flow data assimilation must infer hidden properties and forecast reservoir behavior in high-dimensional nonlinear inverse problems. Ensemble simulations are expensive to run, and geological structures such as fracture networks or faulted reservoirs are hard to describe efficiently.

First-Principles Model

Generative models learn a low-dimensional or structured distribution over possible subsurface fields and responses. A latent diffusion model (a diffusion generative model operating in a compressed representation) parameterizes discrete fracture networks and is coupled with ensemble data assimilation to tune networks and improve flow and thermal predictions. Generative data-space inversion parameterizes spatiotemporal system responses, enabling posterior prediction of flow and geomechanical quantities for carbon storage in faulted reservoirs.

Key Claims

  • Data assimilation is critical for inferring subsurface properties and forecasting reservoir performance.
  • The inverse problem is high-dimensional and nonlinear.
  • Ensemble simulations require significant computational effort.
  • Deep generative models provide efficient description and conditional sampling.
  • Latent diffusion can model discrete fracture networks inside an ensemble assimilation workflow.
  • Generative data-space inversion supports direct posterior prediction for flow and geomechanical quantities.

Important Terms

Generative Model

A model trained to create samples from a distribution of plausible data or states.

Data Assimilation

Combining model predictions and observations to infer states or parameters.

Subsurface Flow

Flow through underground porous media, reservoirs, aquifers, or fractured rock.

Latent Diffusion Model

A diffusion generative model operating in a compressed latent representation.

Data-Space Inversion

An inverse workflow that describes and updates predicted observations or responses rather than only physical parameters.

Connections Across The Series

  • This talk connects generative models, latent spaces, data assimilation, and subsurface digital twins.
  • It complements Nan Chen's assimilation lecture by focusing on generative description for inverse problems.
  • It also links to uncertainty and foundation-model themes because posterior sampling is central to trustworthy prediction.

Practical Caution

A generative prior can make assimilation efficient but can also limit posterior possibilities to what the generator learned during training. Geological plausibility and whether the posterior distribution covers all realistic outcomes must be checked.

Takeaway

The first-principles lesson is that generative models help data assimilation by turning impossible high-dimensional inverse problems into structured conditional sampling problems.
