Talk 69 · Johns Hopkins University

Soledad Villar: The Passive Symmetries Of Machine Learning

This lecture explains passive symmetries as invariances induced by arbitrary representation choices, and argues that respecting them can improve machine-learning generalization.

YouTube source · Talk page

Core Problem

Every dataset representation includes investigator choices: coordinates, units, node labels, gauges, or basis conventions. These choices are not part of the data-generating process. A model that depends on them may learn artifacts of representation rather than structure of the phenomenon.

First-Principles Model

A passive symmetry is a transformation between equivalent representations of the same underlying object. Coordinate changes, unit conversions, gauge transformations, and graph node permutations should change model inputs and outputs consistently without changing the underlying prediction. Group equivariance is one way to implement this consistency in neural architectures.

Key Claims

  • Representation choices induce exact symmetries because different representations can describe the same object.
  • Passive symmetries include coordinate freedom, gauge symmetry, units covariance, and permutation symmetry.
  • These symmetries are external to the data-generating process but affect machine-learning practice.
  • Some passive symmetries can be implemented as group equivariances.
  • Respecting passive symmetries is especially valuable for out-of-sample generalization.
  • The topic connects machine learning practice to ideas from physics and causal modeling.

Important Terms

Passive Symmetry

A symmetry arising from changing representation while leaving the underlying object unchanged.

Coordinate Freedom

The fact that the same object or system can be represented in different coordinate systems.

Gauge Symmetry

A redundancy in representation where multiple mathematical descriptions correspond to the same physical state.

Units Covariance

Consistent transformation of quantities when measurement units are changed.

Group Equivariance

A model property where transforming the input causes a predictable corresponding transformation of the output.

Connections Across The Series

  • This lecture connects to equivariant neural networks, graph models, and structure-preserving learning throughout the series.
  • It also clarifies why symmetries are not just physics decoration; they protect models from arbitrary representation artifacts.
  • It links to out-of-distribution reliability: generalization improves when models ignore irrelevant choices.

Practical Caution

Not every symmetry should be blindly imposed. The model should respect symmetries of representation, but not erase meaningful asymmetries in the underlying data-generating process.

Takeaway

The first-principles lesson is that ML models should not depend on arbitrary representational choices. Passive symmetries define what the model must treat as the same.
