Talk 69 · Johns Hopkins University

Soledad Villar: The Passive Symmetries Of Machine Learning

This lecture explains passive symmetries as invariances that come from arbitrary choices in how we write down data, and shows that respecting these symmetries can help machine-learning models generalize better.

YouTube source · Talk page

Core Problem

Every time we write down data, we make choices: which coordinates to use, which units to measure in, how to label nodes in a graph, which gauge convention to pick, or which basis vectors to start with. None of these choices are part of the real-world process that generated the data. A model that shifts its predictions when we make different choices is learning artifacts of how we wrote things down, not the real structure of what's happening.

First-Principles Model

A passive symmetry is a change between two different ways of writing the same real object. When we rotate coordinates, convert units, apply a gauge transformation, or relabel nodes in a graph, the model's inputs and outputs should change in matching ways without changing what the model actually predicts. Group equivariance (a mathematical property where transforming an input causes a predictable change in the output) is one way to build this matching directly into neural networks.

Key Claims

  • Representation choices create exact symmetries because the same real object can be written down in many different ways.
  • Passive symmetries include coordinate freedom, gauge symmetry, unit transformation, and permutation symmetry.
  • These symmetries come from our choices of notation, not from the data-generating process itself, yet they affect how well machine learning works.
  • Some passive symmetries can be built into neural networks as group equivariances.
  • Respecting passive symmetries is especially useful for making predictions on data the model has never seen.
  • This topic connects what machine-learning practitioners do to ideas from physics and causal reasoning.

Important Terms

Passive Symmetry

A symmetry that arises when we change how we write something down while the actual thing we're describing stays the same.

Coordinate Freedom

The fact that the same object or system can be described using different coordinate systems without changing what it is.

Gauge Symmetry

A redundancy in notation where multiple different mathematical descriptions represent the exact same physical state.

Units Covariance

Quantities change in a consistent, predictable way when measurement units are switched.

Group Equivariance

A property of a model where transforming the input causes the output to transform in a matching way.

Connections Across The Series

  • This lecture connects to equivariant neural networks, graph models, and structure-preserving learning throughout the series.
  • It shows why symmetries matter for actual machine learning—not just as physics decoration, but because models need to ignore arbitrary choices in how data is written down.
  • It ties into making models work on new kinds of data: generalization improves when models ignore representation choices that don't matter.

Practical Caution

Not every symmetry should be forced onto a model without thought. A model should respect symmetries that come from representation choices, but it must not erase real asymmetries that actually exist in the process generating the data.

Takeaway

The core lesson is that machine-learning models should give the same answer regardless of arbitrary representational choices. Passive symmetries tell us what the model must treat as truly equivalent.
