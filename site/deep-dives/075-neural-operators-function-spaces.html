Talk 75 · Caltech / NVIDIA

Anima Anandkumar: Neural Operators On Function Spaces

Neural operators learn to predict output fields directly from input fields for PDEs and multiscale scientific systems, generalizing across resolutions and achieving thousands-of-times speedups over traditional numerical solvers.

YouTube source · Talk page

Core Problem

Scientific systems such as weather, climate, deep earth, materials, and quantum-to-planetary-scale processes involve mappings between fields, not fixed-size vectors. Standard neural networks are tied to one specific mesh size and struggle to work on different resolutions, different geographical areas, or different boundary conditions.

First-Principles Model

A PDE solver takes input functions (like initial conditions or forcing) and produces output functions (like solutions). A neural operator learns this input-to-output mapping directly on function spaces. Because the learned map does not depend on a specific mesh size, it can work on new grids and naturally handles multi-scale (small and large features together) field-to-field structure better than ordinary neural networks tied to one discretization.

Key Claims

  • Neural operators learn the mappings between input and output fields that PDEs define.
  • Function-space learning works especially well for scientific applications across many scales.
  • Applications include weather and climate, deep earth, and other scientific simulations.
  • Well-designed neural operators can generalize to new problems without retraining, going beyond the training data.
  • Neural operators can run thousands of times faster than numerical weather models and similar simulations.
  • The advantage comes from learning the right mathematical object: an operator (a function-to-function map), not just using neural networks.

Important Terms

Neural Operator

A neural network that learns mappings from input functions to output functions, rather than from fixed-size vectors to fixed-size vectors.

Function Space

A mathematical collection of functions, such as temperature or pressure fields defined over a region.

Zero-Shot Generalization

Working correctly on new problems or new conditions without seeing training examples from those specific cases.

Multiscale Process

A system where behavior depends on interactions happening at many different scales of size or time, all at once.

Operator Learning

Training a model to learn the map that converts input conditions into solution fields for a family of related problems.

Connections Across The Series

  • This talk anchors the neural-operator concept and connects to Kaushik Bhattacharya's work on operators across multiple scales.
  • It relates to reduced-order models because both aim to build fast, reusable maps, but operators work directly on fields rather than vector snapshots.
  • It also ties to talks on weather and data assimilation because both need fast field predictions for atmospheric systems.

Practical Caution

Zero-shot generalization (working on new problems never seen during training) must be tested against real cases, not assumed from the architecture alone. Operator learning can fail when the new problem has different physics or boundary conditions than the training set.

Takeaway

The key lesson is that learning should target the operator that maps between field solutions, not individual solution snapshots. The architecture should match what you are actually trying to learn: a function-to-function map.
