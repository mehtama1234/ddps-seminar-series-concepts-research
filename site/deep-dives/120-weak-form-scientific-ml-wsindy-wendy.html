Talk 120 · University of Colorado Boulder

David Bortz: The Weak Form Is Stronger Than You Think

This lecture explains how weak-form methods make equation learning and parameter estimation more robust to noisy data.

YouTube source · Talk page

Core Problem

Early data-driven equation-learning methods often minimized strong-form equation errors requiring pointwise derivatives. Noise-corrupted data makes those derivatives unreliable, which causes model discovery and parameter inference to fail.

First-Principles Model

A weak form multiplies the governing equation by test functions and integrates, moving derivatives from noisy data onto smoother test functions through integration by parts. This reduces sensitivity to noise and discretization artifacts. WSINDy uses weak-form sparse identification to learn equations, while WENDy uses related ideas for parameter estimation and uncertainty-aware inference.

Key Claims

  • Learning governing equations is powerful because it produces explainable scientific ML models.
  • Strong-form equation-error methods are poorly suited to noise-corrupted data.
  • Weak-form approaches address challenges in model development, discretization, parameter inference, and refinement.
  • WSINDy supports weak-form equation learning.
  • WENDy supports weak-form parameter estimation.
  • The approach can deliver strong robustness, accuracy, and performance advantages.

Important Terms

Weak Form

An integral formulation of a differential equation using test functions.

Strong Form

A pointwise differential-equation formulation involving direct derivatives.

WSINDy

Weak-form Sparse Identification of Nonlinear Dynamics for equation learning.

WENDy

A weak-form method for parameter estimation in dynamical systems.

Equation Learning

Discovering governing equations from observed data.

Connections Across The Series

  • This talk connects symbolic regression, sparse model discovery, inverse problems, and noise-robust scientific ML.
  • It complements PINN and differentiable-solver lectures by emphasizing variational/integral formulations.
  • It also links to practical experimental data, where noise is unavoidable.

Practical Caution

Weak forms reduce derivative noise but introduce choices of test functions, integration windows, and libraries. These choices can affect discovered equations.

Takeaway

The first-principles lesson is that integrating equations against test functions can turn noisy derivative estimation into a more stable discovery problem.
