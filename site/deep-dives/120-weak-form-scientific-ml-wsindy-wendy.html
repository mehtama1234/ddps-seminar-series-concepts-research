Talk 120 · University of Colorado Boulder

David Bortz: The Weak Form Is Stronger Than You Think

This lecture shows how weak-form methods make finding equations and estimating parameters work better when data contains noise.

YouTube source · Talk page

Core Problem

Early data-driven methods for discovering equations often minimized errors by computing derivatives directly from data at each point. Noise in the data makes those derivatives unreliable, which causes the discovered equations and estimated parameters to be wrong.

First-Principles Model

A weak form multiplies the equation by test functions (auxiliary functions you choose) and integrates over a region, moving the need to compute derivatives from noisy data onto smoother test functions through integration by parts. This cuts down sensitivity to noise and errors from discretization choices. WSINDy (Weak-form Sparse Identification of Nonlinear Dynamics) uses this idea to find equations, while WENDy applies similar reasoning to estimate parameters and quantify uncertainty.

Key Claims

  • Finding governing equations is valuable because it produces scientific machine learning models that humans can understand and explain.
  • Methods that minimize pointwise equation errors perform poorly when data is noisy.
  • Weak-form methods address difficulties in building models, handling discretization choices, estimating parameters, and refining equations.
  • WSINDy enables weak-form equation discovery.
  • WENDy enables weak-form parameter estimation.
  • This approach can deliver big improvements in reliability, accuracy, and speed.

Important Terms

Weak Form

An integral version of a differential equation, written using test functions you multiply by and integrate instead of taking derivatives at individual points.

Strong Form

A differential equation written by taking derivatives directly at each point without integration.

WSINDy

Weak-form Sparse Identification of Nonlinear Dynamics, a method to discover equations from noisy data.

WENDy

A weak-form method for finding the parameters (numbers that define a system) in dynamical equations.

Equation Learning

Finding the governing equations (the rules that describe how a system behaves) by observing data from that system.

Connections Across The Series

  • This talk connects symbolic regression (turning data into human-readable equations), sparse model discovery (finding which terms matter most), inverse problems (working backward from measurements to find what caused them), and noise-tolerant scientific machine learning.
  • It complements lectures on PINNs (Physics-Informed Neural Networks) and differentiable solvers by focusing on variational and integral formulations (different mathematical angles on the same equations).
  • It also bridges to real experimental data, where noise is always present.

Practical Caution

Weak forms reduce noise effects but require you to pick test functions, set the size of integration regions, and choose a library of possible terms. These choices change which equations get discovered.

Takeaway

The main insight is that integrating equations against test functions can turn a problem of noisy derivative calculation into one that is more stable and reliable.
