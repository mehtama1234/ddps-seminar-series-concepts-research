Talk 65 · Politecnico di Milano

Andrea Manzoni: Deep Learning For Reduced Order Modeling

This whole series is about getting computers to predict how physical things behave by learning from examples instead of only hand-written math. One way to speed this up is to work with a smaller, cheaper version of the problem — but when the physics is highly nonlinear, those small versions become expensive too. This talk shows how a program that learns by trial and error (what we call deep learning) can build small versions that stay both accurate and fast, even when the physics twists in complicated ways.

YouTube source · Talk page

Core Problem

When engineers solve real physics problems — how heat spreads through a metal, how a plane's wing flexes, how fluids swirl — they often need to solve the same problem many times with different starting conditions or boundaries. The math (a differential equation, which is a rule saying how something changes moment by moment) might take minutes or hours to solve even once. One trick is to make a smaller, simpler version that runs in seconds instead — we call this a reduced model. It works well for simple physics, but breaks down when the physics behaves in deeply nonlinear ways (when tiny changes at one place can cause huge effects somewhere else). The challenge is building these smaller versions without digging into the original solver's code, which in real industry is often locked down or proprietary.

First-Principles Model

Start with a high-resolution solution — a detailed picture of what the physics does (temperature at every point, velocity at every point). We want to squash this into a few key numbers (like 10 instead of 1 million) that still capture the essential behavior. A classical approach: find the simplest fixed basis vectors that matter most, then project everything onto them. A program that learns by trial and error can improve this in several ways. First, it can learn a squashing rule (we call this an encoder) to compress the high-resolution picture into those few key numbers, and a reconstruction rule (a decoder) that expands them back. Second, it can learn the rules for how those key numbers evolve in time or across different conditions. Third, it can mix the best of both: use the classical fixed basis vectors but also teach the program nonlinear tweaks on top. The goal is fast predictions without needing to open up and modify the original solver.

Key Claims

  • Reduced models — simplified versions of expensive physics solvers — are necessary for real-time prediction and repeated evaluations when uncertainty needs to be quantified, systems need to be controlled, or digital twins must run fast.
  • A program learning by trial and error can build reduced models by looking only at saved snapshots of the high-resolution physics, without modifying the original solver.
  • Learning programs are especially useful for the nonlinear maps that simple basis vectors struggle to represent.
  • Mixing classical basis vectors with neural learning can combine speed, accuracy, and interpretability.
  • A learned reduced model can compress not only the state variables but also the operators and intermediate terms that classical reduction struggles with.
  • The main payoff is speed: nonlinear physics that takes hours to solve can be approximated in milliseconds.

Important Terms

Reduced-Order Model

A fast approximation made by squashing a huge, expensive physics problem into a smaller version with just the most important pieces, so predictions run in seconds instead of hours.

Full-Order Model Snapshot

One saved example showing the full detailed state of the physics at one moment (temperature and pressure at every point, velocity at every location) — used as training data.

DL-ROM

A reduced model built by a learning program: the computer finds the squashing rule and unfolding rule and the evolution rules by trial and error on examples.

POD-DL-ROM

A hybrid approach: start with classical fixed basis vectors (found by a statistical trick called POD, which identifies the most important patterns in the data), then layer on a learning program to handle the nonlinear parts that the fixed vectors miss.

Non-Intrusive ROM

A reduced model built by observing examples from the original solver without ever needing to look at or edit its code — the solver remains a sealed box.

Connections Across The Series

  • This talk builds on earlier discussions of reduced basis methods and POD, showing how to mix them with programs that learn from data.
  • It connects to real-world digital twins, where real-time simulation of many scenarios is the entire point — a reduced model is often the only way to run fast enough.
  • It relates to the broader search for cheap replacements to expensive physics solvers, including other learning-based surrogates and operators that act on data directly.

Practical Caution

A program trained on snapshots (saved examples of the physics) only knows patterns from those specific examples. If you ask it to predict behavior for a new set of conditions it never saw during training — a different shape, a new temperature range, a sudden transient event — it may fail or drift away from the true answer. You must always test whether the model is still trustworthy before using it in real decisions.

Takeaway

Deep learning helps here because it can learn the twisted, highly nonlinear rules that simple fixed basis vectors cannot capture well. When classical methods are cheap but not accurate enough, and the physics is too tangled for simple compression, teaching a program to learn the nonlinear map is what saves the day.
