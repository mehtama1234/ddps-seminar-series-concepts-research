Talk 65 · Politecnico di Milano

Andrea Manzoni: Deep Learning For Reduced Order Modeling

This lecture explains how deep neural networks can enhance reduced-order modeling by learning non-intrusive ROMs and nonlinear operators for parametrized PDEs.

YouTube source · Talk page

Core Problem

Classical ROMs accelerate parametrized PDE solves for real-time simulation, UQ, control, monitoring, and digital twins. But nonlinear time-dependent problems often remain expensive because reduced dynamics, hyper-reduction, and intrusive solver access can be hard to build or deploy.

First-Principles Model

A ROM approximates high-fidelity solutions in a low-dimensional representation. Deep learning can replace or augment several ROM components: encoders map full-order snapshots to latent coordinates, decoders reconstruct high-fidelity fields, neural maps evolve or parameterize reduced states, and POD-enhanced variants combine classical linear bases with neural nonlinear approximation. The goal is fast simulation without requiring full intrusive access to the solver.

Key Claims

  • ROM techniques such as reduced basis methods are essential for efficient approximation of parametrized differential problems.
  • ROMs enable real-time simulation and repeated scenario evaluation for UQ, control, monitoring, data assimilation, and digital twins.
  • Deep neural networks can build ROMs from full-order model snapshots in a fully non-intrusive way.
  • DL-ROMs use neural networks as core building blocks for parametrized PDE approximation.
  • POD-enhanced DL-ROMs combine classical projection structure with neural nonlinear maps.
  • Deep learning can also approximate nonlinear ROM operators and improve hyper-reduction.

Important Terms

Reduced-Order Model

A lower-dimensional approximation of a high-fidelity model used to accelerate simulation.

Full-Order Model Snapshot

A stored high-fidelity solution sample used as training or basis data for a ROM.

DL-ROM

A deep-learning-based reduced-order model that uses neural networks to learn reduced coordinates, reconstruction, or dynamics.

POD-DL-ROM

A ROM that combines Proper Orthogonal Decomposition with deep neural networks.

Non-Intrusive ROM

A reduced model built without modifying or deeply accessing the original high-fidelity solver.

Connections Across The Series

  • This lecture continues the ROM thread and bridges classical reduced basis/POD methods with neural surrogates.
  • It connects to industrial digital twins because real-time parametrized simulation is a core twin capability.
  • It also links to CUR, adaptive ROMs, and neural operators as different answers to the same compression-and-speed problem.

Practical Caution

A neural ROM trained on snapshots inherits the coverage limits of those snapshots. Non-intrusive convenience does not remove the need for error checks under new parameters, geometries, or transient regimes.

Takeaway

The first-principles lesson is that deep learning helps ROMs when it learns the nonlinear maps classical linear reduction cannot represent cheaply.
