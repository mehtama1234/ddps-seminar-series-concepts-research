Talk 4 · EPFL

Jan Hesthaven: Non-Intrusive ROMs Using Physics-Informed Neural Networks

This lecture frames neural networks as tools for removing bottlenecks in reduced-order modeling, especially when the full simulator is a black box and projection-based intrusive access is unavailable.

YouTube source · Talk page

Core Problem

Projection-based ROMs are powerful when you can access the governing operators, but many real solvers are legacy, classified, commercial, or otherwise black-box. For nonlinear problems, even intrusive ROMs can lose speed because evaluating projected nonlinear operators may require returning to the full state dimension.

First-Principles Model

A ROM trades generality for speed by learning a compact map from parameters to solution coefficients. If the full operator is accessible, projection gives equations for those coefficients. If the operator is not accessible, a neural network can learn the parameter-to-coefficient map from simulator input-output data, and physics-informed terms can improve consistency.

Key Claims

  • Reduced-order modeling accelerates repeated parameterized PDE solves by representing solutions in a low-dimensional basis.
  • Nonlinear problems introduce a bottleneck because projected nonlinear operators may still depend on the full-order state.
  • Non-intrusive ROMs are needed when the solver is only available as an input-output code.
  • A neural network can map parameters directly to reduced-basis expansion coefficients.
  • If a good reduced basis exists, the parameter-to-coefficient map should often be smooth enough for a small neural network.
  • Physics-informed neural nets can be used as part of ROM construction rather than as a wholesale replacement for numerical analysis.

Important Terms

Intrusive ROM

A reduced-order model that requires access to the solver operators or internal discretized equations.

Non-Intrusive ROM

A reduced-order model built from input-output data without modifying or inspecting the full solver.

Expansion Coefficients

The low-dimensional coordinates multiplying reduced basis vectors to reconstruct an approximate solution.

Projection Bottleneck

The cost or access problem that appears when reduced equations require full-order operator evaluations.

Overfitting In ROM Nets

A failure mode where the neural parameter-to-coefficient map is too rich for the available simulator samples.

Connections Across The Series

  • This gives the practical ROM workflow behind many later talks: offline snapshots, reduced basis construction, online fast prediction.
  • It links PINNs to a narrower engineering role: solving ROM bottlenecks rather than replacing full solvers.
  • It connects to uncertainty and design loops because ROMs are most useful when many repeated simulations are required.

Practical Caution

A neural ROM is only useful if the reduced basis is good and the learned coefficient map generalizes. Increasing neural-network size without enough simulator data can make the online predictor worse.

Takeaway

The lecture's central lesson is pragmatic: use neural networks where classical ROM workflows have bottlenecks, especially black-box solvers and nonlinear coefficient maps.
