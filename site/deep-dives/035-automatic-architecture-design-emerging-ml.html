Talk 35 · Carnegie Mellon University

Misha Khodak: Automatic Architecture Design For Emerging Machine Learning Tasks

This lecture studies how to automate architecture transfer so neural networks can be adapted to emerging domains beyond hand-designed image convolutions.

YouTube source · Talk page

Core Problem

Many successful architectures were hand-designed for images, but scientific tasks involve sequences, graphs, PDEs, and other structures. Manually inventing new operations for every domain is slow and requires expertise; standard NAS over topology alone may not discover the right operation family.

First-Principles Model

An architecture encodes constraints on degrees of freedom: convolution restricts how weights share across spatial locations. XD-operations generalize this idea by defining expressive neural operations that can mimic useful constraints while being searchable for a target domain. This turns architecture design into a transfer problem: learn or search operations that fit new task structure.

Key Claims

  • Hand-designed neural networks accelerated traditional ML but transfer poorly to new domains without task-specific operations.
  • Emerging tasks such as graph learning, sequence modeling, and PDE solving need appropriate neural operations.
  • XD-operations mimic useful degree-of-freedom constraints of convolutions while being more expressive.
  • Architecture design can be automated as an operation-search problem.
  • The right architecture depends on data availability and task structure.
  • Jointly optimizing discrete topology search and continuous operation choices is possible but difficult.

Important Terms

Architecture Transfer

Adapting neural architecture ideas from one domain to another.

XD-Operation

A family of neural operations designed to generalize useful constraints from convolutions to broader tasks.

Degree-of-Freedom Constraint

A structural restriction on parameters that encodes sharing, locality, symmetry, or other inductive bias.

Topology Search

Searching over how neural operations are connected in a network graph.

Architecture Design

Choosing the neural operations and connectivity that define a model class.

Connections Across The Series

  • This talk complements the NAS surrogate-modeling lecture by focusing on the operations themselves, not only the topology.
  • It connects to graph networks, FNO-style models, and PDE learners because architecture must match data geometry.
  • It also reinforces the broader DDPS theme that inductive bias is often the difference between interpolation and useful generalization.

Practical Caution

Architecture automation can make search easier, but it does not know the scientific objective unless the evaluation metric includes it. Accuracy, cost, stability, and physical consistency should all be part of the design loop.

Takeaway

The first-principles lesson is that architecture is an inductive-bias language. Automatic design searches for the right bias for a new scientific task.
