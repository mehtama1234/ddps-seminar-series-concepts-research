Talk 81 · The Ohio State University

Dongbin Xiu: Data-Driven Modeling Of Unknown Systems With Deep Neural Networks

Deep neural networks can learn the hidden rule—the evolution operator, or map from one system state to the next—from measurement data alone, then use that learned map to predict how an unknown system will behave.

YouTube source · Talk page

Core Problem

Many dynamical systems (systems that change over time) are only partially observed: the equations that govern them are unknown, some variables are not measured, some parameters are hidden, and the structure of partial differential equations (PDEs—equations with multiple variables and rates of change) may not be available. The question is whether you can build a model that predicts the future just from the measured history.

First-Principles Model

Instead of trying to learn the differential equation directly, flow map learning finds the evolution operator—the rule that maps a current observed state to a future observed state. A deep neural network (a flexible mathematical model with many layers) learns this map from data. Once trained, the learned map can predict how the observed system will evolve and answer questions about the system, even when you don't have complete measurements or know what hidden variables exist.

Key Claims

  • Predictive modeling of unknown systems can be reframed as finding the evolution operator (the rule that advances the system in time) behind the data.
  • The evolution operator is the flow map: it takes the system state now and gives you the system state later.
  • Deep neural networks can learn this flow map by training on measurement data.
  • A well-trained learned flow map becomes a working predictive model for the unknown system.
  • Flow map learning works for dynamical systems, systems with missing variables, systems with hidden parameters, and PDEs.
  • The method can predict the measured variables even when the full system dimension (the total number of variables, hidden and visible) is unknown.

Important Terms

Flow Map

The rule that shows how a system state at one time changes to a new state at a later time.

Evolution Operator

A rule that describes how a system advances forward through time.

Missing Variables

Unobserved parts of the system state that affect how it moves but are not directly measured.

Hidden Parameters

Numbers that control the system's behavior but are not known or not measured.

Predictive Model

A mathematical tool that forecasts what the system will do next based on what you know right now or recently.

Connections Across The Series

  • This approach builds on Koopman operator theory, charting of dynamics, and equation-free modeling—other methods that learn how systems evolve from data without needing the equations.
  • It differs from equation discovery (which tries to recover the actual differential equations) by focusing on learning the time-advance map instead.
  • It also relates to reservoir computing, manifold linearization, and operator learning because all of these learn maps from data.

Practical Caution

A flow map trained only on the variables you can observe may miss effects from variables you cannot see. The prediction might work well for nearby conditions but fail when hidden states shift the way the observed system behaves.

Takeaway

A system can be modeled by learning how it advances through time—the evolution operator from one state to the next—even when you don't have its governing equations.
