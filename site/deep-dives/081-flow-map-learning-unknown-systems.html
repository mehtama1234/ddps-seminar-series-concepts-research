Talk 81 · The Ohio State University

Dongbin Xiu: Data-Driven Modeling Of Unknown Systems With Deep Neural Networks

This series chases getting computers to predict physical behavior by learning from data. One method: instead of finding the full set of rules that govern a system, a neural network (a program with millions of dials it tunes by trial and error until answers look right) learns the simple machine that advances the system forward one step at a time—just from watching what happens. Once it learns that stepping rule, it can forecast the system's future without knowing what's actually going on inside.

YouTube source · Talk page

Core Problem

Real systems are messy. The equations that govern them are often unknown. You can only measure some of the things happening—other parts of the system hide from you. Some numbers that control the system stay secret. And the equations themselves (rules that say how something changes from moment to moment or place to place) might be too tangled to write down. The question: can you build a model that predicts what comes next, knowing only what you can see?

First-Principles Model

Instead of hunting for the actual equations, this method hunts for the stepping machine—the operation that takes the system's current state and produces its next state. A deep neural network learns this stepping machine directly from measurement data. Think of it like watching a ball bounce: you don't need the full physics equations; you just need to learn the rule 'given where the ball is now, here's where it goes next.' Once the program learns that, it can predict the whole bounce without understanding gravity. The learned stepping machine works even when you have gaps in your measurements or don't know what hidden things exist inside the system.

Key Claims

  • Predicting unknown systems means finding the stepping machine: the rule that takes the state now and gives the state later.
  • The stepping machine is called a flow map, and it's the core object to learn.
  • Neural networks can learn this flow map directly by watching measurement data.
  • Once trained, the learned flow map becomes a working predictor for the system.
  • This method works for systems that change over time, systems where you miss variables, systems where numbers controlling them are hidden, and even tangled equations with multiple variables and rates of change.
  • The method predicts what you measure, even when you don't know the total count of all variables (hidden and visible) in the system.

Important Terms

Flow Map

The stepping machine: a rule that takes the system state at one moment and produces the system state at the next moment.

Evolution Operator

A rule that shows how a system advances forward through time, one step at a time.

Missing Variables

Parts of the system you cannot see or measure, but that affect how the system behaves.

Hidden Parameters

Numbers inside the system that control what it does, but you don't know them or can't measure them.

Predictive Model

A tool (often made of math or code) that guesses what the system will do next, built from what you know right now.

Connections Across The Series

  • This approach uses ideas from Koopman operator theory—a way to think about how systems change—and equation-free methods that learn the system's motion from data without needing to write down equations.
  • It differs from equation discovery, which tries to recover the actual equations; instead, this learns the time-stepping rule and stops there.
  • It connects to reservoir computing, manifold learning, and operator learning, all of which train on examples to extract maps—the rules that take you from one place to another.

Practical Caution

A stepping machine trained only on what you can see might miss invisible parts of the system. It learns the pattern of the visible stuff, but if something hidden shifts underneath, the prediction breaks. The model works well nearby where it trained but falls apart far away or when hidden states change how the visible world behaves.

Takeaway

You can predict a system by learning just the stepping machine—the rule that advances it one moment at a time—without ever knowing its governing equations.
