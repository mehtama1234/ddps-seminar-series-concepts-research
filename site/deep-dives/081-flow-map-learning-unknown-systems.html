Talk 81 · The Ohio State University

Dongbin Xiu: Data-Driven Modeling Of Unknown Systems With Deep Neural Networks

This lecture presents flow map learning, where deep neural networks approximate the unknown evolution operator behind measurement data and become predictive models for unknown systems.

YouTube source · Talk page

Core Problem

Many dynamical systems are only partially observed: governing equations may be unknown, variables may be missing, parameters may be hidden, and PDE structure may be unavailable. The immediate question is whether one can build a predictive model from the measured time history alone.

First-Principles Model

Instead of learning the differential equation directly, flow map learning approximates the evolution operator that maps a current observed state to a future observed state. A DNN is used as a flexible map approximator. Once trained, the learned flow map can predict the observed system and support system analysis, even when the complete state or hidden variables are not known.

Key Claims

  • Predictive modeling of unknown systems can be framed as discovering or approximating the evolution operator behind data.
  • The evolution operator is the flow map from one system state to another.
  • Deep neural networks can approximate this flow map from measurement data.
  • An accurate learned flow map becomes a predictive model for the unknown system.
  • Flow map learning applies to dynamical systems, missing-variable systems, hidden-parameter systems, and PDEs.
  • The method can model measured variables even when the full system dimension is unknown.

Important Terms

Flow Map

The operator that maps a system state at one time to its state at a later time.

Evolution Operator

A map describing how a dynamical system advances through time.

Missing Variables

Unobserved state components that influence dynamics but are not measured.

Hidden Parameters

Unknown parameters affecting the system's evolution.

Predictive Model

A model used to forecast future system behavior from current or past observations.

Connections Across The Series

  • This lecture connects to Koopman, charting dynamics, and equation-free modeling as alternative ways to learn evolution from data.
  • It complements equation discovery by learning the time-advance map rather than explicitly recovering a differential equation.
  • It also links to reservoir manifold linearization and operator learning because all focus on learning maps.

Practical Caution

A flow map learned only on observed variables may hide unresolved memory effects from missing variables. Prediction can work locally but fail when hidden states change the observed dynamics.

Takeaway

The first-principles lesson is that a system can be modeled through its time-advance operator even when its governing equations are unknown.
