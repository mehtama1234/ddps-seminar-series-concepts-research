Talk 22 · MINES ParisTech

David Ryckelynck: Model Order Reduction Assisted By Deep Neural Networks

This lecture presents ROM-net as a projection-based model reduction framework where neural networks select or adapt local reduced models for high-dimensional inputs such as images.

YouTube source · Talk page

Core Problem

Many practical simulations have stochastic or image-like inputs whose variability strongly affects quantities of interest. A single global reduced basis may be inefficient or uninterpretable across such variability, while fully black-box neural surrogates may lose the structure and hyper-reduction benefits of projection-based ROMs.

First-Principles Model

ROM-net combines deep learning with projection-based ROM. A dictionary of local reduced-order models is built, often by clustering simplified simulations and computing local reduced bases. A feedforward neural network maps an input tensor, such as an image of a defect, to the appropriate local ROM or latent subspace. This gives a piecewise-linear reduced representation that can remain compatible with hyper-reduction.

Key Claims

  • ROM-net extends model order reduction to settings with high-dimensional image-like parameters.
  • Sparse dictionary learning can be interpreted as a piecewise-linear latent space.
  • Clustering data allows each cluster to receive its own local reduced basis.
  • Local ROM dictionaries can improve interpretability compared with opaque autoencoders.
  • Hyper-reduction is straightforward when the latent structure is piecewise linear.
  • The method is designed to use existing simulation data while retaining information from classical mathematical models.

Important Terms

ROM-net

A neural-network-assisted framework that connects input data to projection-based reduced-order models.

Dictionary-Based ROM

A collection of local reduced models from which one is selected or combined for a given input.

Sparse Dictionary Learning

Learning representations that use only a small number of dictionary elements or local latent components.

Piecewise Linear Latent Space

A latent representation made from multiple local linear subspaces rather than one global linear space.

Image-Type Parameter

A high-dimensional input, such as tomography data, used as a simulation parameter.

Connections Across The Series

  • This talk sits between non-intrusive ROM, NAS, and nonlinear manifold ROMs: it uses neural networks to route among structured reduced models.
  • It connects to hybrid twins because image or sensor inputs can choose the right local twin behavior.
  • It also reinforces a recurring DDPS theme: neural networks are often most valuable when they assist classical reduction rather than replace it.

Practical Caution

The number and quality of clusters matter. Too few local models may underfit heterogeneous inputs, while too many increase memory and training demands. The neural routing model must also be validated under input variability.

Takeaway

The first-principles lesson is that neural networks can choose the right reduced model for the input, while projection and hyper-reduction keep the solver structure.
