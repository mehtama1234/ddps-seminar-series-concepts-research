Talk 22 · MINES ParisTech

David Ryckelynck: Model Order Reduction Assisted By Deep Neural Networks

This lecture presents ROM-net, which uses neural networks to pick or adapt local simplified models from a dictionary for high-dimensional inputs like images.

YouTube source · Talk page

Core Problem

Many real simulations take random or image-like inputs, and how these inputs vary strongly shapes the answer you care about. A single global simplified basis may work poorly or be hard to understand across that variability, while using a neural network as a complete replacement loses the structure and speed benefits of projection-based reduced-order models (ROMs—versions of a simulation that run much faster by solving in fewer dimensions).

First-Principles Model

ROM-net combines deep learning with projection-based ROM. A dictionary of local simplified models is built by grouping similar simulation data and computing a reduced basis (a small set of directions that capture the main variation) for each group. A feedforward neural network takes an input tensor, such as an image showing where a material is damaged, and routes it to the right local ROM or subspace (a lower-dimensional space that captures the key behavior). This gives a piecewise-linear reduced version—made from pieces of different linear spaces—that still works with hyper-reduction (a speedup method that reduces not just dimensions but also the number of calculations needed).

Key Claims

  • ROM-net extends model order reduction to settings where inputs are high-dimensional and image-like.
  • Sparse dictionary learning can be read as a piecewise-linear latent space (a lower-dimensional representation built from separate linear pieces).
  • Grouping data allows each group to get its own local reduced basis.
  • Local ROM dictionaries are easier to understand and work with compared to autoencoders (neural networks that compress data to a dense code and uncompress it).
  • Hyper-reduction becomes straightforward when the latent structure is made of separate linear pieces.
  • The method works with simulation data you already have while keeping the understanding that comes from classical mathematical models.

Important Terms

ROM-net

A neural-network-assisted approach that connects input data to projection-based reduced-order models (simplified versions that run much faster).

Dictionary-Based ROM

A collection of local simplified models from which the right one is selected or combined for a given input.

Sparse Dictionary Learning

Learning representations that use only a small number of dictionary elements or local lower-dimensional components.

Piecewise Linear Latent Space

A lower-dimensional representation built from multiple local linear subspaces (separate flat regions) rather than one global flat region.

Image-Type Parameter

A high-dimensional input, such as medical scan data, used as a simulation parameter.

Connections Across The Series

  • This talk sits between non-intrusive ROM (reduced-order models that work from data without needing to change the original simulator), neural architecture search (NAS—automatically finding network designs), and nonlinear manifold ROMs (advanced simplifications that handle curved spaces): it uses neural networks to route among structured simplified models.
  • It connects to hybrid twins because image or sensor inputs can choose the right local digital twin behavior.
  • It reinforces a recurring DDPS theme: neural networks are often most useful when they assist classical reduction methods rather than replace them.

Practical Caution

The number and quality of groups matter. Too few local models may not capture the range of different inputs, while too many demand more memory and training time. The neural routing model must also be tested to make sure it works well when the input changes in new ways.

Takeaway

The first-principles lesson is that neural networks can select the right simplified model for each input, while keeping the structure and efficiency that come from projection and hyper-reduction.
