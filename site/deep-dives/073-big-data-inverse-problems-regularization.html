Talk 73 · Emory University

Matthias Chung: Big Data Inverse Problems

This lecture explains sparse inverse problems at big-data scale and shows how variable projection and neural networks can help choose regularization—adjustments that keep solutions stable when working backward from noisy measurements.

YouTube source · Talk page

Core Problem

Inverse problems recover hidden causes from indirect measurements, but they are often ill-posed: many different solutions fit the data equally well, noise gets amplified, and large datasets make traditional statistical methods too slow. Sparsity—assuming the answer has only a few large values—helps, but L1-regularized problems require difficult choices about regularization strength and how to optimize.

First-Principles Model

An inverse problem trades off data match against prior structure. Sparsity says the unknown quantity is simple in some vector space or dictionary, so L1 regularization (a penalty on absolute coefficient values) encourages sparse reconstructions. Variable projection reduces coupled optimization by analytically or implicitly eliminating variables, while learned regularization uses deep neural networks to infer stabilizing adjustments from data or problem features.

Key Claims

  • Modern data analytics, machine learning, and uncertainty quantification depend on efficient inverse-problem solvers.
  • Growing model size and data volume exceed the limits of many existing statistical methods.
  • Many inverse problems aim to reconstruct quantities with sparse representations.
  • L1 regularization is widely useful in compressed sensing, dictionary learning, and imaging.
  • Variable projection provides a new route for sparse inverse optimization.
  • Deep neural networks can infer regularization parameters for solving inverse problems.

Important Terms

Inverse Problem

A problem of inferring unknown causes, fields, or parameters from observed effects.

Ill-Posed Problem

A problem where solutions may not exist, may not be unique, or may change wildly when data shifts slightly.

Sparse Representation

A representation where only a small number of coefficients are nonzero or matter.

L1 Regularization

A penalty on absolute coefficient values that encourages solutions with many coefficients equal to zero.

Variable Projection

An optimization technique that removes some variables to reduce or stabilize the remaining problem.

Connections Across The Series

  • This lecture connects to inverse scattering, adaptive reduced-order models, and Bayesian calibration across the series.
  • It clarifies why regularization is not an afterthought; it is how prior assumptions stabilize inverse inference.
  • It links scientific machine learning with classical computational mathematics rather than replacing regularization theory.

Practical Caution

Learning a regularization parameter does not eliminate the need to understand the prior. A network-selected parameter can still encode the wrong bias if the training inverse problems differ from the ones you apply it to.

Takeaway

The first-principles lesson is that inverse problems need stabilizing assumptions. Sparsity and learned regularization are ways to encode those assumptions at scale.
