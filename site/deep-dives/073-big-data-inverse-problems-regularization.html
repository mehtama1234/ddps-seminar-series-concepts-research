Talk 73 · Emory University

Matthias Chung: Big Data Inverse Problems

This lecture explains sparse inverse problems at big-data scale and shows how variable projection and neural networks can help choose regularization for stable reconstruction.

YouTube source · Talk page

Core Problem

Inverse problems seek hidden causes from indirect measurements, but they are often ill-posed: many solutions fit the data, noise is amplified, and large data volumes make classical inference expensive. Sparsity helps, but L1-regularized problems introduce difficult choices such as regularization parameters and optimization strategy.

First-Principles Model

An inverse problem balances data fidelity with prior structure. Sparsity says the unknown quantity is simple in some vector space or dictionary, so L1 regularization promotes sparse reconstructions. Variable projection reduces coupled optimization by analytically or implicitly eliminating variables, while learned regularization uses DNNs to infer stabilizing hyperparameters from data or problem features.

Key Claims

  • Modern data analytics, ML, and UQ depend on efficient inverse-problem solvers.
  • Growing model complexity and data volume exceed the limits of many existing inference methods.
  • Many inverse problems aim to reconstruct quantities with sparse representations.
  • L1 regularization is widely useful in compressed sensing, dictionary learning, and imaging.
  • Variable projection provides a new route for sparse inverse optimization.
  • Deep neural networks can be used to obtain regularization parameters for solving inverse problems.

Important Terms

Inverse Problem

A problem of inferring unknown causes, fields, or parameters from observed effects.

Ill-Posed Problem

A problem where solutions may not exist, be unique, or depend stably on the data.

Sparse Representation

A representation where only a small number of coefficients are nonzero or important.

L1 Regularization

A penalty on absolute coefficient values that promotes sparse solutions.

Variable Projection

An optimization technique that eliminates some variables to reduce or stabilize the remaining problem.

Connections Across The Series

  • This lecture connects to inverse scattering, adaptive ROMs, and Bayesian calibration across the series.
  • It also clarifies why regularization is not a tuning afterthought; it is how prior knowledge stabilizes inverse inference.
  • It links SciML with classical computational mathematics rather than replacing regularization theory.

Practical Caution

Learning a regularization parameter does not eliminate the need to understand the prior. A DNN-selected parameter can still encode the wrong bias if the training inverse problems differ from deployment.

Takeaway

The first-principles lesson is that inverse problems need stabilizing assumptions. Sparsity and learned regularization are ways to encode those assumptions at scale.
