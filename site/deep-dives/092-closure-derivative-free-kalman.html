Talk 92 · University of Wisconsin-Madison

Jinlong Wu: Data-Driven Closure Modeling Using Derivative-Free Kalman Methods

This lecture shows how to use derivative-free Kalman methods (techniques that update estimates without computing derivatives) to learn what happens to a system's large-scale variables when small-scale details can't be tracked, using limited and indirect measurements.

YouTube source · Talk page

Core Problem

Real systems like turbulent flows and cloud formation have far too many moving parts to track every single one. Instead, you have to describe what the small-scale details do to the large-scale flow you can see—this description is the closure model. But making good closures is hard: traditional methods don't capture the real physics well enough, they need to be tuned by hand for each case, and learning from data gets even harder when measurements are indirect, sparse, or noisy.

First-Principles Model

A closure takes what you can observe directly—the large-scale variables—and predicts what the unobserved small-scale motion does to them. Kalman inversion methods treat the unknown parts of the closure as hidden states and update them using ensemble-based data assimilation, which means combining many parallel estimates to gradually fit them to the data without ever computing derivatives. This lets you learn closures from measurements that don't directly show what you want to learn, and it extends the method from simple deterministic closures to richer ones that include randomness and sparsity.

Key Claims

  • Closure models are essential in complex systems because simulating every tiny motion is impossible.
  • Current closure models are not good enough, partly because they can't capture enough detail and partly because hand-tuning each one is impractical.
  • Derivative-free Kalman methods can learn closure models even from measurements that don't directly show closure behavior.
  • This approach works for simple deterministic closures.
  • The same method also handles sparse identification—picking out which terms in the equations actually matter.
  • Derivative-free Kalman inversion can even learn closures with randomness built in, from indirect measurements.

Important Terms

Closure Model

A description of how the small-scale motion you can't track affects the large-scale motion you can see.

Derivative-Free Kalman Method

A way to update estimates using many parallel copies of the system, comparing them to real data, without ever calculating derivatives.

Indirect Data

Measurements of one thing that you use to infer something else—like measuring wind speed at one height to understand turbulence you can't see directly.

Sparse Identification

Learning what equation or closure describes a system by finding which terms are active and which can be ignored.

Stochastic Closure

A closure model that includes randomness—describing not just the average effect of small-scale motion, but its unpredictable part too.

Connections Across The Series

  • This lecture builds on the closure ideas from LES (large-eddy simulation), reduced-order models, and structure-preserving closures discussed earlier in the seminar.
  • It uses data assimilation—the practice of blending measurements with models—in the same way that Kalman filters do, but to learn closure parameters instead of just estimating state.
  • It connects to SINDy and sparse system identification, which are methods to learn simple, interpretable equations and closures from data.

Practical Caution

Derivative-free methods skip the work of computing derivatives, but they don't fix the deeper problem of identifiability: if your indirect measurements are weak, many completely different closure models might fit the data equally well. You need to check whether the learned model is actually unique.

Takeaway

The underlying principle is this: closure learning is really just inference from incomplete evidence. Kalman-based methods give you a way to do that inference without gradients—useful when your data never directly show the closures you're trying to learn.
