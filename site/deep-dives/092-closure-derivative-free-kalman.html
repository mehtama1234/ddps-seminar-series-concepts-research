Talk 92 · University of Wisconsin-Madison

Jinlong Wu: Data-Driven Closure Modeling Using Derivative-Free Kalman Methods

This whole series is about getting computers to predict how physical things behave by learning from examples instead of hand-written math. When you can't track every tiny detail—like every swirl in turbulent air or every water droplet in a cloud—you need a stand-in that says what those small, invisible details do to the big patterns you can see. This talk shows one way to learn that stand-in from real measurements: a method that updates guesses by running many parallel copies of your system and comparing them to what actually happened, without needing to compute how sensitive your answer is to each dial you turn.

YouTube source · Talk page

Core Problem

Real systems like turbulent flows and clouds have far too many tiny parts to track at once. Engineers handle this by writing a stand-in—a description that says what all those untracked small parts do to the big-scale flow you can see. Making a good stand-in is hard: the traditional hand-built ones miss real physics, need to be tuned differently for each case, and learning from data gets even harder when your measurements are indirect, scattered, or noisy.

First-Principles Model

A stand-in takes what you can observe directly—the large-scale variables—and predicts what the unobserved small-scale motion does to them. One approach treats the unknown parts of the stand-in as hidden pieces and updates them by using many parallel copies of your system (ensemble-based assimilation, meaning you blend many estimates together to gradually match the real data). This works without ever computing how sensitive the answer is to each input, so you can learn stand-ins from measurements that don't directly show what you want to learn. It even extends to richer stand-ins that include randomness, and to picking out which terms in an equation actually matter.

Key Claims

  • Stand-ins are essential in complex systems because simulating every tiny motion is impossible.
  • Current stand-ins are not good enough, partly because they can't capture enough detail and partly because hand-tuning each one for a new case is impractical.
  • Methods that skip computing sensitivities can learn stand-ins even from measurements that don't directly show stand-in behavior.
  • This approach works for deterministic stand-ins.
  • The same method also picks out which terms in the equations actually matter (sparse identification).
  • Methods that skip computing sensitivities can learn stand-ins that include randomness, from indirect measurements.

Worked Example

Turbulence closure modeling: flow over periodic hills with Reynolds-averaged Navier-Stokes; sparse measurement of resolved velocity field to estimate full-field Reynolds stress discrepancy. Prior distribution on stress difference via Gaussian process with Karhunen-Loève basis function expansion. Posterior velocity distribution achieves much better agreement with DNS (high-fidelity simulation) in recirculation regions. L1 error of radial distribution function (test metric not used in training) demonstrates viability. Example shows shift from scattered prior velocity profiles to concentrated posterior profiles matching ground truth.

One Level Deeper

Ensemble Kalman inversion (EKI) iterative update formula: for ensemble index j and EKI step m, normalize data mismatch (difference between forward map output and observations) using covariance in data space and parameter space, project normalized mismatch back to parameter space via cross-covariance matrix to adjust parameter estimates. Prior constructed as Gaussian random field with covariance parameterized by field-varying variance (sigma as function of spatial coordinates). Basis functions from Karhunen-Loève expansion allow linear combination to parametrize closure model. Sparse, indirect observation data (point velocity measurements) drive Bayesian inference toward posterior parameter distribution.

Failure Boundary

Model form error: basis function restrictions may not span true closure model space, leading to persistent discrepancy between optimal posterior and DNS truth despite improved fit. Sparsity of spatial measurements affects performance; dense measurements in fringe/recirculation regions needed for accurate parameter recovery. Computational cost of matrix inversion scales with data space dimension; mitigation via localization (threshold long-range covariances, keep sparse matrix structure). Assumption that closure term depends only on spatial coordinates (not velocity history) limits scope; extension to velocity-dependent formulations mentioned but more complex.

Important Terms

Closure Model

A description of how the small-scale motion you can't track affects the large-scale motion you can see. Think of it as a stand-in that captures the effect of all those invisible details.

Derivative-Free Kalman Method

A way to update estimates by running many parallel copies of your system and comparing all of them to real data, gradually shifting them until they match—without ever computing how sensitive each answer is to each input dial.

Indirect Data

Measurements of one thing that you use to infer something else you can't measure directly—like measuring wind speed at one height to understand turbulence you can't see.

Sparse Identification

Learning which terms in an equation or stand-in are active (matter) and which can be ignored, so you end up with a simple, understandable description.

Stochastic Closure

A stand-in that includes randomness—describing not just the average effect of small-scale motion, but its unpredictable part too.

Connections Across The Series

  • This lecture builds on closure ideas from large-eddy simulation (watching only the big swirls and modeling what the tiny ones do), reduced-order models (describing a complex system with fewer moving parts), and structure-preserving stand-ins discussed earlier in the seminar.
  • It uses data assimilation—the practice of blending real measurements with a model to gradually correct it—in the same way that Kalman filters do, but to learn stand-in parameters instead of just estimating current state.
  • It connects to SINDy and sparse system identification, which are methods to learn simple, interpretable equations and stand-ins directly from data.

Practical Caution

Skipping the derivative calculations saves work, but it doesn't solve the deeper problem of identifiability: if your measurements are weak or indirect, many completely different stand-ins might fit the data equally well. You need to check whether the learned model is truly the only one that works.

Takeaway

At heart, learning a stand-in is just inference from incomplete information. Methods based on Kalman's approach give you a way to do that inference without computing sensitivities—useful when your data never directly show the stand-ins you're trying to learn.
