Talk 27 · Sandia National Laboratories

Marta D'Elia: Data-Driven Learning Of Nonlocal Models

This series is about getting computers to predict how physical things behave by learning from examples instead of hand-written math. This talk focuses on a harder case: materials and systems where distant particles reach out and influence each other, not just neighbors touching. The problem is figuring out the right weight to give each distant effect so that a simplified model (which ignores tiny details) still predicts the big-picture results. This talk shows how to learn those weights from high-resolution data.

YouTube source · Talk page

Core Problem

Most everyday math treats change as local: what happens at one spot depends only on what's right there. But many real materials and complicated systems break this rule—a particle feels the tug of others far away, not just its neighbors. You can write down a new kind of math rule using integrals (adding up weighted contributions) to capture this spread-out influence, but you have to guess what those weights are. This talk is about pulling those weights from real, fine-grained measurements of how the system actually behaves.

First-Principles Model

A nonlocal operator works by adding up effects from all the other pieces touching or nearby, each effect weighted by how far away it is. The weighting function (called the kernel) is the recipe—it says which distant partners matter most and by how much. When you train this on pairs of detailed measurements (what you see) and what forces caused the change, you get a simplified model that predicts large-scale results without simulating every tiny detail.

Key Claims

  • Nonlocal models build distance scales directly into addition operators that span regions.
  • They work well when small-scale activity drives overall results but is too expensive to compute directly.
  • The real job is finding the weighting function that defines how influence spreads over distance.
  • Peridynamic operators generalize nonlocal ideas to solid mechanics by including material properties.
  • Learning programs designed to learn operators can speed up simulations of molecular motion and problem-size reduction.
  • Nonlocal weighting ideas inspire new designs for neural-network layers that respect how physics works.

Important Terms

Nonlocal Model

A math rule where the state at one point is affected by values spread across a region, not just what's at that one spot.

Kernel Function

A rule that assigns weights to how much each distance and direction affects the total influence in a spread-out operator.

Coarse-Grained Model

A simplified model that correctly predicts large-scale results without tracking every small-scale detail.

Peridynamics

A mechanics theory that describes how materials behave by tracking forces traveling over distance, rather than only pointwise stress.

Nonlocal Kernel Network

A learning program design inspired by learnable nonlocal weightings, where each layer computes weighted averages across a neighborhood.

Connections Across The Series

  • This talk ties together fractional calculus, network graphs with learned connections, and operator learning all through the common idea of spread-out interaction.
  • It extends the many-scales-working-together theme by replacing the need to simulate fine details with learned operators that copy their effects.
  • It also touches on understanding what learning programs actually learned because inspecting learned weightings can reveal the underlying physical interaction rules.

Practical Caution

A learned weighting only captures real physics if your training examples actually exercise all the important long-range effects and if your chosen weighting shape can truly match the real physical law. Otherwise you have a model that fits your training examples but fails on new situations it hasn't seen.

Takeaway

The central idea is learning the interaction law—the rule for how distant parts push and pull on each other—not just curve-fitting to numbers. The weighting function bridges the gap between small-scale behavior and large-scale prediction.
