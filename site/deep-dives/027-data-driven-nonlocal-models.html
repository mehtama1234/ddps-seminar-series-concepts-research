Talk 27 · Sandia National Laboratories

Marta D'Elia: Data-Driven Learning Of Nonlocal Models

This lecture explains how data-driven learning can identify nonlocal kernels that bridge unresolved small-scale dynamics and coarse-grained global behavior.

YouTube source · Talk page

Core Problem

Classical PDEs are local, but many materials and multiscale systems depend on small-scale interactions that are too expensive to resolve directly. Nonlocal models can represent those effects through integral operators, but their kernels are often unknown and must be learned from high-fidelity data.

First-Principles Model

A nonlocal operator computes a state change from interactions over a finite neighborhood rather than a pointwise derivative. The kernel determines the strength and shape of those interactions. Learning the kernel from paired solution and forcing data produces a coarse-grained model that captures global behavior without explicitly resolving all small scales.

Key Claims

  • Nonlocal models embed length scales directly in integral operators.
  • They are useful when small-scale dynamics influence global behavior but are too expensive to resolve.
  • The key inverse problem is learning the kernel function defining the nonlocal operator.
  • Peridynamic solid operators extend nonlocal ideas to mechanics with material properties.
  • Operator-learning tools for nonlocal equations can help homogenization and molecular-dynamics surrogate design.
  • Nonlocal kernel ideas can also guide new neural-network architectures.

Important Terms

Nonlocal Model

A model where the state at a point depends on values over a neighborhood rather than only local derivatives.

Kernel Function

The function that weights interactions across distances in a nonlocal operator.

Coarse-Grained Model

A model that represents large-scale behavior without explicitly resolving every small-scale detail.

Peridynamics

A nonlocal mechanics theory that models material behavior through finite-distance interactions.

Nonlocal Kernel Network

A neural architecture inspired by learnable nonlocal kernel operators.

Connections Across The Series

  • This talk connects fractional operators, graph networks, and operator learning around the theme of nonlocal interaction.
  • It extends the multiscale-coupling theme by replacing explicit fine-scale resolution with learned coarse-grained operators.
  • It also relates to mechanistic interpretability because learned kernels can be inspected as physical interaction laws.

Practical Caution

A learned nonlocal kernel is only meaningful if the training data excites the relevant interactions and the chosen kernel family can represent the true coarse physics. Otherwise the model may fit observations without giving a reliable bridge across scales.

Takeaway

The first-principles lesson is that nonlocal learning tries to learn the interaction law, not only the response. The kernel is the bridge between scales.
