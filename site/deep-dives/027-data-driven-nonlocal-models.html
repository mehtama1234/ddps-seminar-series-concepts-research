Talk 27 · Sandia National Laboratories

Marta D'Elia: Data-Driven Learning Of Nonlocal Models

This lecture shows how to use data to find the right nonlocal kernels—mathematical descriptions of how far-away particles influence each other—so that a coarse model can capture the effects of tiny details it doesn't explicitly track.

YouTube source · Talk page

Core Problem

Normal differential equations work locally: they say a change at one point depends only on what's happening right there. But many materials and systems that involve multiple scales don't follow this rule—tiny interactions far away matter. You can build models using integrals over a region instead of just local derivatives, but you need to know what weights those distant interactions. Those weights must be learned from real, high-resolution data.

First-Principles Model

A nonlocal operator computes how a state changes by adding up influences from all points within a certain distance, using a weighted sum. The kernel is the weighting function—it determines which distant neighbors matter most. When you train this on pairs of high-resolution data (what you observe) and what forces caused it, you get a coarse model that reproduces the large-scale results without having to simulate every tiny detail.

Key Claims

  • Nonlocal models build length scales directly into integral operators.
  • They work well when tiny-scale behavior drives global results but is too expensive to compute directly.
  • The real problem to solve is finding the kernel function that defines the nonlocal operator.
  • Peridynamic operators extend nonlocal ideas to solid mechanics by including material properties.
  • Neural networks designed to learn operators can help speed up molecular-dynamics simulations and coarse-graining.
  • Nonlocal kernel ideas suggest new ways to design neural-network layers that respect physical structure.

Important Terms

Nonlocal Model

A mathematical model where the state at any point depends on values spread across a region, not just on a single point's properties.

Kernel Function

A function that assigns weights to how much each distance contributes to an interaction in a nonlocal operator.

Coarse-Grained Model

A simplified model that reproduces large-scale behavior accurately without tracking every small-scale detail.

Peridynamics

A mechanics theory that describes materials by how forces travel over finite distances, instead of using only pointwise stresses.

Nonlocal Kernel Network

A neural-network design inspired by learnable nonlocal kernels, treating layers as learnable weighted-average operations across neighborhoods.

Connections Across The Series

  • This talk brings together fractional calculus, graph neural networks, and operator learning through the common idea of nonlocal interaction.
  • It builds on the multiscale-coupling theme by replacing the need to resolve fine details with learned operators that mimic their effects.
  • It also touches on mechanistic interpretability because inspecting learned kernels can reveal the underlying physical interaction rules.

Practical Caution

A learned kernel only tells you something real if your training data actually exercises all the important interactions and your choice of kernel shape can actually match the true physics. Otherwise you get a model that matches your data but doesn't reliably transfer to new problems.

Takeaway

The big idea is that nonlocal learning tries to discover the interaction law—the rule for how distant parts influence each other—not just fit a curve to outputs. The kernel is the bridge connecting small scales to large scales.
