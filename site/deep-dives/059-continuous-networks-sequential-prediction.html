Talk 59 · University of Pittsburgh

Ben Erichson: Continuous Networks For Sequential Predictions

This lecture treats recurrent neural networks for time-series prediction as discretized dynamical systems (equations describing how a system changes over time) and shows how numerical integration methods, stochastic differential equations, and multiscale ODEs (ordinary differential equations with fast and slow dynamics) improve accuracy and long-term sequential modeling.

YouTube source · Talk page

Core Problem

Sequential prediction models are deployed in scientific settings such as fluid dynamics and climate modeling, where accuracy and reliability matter. Standard recurrent units can be sensitive to small changes in the input and may not capture the continuous-time structure of the underlying physical system.

First-Principles Model

A recurrent network can be understood as a time-discretized dynamical system (a rule for evolving a system broken into discrete time steps). Once viewed this way, numerical analysis becomes architecture design: forward Euler resembles a simple residual update, higher-order integrators such as explicit midpoint can improve accuracy by evaluating slopes at intermediate points, adding stochastic differential equations adds random forcing for stability, and multiscale ODEs can represent long-term dependencies that evolve at different speeds.

Key Claims

  • Time-series neural networks can be analyzed through the lens of dynamical systems (equations describing how a system evolves).
  • Out-of-the-box deep networks may not be suitable for mission-critical scientific applications because they can be sensitive to small input changes.
  • Continuous-time recurrent neural networks can be more reliable and accurate than traditional recurrent units.
  • Classical numerical time integration methods can improve neural sequential prediction.
  • Explicit midpoint integration can outperform simpler forward Euler discretization by using more slope information.
  • Connections to stochastic differential equations (equations with random terms) and multiscale ODEs support reliable long-term sequence modeling.

Important Terms

Continuous-Time Recurrent Network

A recurrent architecture based on an underlying continuous-time dynamical system before it is broken into discrete time steps.

Forward Euler

A first-order numerical time integration method that advances a state using one slope evaluation per time step.

Explicit Midpoint

A higher-order time integration method that evaluates the slope at the midpoint of a time step to improve accuracy.

Stochastic Differential Equation

A differential equation that includes random or diffusion terms in addition to deterministic changes.

Multiscale ODE

An ordinary differential equation representation where dynamics operate across multiple time scales, with some changes happening quickly and others slowly.

Connections Across The Series

  • This lecture connects neural architecture design to numerical methods, a recurring theme in physics-informed neural networks and neural ODE talks.
  • It also complements structure-preserving mechanics and differentiable programming by treating learning models as dynamical systems.
  • It gives a stability-focused alternative to purely empirical sequence-model design.

Practical Caution

A recurrent model's time discretization is part of the model itself. Changing the time step size, the integration method, or the noise level can change stability and robustness, so sequential models need numerical validation before deployment.

Takeaway

The first-principles lesson is that sequence models are numerical dynamical systems. Better scientific architectures come from better discretization (breaking continuous dynamics into time steps) and stability thinking.
