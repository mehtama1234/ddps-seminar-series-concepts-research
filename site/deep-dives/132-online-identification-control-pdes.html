Talk 132 · Sapienza University of Rome

Alessandro Alla: Data-Driven Algorithms for Online Identification and Control of Partial Differential Equations

This lecture shows algorithms that learn unknown PDE parameters at the same time they control the system.

YouTube source · Talk page

Core Problem

PDE control usually assumes you know all the parameters and have complete information, but real systems have unknown coefficients, unknown starting conditions, sparse measurements at the boundary, or limited observations. The controller must make decisions while simultaneously learning what the system actually is.

First-Principles Model

In the first case, assume the PDE produces measurements from a control input and starting condition. The controller begins with an initial guess for the parameters and computes control actions using the State-Dependent Riccati Equation (a method that adapts control design to systems where behavior depends on the current state). After each step, the observed trajectory updates the parameter estimates using Bayesian linear regression (a statistical method that treats parameters as quantities with uncertainty and updates them as new data arrive) until a stopping rule is met. In the second case, the method uses physics-informed neural networks (neural networks trained to respect physics equations) to handle incomplete information such as unknown starting conditions, sparse boundary measurements, and unknown PDE coefficients.

Key Claims

  • The goal is to identify and control PDEs with unknown parameters in real time.
  • One scenario assumes you can observe the PDE state given a control input and starting condition.
  • The State-Dependent Riccati Equation produces a control rule from the current parameter estimate.
  • Observed trajectories are used to repeatedly refine the parameter estimate.
  • Bayesian linear regression gives a data-driven way to update parameters with uncertainty.
  • Physics-informed neural networks are used when the available information is incomplete.

Important Terms

Online Identification

Estimating model parameters while the system is running and data are arriving.

PDE Control

Choosing inputs to guide systems whose behavior is described by partial differential equations.

State-Dependent Riccati Equation

A method to design control that adapts the solution at each state, generalizing classical Riccati methods to systems where the equations depend on the current state.

Bayesian Linear Regression

Linear regression where parameters are treated as uncertain quantities that shift as you gather more data.

Physics-Informed Neural Network

A neural network trained by enforcing physics equations as constraints alongside data fitting.

Connections Across The Series

  • This talk brings together control theory, online learning, Bayesian updating, and physics-informed neural networks.
  • It extends flow-control and reduced-order-model control lectures by treating model uncertainty as something the controller must handle actively.
  • It also connects to adaptive digital twins because the model evolves as the system runs.

Practical Caution

Online identification can make control unstable if parameter updates are noisy or delayed. The system that learns and controls must include safeguards, stopping rules, and control decisions that account for uncertainty in the current parameter estimate.

Takeaway

The central lesson is that controlling a PDE with unknown parameters requires learning and control to run together as a single closed loop.
