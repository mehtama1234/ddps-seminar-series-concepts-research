Talk 132 · Sapienza University of Rome

Alessandro Alla: Data-Driven Algorithms for Online Identification and Control of Partial Differential Equations

This whole series is about teaching computers to predict and control physical systems by learning from data. This talk focuses on a harder problem: what if the system is governed by rules (called PDEs—equations that describe how things like heat, fluid flow, or vibrations change across space and time) but you don't know all the numbers that go into those rules? This talk shows how to learn those missing numbers while simultaneously steering the system where you want it to go.

YouTube source · Talk page

Core Problem

Controlling systems described by PDEs usually assumes you already know every coefficient and number in the governing equations and that you can measure the entire system perfectly. But real systems are messier: some numbers are unknown or change over time, you might only have sensors at boundaries or scattered locations, starting conditions are hidden, or measurements arrive with noise. A controller has to make steering decisions moment by moment while simultaneously figuring out what the system actually is—working with incomplete information.

First-Principles Model

The first approach assumes the PDE (a rule showing how something changes moment to moment and place to place) connects your control input and starting state to the measurements you observe. Start with a rough initial guess for the unknown numbers. At each time step, compute control actions using the State-Dependent Riccati Equation—a recipe that automatically adjusts the steering strategy based on the current state of the system (like how you steer a car differently depending on whether you are going fast or slow). After each step, feed the new observations into Bayesian linear regression, a technique that treats each unknown number as having some uncertainty and updates your guess as new data arrive, refining your estimate. Keep updating until a stopping rule says you know enough. In the second approach, replace the classical equations with a neural network (a program with millions of little dials you tune by trial and error until its answers look right) trained to respect the physics equations even when you have incomplete or scattered measurements—unknown starting conditions, sparse sensor readings at boundaries, or missing coefficients.

Key Claims

  • Identifying and controlling PDEs with unknown parameters must happen at the same time, in real time.
  • One method assumes you observe the PDE's behavior when you apply a control input and starting condition.
  • A recipe called the State-Dependent Riccati Equation uses your current parameter estimate to generate steering actions.
  • Measurements flowing in update and improve your parameter estimate repeatedly as time passes.
  • Bayesian linear regression offers a data-driven way to revise unknown numbers, accounting for uncertainty.
  • Neural networks trained to obey physics equations work when you have incomplete information or scattered measurements.

Worked Example

Viscous Burgers equation (ν=0.5 or 0.05, μ²=unknown, control u): state-dependent receding-horizon optimal control. Library {diffusion, advection, Burgers nonlinearity} = 7 parameters to identify via Bayesian linear regression on 121 discrete states. CPU solver 1.0s (reference optimal u₁), RL identification+control ~1.05s (suboptimal u_RL). Parameter convergence monotonic, cost functional ≈0.3 error vs 0.23 reference. Allen-Cahn (cubic nonlinearity, 2 scenarios: ν=0.1 μ=1 vs ν=1 μ=11): identifies diffusion from 12 uncontrolled data points + 12 boundary constraints only. Error in identified parameters <2% for easy case, 5-7% for stiff case.

Physics-Informed Neural Network control (Burgers parabolic regime): 10 data points + 18 sparse boundary sensors, no initial condition. Identifies dynamics + solves optimal tracking PDE in two-stage network architecture (uncontrolled identification stage, then control stage). Final-time control error 10^-2–10^-3. CPU solver vs PINN accuracy difference 1-2%, but PINN computes joint λ(t) end-to-end without solving algebraic Riccati backward in time.

One Level Deeper

Online identification via state-dependent receding horizon: freeze current state x_i → solve state-dependent C equation Π(x_i)A(x_i) + A(x_i)^T Π(x_i) - Π(x_i)B(x_i)R^{-1}B(x_i)^T Π(x_i) + Q = 0 → extract feedback gain K(x_i) = R^{-1}B(x_i)^T Π(x_i) → apply u(t_i) = -K(x_i)x(t_i). Dynamics identified via library regression: observe trajectory y(t), solve min ||ẏ - [a_j(y)·μ_j]||²_2 using Bayesian regression (covariance-weighted least squares).

Failure Boundary

The library-regression approach only works if the user-supplied candidate terms {a_j} actually contain the true dynamics; a missing essential term makes the identified system uncontrollable and the state-dependent Riccati equation unsolvable, so the practitioner observes the feedback gain diverging or the controller failing to stabilize rather than a graceful accuracy loss. Because identification is done on-the-fly from a single observed trajectory (not repeated rollouts), poorly-excited inputs leave some parameters unidentifiable and the estimate stalls at the wrong value.

PINN control degrades sharply for advection-dominated (low-viscosity) and stiffer nonlinear regimes (e.g., Allen-Cahn with large reaction coefficient), where identified-parameter error climbs to 5-7% and final-time tracking error saturates around 10^-2–10^-3—never beating a classical numerical solver on accuracy or speed. For 2D/3D PDEs the coupled state-adjoint-control system becomes very expensive and convergence is fragile (Adam plateaus, needing L-BFGS or SOAP), so PINNs are only worth it when boundary/initial conditions or the state equation are genuinely unknown and standard numerical methods cannot be applied.

Important Terms

Online Identification

Guessing unknown numbers that describe a system while the system is already running and new data keep arriving, so your guess improves continuously.

PDE Control

Choosing inputs to steer a system whose behavior is defined by equations showing how things change across space and time.

State-Dependent Riccati Equation

A recipe for designing steering actions that automatically shifts its strategy as the system's current condition changes, adapting moment by moment.

Bayesian Linear Regression

A way to guess unknown numbers where you start unsure, treat each guess as having some wiggle room, and shrink that wiggle room as more data arrives.

Physics-Informed Neural Network

A program with millions of dials tuned by trial and error to match data while also obeying the laws of physics written as equations.

Connections Across The Series

  • This talk weaves together ideas from control theory (steering systems), online learning (improving as data arrives), updating beliefs with new evidence (Bayesian thinking), and neural networks trained to obey physics.
  • It builds on earlier talks about steering fluid flow and reduced-order models by treating uncertainty in the model itself—something the controller must actively handle and learn.
  • It also connects to digital twins (a virtual copy of a system that stays in sync with the real thing as both change together) because the model updates as the system runs.

Practical Caution

Identification happening live—while the system is running—can destabilize control if parameter updates arrive noisy or delayed. The system that learns must have safeguards built in: rules for when to stop learning, controls that account for uncertainty in the current parameter guess, and checks to prevent wild swings from early mistakes.

Takeaway

Steering a PDE with unknown numbers is not a one-then-the-other process—learn first, control second. Instead, learning and control must run together as a single closed loop, each informing the other.
