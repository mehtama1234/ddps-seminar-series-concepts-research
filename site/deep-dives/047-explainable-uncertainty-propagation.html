Talk 47 · TU Delft

Alice Cicirello: Interpretable, Explainable And Non-Intrusive Uncertainty Propagation

This lecture explains how machine-learning-based optimization can propagate interval uncertainty through expensive black-box engineering models while preserving interpretability, explainability, and non-intrusiveness.

YouTube source · Talk page

Core Problem

Engineering decisions depend on whether a system satisfies performance bounds under uncertainty, but high-fidelity physics models can be expensive to evaluate. Standard uncertainty propagation may require too many model runs or intrusive changes to the solver, making it impractical for expensive engineering simulations.

First-Principles Model

Uncertainty propagation asks how uncertain inputs map through a computational model into uncertain performance outputs. A non-intrusive method treats the simulator as a black box and chooses a small number of evaluations. Machine-learning optimization, especially Bayesian optimization-style sampling, can search for output bounds while explanations and interpretable surrogate structure help humans understand why those bounds arise.

Key Claims

  • Uncertainty quantification supports decisions by estimating how input uncertainty affects system performance.
  • For expensive-to-evaluate models, the main bottleneck is selecting as few physics-model runs as possible.
  • Non-intrusive methods avoid modifying the simulator or simplifying the underlying physics.
  • Interpretability asks whether a human can understand how a prediction was made.
  • Explainability asks whether results are presented in a form that humans can use.
  • Machine-learning optimization can target performance bounds rather than densely sampling the full input space.

Important Terms

Uncertainty Propagation

Computing how uncertainty in model inputs affects uncertainty in model outputs or performance metrics.

Non-Intrusive Method

A method that uses an existing simulator as a black box without altering its equations or implementation.

Interval Uncertainty

Uncertainty represented as ranges of possible values rather than full probability distributions.

Bayesian Optimization

A sample-efficient optimization method that uses a probabilistic surrogate to choose informative evaluations.

Performance Bound

An upper or lower limit on a quantity of interest under uncertain inputs.

Connections Across The Series

  • This talk connects to the series' uncertainty theme and gives a decision-oriented version of surrogate modeling.
  • It also links to active learning because both select evaluations strategically under expensive data generation.
  • It complements interpretability talks by defining explanation as a requirement for engineering uncertainty decisions.

Practical Caution

A non-intrusive UQ method can miss true extremes if the sampling strategy or surrogate is overconfident. Performance bounds should be treated as certified only when the search and validation assumptions justify them.

Takeaway

The first-principles lesson is that UQ is a decision problem under computational scarcity. The method must choose simulations efficiently and explain the resulting bounds clearly.
