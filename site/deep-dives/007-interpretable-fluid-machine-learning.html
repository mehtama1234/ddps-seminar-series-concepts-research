Talk 7 · University of Washington

Steven Brunton: Interpretable And Generalizable Machine Learning For Fluid Mechanics

This lecture argues that fluid ML should prefer parsimonious, interpretable, physically meaningful models that generalize beyond the data distribution.

YouTube source · Talk page

Core Problem

Fluid mechanics produces high-dimensional data and expensive simulations, but black-box prediction alone is not enough. A model can reproduce seen trajectories while failing under new regimes, controls, geometries, or parameters if it has not captured the sparse physical structure behind the flow.

First-Principles Model

Many fluid systems are high-dimensional in measurement space but lower-dimensional in the right coordinates, and their governing dynamics often use only a sparse subset of possible terms. Interpretable ML tries to discover those coordinates, active terms, closures, or discrepancy corrections rather than learning an opaque input-output map.

Key Claims

  • Machine learning for engineering can be viewed as optimization and regression over rich data.
  • Generalization requires more than fitting trajectories; models should capture simple structure where it exists.
  • The principle of parsimony motivates sparse models: as simple as possible, but no simpler.
  • Sparse Identification of Nonlinear Dynamics (SINDy) learns governing equations from measured states and derivatives.
  • Choosing the right coordinate system can turn a high-dimensional fluid problem into a low-dimensional model.
  • ML can also focus on discrepancy modeling: learning the mismatch between an imperfect physical model and observed dynamics.

Important Terms

Parsimony

The modeling principle that a useful explanation should use the simplest structure sufficient to describe the phenomenon.

SINDy

Sparse Identification of Nonlinear Dynamics, a method that selects a small number of active terms from a library of candidate dynamics.

Sparse Regression

Regression that encourages most candidate coefficients to be zero, leaving only the important terms.

Coordinate Discovery

Finding variables in which complicated high-dimensional dynamics become simpler.

Discrepancy Modeling

Learning the mismatch term between an approximate physical model and the true observed system.

Connections Across The Series

  • This is the conceptual bridge between ROMs, operator inference, and scientific ML: learn structure, not just outputs.
  • It connects to later surrogate and closure talks because closures are often discrepancy models for unresolved physics.
  • It also gives a benchmark for interpretability: can the learned object be inspected as equations, modes, balances, or correction terms?

Practical Caution

A neural model that forecasts fluid snapshots may still be scientifically weak if it does not expose the variables, balances, or closure terms driving the flow. Generalization should be tested under changed regimes, not only interpolation.

Takeaway

The lecture's first-principles message is that interpretability is not cosmetic. In fluids, interpretable structure is often what makes out-of-distribution generalization possible.
