Talk 133 · Georgia Tech

Raphael Pestourie: Input-Space Scientific Machine Learning for PDE-Constrained Optimization of Geometries

This lecture proposes input-space scientific ML, where learned models speed up PDE-driven design by learning solver inputs rather than relearning the PDE solution.

YouTube source · Talk page

Core Problem

Most SciML methods learn the PDE solution directly, forcing the model to relearn physical laws already built into the numerical solver. For geometry optimization, this wastes effort because the design variable is the input geometry and the solver already understands the governing PDE (the equations describing the physics).

First-Principles Model

Input-space SciML keeps the physics inside the numerical solver and learns transformations or surrogate structure in the solver input space. Physics-Enhanced Deep Surrogates (PEDS) speed up simulation of PDE-driven properties, while HiLAB supports efficient search through high-dimensional geometry design spaces for PDE-constrained optimization (finding the best shape when the quality is measured by running a PDE solver). The method is tested on benchmark PDEs and nanophotonic metasurface design.

Key Claims

  • Scientific ML can improve both simulation and optimization of PDE-governed properties.
  • Learning the PDE solution wastes effort by relearning laws already built into solvers.
  • Input-space SciML learns in the input space of a PDE solver.
  • The numerical solver stays responsible for the physics.
  • Physics-Enhanced Deep Surrogates speed up simulation of PDE-driven properties.
  • HiLAB enables efficient optimization across high-dimensional geometry spaces.

Important Terms

Input-Space SciML

Scientific ML that learns transformations of solver inputs while leaving the actual PDE solving to a numerical physics solver.

PDE-Constrained Optimization

Finding the best design when each candidate design must be evaluated by running a PDE (partial differential equation) solver.

Physics-Enhanced Deep Surrogate

A learned speedup model that replaces expensive simulation while keeping a real physics solver in the loop to stay accurate.

Geometry Optimization

Design optimization where you change the shape or physical form to improve some goal.

Metasurface

An engineered surface made of tiny repeated structures (smaller than the wavelength of light) that control how light behaves.

Connections Across The Series

  • This talk connects PDE-constrained design, differentiable solvers, inverse design, and scientific ML.
  • It complements neural PDE surrogate talks by arguing that the solver can stay as the physics engine.
  • It also links to materials and nanophotonics design where the geometry is the main input you can change.

Practical Caution

Input-space ML can be efficient, but the solver determines what physics gets simulated. If the solver model is incomplete, input-space learning will optimize against incomplete physics.

Takeaway

The key lesson is that for design problems, learning the input-to-solver interface can be more effective than learning the whole PDE solution.
