Talk 29 · Cornell University

Christopher Earls: Gaining Mechanistic Insight Through Learning Green's Functions

This lecture shows how learning Green's functions can turn observed system responses into interpretable solution operators (maps that convert inputs to outputs) for hidden PDEs.

YouTube source · Talk page

Core Problem

Deep networks can predict what a system does, but science requires understanding why. When the equation that governs the system is unknown, you can learn the solution operator, or Green's function, that maps sources to fields, then examine that operator to find physical structure hiding in the data.

First-Principles Model

For a linear PDE, a Green's function is the response to an impulse source. Once you have it, it acts as an integral kernel: you integrate the Green's function against a source to produce the solution. Learning this kernel from data gives a compact, interpretable operator that can suggest what PDE structure is hidden and which predictions you can test.

Key Claims

  • Observed system responses hold patterns that reveal hidden mechanistic structure.
  • The goal is not only to learn the PDE directly but to learn linear solution operators and compact integral kernels.
  • Green's functions provide a classical bridge between impulse response and PDE solution.
  • Deep learning can extend empirical Green's function ideas to new settings.
  • Extracted operators can be inspected for features suggesting hidden mechanisms.
  • The method is related to but distinct from broader neural operator approaches.

Important Terms

Green's Function

The response of a linear differential operator to an impulse, used as a kernel inside an integral to construct solutions.

Solution Operator

A map that takes forcing, sources, or inputs and produces the corresponding system response.

Integral Kernel

A function used inside an integral to convert input functions into output functions.

Hidden PDE

An unknown governing equation inferred indirectly from data, not written down in advance.

Mechanistic Insight

Understanding the physical or mathematical mechanism behind observed behavior, not just predicting it.

Connections Across The Series

  • This talk links operator learning with interpretability: the learned operator should teach us something about the hidden physics.
  • It connects to nonlocal kernels because both learn integral kernels from response data.
  • It also complements SINDy-style equation discovery by learning the solution operator rather than directly selecting PDE terms.

Practical Caution

A learned Green's function is most natural for linear or linearized systems. For strongly nonlinear regimes, the operator interpretation must be checked carefully or applied only near the conditions where you trained it.

Takeaway

The first-principles lesson is that an interpretable learned operator can be more scientifically useful than a pure predictor, because it points back toward the mechanism.
