Talk 84 · Vanderbilt University

Thomas Beckers: Physics-Enhanced Gaussian Processes For Electromechanical Systems

This lecture shows how to combine physics-enhanced Gaussian processes (a way to learn probability distributions over functions) with Port-Hamiltonian systems (models that respect energy conservation) so you can learn how electromechanical machines behave from data while keeping uncertainty estimates and staying physically correct without adding penalty tricks.

YouTube source · Talk page

Core Problem

Data-driven models for nonlinear electromechanical systems struggle with two problems: they need a lot of training data, and they can make physically impossible predictions if you don't tell them about known physics like energy conservation. Adding soft penalties during training can help, but the model can still violate physics or need a lot of tuning to behave well.

First-Principles Model

Gaussian processes describe a distribution over all possible functions and give you uncertainty estimates for any prediction. Port-Hamiltonian systems are a way to write down dynamics (how things change over time) that automatically respect energy flow, losses, and how parts connect. Combining them means building a Bayesian distribution over possible systems that obey Port-Hamiltonian structure, rather than treating dynamics as a single opaque learned function. Physics-enhanced variational autoencoders (models that learn compressed hidden representations) go further by putting a Gaussian process prior (a built-in guess about what dynamics should look like) with Green's-function structure (a way to encode how linear systems respond) on the hidden dynamics.

Key Claims

  • Data-driven electromechanical models should encode basic physical principles to use data efficiently and avoid impossible predictions.
  • Physics-enhanced Gaussian processes let you learn nonparametric Bayesian models (models that use data directly without assuming a fixed number of parameters) and track uncertainty.
  • Gaussian Process Port-Hamiltonian systems enforce physical correctness in their structure, not by penalizing violations during training.
  • GP-PHS uses data to form a probability distribution over different possible Port-Hamiltonian systems.
  • Physics-enhanced variational autoencoders use Gaussian process priors with Green's-function structure on hidden-layer dynamics.
  • Green's functions (which describe how a linear system responds to a sudden input) can encode prior knowledge about linear behavior into the process kernel (the mathematical object that defines distances between functions).

Important Terms

Gaussian Process

A Bayesian method that treats functions as random objects, giving you a distribution over possible functions and uncertainty for each prediction.

Port-Hamiltonian System

A way to write dynamics that explicitly tracks energy storage, dissipation (energy lost), and how subsystems connect to each other.

Physically Correct By Design

A model built so that physical laws are wired into its structure, rather than added as penalties or soft constraints.

Green's Function

A mathematical function showing how a linear system responds when you give it a single brief input; used to embed physics knowledge into the similarity measures that Gaussian processes use.

Latent Dynamics

The behavior that happens in a learned hidden layer or compressed representation, such as the code space of a variational autoencoder.

Connections Across The Series

Practical Caution

A physics-based structure only works if the real system actually follows that structure. If your physical assumptions don't match the true system, the model can be very confident in predictions that are systematically biased in the same wrong direction every time.

Takeaway

The key insight is that you can bake both Bayesian uncertainty and physical structure into the model architecture itself, instead of bolting physics on as a penalty after training.
