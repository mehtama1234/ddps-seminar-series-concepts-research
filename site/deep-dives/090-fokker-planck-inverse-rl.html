Talk 90 · University of Michigan

Krishna Garikipati: Fokker-Planck Inverse Reinforcement Learning

This lecture connects inverse reinforcement learning (inferring why an agent behaves as it does) with Fokker-Planck mean-field dynamics (how probability spreads in random systems) to infer both reward and transition functions from observed noisy trajectories.

YouTube source · Talk page

Core Problem

Inverse reinforcement learning tries to infer a reward function from observed agent behavior, but most IRL methods assume the transition function (the rule for how states change) is already known. In many scientific and biological systems, such as cancer cell dynamics, the transition rules themselves are hidden and must be figured out at the same time as the reward.

First-Principles Model

An MDP (Markov Decision Process: a model with states, actions, probabilities of state changes, rewards, and decision rules) describes how an agent makes choices. If agent motion in state-action space follows SDEs (stochastic differential equations: rules with random noise), then the resulting probability density (the likelihood of being in each state) evolves according to a Fokker-Planck equation (a differential equation for probability flow). The lecture proposes that time-discrete Fokker-Planck dynamics and MDP structure are mathematically equivalent, allowing FP-IRL to simultaneously infer the transition rules, reward values, and decision policy from observed trajectories using variational system identification (fitting a model by optimizing an objective function based on weak mathematical forms).

Key Claims

  • IRL estimates an unknown reward function from observed agent trajectories.
  • Most IRL methods require a transition function that is known or estimated beforehand.
  • When transition dynamics are unknown, inferring both reward and dynamics becomes much harder.
  • Random motion in state-action space can be represented at the average level by the Fokker-Planck equation.
  • A time-discrete Fokker-Planck to MDP correspondence can enable physics-aware IRL.
  • FP-IRL can simultaneously infer transition and reward functions from observed trajectories.

Important Terms

Inverse Reinforcement Learning

Finding the reward function that explains why an agent chooses the actions it does.

Markov Decision Process

A model with states (current situation), actions (choices), transition probabilities (odds of moving to the next state), rewards, and policies (rules for picking actions).

Fokker-Planck Equation

A differential equation that describes how a probability density (the spread of likely outcomes) changes over time in a random system.

Transition Function

The rule that says, given your current state and action, what are the odds of reaching each next state.

Variational System Identification

Discovering system rules by adjusting parameters to minimize a math objective based on weak forms of the equations.

Connections Across The Series

  • This lecture connects stochastic dynamics (random motion over time), inverse problems (inferring hidden inputs from outputs), and reinforcement learning (learning to act) in a science-driven setting.
  • It complements talks on Fokker-Planck equations, SDEs, and stochastic model reduction elsewhere in the seminar series.
  • It demonstrates a key theme: using physics structure to make a learning problem solvable when otherwise it would be ambiguous.

Practical Caution

Inferring reward from behavior is inherently ambiguous—multiple different rewards can produce the same actions. Physics constraints can reduce this ambiguity, but the inferred reward should not be treated as the true cause without checking it against real-world knowledge from the field.

Takeaway

The core lesson is that behavior inference requires knowing both the goal (reward) and the rules (dynamics). Fokker-Planck structure gives IRL the missing part: it models how the system's state spreads over time.
