Talk 125 · Seoul National University

Youngjoon Hong: Operator Networks Based on Numerical Analysis

This lecture proposes operator networks for parametric PDEs that are grounded in finite-element and spectral-element numerical analysis.

YouTube source · Talk page

Core Problem

Parametric PDE solvers need accuracy, generalization, and efficiency across many parameter settings. Pure data-driven operator networks often require paired input-output training data, while classical numerical methods already encode structure that should not be wasted.

First-Principles Model

The approach combines deep operator learning with finite element or spectral element methods. Instead of treating PDE solution learning as arbitrary function approximation, it builds the operator network around numerical-analysis structure so that the solver can address problems from singularly perturbed convection-diffusion equations to Navier-Stokes equations without paired input-output training data.

Key Claims

  • Operator networks can solve parametric PDEs by learning maps between function spaces.
  • Numerical-analysis structure can improve operator-network design.
  • Finite element and spectral element methods provide useful discretization foundations.
  • The framework targets parametric PDEs across difficult regimes.
  • The method avoids requiring paired input-output training data.
  • Benchmarks show versatility in accuracy, generalization, and computational efficiency.

Important Terms

Operator Network

A neural architecture designed to approximate an operator mapping inputs such as coefficients or forcing functions to solution functions.

Finite Element Method

A numerical PDE method based on approximating solutions over discrete elements.

Spectral Element Method

A high-order element-based numerical method combining spectral accuracy with geometric flexibility.

Parametric PDE

A PDE family whose behavior varies with parameters.

Convection-Diffusion Equation

A PDE describing transport by flow and smoothing by diffusion.

Connections Across The Series

  • This talk connects neural operators with classical finite-element and spectral discretization.
  • It complements differentiable-solver talks by making numerical analysis a design principle for the neural operator itself.
  • It also links to data-efficient PDE learning because built-in numerical structure reduces dependence on paired data.

Practical Caution

Numerical-analysis-based operator networks still depend on discretization choices. Good benchmarks across PDE classes are needed before assuming broad generalization.

Takeaway

The first-principles lesson is that operator learning should inherit the structure of numerical methods when the problem is a PDE.
