Talk 125 · Seoul National University

Youngjoon Hong: Operator Networks Based on Numerical Analysis

This lecture proposes operator networks for PDEs with varying parameters, built on the same ideas that make finite-element and spectral-element methods (classical numerical techniques for solving PDEs on meshes) work well.

YouTube source · Talk page

Core Problem

Solvers need to find PDE solutions quickly and accurately, even when the PDE's coefficients or forcing functions change. Most learning-based operator networks need many input-output pairs from expensive PDE solutions to train. Classical numerical methods already capture the right structure for this problem—why build a solver from scratch when we could take what works and add neural learning on top?

First-Principles Model

The approach merges deep learning for operators with numerical analysis ideas from finite element and spectral element methods. Instead of treating PDE solving as generic function approximation (fitting any curve), it anchors the neural network to how numerical methods discretize the PDE—breaking the domain into small pieces and solving locally. This design handles difficult PDEs like convection-diffusion (flow with smoothing) and Navier-Stokes (fluid motion) without needing paired example solutions.

Key Claims

  • Operator networks can solve PDEs with changing parameters by learning how to map input properties (like coefficients) to solution functions.
  • Using the structure of numerical analysis methods improves how well operator networks learn.
  • Finite element and spectral element methods provide natural ways to split up the problem that neural networks can build on.
  • The method handles difficult PDE families across different parameter ranges.
  • You don't need thousands of paired PDE solutions to train the network.
  • Tests show the method stays accurate, generalizes well to unseen parameters, and runs efficiently.

Important Terms

Operator Network

A neural network that learns the relationship between inputs (like a PDE's coefficients) and outputs (the solution function), rather than solving point-by-point.

Finite Element Method

A way to solve PDEs by dividing the domain into many small elements and approximating the solution inside each piece.

Spectral Element Method

A higher-accuracy version of finite elements that uses special polynomials (spectral polynomials) to get very precise solutions without needing finer mesh divisions.

Parametric PDE

A PDE whose solution changes when certain numbers (the parameters—like speed, viscosity, or source strength) are changed.

Convection-Diffusion Equation

A PDE where something (heat, pollutant, etc.) both moves with a flow and spreads out over time.

Connections Across The Series

  • This talk brings together neural operators and classical numerical methods, showing how to use the old tools inside the new learning approach.
  • It builds on work about learnable differential equations by going deeper: making the numerical analysis method itself central to how the network is designed.
  • It also relates to learning PDEs with less data, since building numerical structure into the network reduces how many example solutions you need to collect.

Practical Caution

How you split up the domain and how fine you make the mesh still matters. The method works well in research papers, but testing across more types of PDEs and real applications is needed before assuming it will work everywhere.

Takeaway

When you learn to solve a PDE with a neural network, the neural network should be built on top of the same ideas that already made numerical solvers work, not from blank canvas.
