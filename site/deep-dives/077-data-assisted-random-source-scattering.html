Talk 77 · Purdue University

Ying Liang: Data-Assisted Algorithms For Inverse Random Source Scattering

This whole series is about getting computers to predict how physical things behave by learning from data instead of only hand-written math. This talk tackles a specific puzzle: when waves scatter off hidden sources and you can only measure at the edges, how do you figure out what those sources are—especially when they're random or unpredictable? Traditional answers require thousands of guesses and knowing every detail of the space around them. This talk shows a faster path: use the real measurements you collected plus a learning program (a huge bank of dials tuned by trial and error) to skip past the expensive old steps and land on the source properties in far fewer guesses.

YouTube source · Talk page

Core Problem

Inverse source scattering comes up in antenna design (tracking where radio signals come from), medical imaging (finding tumors from ultrasound echoes), earthquake monitoring (locating where the ground moved), and similar detective work. The puzzle: the source keeps changing randomly in ways you can't predict, and you don't know every detail about the space around it. Old methods need to guess thousands of times and require complete knowledge of the medium to work. This talk asks: can you learn from actual measured data at the edges to figure out what the random source is, using fewer guesses?

First-Principles Model

It starts with the physics: waves bounce off the hidden source and create patterns you can measure at the boundary (the edges of your region). Wave equations or scattering equations describe this mathematically. From these equations, you can write down integral equations—mathematical rules where unknowns hide inside integrals—that give you a first rough estimate of the source. But that first guess is not great. Machine learning (a learning program with millions of dials tuned by trial and error) then takes that rough estimate and uses the real measured data to learn the true mapping: it watches the pattern of what rough-estimate-to-true-answer should be, and tunes its dials until it gets really good at it. The goal is not to throw physics away but to let observed data teach the program how to skip past repetitive expensive guessing.

Key Claims

  • Inverse random source scattering shows up in many real fields.
  • Standard methods demand many guesses and need to know every detail about the space.
  • Combining measured data at the edges with a learning program can find what a random source's statistics are.
  • A learning program can take a rough initial guess from integral equations and sharpen it.
  • This method got better answers using one tenth the number of guesses traditional methods need.
  • Among different translation models tested, pix2pix worked best when the hidden pieces of the source were far apart and their locations were known exactly.

Important Terms

Inverse Source Scattering

The detective work of figuring out what a hidden source is by watching how its waves bounce and measuring them at the edges.

Stochastic Inverse Problem

A detective problem where the hidden source, or the space around it, or the measurements themselves contain randomness and unpredictability.

Boundary Measurement

Data you collect at the edges of a region, which you then use to figure out what is hidden inside.

Integral Equation

A mathematical rule where unknown values hide inside integral signs (adding-up operations); used here to translate wave measurements into source information.

Pix2Pix

A learning program that watches pairs of pictures and learns how to translate one type into another; here, it learns to translate rough initial guesses into accurate source properties.

Connections Across The Series

  • This talk stitches together inverse problems, randomness and uncertainty in data, and learning programs that help reconstruct hidden sources.
  • It shows how inverse-problem ideas work when randomness is part of the puzzle.
  • It also connects to real uses like earthquake monitoring and medical imaging, where you measure at boundaries to reveal what is hiding inside.

Practical Caution

Image translation models (learning programs that map one kind of picture to another) work only when the data they learned from looks like the physics and geometry of your real problem. Treat them as helpers that start you off better, not as proof that your answer is correct or the only one possible.

Takeaway

Observed measurement data can cut down how many guesses you need to make when you're trying to find random or unknown sources, but only if your learning program stays connected to the actual physics equations underneath.
