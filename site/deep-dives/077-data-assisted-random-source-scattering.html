Talk 77 · Purdue University

Ying Liang: Data-Assisted Algorithms For Inverse Random Source Scattering

This lecture presents data-assisted algorithms that use boundary measurements and image-to-image learning to reconstruct statistical properties of random sources in stochastic inverse scattering with fewer realizations.

YouTube source · Talk page

Core Problem

Inverse source scattering appears in antenna synthesis, medical imaging, earthquake monitoring, and related fields. When the source is random and the medium is uncertain, traditional methods may require many realizations and detailed medium coefficients to reconstruct source statistics accurately.

First-Principles Model

The physical inverse problem starts from boundary measurements generated by wave or scattering equations. Integral-equation methods provide an initial reconstruction, while data-driven image-to-image algorithms improve it by learning the mapping from measurement-derived approximations to source statistics. The key is not replacing physics but using data to reduce the number of random realizations needed.

Key Claims

  • Inverse random source scattering is a stochastic inverse problem with important applications.
  • Traditional methods require many realizations and information about medium coefficients.
  • A data-assisted approach can use boundary measurement data to reconstruct statistical properties of the random source.
  • Data-driven algorithms can enhance initial approximations obtained from integral equations.
  • The proposed approach achieved better reconstruction with only one tenth of the realizations needed by traditional methods.
  • Among tested image-to-image algorithms, pix2pix performed best for well-separated inclusions with accurate positions.

Important Terms

Inverse Source Scattering

Recovering properties of a source that generated observed scattered waves.

Stochastic Inverse Problem

An inverse problem involving random sources, parameters, measurements, or media.

Boundary Measurement

Data collected on the boundary of a domain, used to infer interior properties.

Integral Equation

An equation formulation where unknowns appear under integrals, often used in scattering problems.

Pix2Pix

A conditional image-to-image translation model used here to improve reconstruction maps.

Connections Across The Series

  • This talk connects inverse problems, uncertainty, and ML-assisted reconstruction.
  • It complements Big Data Inverse Problems by showing a specific scattering application with stochastic structure.
  • It also links to earthquake monitoring and medical imaging as domains where boundary data must reveal hidden sources.

Practical Caution

Image-to-image models can improve reconstruction only if their training distribution matches the physics and geometry of the inverse problem. They should be treated as data-assisted corrections, not proof of unique recovery.

Takeaway

The first-principles lesson is that data can reduce the sampling burden in stochastic inverse problems when it is anchored to physics-based reconstruction.
