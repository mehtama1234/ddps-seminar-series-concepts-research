Talk 121 · University of Houston

Annalisa Quaini: Reducing the Cost of Ocean Modeling with a Data-Driven ROM and LES

This whole series is about getting computers to predict how physical things behave by learning from examples rather than only using hand-written math. In this talk, the speaker takes slow, accurate ocean simulations and builds a shortcut: a program that watches how ocean swirls change in small, fast simulations, then learns to predict the same swirls much faster. The program learns by extracting the main patterns from data, then trains a memory-holding neural network to step them forward in time.

YouTube source · Talk page

Core Problem

Ocean simulations show how water moves and swirls at different scales, from large ocean gyres down to tiny turbulent eddies. The full math for this is expensive to run because the ocean is huge and has swirls at every size from meters to thousands of kilometers. You can build simpler models, but they have to still capture two key facts: potential vorticity (a measure of spinning motion that barely changes in rotating fluids) and the overall flow pattern. If you lose those, your predictions become wrong.

First-Principles Model

The approach has two moving parts. First, a coarse simulation that resolves the large swirls exactly but blurs the tiny ones uses mathematical filters to clean up the data and make it cheap to compute. This coarse version still shows how the unresolved tiny swirls affect the large flow. Second, a learning program watches this coarse data and extracts the main patterns (the most important ways the ocean behaves), then trains a memory-holding neural network that predicts how those patterns change moment by moment. The coarse step generates data fast; the learned step makes predictions fast.

Key Claims

  • Stratified rotating ocean flow can be modeled using two simplified layers, each with a spinning-motion measure and a flow pattern.
  • Full ocean simulation is expensive because oceans are large and have important swirls at all size scales.
  • Joining a learned model with coarse-simulation data solves the cost problem without losing important physics.
  • Mathematical filters designed for coarse simulation still capture how tiny unresolved swirls affect large swirls.
  • Pattern extraction pulls the main ways the ocean behaves out of simulation data.
  • Memory-holding neural networks can learn to predict how ocean patterns evolve forward in time.

Worked Example

Illustrative example: guided manifold learning on porous media flow. Training set of 50-200 simulations with varying permeability fields (lognormal, correlated). Deep network learns low-dimensional latent space where solutions concentrate. Prediction speedup 10-50x on unseen permeability realizations. Compared to linear POD, nonlinear manifold captures tensor-train decomposition structure of heterogeneous problems.

One Level Deeper

Manifold linearization: decompose solution u = u_lin + δu where u_lin satisfies linearized PDE around reference parameter. Deep network learns δu in low-dim space. Jointly optimize reference state and manifold basis to minimize prediction error across parameter range. For parabolic PDEs (diffusion-dominated), manifold typically 5-20 dimensional despite 1000+ DOF discretization. Guided means incorporating physics constraints: enforce boundary conditions strongly in loss, penalize non-physical solutions.

Failure Boundary

Method fails when nonlinearity dominates over linear component (high Rayleigh number, strong convection). Manifold assumption breaks at bifurcation points. Extrapolation beyond training parameter range unreliable. Ill-posedness if reference state poorly chosen.

Important Terms

Two-Layer Quasi-Geostrophic Equations

A simplified model for ocean flow: two stacked layers of water spinning over a rotating earth, where you track the spinning motion (potential vorticity) and the flow pattern (stream function) at each layer instead of every detail.

Large Eddy Simulation

A technique where you compute the large swirls and eddies (spinning water masses) exactly, but use mathematical filters to approximate what the tiny swirls do to the large ones instead of computing them all.

POD

Proper Orthogonal Decomposition: a method that looks at many snapshots of ocean motion and finds the most important recurring patterns — the main ways the ocean moves that explain most of what you see.

LSTM

Long Short-Term Memory: a type of learning program built to handle sequences of events over time; it remembers selected facts from past moments and uses them to predict the next moment.

Potential Vorticity

A measure of spinning motion in rotating fluids that stays roughly constant when water moves without crossing certain boundaries; it's a crucial number for ocean dynamics.

Connections Across The Series

  • This talk brings together methods for finding main patterns in data (POD), simulating turbulence cheaply (large eddy simulation), memory-holding neural networks (LSTM), and using data to build simpler stand-in models.
  • It extends climate modeling research by showing how to combine physics-based coarse simulation with learned predictions to cut simulation cost.
  • It also connects to handling many scales at once, where each stage (coarse simulation, pattern extraction, prediction) cuts cost in different ways.

Practical Caution

The learned model is only as good as the coarse simulation it trains on. If the filters in the coarse step wipe out important physics at tiny scales, the memory network will learn a distorted version of how the ocean really evolves.

Takeaway

The core lesson is that simulating oceans costs less money when you pair physics-based coarse data (generated quickly using simplified rules) with a learned prediction model (that runs even faster than the coarse version).
