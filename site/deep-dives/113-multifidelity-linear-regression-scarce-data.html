Talk 113 · Georgia Tech

Elizabeth Qian: Multi-Fidelity Linear Regression for Scientific Machine Learning from Scarce Data

This lecture shows how low-fidelity and high-fidelity data can be combined to make scientific ML more reliable when expensive data are scarce.

YouTube source · Talk page

Core Problem

Scientific surrogate models often need high-fidelity simulation data, but those data are expensive and limited. Models trained on only a small high-fidelity dataset have high variance and can depend too strongly on accidental details of the training set.

First-Principles Model

Multi-fidelity learning starts from a cost hierarchy: high-fidelity simulations are accurate but scarce, while lower-fidelity models are cheaper but biased. The method uses abundant low-fidelity data to reduce variance and limited high-fidelity data to correct bias. In the linear-regression setting, this gives a controlled way to understand how mixed-fidelity data can improve scientific ML under small-data constraints.

Key Claims

  • Scarce high-fidelity training data produce high-variance scientific ML models.
  • Lower-fidelity data can be useful even when they are not fully accurate.
  • The proposed approach focuses on multi-fidelity linear regression as a step toward broader ML models.
  • The scientific context often naturally provides data at different fidelity and cost levels.
  • The main objective is to improve trust when high-fidelity data are limited.
  • The method frames scarce-data learning as a bias-variance and cost-allocation problem.

Important Terms

Multi-Fidelity Learning

Learning from data sources with different cost and accuracy levels.

High-Fidelity Data

Accurate but expensive data, often from fully resolved physics simulation or experiment.

Low-Fidelity Data

Cheaper data from simplified models, coarser simulations, or approximations.

Linear Regression

A model that represents the target as a linear function of features.

Scarce Data

A regime where the number of reliable training examples is small relative to model uncertainty.

Connections Across The Series

  • This talk connects UQ, active data selection, surrogate modeling, and small-data scientific ML.
  • It complements neural operator and ROM talks by emphasizing that data cost and data fidelity are part of the modeling problem.
  • It also links to practical design of training sets for expensive simulators.

Practical Caution

Low-fidelity data can reduce variance while importing bias. The value of multi-fidelity learning depends on whether the fidelity relationship is stable across the prediction domain.

Takeaway

The first-principles lesson is that scarce-data learning improves when the model uses cheap approximate information without forgetting which data are actually trustworthy.
