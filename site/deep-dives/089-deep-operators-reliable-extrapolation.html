Talk 89 · Yale University

Lu Lu: Deep Neural Operators With Reliable Extrapolation

This lecture shows how to build neural operators (neural networks that learn transformations between functions, not just numbers) that work well beyond the data they learned from, especially for problems involving multiple physical systems and different scales.

YouTube source · Talk page

Core Problem

Neural operators can learn how to solve complex systems, but deep learning tends to work best when guessing answers for data similar to what it saw during training. Real science needs to predict what happens in new regimes—different physical conditions, different accuracy levels, new kinds of inputs, and problems where different physical laws interact—where a simple neural operator might give wrong answers without warning.

First-Principles Model

DeepONet builds operators by using two separate networks: one that reads in the input function and one that evaluates at specific locations, then combines their answers. Variants of this idea extend it to handle problems where multiple physical systems interact, use reduced representations (proper orthogonal decomposition, which picks out the most important patterns), handle multiple inputs at once, use patterns from Fourier analysis, and combine data that has different levels of cost and accuracy. To make extrapolation trustworthy, you need to understand how hard it is to move outside the training regime and create checks that catch or reduce that risk.

Key Claims

  • Neural networks can learn nonlinear operators—transformations between functions—not just mappings from numbers to numbers.
  • DeepONet can learn operators that represent both deterministic equations (rules with no randomness) and stochastic equations (rules with randomness).
  • DeepM&Mnet extends operator learning to problems where different physical systems interact.
  • POD-DeepONet combines proper orthogonal decomposition (a method to find the most important patterns in data) with operator learning.
  • MIONet handles multiple-input operators, while multifidelity DeepONet mixes data from sources that have different costs and accuracies.
  • For science to trust these models, you need to measure how hard extrapolation is and build workflows that detect problems or improve predictions outside the training range.

Important Terms

DeepONet

A neural network designed to learn transformations from functions to functions, using a branch network that encodes inputs and a trunk network that encodes evaluation points.

POD-DeepONet

A version of DeepONet that first uses proper orthogonal decomposition (a method to compress data by keeping only the most important patterns) before applying the operator network.

MIONet

A neural operator network built to handle operators with multiple inputs.

Multifidelity Learning

Training a model using data from different sources that have different costs (some cheap and approximate, some expensive and accurate).

Extrapolation Complexity

A measurement or description of how hard it is for a model to make correct predictions when it encounters data or situations outside its training domain.

Practical Caution

Learning operators does not automatically solve the extrapolation problem. A model can work perfectly on the functions it learned from but fail when it meets new physics, new scales, or interactions it wasn't trained on.

Takeaway

The real lesson is that neural operators should be judged not just by how well they fit known data, but by which types of new problems they can handle correctly.
