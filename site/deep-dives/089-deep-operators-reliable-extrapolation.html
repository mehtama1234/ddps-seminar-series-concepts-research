Talk 89 · Yale University

Lu Lu: Deep Neural Operators With Reliable Extrapolation

This series is about getting computers to predict physical behavior by learning from examples instead of only hand-written math. One way to do that is to teach a neural network (a program with millions of little dials the computer tunes by trial and error until answers look right) to learn how to transform one kind of information into another—not just guess a number, but learn a whole process. This talk covers how to build these neural operators so they work well beyond the examples they learned from, especially when facing new physical conditions, different scales, or situations where multiple physical systems interact.

YouTube source · Talk page

Core Problem

Neural operators—programs that learn transformations between entire functions, not just single numbers—can master complex systems. But the trial-and-error learning process usually works best when the computer is guessing about data similar to what it saw during training. Real science has a different demand: predict what happens in completely new regimes—different physical conditions, different precision needs, new types of inputs, problems where multiple physical forces interfere—where a neural operator trained only on old examples might give terrible, confident-sounding wrong answers.

First-Principles Model

DeepONet works by splitting the job into two parts: one program reads in the input signal and captures its essence; another program evaluates the answer at specific points; then you combine them. Related ideas build from there: some handle problems where multiple physical systems push on each other; some use proper orthogonal decomposition (a technique that keeps only the most important patterns and throws away noise), which compresses the data before learning; some take multiple inputs at once instead of one; some use patterns from Fourier analysis (breaking signals into repeating waves); some combine measurements that cost different amounts to get. To make predictions trustworthy outside the training range, you need to measure how hard that leap is and create checks that warn when the model might be failing or fix the prediction.

Key Claims

  • Neural networks can learn transformations between entire functions—not just mappings from one number to another number.
  • DeepONet can learn transformations that represent both deterministic equations (rules with no randomness) and stochastic equations (rules with randomness built in).
  • DeepM&Mnet extends operator learning to problems where different physical systems interact and push on each other.
  • POD-DeepONet combines proper orthogonal decomposition (a method to find and keep only the most important patterns while discarding noise) with operator learning.
  • MIONet handles transformations with multiple inputs, while multifidelity DeepONet mixes data from sources that cost different amounts to collect and have different accuracies.
  • For science to trust these models, you need to measure how hard extrapolation is and design workflows that spot problems or improve predictions when the model ventures outside its training range.

Worked Example

Structural mechanics: cantilever plate with notch under traction. DeepONet trained on boundary conditions, predicts displacement field L² error ~2%. Advection-diffusion PDE with multiple inputs (boundary, diffusion coefficient, source): maps 3-input functions to solution, handles parametric variations.

Geologic carbon storage (multiphysics 3D): 24 snapshots over 30 years, coarse-fine spatial coupling (100m wells, million-meter far field). Multi-fidelity hybrid: pod-DeepONet reduces parameters 33M → 3M, GPU memory 16GB → 6GB, training 42h → 12h while maintaining accuracy R²=0.99. Predicts unseen time snapshots t=2,4,6 (trained only on t=1,3,5,7) by conditioning on temporal coordinate.

Waveform inversion seismic: 2D acoustic domain, 5 source locations, various frequencies. Predicts subsurface velocity from noisy pressure records. Tests: Gaussian noise +50%, missing traces 50% dropped, source noise in wavelet—DeepONet robust across all; baseline networks fail at noise levels >20%.

One Level Deeper

Multiple-input DeepONet (μ-net): m branch networks {φ_i} each processes one input function v_i, concatenate outputs, trunk network ψ(y) encodes query location y. Merge: G(y)=Σ_k[⊙_{i=1}^m φ_i(v_i)]·ψ_k(y) (element-wise product then sum reduces tensor explosion). Fourier-μ-net: replace element-wise merge with Fourier transform layer + 2D/3D UNet to preserve spatial structure while reducing parameters. Temporal extension: add time t as additional trunk input, condition solution continuity over time.

Multi-fidelity: cascade two DeepOnets: low-fidelity G_lo trains on 10k samples, high-fidelity G_hi learns correction Δ = G_hi - G_lo using few high-quality samples (<5k) and penalizes correlation mismatch.

Failure Boundary

Extrapolation minus (smoother training distribution, rougher test) succeeds; extrapolation plus (complex training, smooth test) fails catastrophically due to spectral bias. Wasserstein-2 distance between training and test function spaces predicts error magnitude in log-log scaling—requires pre-computed reference for new problem class. Cannot handle phase transitions or regime switches (e.g., laminar-turbulent, nucleation) without separate operator per regime. Stochastic noise in source signal amplifies through wave propagation—architecture sensitive to input noise distribution. Memory scaling: m-input problems still require m branch forward passes; not amortized if m >> 1.

Important Terms

DeepONet

A neural network (a program with millions of dials tuned by trial and error) designed to learn transformations from one function to another, using one program that reads and understands the input and another program that produces the output at specific points.

POD-DeepONet

A version of DeepONet that first uses proper orthogonal decomposition (a technique for keeping only the most important patterns in data and throwing away noise and clutter) before applying the operator network.

MIONet

A neural operator network (a program that learns transformations between functions) built to handle transformations with multiple inputs instead of just one.

Multifidelity Learning

Training a model using data from different sources where some are cheap and approximate and others are expensive and accurate—mixing them together to train faster.

Extrapolation Complexity

A way to measure or describe how hard it is for a model to make correct predictions when it runs into data or situations completely different from what it learned on.

Practical Caution

Learning operators does not automatically solve the problem of extrapolation—predicting in new territory. A model can work perfectly on the exact functions it learned from but collapse when it meets new physics, new scales, or interactions it never saw during training.

Takeaway

The real lesson is that neural operators should be tested not just on how well they remember known data, but on whether they get the right answer for entirely new types of problems.
