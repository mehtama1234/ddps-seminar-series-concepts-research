Talk 109 · University of Naples Federico II

Fabio Giampaolo: Learning Paradigms for Neural Networks: The Locally Backpropagated Forward-Forward Algorithm

This whole series is about getting computers to predict physical behavior by learning from examples instead of only hand-written math. One method teaches neural networks using small steps within each layer instead of one big step from the output all the way back to the input. This talk shows how that method, called locally backpropagated forward-forward, works: each layer gets its own score for how good its answer is, instead of waiting for error signals to bounce backward from the end.

YouTube source · Talk page

Core Problem

Backpropagation—the standard way to train neural networks by sending error signals backward through all layers—runs into trouble when models have pieces that don't change smoothly (so you can't compute how to fix them), when computers doing the learning are scattered across different machines, or when they include physics simulators that can't be fed into a single chain of calculations.

First-Principles Model

Backpropagation squeezes a single error signal backward through the whole network to nudge every dial in the right direction. The forward-forward algorithm instead gives each layer its own job: look at correct answers versus wrong answers and learn which one looks right. The locally backpropagated forward-forward strategy combines these ideas—it uses calculus-based direction-finding inside each layer (like backpropagation) but lets each layer work more on its own, without needing one giant error signal flowing all the way through.

Key Claims

  • Backpropagation is still the most common way to train neural networks.
  • Real-world and physics-based settings show where backpropagation sending signals backward through the whole network hits a wall.
  • Pieces that don't change smoothly can block error signals from flowing backward.
  • When training is split across different types of computers, it pushes us toward methods where each part works more on its own, without needing one central signal.
  • The locally backpropagated forward-forward algorithm merges backpropagation's calculus-based tuning with forward-forward's layer-by-layer learning goals.
  • The aim is to make deep-learning methods work in more places and situations.

Important Terms

Backpropagation

The standard method for training neural networks: use calculus to figure out how much to nudge each dial, by sending error signals backward through all layers step by step.

Forward-Forward Algorithm

A training method created by Geoffrey Hinton that scores each layer by looking at correct answers and wrong answers separately, without computing backward error signals.

Local Learning

Training where each layer or section of the network uses its own score or goal, instead of having one error signal from the final output control everything.

Non-Differentiable Component

A piece of the model where small changes to input don't cause smooth, predictable changes to output—this breaks the calculus chain that backpropagation needs.

Heterogeneous Devices

A collection of different computers or processors—perhaps fast ones and slow ones, with different memory or designs—all working together on one job.

Connections Across The Series

  • This talk connects to how we design rules that make neural networks learn, how to spread that learning across many computers, and how to build learning systems for science and physics.
  • It builds on earlier talks where smooth calculus doesn't hold—showing what to do when models break those normal assumptions.
  • It also fits into broader conversations about what makes learning succeed beyond just the network design itself—the actual training rules are what drive progress forward.

Practical Caution

When testing new training methods, look at whether they stay steady while learning, whether they scale up to bigger networks, and whether they actually get right answers on real jobs—not whether they sound like how brains work or fit nicely on scattered computers.

Takeaway

Training that happens layer-by-layer, with each layer working toward its own goal, can make learning more separated and modular. But it still has to solve the credit-assignment problem: each part of the network has to figure out which of its own changes help or hurt the final answer, and it needs to do that well enough to keep up with backpropagation.
