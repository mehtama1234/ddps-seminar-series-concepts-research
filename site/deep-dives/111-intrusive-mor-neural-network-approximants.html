Talk 111 · Weierstrass Institute

Francesco Romor: Intrusive Model Order Reduction Using Neural Network Approximants

This lecture proposes an intrusive and interpretable ROM approach that uses neural networks as nonlinear solution-manifold approximants while retaining physical models online.

YouTube source · Talk page

Core Problem

Linear projection-based ROMs struggle when the solution manifold has slowly decaying Kolmogorov n-width, because too many reduced modes are needed for accuracy. Neural networks can approximate nonlinear manifolds, but many neural ROMs become non-intrusive black-box surrogates that abandon the governing model during prediction.

First-Principles Model

The method keeps the physical and numerical model in the online stage while using neural networks to approximate the nonlinear solution manifold. Autoencoders further compress linear approximations into latent coordinates. Hyper-reduction then reduces the cost of evaluating the retained model terms, so the method aims to combine nonlinear approximation power with intrusive interpretability.

Key Claims

  • Slow Kolmogorov n-width decay limits efficient linear reduced bases.
  • Neural networks can provide accurate nonlinear regressions of solution manifolds.
  • Most existing implementations are black-box surrogates.
  • The proposed methodology is intrusive because it retains the underlying physical and numerical model online.
  • Autoencoders compress the dimensionality of linear approximations to latent coordinates.
  • Adaptive hyper-reduction is needed to make the retained model computationally efficient.

Important Terms

Intrusive MOR

Model order reduction that uses access to the governing equations or numerical operators.

Kolmogorov n-Width

A measure of how well a solution manifold can be approximated by an n-dimensional linear subspace.

Solution Manifold

The set of all solutions produced as parameters or inputs vary.

Autoencoder

A neural network that learns to encode and decode data through a low-dimensional latent space.

Hyper-Reduction

Techniques that reduce the cost of evaluating nonlinear or high-dimensional terms in a ROM.

Connections Across The Series

  • This talk sits at the intersection of intrusive ROMs, autoencoders, nonlinear manifolds, and scientific ML.
  • It complements non-intrusive neural surrogate talks by showing why retaining equations can matter.
  • It also connects to manifold-learning discussions where linear subspaces are insufficient.

Practical Caution

Intrusive neural ROMs require access to and careful handling of the governing numerical model. They can be more interpretable than black-box surrogates but harder to deploy when only simulator input-output data are available.

Takeaway

The first-principles lesson is that nonlinear neural compression can be combined with intrusive physics rather than replacing the equations entirely.
