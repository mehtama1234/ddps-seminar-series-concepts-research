Talk 103 · University of Connecticut

George M. Bollas: Physics-Informed Machine Learning through Symbolic Regression

This whole series is about getting computers to predict how physical systems behave by learning from examples instead of hand-written math. One approach is to have a learning program search for actual equations that match your data—not just predict the next number, but show you the real rule. This talk is about why that method works especially well when you have little data, lots of noise, or need to understand what's actually happening instead of just guessing the next step.

YouTube source · Talk page

Core Problem

Many engineering systems need the actual equations that describe how things work. When you build a bridge or design an engine, you can't just know 'the next load is 50 tons'—you need to know the rules that govern how forces move and change, so you can diagnose problems and predict what happens next. Scientists have two choices right now: write down the rules by hand (slow and hard when the rules are complicated or unknown), or use learning programs that predict numbers without showing you the actual rules. This talk asks: can a computer hunt for equations instead?

First-Principles Model

Symbolic regression is a search process: the computer tries millions of different equations (like x+y, x*sin(y), sqrt(x)/y) and keeps the ones that match your data best. To find equations that describe how things change over time, the computer uses automatic differentiation—a way to compute how much each number affects the final answer by working backward through the calculation, step by step, like unwinding a chain. Instead of stopping to solve big equations over and over, the search just computes these changes and keeps looking. The computer can also use genetic programming: start with simple equations, randomly change them (swap a plus for a times, add a new term), breed the ones that work better, and repeat—like evolution of equations. This lets the method discover not just what rule is breaking, but how the damage or fault spreads over time.

Key Claims

  • Symbolic regression is useful when you want to discover the actual equation instead of just making predictions.
  • The method works well when you have little data.
  • The approach holds up even with high noise, including as much as 50 percent noise added to measurements.
  • Automatic differentiation removes the need to solve equations over and over while searching for the right formula.
  • Comparing symbolic regression with physics-informed neural networks shows different tradeoffs—finding equations you can write down versus fitting while obeying physics rules.
  • Predicting how faults grow benefits from symbolic equations that describe fault behavior step by step.

Worked Example

Heat exchanger fouling fault detection: 125 differential-algebraic equations discretized, 2 temperature sensors, fouling modeled as thermal resistance vs time (asymptotic function). System evolves under altitude/speed variability. Discovers fault progression via 1 soft sensor + genetic programming with symbolic regression. Remaining useful life predicted to ~2% error (initially 50% error) within 5 iterations after seeing 50 minutes of data; converges to zero error after 6-7 updates.

Plug flow reactor PDE identification (isothermal, C^2 reaction): 2 different feed conditions, discovers pure cubic reaction kinetics from sparse data. Standard SINDy fails at 20min computation; hybrid approach finds analytical solution in 100s with 3 parameters vs PINN's 7500. Burgers equation: recovers exact diffusion coefficient from 10 points + 5% noise in under 100 seconds.

One Level Deeper

Genetic programming + differential solver loop: candidate expression trees from mutation/crossover operations encode right-hand side of PDE. Each tree instance → parameter estimation via Casadi ODE solver (expensive integration step) → Bayesian Information Criterion fitness scoring to penalize complexity. Evolutionary loop iterates until BIC stagnates. Symbolic regression avoids derivatives (noisy) by using Runge-Kutta scheme as constraint: ||x_{i+1} - RK4[Φ(x_i)·ψ]||^2_2 + λ||ψ||_1 where ψ selects library terms via sequential thresholding.

Inverse PINN hybrid: neural network g_θ(x,t) approximates solution; automatic differentiation computes residual ∂g/∂t - f[g,∂g/∂x,...]; loss combines data fit + PDE penalty + gradient consistency regularization.

Failure Boundary

Computational expense dominates: genetic programming + full PDE integration 20min for one 1D equation (vs weak SINDy <1min). Scalability to coupled multiphysics systems (100s equations) impractical. Dictionary/library structure must be user-provided; missing dominant term class (e.g., rational functions if only polynomials guessed) causes systematic bias—no automatic discovery of basis functional forms. Noise sensitivity: high noise (>5%) without denoising causes false positive features unless gradient loss included. Chaotic systems or stiff problems (wide timescale separation) ill-suited unless integrator chosen carefully; Newton-Krylov iteration expensive for large-scale PDEs.

Important Terms

Symbolic Regression

A search process where the computer tries millions of different equations to find ones that match your data, keeping the simplest ones that work best.

Genetic Programming

A search method that starts with random equations, randomly changes them (swap operations, add terms), and keeps breeding the ones that fit better—like evolution applied to equations.

Automatic Differentiation

A way to compute how much each piece of a calculation affects the final answer by working backward through the calculation step by step, without doing complicated math by hand.

PDE Discovery

Searching data to find the rules that describe how quantities (like temperature or pressure) change in space and over time.

Fault Prognosis

Predicting how a broken or damaged part of a system will get worse over time.

Connections Across The Series

  • This lecture connects finding the smallest set of equations needed to describe something, physics-informed learning (teaching computers the laws of physics while they learn), symbolic methods, and learning algorithms that explain their answers.
  • It picks up the thread of recovering equations you can write down and solve by hand—a contrast to just getting numbers without seeing the rule.
  • It also links to virtual copies of real systems (called digital twins), where discovered equations can help you spot problems and predict how the system will behave.

Practical Caution

Symbolic regression can find equations that look good and match your numbers, but turn out wrong when you test them on new data. The equations you hunt for depend totally on which pieces you let the computer choose from (if you never offer 'times', you'll never find multiplication). Noise in your measurements throws off the discovery, and bad handling of noise creates fake equations. Finding an equation that fits your old data is only step one—you must always test it on fresh data you've never seen before.

Takeaway

When understanding how things work matters—because you need to fix something broken, predict what happens in a new situation, or make sure a system is safe—then learning algorithms should try to find actual equations, not just predict one number at a time.
