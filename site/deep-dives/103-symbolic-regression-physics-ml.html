Talk 103 · University of Connecticut

George M. Bollas: Physics-Informed Machine Learning through Symbolic Regression

This lecture shows how symbolic regression—a search method that discovers mathematical expressions—can recover interpretable physics models from scarce and noisy data.

YouTube source · Talk page

Core Problem

Many engineering systems need actual equations, not just predictions that say what will happen next. This is especially true when data are scarce, noisy, or when you need to diagnose what's wrong or predict what comes next. Physics-Informed Neural Networks (PINNs) can fit differential equations (rules about how things change), but they can be slow and don't directly show you the governing equation itself.

First-Principles Model

Symbolic regression searches over possible mathematical expressions to find compact equations that match observed data. When combined with automatic differentiation (a method to compute derivatives exactly through the chain rule), it can estimate how quantities change over time from data and search for differential equation terms without needing to solve candidate equations repeatedly. Genetic programming (an evolutionary search that creates and mutates equations like biological evolution) can also add new symbolic equations to an existing model to show how a fault spreads over time.

Key Claims

  • Symbolic regression is useful when you want to discover the actual model instead of just making predictions.
  • The method works well when you have little data.
  • The approach holds up even with high noise, including as much as 50 percent noise added to measurements.
  • Automatic differentiation removes the need to solve differential equations over and over during discovery.
  • Comparing symbolic regression with PINNs shows different tradeoffs—equation discovery versus fitting while respecting differential equations.
  • Fault detection and predicting how faults evolve both benefit from symbolic expressions that describe fault progression analytically.

Important Terms

Symbolic Regression

A search procedure that discovers mathematical expressions to fit data by testing many possible combinations of operations.

Genetic Programming

An evolutionary search method that creates, combines, and mutates candidate equations to find better ones, similar to how species adapt.

Automatic Differentiation

A computational method that computes exact derivatives (rates of change) by applying the chain rule through a program or neural network.

PDE Discovery

Finding the partial differential equations (rules describing how quantities change across space and time) from observed data.

Fault Prognosis

Predicting how a system fault or damage will grow or worsen over time.

Connections Across The Series

  • This lecture connects sparse model discovery (finding the smallest set of equations needed), Physics-Informed Neural Networks, symbolic methods, and interpretable scientific machine learning.
  • It complements the broader physics-informed learning thread by emphasizing recovery of closed-form equations (equations you can write down and solve by hand).
  • It also links to industrial digital twins (virtual copies of real systems), where discovered equations can support diagnosis and prognosis.

Practical Caution

Symbolic regression can find elegant-looking but false equations if the candidate library of terms, derivative estimates, or noise handling are poor. Finding an equation that looks right does not replace the need to test it against new data.

Takeaway

The first-principles lesson is that when decisions require understanding how things work, learning algorithms should try to find equations, not only predict outputs without showing the mechanism.
