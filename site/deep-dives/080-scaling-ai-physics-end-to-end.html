Talk 80 · Purdue University

Yexiang Xue: Scaling Up AI-Driven Scientific Discovery

This lecture tackles computational bottlenecks in AI-driven scientific discovery by embedding differentiable PDE solvers into end-to-end learning and using projection/hash-style acceleration for sparse physics updates.

YouTube source · Talk page

Core Problem

Learning first-principles physics models from experimental data requires a closed loop between data, simulation, gradients, and model discovery. The bottleneck is computational: large-scale PDE simulations are expensive in the forward pass, and backpropagating gradients through them can be even more expensive.

First-Principles Model

The proposed view is to treat a PDE solver as a differentiable layer inside a learning pipeline. This lets the model learn PDE structure directly from experimental data while propagating gradients through physics simulation. Scaling then depends on exploiting structure: sparse updates in PDE dynamics, locality in neighbor interactions, and random projection or locality-sensitive hashing to group elements with similar temporal behavior.

Key Claims

  • Closed-loop AI-driven scientific discovery is limited by missing end-to-end frameworks that embed large-scale physics simulation into learning.
  • Backward gradient propagation through physics models is often more demanding than forward simulation.
  • PDE solvers can be formulated as fully differentiable neural-network layers.
  • Differentiable solver layers allow large-scale physics simulations to be embedded into learning workflows.
  • Locality Sensitive Hashing can accelerate sparse PDE updates by grouping elements with similar neighborhoods.
  • Random projection and symbolic regression can support efficient discovery of sparse and decomposable PDEs.

Important Terms

End-To-End Scientific Discovery

A learning loop where model discovery, simulation, and gradient-based optimization are integrated into one differentiable pipeline.

Differentiable PDE Solver

A PDE solver implemented so gradients can be propagated through its computations.

Locality Sensitive Hashing

A hashing method that groups similar objects together, used here to exploit similar local PDE neighborhoods.

Sparse PDE Update

An update pattern where only a subset of state elements changes in an informative way at each step.

Random Projection

A dimensionality-reduction technique that projects data into a lower-dimensional random subspace while approximately preserving structure.

Connections Across The Series

  • This lecture directly connects automatic differentiation, differentiable programming, and PDE discovery.
  • It also complements neural solver and operator talks by emphasizing scalability of both forward and backward computation.
  • It extends the equation-discovery thread from symbolic search to differentiable simulation pipelines.

Practical Caution

End-to-end differentiable physics can be limited by memory, numerical stiffness, and biased experimental data. Fast gradients are useful only if the embedded solver and discovered PDE remain physically meaningful.

Takeaway

The first-principles lesson is that scaling scientific discovery requires making physics differentiable and computationally sparse enough to learn from.
