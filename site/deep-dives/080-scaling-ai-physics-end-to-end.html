Talk 80 · Purdue University

Yexiang Xue: Scaling Up AI-Driven Scientific Discovery

This lecture tackles computational bottlenecks in AI-driven scientific discovery by building differentiable PDE solvers into end-to-end learning and using random projection and hash-based tricks to speed up sparse physics updates.

YouTube source · Talk page

Core Problem

Learning first-principles physics models from experimental data requires a loop where data, simulation, gradients, and model discovery all feed back into each other. The bottleneck is computational: running large-scale PDE simulations is expensive in the forward pass (computing what happens next), and sending gradients backward through them can be even more expensive.

First-Principles Model

The key idea is to treat a PDE solver as a differentiable layer (a step you can send gradients backward through) inside a learning pipeline. This lets the model learn PDE structure directly from experimental data while gradients flow backward through the physics simulation. Scaling then depends on exploiting structure: only updating parts of the state that change meaningfully, using locality in how elements affect their neighbors, and applying random projection or locality-sensitive hashing (a trick that groups elements with similar temporal patterns) to speed up which pieces to compute.

Key Claims

  • AI-driven scientific discovery is held back by the lack of end-to-end pipelines that embed large-scale physics simulation into learning.
  • Backward gradient propagation through physics models is often more computationally expensive than running the simulation forward.
  • PDE solvers can be written as fully differentiable layers in neural networks.
  • Differentiable solver layers allow large-scale physics simulations to be embedded into learning workflows.
  • Locality-sensitive hashing can speed up sparse PDE updates by grouping elements with similar local neighborhoods.
  • Random projection and symbolic regression can support efficient discovery of sparse and decomposable PDEs.

Important Terms

End-To-End Scientific Discovery

A learning loop where model discovery, simulation, and gradient-based optimization are all connected into one differentiable pipeline.

Differentiable PDE Solver

A PDE solver built so that gradients can be sent backward through its computations.

Locality Sensitive Hashing

A hashing method that groups similar objects together; used here to find and speed up computing on PDE elements with similar local neighborhoods.

Sparse PDE Update

An update pattern where only a subset of state elements changes in an informative way at each time step.

Random Projection

A dimensionality-reduction technique that projects data into a lower-dimensional random subspace while roughly preserving the structure.

Connections Across The Series

  • This lecture directly connects automatic differentiation, differentiable programming, and PDE discovery.
  • It also complements neural solver and operator talks by emphasizing how to scale both forward and backward computation.
  • It extends the equation-discovery thread from symbolic search to differentiable simulation pipelines.

Practical Caution

End-to-end differentiable physics has real limits: memory constraints, numerical stiffness (when equations resist stable computation), and biased experimental data. Fast gradients help only if the embedded solver and the discovered PDE stay physically meaningful.

Takeaway

The first-principles lesson is that scaling scientific discovery requires making physics differentiable and computationally sparse enough to learn from.
