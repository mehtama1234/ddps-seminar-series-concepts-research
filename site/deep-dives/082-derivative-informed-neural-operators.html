Talk 82 · Georgia Institute of Technology

Peng Chen: Derivative-Informed Neural Operators

This whole series is about getting computers to predict physical behavior by learning from examples. This talk focuses on teaching a learning program (a neural network) to do two things at once: predict what happens when rules for how things change in space and time are given some starting values, AND tell you how sensitive that prediction is—if you nudge an input a little, how much does the prediction shift? This matters when you're doing detective work to find hidden values from messy data, choosing where to measure next to learn the most, or finding the best decision when some values are uncertain.

YouTube source · Talk page

Core Problem

Many real problems involve a rule that says how something changes in space and time (like heat spreading or air flowing), combined with random or uncertain starting values. To solve these problems—say, to figure out an unknown number from data, or pick the best action when inputs are uncertain—you need to run the rule forward many, many times. Each run is slow and expensive. And you don't just need the answer; you need to know how it shifts when you nudge an input, so your method can find the best answer.

First-Principles Model

A neural network can learn to mimic a rule for how things change, without running the slow rule forward each time. But for finding the best answer, you need more than just a good prediction—you need accurate sensitivity: if I shift an input by a tiny amount, how much does the prediction shift? The approach here trains a neural network in a reduced (squeezed-down) space that learns both the prediction and the sensitivity at the same time, using fewer slow rule-runs than before.

Key Claims

  • Many problems involve a rule for how things change in space and time, combined with finding unknown values from data, choosing measurements wisely, or making good decisions when values are uncertain.
  • Traditional methods are too expensive because they require running the rule forward many times.
  • A neural network can learn to approximate both the prediction and how the prediction responds to small changes in inputs.
  • Using a squeezed-down space inside the neural network makes it practical for problems with many uncertain variables.
  • Training with a limited amount of slow rule-runs can give high accuracy for both the prediction and the final answer.
  • Sensitivity information makes learned models useful for finding the best answer, not just for guessing what happens next.

Important Terms

Derivative-Informed Neural Operator

A learning program trained to predict what happens when a rule for change is run forward, plus how that prediction shifts if you nudge an input by a tiny amount.

Bayesian Inverse Problem

Detective work: using messy data to figure out hidden values, treating each unknown as something that could be different with different odds.

Optimal Experimental Design

Picking where and how to measure so you learn the most about the system with the fewest measurements.

Stochastic Optimization

Finding the best choice when some values are uncertain or random instead of fixed.

Reduced Basis Architecture

A way to build a neural network that squeezes outputs into fewer dimensions, making training faster and predictions more accurate.

Connections Across The Series

  • This work extends learned models into inverse problems (finding unknowns from data) and design, where how-much-does-the-output-shift matters.
  • It connects to finding the few most important input directions, adjusting unknown numbers to match data, and automatic sensitivity calculation, because all three need to know how outputs respond to input changes.
  • It builds on earlier talks about compressed-space models by putting those compressed spaces inside neural networks.

Practical Caution

A neural network that predicts what happens accurately might still get sensitivities wrong. If you use those wrong sensitivities to guide decisions (like choosing a better design), you will make poor choices. Test the sensitivities before you trust them to guide important decisions.

Takeaway

Finding the best answer under uncertainty needs more than fast predictions. It needs trustworthy sensitivities—accurate answers to 'if I nudge this input a tiny bit, how much does the output shift?'—from a learned model.
