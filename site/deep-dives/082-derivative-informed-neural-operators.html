Talk 82 · Georgia Institute of Technology

Peng Chen: Derivative-Informed Neural Operators

This lecture introduces derivative-informed neural operators—learned approximations that predict both PDE solutions and their sensitivities to input changes—for use in Bayesian inference (inferring unknown values from uncertain data), optimal experiment design (choosing measurements that give the most information), and stochastic optimization (finding best choices under uncertainty).

YouTube source · Talk page

Core Problem

Optimization and inference problems governed by large-scale PDEs (partial differential equations—rules describing how quantities change over space and time) with high-dimensional random parameters require many expensive PDE solves. Classical methods become impractical because each sampling step or optimization iteration needs not only state predictions but also statistical measures, derivatives, and sensitivities.

First-Principles Model

A neural operator learns to map from parameters and controls to a PDE solution. For optimization to work well, you also need the derivative of that map—how the output changes when inputs shift slightly. A derivative-informed neural operator trains a reduced-basis architecture (a neural network that represents outputs in a smaller-dimensional space for speed) to learn both the solution and its derivative, cutting down the number of expensive PDE solves while keeping sensitivity information intact for downstream algorithms.

Key Claims

  • Large-scale PDE optimization with high-dimensional random parameters comes up in Bayesian inverse problems (finding unknown values from data), optimal experimental design (picking which measurements give the most information), and stochastic optimization (finding good answers when parameters are uncertain).
  • Classical approaches cost too much in computation because statistical measures require solving the PDE many times.
  • Derivative-informed neural operators learn to approximate both the PDE solution map and how it responds to small changes in input variables.
  • Reduced-basis architectures (neural networks that work in a compressed space) make the operator practical for high-dimensional problems.
  • Training with only a limited amount of data can achieve high accuracy for both the PDE solution and the optimization solution.
  • Derivative information makes neural operators useful for optimization, not just for predicting forward.

Important Terms

Derivative-Informed Neural Operator

A neural network trained to approximate both a PDE solution map and how that solution changes with respect to input variables.

Bayesian Inverse Problem

Finding unknown values by inferring them from observed data, treating the unknowns as random variables with probabilities.

Optimal Experimental Design

Choosing how and where to collect data so that you learn the most about the system.

Stochastic Optimization

Finding the best choice for something when some quantities are uncertain or random.

Reduced Basis Architecture

A neural network design that compresses outputs into a smaller set of dimensions for faster and more accurate training and prediction.

Connections Across The Series

  • This lecture extends neural operators into inverse problems and design, where sensitivities—how outputs respond to changes—matter.
  • It connects to active subspaces (finding the most important input directions), Bayesian calibration (adjusting parameters to match data), and differentiable programming (writing code that computes gradients automatically) because all three depend on understanding how outputs shift with inputs.
  • It also builds on reduced-order model talks by using compressed bases inside neural operators.

Practical Caution

A neural operator that predicts states accurately may still produce wrong derivatives. If those wrong sensitivities guide your optimization, decisions will be poor. You must validate derivatives when the learned surrogate is making real choices.

Takeaway

Optimization needs more than fast predictions of what will happen. It needs trustworthy derivatives—accurate answers to 'if I change this input a little, how much does the output shift?'—from the learned physics model.
