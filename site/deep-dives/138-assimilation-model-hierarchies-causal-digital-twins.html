Talk 138 · University of Wisconsin-Madison

Nan Chen: Bridging Models and Data: Assimilation, Model Hierarchies, Causal Inference and Digital Twins

This lecture uses data assimilation (updating model predictions with real observations) to connect model hierarchies, causal inference, and digital twins.

YouTube source · Talk page

Core Problem

Scientific systems have three sources of knowledge that usually stay separate: real data, simplified models that capture basic physics, and detailed models that handle real-world complexity. A working digital twin (a live copy of a physical system inside a computer) needs to combine all three, deal with scattered observations, and answer questions about what caused what and whether predictions will hold—not just forecast one step ahead.

First-Principles Model

Data assimilation updates what a model thinks the system's state is (and the model's own settings) by comparing predictions to real measurements. The lecture extends this in three directions. Latent data assimilation—a technique where models of different complexity map into a shared compressed space—lets simple and detailed models trade information without rewriting either one. Assimilative causal inference uses Bayesian updates (a method for updating beliefs with new evidence) to trace backward from what you see to what caused it. Digital twins combine these assimilation and causal tools to test "what if this happened?" scenarios and predict rare extreme events.

Key Claims

  • Data assimilation connects models and observations in a mathematically sound way.
  • Model hierarchies let you combine simple idealized models with detailed operational ones.
  • Latent data assimilation cuts cost and connects models that would otherwise be incompatible.
  • You can trace causes backward from observed effects using Bayesian data assimilation.
  • Answering "what caused what?" and "will this hold?" matters for climate tipping points and rare extreme events.
  • These tools are essential for building working digital twins.

Important Terms

Data Assimilation

A method that updates a model's view of the system (its state and settings) by comparing model predictions to real measurements.

Model Hierarchy

A set of models arranged by how detailed they are, from simple physics-based models to complex real-world versions.

Latent Data Assimilation

Assimilation done inside a compressed representation learned from data, so models of different detail levels can interact.

Assimilative Causal Inference

Using Bayesian updates (mathematical methods for changing beliefs based on new evidence) to figure out what causes produced the effects you see.

Digital Twin

A constantly updated computer model of a real physical system that predicts its future and supports decisions about it.

Connections Across The Series

  • This talk brings together data assimilation, latent spaces, digital twins, model hierarchies, and causal reasoning.
  • It builds on earlier lectures about oceans, underground reservoirs, weather, and uncertainty by showing assimilation as a common workflow across all of them.
  • It also connects to agentic reasoning because a digital twin lets you test out counterfactual scenarios ("what if we changed this?") before acting.

Practical Caution

A digital twin can appear reliable while passing along bias from the choice of model hierarchy and the gaps in where you collected observations. Assimilation must track uncertainty and admit when models don't match reality.

Takeaway

The core lesson: assimilation is not just filtering out noise. It is a bridge for combining models, observations, causality, and real-world decision-making.
