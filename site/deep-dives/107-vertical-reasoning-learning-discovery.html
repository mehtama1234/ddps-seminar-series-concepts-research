Talk 107 · Purdue University

Yexiang Xue: Vertical Reasoning Enhanced Learning, Generation and Scientific Discovery

This lecture shows how embedding explicit reasoning steps inside learning systems can improve generation quality, finding mathematical equations from data, discovering physical equations, and counting problems.

YouTube source · Talk page

Core Problem

Machine learning excels at finding patterns, while automated reasoning excels at enforcing explicit rules. Autonomous scientific agents need both skills, but combining reasoning and learning remains difficult.

First-Principles Model

Vertical reasoning means placing a structured reasoning process inside or alongside a learned model instead of using it only after generation. In image generation, SPRING embeds spatial reasoning directly into a deep generator so outputs obey constraints and work on new, unseen data. In scientific discovery, reasoning shrinks the space of possible equations for symbolic regression and PDE learning to explore. In satisfiable modulo counting (a problem type combining logical rules with counting), reasoning over XOR constraints (parity rules) improves the guarantees a solver can provide.

Key Claims

  • Automated reasoning and machine learning are complementary tools in AI.
  • Spatial reasoning can be woven directly into a generative network.
  • Reasoning steps can improve constraint satisfaction and interpretability.
  • Vertical reasoning can speed up finding mathematical equations from data and discovering physical equations.
  • Organizing XOR constraints can improve satisfiable modulo counting.
  • The larger goal is autonomous agents that combine learning and reasoning instead of picking one.

Important Terms

Vertical Reasoning

A reasoning layer placed inside a learning or generation process to enforce structure and guide the search for solutions.

SPRING

Spatial Reasoning INtegrated Generator; a generator with a spatial reasoning module built inside it.

Symbolic Regression

Searching over mathematical expressions to discover equations that fit data.

Satisfiable Modulo Counting

A problem type that combines logical constraints with counting or probability reasoning.

XOR Constraints

Logical parity (odd-even) rules that can organize and speed up solver search.

Connections Across The Series

  • This talk connects directly to the first-principles reasoning and scientific discovery themes throughout the seminar.
  • It complements talks on finding mathematical equations from data, discovering physical equations, and generation with constraints.
  • It also ties to modern agent design: learned models need explicit reasoning and verification steps when constraints matter.

Practical Caution

Embedding reasoning can improve reliability, but only when constraints are stated correctly. Missing or incorrect constraints can make the system confidently solve the wrong problem.

Takeaway

The core lesson is that reasoning acts as an internal support structure for learning, generation, and discovery when a task has explicit structure to exploit.
