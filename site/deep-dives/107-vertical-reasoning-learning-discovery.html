Talk 107 · Purdue University

Yexiang Xue: Vertical Reasoning Enhanced Learning, Generation and Scientific Discovery

This lecture argues that embedding explicit reasoning modules inside learning systems can improve generation, symbolic regression, PDE discovery, and counting problems.

YouTube source · Talk page

Core Problem

Machine learning is strong at pattern fitting, while automated reasoning is strong at satisfying explicit constraints. Autonomous scientific agents need both, but integrating reasoning and learning remains difficult.

First-Principles Model

Vertical reasoning means putting a structured reasoning process inside or alongside a learned model rather than using it only after generation. In image generation, SPRING embeds spatial reasoning inside a deep generator so outputs satisfy constraints and transfer zero-shot. In scientific discovery, reasoning narrows the search space for symbolic regression and PDE learning. In satisfiable modulo counting, reasoning over XOR constraints improves solver guarantees.

Key Claims

  • Automated reasoning and machine learning are complementary pillars of AI.
  • Spatial reasoning can be integrated directly into a generative network.
  • Reasoning modules can improve constraint satisfaction and interpretability.
  • Vertical reasoning can accelerate symbolic regression and PDE discovery.
  • Streamlining XOR constraints can improve satisfiable modulo counting.
  • The broader goal is autonomous agents that integrate learning and reasoning rather than choosing one.

Important Terms

Vertical Reasoning

A reasoning layer embedded into a learning or generation pipeline to enforce structure and guide search.

SPRING

Spatial Reasoning INtegrated Generator, a generator with an embedded spatial reasoning module.

Symbolic Regression

Searching over mathematical expressions to discover equations from data.

Satisfiable Modulo Counting

A problem class combining logical constraints with counting or probabilistic reasoning.

XOR Constraints

Logical parity constraints that can structure and accelerate solver search.

Connections Across The Series

  • This talk connects directly to the first-principles reasoning and scientific discovery themes from the broader study system.
  • It complements symbolic regression, PDE discovery, and constrained generation lectures.
  • It also links to modern agent design: learned policies need explicit reasoning and verification when constraints matter.

Practical Caution

Embedding reasoning can improve reliability, but only for constraints that are correctly formalized. Missing or wrong constraints can make the system confidently satisfy the wrong problem.

Takeaway

The first-principles lesson is that reasoning can act as an internal scaffold for learning, generation, and discovery when the task has explicit structure.
