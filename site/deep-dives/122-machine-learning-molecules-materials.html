Talk 122 · University of Amsterdam

Max Welling: Machine Learning for Molecules and Materials

This whole series is about getting computers to predict how physical things behave by learning from data instead of only using hand-built math. This talk zooms into molecules and materials: how to teach a learning program (millions of little dials tuned by trial and error) to predict the energy stored in an arrangement of atoms, the forces pushing them apart or together, and what happens when you heat or squeeze a solid—and why doing this well means baking in physics rules that the program must follow.

YouTube source · Talk page

Core Problem

Figuring out how atoms and molecules interact, and how materials behave at large scales, is essential for designing new chemicals and materials. Physicists have written down rules for this (called differential equations or wave equations—rules that say how things change from moment to moment or place to place), but solving these rules for real molecules is so slow and expensive that scientists can't test many designs. Generic learning programs (with millions of dials) work well for pictures and text, but they often ignore the hidden patterns: that certain rules never change no matter how you rotate the molecule, and that energy is conserved—meaning it can't appear from nowhere. When a program ignores these truths, it makes bad guesses on new molecules it hasn't trained on.

First-Principles Model

The solution is to build a learning program that is forced to respect these physical truths from the start. You teach the program to predict the energy stored in an atom arrangement and the forces on each atom by showing it examples from expensive but accurate quantum calculations. You also tell the program 'this energy value must look the same if you rotate the molecule' and 'forces must always follow from energy in a specific way'—mathematical rules derived from physics. Once trained, the program runs in milliseconds instead of hours. In other areas like density-functional theory (a shortcut method physicists use: instead of tracking every electron's full wave-like nature, just track the total electron density at each point), machine learning can speed up the slowest step. The same goes for differential-equation models that predict large-scale behavior: you can train a learning program to copy the expensive calculations, but only if you make sure it respects the physical structure—the fact that flows conserve mass, heat spreads from hot to cold, and so on.

Key Claims

  • Machine learning has become a major way to solve real problems in natural sciences, not just images and language.
  • Training programs on molecular and materials data has produced tools that scientists actually use.
  • Learned force fields—programs that predict atomic forces from positions—are now fast enough to drive large simulations, replacing expensive quantum calculations.
  • Methods like density-functional theory and differential-equation solvers can be sped up by teaching programs to imitate their slow but accurate predictions, if you constrain the program to preserve the physics.
  • The best machine-learning tools for science come from combining what mathematicians, physicists, and neuroscientists have learned about building smarter programs.
  • Solving big challenges like climate change, materials design, and drug discovery will probably need machine learning that respects physical laws, not generic learning.

Important Terms

ML Force Field

A learned program that takes the positions of atoms and predicts how much energy the arrangement has, and how hard each atom is pushed by the others. It replaces slow quantum-mechanical calculations, letting scientists simulate molecular motion thousands of times faster.

Density Functional Theory

A shortcut for studying materials with many electrons: instead of tracking the quantum wave-nature of every single electron, just track the total electron density (how crowded electrons are) at each point in space. Much faster than full quantum calculations, still reasonably accurate.

Molecular Simulation

A program that steps forward in tiny time increments, calculating forces on atoms and nudging them, to show how a molecule will bend, vibrate, or react. Like a video of atoms playing out the laws of physics.

Materials Discovery

The process of hunting for new materials with useful properties by running calculations and experiments: instead of randomly guessing, machine learning can help predict which materials to try.

Physical Inductive Bias

Built-in rules that steer a learning program toward answers that obey physics. For example: 'this quantity must never change,' 'the answer looks the same if you rotate the input,' or 'forces follow from energy in this specific mathematical way.' These are guardrails, not frozen assumptions.

Connections Across The Series

  • This talk sits alongside courses on foundation models trained on science data, geometric deep learning (training programs that respect shapes and symmetries), and physics-aware learning architectures—all part of the shift where machine learning enters science.
  • It builds on earlier talks about molecules, differential equations, and neural operators by showing them as tools inside this bigger picture: learning programs that can approximate what expensive calculations give.
  • It also connects to talks on data quality and scientific datasets, because a learning program is only as good as the examples it trains on—garbage in, garbage out.

Practical Caution

A learned program that predicts molecular energy can score very high on test cases pulled from the same data it trained on, but fail badly on new molecules, new chemical bonds, or new temperature ranges it has never seen. Building in physical constraints helps, but you must check: Does the program still fail on chemistry slightly different from training? Does it accidentally violate a conservation law in some corner case? A program that 'memorized' patterns instead of truly learning the physics is dangerous in science.

Takeaway

When computers learn to predict science, they work best when the learning is not a blank slate. Steer the program by baking in the geometry and laws of the real system. A program that is forced to respect symmetries and conservation will generalize to new situations much better than one left to find any pattern that fits the data.
