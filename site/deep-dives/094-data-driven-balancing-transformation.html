Talk 94 · University of Michigan

Elnaz Rezaian: Data-Driven Balancing Transformation For Predictive Model Order Reduction

This lecture covers balanced truncation and data-driven methods for building small models from big systems for control, focusing on error bounds and the challenges when you have many inputs and outputs.

YouTube source · Talk page

Core Problem

Small predictive models can run fast but often break in real engineering if they miss how inputs connect to outputs or don't guarantee how wrong they are. Balanced truncation gives you mathematical promises about accuracy, but computing it directly or from data can be slow when your system has many inputs and outputs.

First-Principles Model

Balanced truncation finds states that are reachable (the system can get there from inputs) and observable (you can see them in the outputs), then deletes states that barely affect input-output behavior. Data-driven versions like ERA build small models by measuring how the system responds to impulses. The result is a model tuned for control goals and comes with mathematical error bounds, but making it scale up needs techniques like tangential interpolation (asking the system about specially chosen directions), output decomposition (breaking the outputs into smaller pieces), and gappy POD-style approximations (filling in missing data).

Key Claims

  • Balanced truncation grows from control theory and is built specifically for steering systems.
  • Data-driven balancing uses measured Gramians (matrices that capture reachability and observability from data) and minimum realization theory (finding the smallest model that matches the input-output measurements).
  • Mathematical error bounds let balanced models work reliably for actual predictions.
  • The eigensystem realization algorithm is a direct data-driven approach to balanced truncation.
  • ERA predicts well on stiff fast-burning chemical flows and sound-driven systems.
  • Many input-output channels mean more computation, so you need tangential interpolation, output decomposition, and gappy POD.

Important Terms

Balanced Truncation

A model reduction method that deletes states with low combined reachability (how far the system can be steered from inputs) and observability (how much they show up in outputs).

System Gramian

A matrix that measures how reachable or observable a dynamical system is based on its structure and properties.

Eigensystem Realization Algorithm

A data-driven method that builds a small state-space model by analyzing how the system responds to impulse inputs.

Markov Parameter

A number in the sequence of impulse-response values used to reconstruct what a system does.

Gappy POD

A method to reconstruct fields from partial or scattered measurements using basis vectors derived from proper orthogonal decomposition.

Connections Across The Series

  • This lecture adds a control-theory perspective on small models to the broader model reduction sequence.
  • It connects to predictive models, reverse engineering, and digital twins because error bounds are needed before you can trust the model in real use.
  • It also builds on CUR and adaptive ROM talks by emphasizing input-output balancing instead of only compressing which states matter.

Practical Caution

A small model can still predict badly if it removes states that matter for outputs or for steering the system. Reduction should focus on the input-output task you actually care about, not just which states have the most energy.

Takeaway

The core lesson is that small predictive models should keep track of what the system can be pushed toward and what you can see, not just what vibrates the loudest.
