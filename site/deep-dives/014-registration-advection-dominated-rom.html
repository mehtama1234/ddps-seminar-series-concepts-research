Tommaso Taddei: Registration-Based Model Reduction Of Parameterized Advection-Dominated PDEs

This lecture presents registration as a way to align moving features in advection-dominated PDEs so that a linear reduced model becomes effective in transformed coordinates.

YouTube source · Talk page

Core Problem

Advection-dominated problems often contain parameter-dependent moving discontinuities, fronts, or shocks. In raw coordinates, these features make the solution manifold poorly approximated by a low-dimensional linear subspace. Standard projection ROMs then need too many modes or fail to preserve sharp features.

First-Principles Model

Registration introduces a mapping from the physical domain to a reference domain that aligns local solution features across parameter values. Once transported features are aligned, the transformed snapshots can become more linearly compressible. A reduced model can then combine registration, projection, and hyper-reduction to produce faster approximations.

Key Claims

  • Parameterized advection-dominated PDEs are difficult for model reduction because moving features are not well represented by fixed linear spaces.
  • Registration aligns local features in a reference configuration to improve compressibility of the solution manifold.
  • The method is intended to be largely equation-independent, focusing on geometric alignment before reduced modeling.
  • Registration can be paired with projection-based and multifidelity reduced modeling.
  • Hyper-reduced least-squares Petrov-Galerkin ingredients are part of the proposed workflow.

Important Terms

Registration

A procedure that finds transformations aligning solution features across samples or parameter values.

Reference Domain

A common coordinate frame where transported or moving features are aligned before approximation.

Advection-Dominated PDE

A PDE where transport of features dominates the behavior and often creates moving fronts or discontinuities.

Linear Compressibility

How well a family of solutions can be represented by a low-dimensional linear space.

Multifidelity ROM

A reduced modeling approach that combines data or models of different accuracy and cost.
