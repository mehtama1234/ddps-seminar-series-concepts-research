Talk 38 · University of California, Santa Barbara

Igor Mezic: Koopman Operator Theory For Dynamical Systems, Control And Data Analytics

This lecture explains Koopman operator theory as a way to represent nonlinear dynamics through a linear operator acting on observables.

YouTube source · Talk page

Core Problem

Nonlinear dynamical systems are difficult to analyze, reduce, and control because the state evolution is nonlinear. Koopman theory changes the viewpoint: instead of evolving states directly, evolve functions of the state. The operator becomes linear, but infinite-dimensional, so the challenge is finding useful observables and spectral decompositions.

First-Principles Model

An observable is a function of the system state. The Koopman operator advances observables forward in time by composition with the nonlinear flow. Its eigenfunctions evolve by simple exponential factors, so if useful eigenfunctions are found, nonlinear dynamics can be represented in linear coordinates. Numerical methods such as DMD approximate parts of this operator from data.

Key Claims

  • Koopman theory reformulates dynamical systems in terms of evolving observables.
  • The Koopman operator is linear even when the original system is nonlinear.
  • Eigenfunctions give coordinates whose evolution is governed by linear equations.
  • Koopman decompositions are orthogonal in time rather than necessarily in space.
  • DMD is one numerical route for approximating Koopman spectra and modes.
  • POD can confuse dynamics when coherent Koopman structure has not been extracted.

Important Terms

Koopman Operator

A linear operator that advances observables of a dynamical system by composing them with the system flow.

Observable

A function of the state whose evolution can be studied instead of the state itself.

Koopman Eigenfunction

An observable that evolves by multiplication with an exponential factor under the Koopman operator.

DMD

Dynamic Mode Decomposition, a data-driven method often used to approximate Koopman modes and eigenvalues.

Coherent Dynamics

Persistent dynamical structures whose time behavior can be captured by spectral components.

Connections Across The Series

  • This talk links equation discovery, Green's functions, and ROMs through operator-theoretic structure.
  • It connects to control because linear representations of nonlinear dynamics can simplify feedback and prediction.
  • It also offers a conceptual alternative to POD-based reduction: choose coordinates by dynamics, not only variance.

Practical Caution

Koopman methods depend heavily on the choice or discovery of observables. A finite-dimensional approximation can look linear and still miss important dynamics if the observable space is wrong.

Takeaway

The first-principles lesson is that nonlinear dynamics may become linear in the right observable space. Koopman theory is a search for that space.
