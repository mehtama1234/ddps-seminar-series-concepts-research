Talk 38 · University of California, Santa Barbara

Igor Mezic: Koopman Operator Theory For Dynamical Systems, Control And Data Analytics

Koopman operator theory describes nonlinear dynamics through a linear operator that acts on functions of the state.

YouTube source · Talk page

Core Problem

Nonlinear dynamical systems are hard to analyze, reduce, and control because the state changes in a nonlinear way. Koopman theory shifts the view: instead of tracking how the state itself changes, track how functions of the state change. The operator becomes linear, but infinite-dimensional, so the real challenge is finding useful functions and understanding the operator's spectral structure.

First-Principles Model

An observable is a function of the system state. The Koopman operator moves observables forward in time by composing them with the nonlinear flow. Its eigenfunctions evolve by multiplying with simple exponential factors, so if you find useful eigenfunctions, nonlinear dynamics can be written in linear form. Numerical methods like DMD approximate parts of this operator from data.

Key Claims

  • Koopman theory reformulates dynamical systems by evolving functions of the state instead of the state itself.
  • The Koopman operator is linear even when the original system is nonlinear.
  • Eigenfunctions give coordinates whose evolution is governed by linear equations.
  • Koopman decompositions are orthogonal in time rather than necessarily in space.
  • DMD is one numerical method for approximating Koopman spectra and modes.
  • POD can miss important dynamics when coherent Koopman structure has not been extracted.

Important Terms

Koopman Operator

A linear operator that moves observables forward in time by composing them with the system flow.

Observable

A function of the state whose evolution can be studied instead of the state itself.

Koopman Eigenfunction

An observable that evolves by multiplying with an exponential factor under the Koopman operator.

DMD

Dynamic Mode Decomposition, a data-driven method for approximating Koopman modes and eigenvalues.

Coherent Dynamics

Persistent dynamical structures whose time behavior can be captured by spectral components.

Connections Across The Series

  • This talk links equation discovery, Green's functions, and reduced-order models through the structure of the Koopman operator.
  • It connects to control because linear representations of nonlinear dynamics simplify feedback and prediction.
  • It offers a different approach to reduction than POD: choose coordinates based on dynamics, not only on variance.

Practical Caution

Koopman methods depend heavily on which functions you choose or discover. A finite-dimensional approximation can look linear but still miss important dynamics if the observable space is not right.

Takeaway

The lesson is that nonlinear dynamics may become linear in the right space of functions. Koopman theory is a search for that space.
