Talk 137 · Texas A&M University

Ulisses M. Braga-Neto: Scientific Machine Learning: From Physics-Informed to Data-Driven

This lecture reviews scientific machine learning as a spectrum from physics-informed collocation methods to data-driven operator learning.

YouTube source · Talk page

Core Problem

SciML combines scientific computation and machine learning, but different methods use physics and data in very different ways. Practitioners need to understand the tradeoff between enforcing known differential equations and learning directly from solution data when equations are unknown, incomplete, or expensive to use.

First-Principles Model

Physics-informed methods such as PINNs and physics-informed Gaussian processes enforce differential equations at collocation points. Data-driven operator learning instead learns the map associated with a parametric differential equation, often without explicit equation knowledge. The slogan is that the physics may be embedded in the data rather than written in the loss. The lecture compares these regimes and discusses applications including plasma turbulence.

Key Claims

  • SciML brings together scientific computation and machine learning.
  • PINNs and PIGPs made SciML widely known through physics-informed collocation.
  • Operator learning is a more recent data-driven SciML paradigm.
  • Operator learning often does not require knowledge of the underlying differential equations.
  • The physics-informed and data-driven approaches have different advantages and disadvantages.
  • The Hasegawa-Wakatani model of plasma turbulence is one application setting.

Important Terms

Scientific Machine Learning

Machine learning methods designed for scientific computation, simulation, discovery, and inverse problems.

PINN

A physics-informed neural network that enforces differential-equation residuals during training.

Physics-Informed Gaussian Process

A Gaussian process model incorporating physical equation constraints.

Operator Learning

Learning maps between functions, such as PDE input-to-solution operators.

Collocation

Enforcing an equation or constraint at selected points in the domain.

Connections Across The Series

  • This lecture synthesizes many earlier talks: PINNs, neural operators, data-driven PDEs, and scientific surrogates.
  • It connects to the first-principles theme by clarifying where physics enters the model.
  • It also links to data-progress discussions because data-driven SciML moves physical structure into the dataset.

Practical Caution

The slogan 'physics is in the data' is only true if the data cover the relevant regimes and preserve the physics. Otherwise data-driven operator learning can extrapolate poorly.

Takeaway

The first-principles lesson is that SciML methods differ mainly in where they put physics: in the equations, in the architecture, or in the data.
