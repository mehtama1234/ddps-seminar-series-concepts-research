Talk 23 · University of Notre Dame

Matthew Zahr: Model Reduction Of PDEs Via Optimization-Based Feature Tracking

This lecture explains how optimization-based feature tracking deforms the computational domain so shocks and discontinuities align before model reduction.

YouTube source · Talk page

Core Problem

Convection-dominated PDEs with shocks and discontinuities are hard for standard ROMs because moving features create high-rank snapshot sets. If the basis is fixed while shocks move, many modes are required and reduced solutions may smear or oscillate.

First-Principles Model

Instead of approximating moving discontinuities in fixed coordinates, feature tracking moves the mesh or domain so discontinuities align in a reference configuration. The method formulates shock tracking as an optimization problem over both the DG solution and mesh coordinates. In the reduced setting, it simultaneously optimizes reduced state coordinates and reduced mesh deformation coordinates.

Key Claims

  • Shock tracking can be formulated as an optimization problem over solution and mesh coordinates.
  • High-order DG properties such as consistency, conservation, and accuracy are preserved by embedding DG equations as constraints.
  • Domain deformation aligns discontinuities across snapshots to improve compression.
  • The reduced problem optimizes over both the ROM state and the mesh deformation.
  • Boundary-preserving maps are needed so mesh motion does not destroy the physical domain.
  • Feature tracking allows linear-subspace tools such as SVD to remain useful for convection-dominated problems.

Important Terms

Feature Tracking

Moving the mesh or coordinate system so important solution features such as shocks remain aligned.

Implicit Shock Tracking

An optimization-based method that locates shocks through the solution and mesh solve rather than explicit front construction.

Domain Deformation

A transformation of the computational domain used to align moving features.

Reduced Mesh Coordinates

Low-dimensional variables controlling mesh deformation in a reduced model.

Boundary-Preserving Map

A mapping that moves interior mesh points while keeping domain boundaries valid.

Connections Across The Series

  • This talk is the optimization-based counterpart to registration-based ROMs: both reduce transport by aligning features.
  • It connects to entropy-stable schemes because shock handling is not only a learning problem but a discretization and geometry problem.
  • It also connects to nonlinear manifold ROMs because domain deformation creates a nonlinear representation while keeping linear tools useful.

Practical Caution

Tracking features adds its own optimization and mesh-validity problems. A bad deformation map can preserve low rank while damaging boundaries, conservation, or solver robustness.

Takeaway

The first-principles lesson is that for shocks, model reduction can start by making the coordinate system follow the physics before compressing the state.
