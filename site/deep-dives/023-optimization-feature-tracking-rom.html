Talk 23 · University of Notre Dame

Matthew Zahr: Model Reduction Of PDEs Via Optimization-Based Feature Tracking

This lecture explains how optimization-based feature tracking warps the computational mesh so shocks and discontinuities align before compressing the model.

YouTube source · Talk page

Core Problem

Convection-dominated PDEs with shocks and discontinuities are difficult for standard ROMs (reduced-order models—mathematical approximations that capture the most important behavior) because moving features force the snapshot set (the collection of solution states at different times) to have high rank. When the basis stays fixed while shocks move, many modes are needed and reduced solutions may blur or oscillate instead of staying sharp.

First-Principles Model

Instead of approximating moving discontinuities in fixed coordinates, feature tracking warps the mesh or domain so discontinuities line up in a reference configuration. The method writes shock tracking as an optimization problem over both the DG (discontinuous Galerkin, a high-order numerical method) solution and mesh coordinates. In the reduced setting, it optimizes reduced state coordinates and reduced mesh deformation coordinates at the same time.

Key Claims

  • Shock tracking can be written as an optimization problem over solution and mesh coordinates.
  • High-order DG properties like consistency, conservation, and accuracy are kept when DG equations appear as constraints.
  • Domain warping lines up discontinuities across snapshots to improve compression.
  • The reduced problem optimizes both the ROM state and the mesh deformation.
  • Boundary-preserving maps are needed so mesh motion does not harm the physical domain.
  • Feature tracking lets simple linear-subspace tools like SVD stay useful for convection-dominated problems.

Important Terms

Feature Tracking

Warping the mesh or coordinate system so important solution features like shocks line up across time steps.

Implicit Shock Tracking

An optimization-based method that finds shocks through the solution and mesh solve rather than building the shock front by hand.

Domain Deformation

A change to the computational domain shape used to line up moving features.

Reduced Mesh Coordinates

Low-dimensional variables that control mesh deformation in a reduced model.

Boundary-Preserving Map

A transformation that moves interior mesh points while keeping the domain edges valid.

Connections Across The Series

  • This talk is the optimization-based version of registration-based ROMs: both reduce transport by lining up features.
  • It ties to entropy-stable schemes because shock handling is not just a learning problem but also a discretization and geometry problem.
  • It also connects to nonlinear manifold ROMs because domain deformation creates a nonlinear representation while keeping simple linear tools useful.

Practical Caution

Tracking features adds its own optimization cost and mesh-validity challenges. A poor deformation map can keep rank small while harming boundaries, conservation of physical quantities, or solver stability.

Takeaway

The core lesson is that for shocks, model reduction can start by letting the coordinate system move with the physics before compressing the state.
