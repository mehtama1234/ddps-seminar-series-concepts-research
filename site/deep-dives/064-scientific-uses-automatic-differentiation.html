Talk 64 · Harvard University / Google Research

Michael Brenner: Scientific Uses Of Automatic Differentiation

This lecture argues that the biggest scientific opportunity from the machine learning revolution isn't ML itself, but automatic differentiation plus large-scale optimization—a new way to formulate and solve scientific problems.

YouTube source · Talk page

Core Problem

Many scientific problems hide inside optimization: solve a PDE (partial differential equation, which describes how things change in space and time), design a material with the right properties, find an unstable flow state (a water or gas flow that doesn't stay put), tune a kinetic pathway (the sequence of steps a molecule takes during assembly), infer developmental rules (how organisms grow), or design a nonequilibrium protocol (driving a system far from balance to achieve something). Traditionally, each domain needs hand-derived gradients (how to calculate the direction to change inputs for a better result), specialized adjoints (customized tricks for computing gradients backward), or brute-force search. That limits the size and flexibility of the problems scientists can attack.

First-Principles Model

Automatic differentiation turns a computation into a differentiable object (something you can take gradients of). If a simulator, loss function (a number measuring how far you are from a goal), or scientific protocol is written as a differentiable program, gradients can be propagated through it and used for large-scale optimization. This makes optimization a general scientific language: propose an objective, encode the physical computation, differentiate it, and search for designs, hidden states, or governing structures.

Key Claims

  • The tools underlying machine learning, especially automatic differentiation, can be more scientifically important than the ML models themselves.
  • Automatic differentiation enables large-scale optimization for scientific discovery.
  • Automatic differentiation can support new algorithms for solving PDEs.
  • The same approach can design energy landscapes and kinetic pathways for self-assembly.
  • Optimization can discover unstable solutions that organize fluid instabilities.
  • Automatic differentiation-based scientific computation can extend to organismal development, nonequilibrium statistical mechanics, fluid rheology, and protein self-assembly.

Important Terms

Automatic Differentiation

A computational technique that exactly differentiates programs by applying the chain rule (a calculus rule for derivatives of composite functions) through their operations.

Large-Scale Optimization

Solving optimization problems with many variables, often made possible by efficient gradient computation (calculating the direction and slope to move toward a better solution).

Energy Landscape

A function describing the energy of a system across all possible configurations, shaping which states are stable and how transitions between them happen.

Kinetic Pathway

A sequence of dynamical states through which a system evolves, such as the steps a cluster of molecules takes during assembly.

Unstable Solution

A mathematically valid state or trajectory that is not stable under small disturbances but can still organize nearby dynamics.

Connections Across The Series

  • This lecture is a conceptual foundation for differentiable programming, embedded closure learning, DPC, and inverse design talks.
  • It reframes machine learning infrastructure as scientific infrastructure: differentiability makes scientific workflows optimizable.
  • It also connects to equation discovery and digital twins because differentiable programs can search over mechanisms and designs.

Practical Caution

Differentiating a computation does not guarantee the objective is scientifically meaningful or numerically stable. Automatic differentiation gives you gradients; scientists still need valid models, constraints, and real-world validation.

Takeaway

The first-principles lesson is that differentiability changes what can be optimized. Automatic differentiation turns scientific computation into a design and discovery engine.
