# Extraction Rubric

This project starts with a broad summit playlist, so the first pass should be conservative:

- Keep transcript-derived claims tied to local source files.
- Treat title/keyword concept matches as review anchors, not final interpretation.
- Prefer first-principles explanations of deployment, hardware, data, safety, economics, and physical AI loops.
- Distinguish demo capability from deployable capability.
- Deepen individual talks manually before treating them as polished lecture notes.
